深读｜WiTac

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 在电池插入、USB 重插等接触密集任务中，相似的指尖形变可能对应不同的手—物体—目标几何关系，因而需要完全不同的纠偏动作；仅靠局部触觉无法消除这种空间歧义。
  • GR00T N1.7、π0.5 等 VLA 虽然已接收腕部图像，但其视觉流与触觉通常在进入策略前没有深度融合；将独立触觉 token 直接附加给策略，可能使触觉脱离周边几何语境，甚至误导精细操作。
  • 本文面向双臂十指灵巧手的真机闭环操作：先离线预训练接触编码器，部署到下游 VLA 时冻结该编码器，仅训练接触注入接口及动作专家，并保留 VLA 原有的视觉、语言和机器人状态输入。
  • 作者目标是学习可跨 VLA 骨干复用、同时保留触觉细节与腕部空间上下文的接触表征，从而提高接触密集操作的闭环成功率。

方法

  • 输入与时空编码：在 30 Hz 的时刻 $t$，模型输入十指八帧触觉历史 $\mathcal T_t$、65D 关节状态 $s_t$、腕坐标系指尖位姿 $p_t$ 及双腕 RGB 图像 $I_t$。触觉经 SharpaWave 空间编码器、因果时序卷积与 FiLM 位姿调制，图像则由冻结的 DINOv3 ViT-B/16 提取腕部特征。
  • 状态条件接触令牌：两层 8 头、宽度 768 的 Transformer 融合触觉、状态和运动学特征，并以状态条件触觉历史查询腕部视觉特征；交叉注意力最终生成十个接触令牌 $C_t\in\mathbb R^{10\times768}$，分别承载各手指的接触与形变信息。
  • 多任务接触预训练：仅预训练阶段使用的解码头从共享 $C_t$ 监督接触状态、形变变化与指尖运动历史；Masked Visual Recovery 在手—物区域遮蔽 50% patch，恢复归一化 DINOv3 特征；另一分支结合动作条件预测力/力矩响应。总目标为加权和 $\mathcal L=\sum_j\lambda_j\mathcal L_j$，部署时全部解码头移除。
  • 策略注入：下游阶段冻结接触编码器，将 $C_t$ 作为条件送入动作专家；策略特征通过门控交叉注意力读取接触令牌，以可学习门控控制触觉信息注入强度，再输出机器人动作，从而避免预训练辅助任务直接增加推理开销。

  • 整体流程为：十指最近触觉历史、机器人状态和腕坐标系下的指尖位姿先形成状态条件化触觉 token；token 再查询双腕图像 patch 特征，输出每根手指一个接触 token；冻结后的这些 token 通过门控交叉注意力注入 VLA 动作专家。
  • 每帧触觉形变图先由从 SharpaWave Deform Encoder 初始化的空间骨干编码，再由因果时间编码器压缩历史；腕坐标系下的指尖位姿经过 Fourier 编码，并通过 FiLM 将运动学信息锚定到各手指特征，机器人当前状态也被投影后加入。
  • 双腕图像由冻结的 DINOv3 ViT-B/16 提取 patch 特征，并加入相机身份和二维 patch 坐标嵌入。两层融合 Transformer 依次执行手指间自注意力、触觉 token 对腕部特征的交叉注意力和前馈变换，得到腕部语境化的十个接触 token。
  • 预训练包含五项自监督目标：当前接触描述符重建、历史触觉形变重建、腕坐标系指尖运动历史重建、掩码腕部视觉特征恢复，以及给定未来动作前缀的指尖力/力矩变化预测；训练不使用任务成功标签，预测头在下游策略推理时移除。
  • 注入 VLA 时，选定动作模块以自身隐状态为 query、WiTac token 为 key/value。共享门控预测器根据有效接触 token 为每个注入层产生范围为 [0.05, 1] 的标量门，策略训练同时优化原有 flow-matching 动作损失和基于触觉活跃像素比例生成的接触门监督。
  • 相对视觉基线，本文没有替换 VLA 原有视觉、语言和状态通道，而是外挂接触条件接口；相对 WiTac-NW，唯一核心变化是加入腕部交叉注意力和掩码视觉恢复，因此可较直接检验腕部条件化本身的作用。

实验与结果

  • 四项真机任务的平均闭环成功率上，GR00T N1.7 从视觉基线的 37.5% 提升至 66.3%，增加 28.8 个百分点；相比 WiTac-NW 的 47.5% 增加 18.8 个百分点，并高于 FTP-1 的 40.0%、T-Rex 的 50.0% 和同样在 SharpaDex v1.0 上预训练的 VT-MUSE joint repr. 的 50.0%。
  • 在 π0.5 上，平均成功率由视觉基线的 43.8% 提升至 58.8%，增加 15.0 个百分点；相比 WiTac-NW 的 51.3% 增加 7.5 个百分点。WiTac 在四项任务上均优于对应的 π0.5 基线和 WiTac-NW。
  • USB 重插最能体现“触觉需要视觉落地”：在 GR00T 上，视觉基线成功率为 10%，加入不含腕部条件的 WiTac-NW 后降至 5%，而完整 WiTac 达到 40%。这说明独立触觉并非必然有益，缺少腕部几何语境时可能产生错误纠偏。
  • GR00T + WiTac 在电池插入、碗内擦拭、USB 重插、开柜门上的成功率分别为 55%、80%、40% 和 90%；π0.5 + WiTac 对应为 70%、75%、20% 和 70%。
  • 对接触阶段单独统计时，GR00T、GR00T + WiTac-NW、GR00T + WiTac 的电池错位失败次数分别为 7、4、1 次；USB 拔出阶段成功率分别为 50%、60%、95%，每项均基于 20 次试验。
  • 原文摘要还报告腕部条件化带来更准确的接触描述、更强的任务—接触联合判别、更低的触觉噪声特征漂移和更清晰的动作方向读出；但所提供正文在表示分析章节开头截断，未包含这些离线指标的具体数值，不能进一步量化。

局限与可以继续做的

  • 证据集中在 Sharpa North 双臂十指平台和四项任务上。虽然任务未出现在预训练数据中，但相同机器人形态、触觉传感器和腕部相机配置下的迁移，尚不能证明其可直接泛化到其他灵巧手、平行夹爪或不同触觉模态。
  • 每种方法每项任务仅评测 20 次，成功率以 5 个百分点为最小分辨率；文中未在已提供部分给出置信区间或多随机种子结果，因此 π0.5 上相对 WiTac-NW 的单任务 5–10 个百分点增益仍需更大样本验证。
  • 腕部视觉可能受遮挡、运动模糊、相机外参漂移或照明变化影响；现有结果主要分析触觉噪声，尚未披露腕部相机退化、单腕缺失和视觉—触觉时间不同步下的鲁棒性。
  • WiTac 依赖近 300 小时、包含同步触觉、双腕图像、机器人状态、指尖运动学及力/力矩的数据。可进一步做分规模预训练和目标消融，分别测量掩码视觉恢复、动作条件力响应预测及历史重建带来的收益与数据成本。
  • 可在 OpenPI 中实现相同的门控交叉注意力接口，并比较三种条件方式：独立触觉 token、预融合 WiTac token、原始触觉与腕部 patch 联合在线融合；同时记录接触阶段成功率、动作方向误差、门值变化和触觉扰动恢复时间，而不只看整段任务成功率。
  • 所提供原文在第 4.3 节开头截断，未包含完整消融表、附录超参数及作者明确列出的局限；因此无法核对不同预训练目标、注入层选择和门控监督的具体消融数字。
实验设置
  • 平台：Sharpa North 真机，配备两只 Sharpa Wave 灵巧手和双腕相机。
  • 动作空间：65 维关节命令，包括每条手臂 7 维、每只手 22 维、头颈 2 维和下肢 5 维。
  • 任务：电池插入、碗内擦拭、USB 拔出后重插、钥匙开柜门，均为双臂接触密集任务，且均不包含在 SharpaDex v1.0 预训练数据中。
  • 下游数据：每个任务通过外骨骼遥操作采集 200 条示范。
  • 评测协议：每种方法在每项任务上执行 20 次闭环真机试验；平均成功率是四项任务成功率的非加权平均。
  • VLA 骨干：GR00T N1.7 和 π0.5；WiTac 在下游策略训练期间冻结，接触接口与动作专家联合优化。
  • 对照：原始视觉 VLA、WiTac-NW；GR00T 还对比 VT-MUSE joint repr.、FTP-1 和 T-Rex。
  • 预训练数据：SharpaDex v1.0，近 300 小时同步灵巧操作数据；包含触觉、腕部图像、机器人状态和指尖力/力矩记录，不使用任务成功标签。
  • 触觉输入：十根手指各自的 240×240 标量形变图，使用包含当前帧在内的 8 帧历史。
  • 接触表示：每根手指一个 768 维 token，整体形状为 10×768；每帧触觉先编码为 512 维特征。
  • 视觉骨干：冻结的 DINOv3 ViT-B/16；两路腕部 patch 特征拼接，并加入相机身份与二维位置嵌入。
  • 融合模块：两层 Transformer，每层包含手指自注意力、对腕部特征的交叉注意力及前馈网络。
  • 门控范围：有效触觉存在时，每个注入动作模块的接触残差门值限制在 [0.05, 1]。
  • 表示分析指标：接触重建误差、任务—接触联合 macro-F1、触觉噪声下的特征/动作稳定性，以及动作方向余弦对齐。
  • 时间偏移、未来预测跨度、各预训练损失权重、门控损失权重和具体注入层位于原文附录；提供的论文片段未披露其数值。
AI导读和推荐理由
  • 这篇论文的价值不只是“给 VLA 增加触觉”，而是用受控对照显示：未经空间语境落地的触觉可能降低成功率，真正关键的是在动作生成前将局部接触与腕部观察到的手—物体—目标几何关系融合。
  • 同一冻结接触编码器可复用于 GR00T N1.7 与 π0.5，并在两者上均取得提升，说明其更接近可外挂的接触表征层，而不是只针对单一策略架构定制的完整新 VLA。

与π系列的关系

  • 本文明确以 π0.5 作为两个下游 VLA 骨干之一，并将冻结的 WiTac token 通过新增的门控交叉注意力注入其动作专家；π0.5 原有视觉、语言和机器人状态输入仍被保留。
  • WiTac 不是 π0.5 的新预训练版本，也没有修改其基础视觉语言输入机制；新增部分主要是外部预训练接触编码器、策略侧投影与注入层，以及接触门监督。下游训练时冻结的是 WiTac，原文明确优化接触接口和动作专家，但所提供片段没有说明 π0.5 其他全部参数是否冻结。
  • 在 π0.5 上，WiTac 将四任务平均成功率从 43.8% 提升到 58.8%；相同编码器去掉腕部条件后为 51.3%，说明 π0.5 已有腕部视觉输入并不能自动替代“视觉—触觉在策略注入前融合”。
  • 所提供原文没有报告 π0、π0-FAST 或 OpenPI 的实验，也没有与这些变体进行直接对比；因此不能据此断言 WiTac 对不同动作分词、动作分块或 OpenPI 实现具有相同收益。

对Austin研究的启发

  • 可在 OpenPI 动作专家的若干 Transformer block 中加入共享的 contact adapter：输入固定数量的每指 token，以动作隐状态查询这些 token，并保留原有图像、语言和本体状态路径，从而避免为了触觉重训整个视觉语言骨干。
  • 将门值作为可观测的运行时信号：在触觉活跃比例、动作方向突变或视觉—触觉不一致时记录各层门值，检查模型是否在接触阶段提高触觉依赖，并把“高门值但无接触”“持续接触但低门值”设为故障监控事件。
  • 设计三组闭环对照：视觉基线、独立触觉注入、腕部条件化触觉注入；除整任务成功率外，单独标注对准、插入、拔出和脱离接触阶段。本文 USB 结果表明，阶段级指标能暴露“总体看似增加模态、局部却被误导”的问题。
  • 对引导场 G 或动作条件模块，可把接触 token 作为局部约束而非直接拼接到全局语义 token：测试其是否能更准确地区分“相似触觉、不同纠偏方向”，并以预测动作与真实纠偏方向的余弦对齐作为离线预筛指标。
  • 加入触觉噪声、单腕遮挡、相机外参扰动和跨模态延迟四类压力测试，同时测量成功率、动作漂移和接触后恢复时间，以验证收益是否来自稳定的多模态互补，而非特定相机视角或同步条件。

一句话总结

Sharpa Robotics、北京大学、上海交通大学、上海科技大学和香港中文大学的作者提出 WiTac，以腕部视觉预融合十指触觉和运动学后再门控注入 VLA，使 GR00T N1.7 与 π0.5 的四任务真机平均成功率分别由 37.5% 提升至 66.3%、由 43.8% 提升至 58.8%。
