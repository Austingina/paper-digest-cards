深读｜Memory before Goal

问题

  • 动态场景下的非马尔可夫性痛点：现有全身 VLA（如 $\pi_{0.5}$, GR00T）仅依赖当前观测，在人形机器人转身或行走导致目标物体离开视野、或被遮挡时，无法利用“动作前”的历史线索（Pre-History Memory），导致决策失败。
  • 现有记忆机制的局限：桌面机械臂常用的长帧历史成本高且稀释关键信息；固定间隔采样易错过短暂线索；压缩方法丢失细节。人形机器人因自身运动导致视角剧烈变化，对因果性、自适应的关键帧选择提出了更高要求。
  • 基准缺失：缺乏专门针对“全身移动操作 + 记忆依赖”的基准测试，现有基准要么目标始终可见，要么仅针对固定基座机械臂。
  • 作者目标：提出一种基于物体事件驱动的感知记忆机制，使策略能根据“过去发生了什么”而非仅“现在看到什么”来执行全身动作，并在仿真与真机上验证其有效性。

方法

  • 整体架构 (WholeBodyMem)：在现有全身 VLA（如 $\Psi_0$）基础上外挂一个对象引导的感知记忆模块。输入为当前图像、本体状态和指令；输出为全身动作。核心在于引入记忆帧集合 $\mathbf{M}_t$ 和物体 Token $\mathbf{O}_t$。
  • 基于 SAM3 的对象追踪与事件检测：使用冻结的 SAM3 模型根据文本提示（如“blue cup”）追踪任务对象。通过计算去除相机运动后的物体位移、掩码重叠率等指标，定义“出现、消失、重现、移动、形变”为关键事件。
  • 因果自适应记忆选择 (Causal Selection)：不保留所有帧，而是根据事件评分动态填充内存预算（$B_{max}=7$ 帧）。始终保留首、中、当前帧，剩余槽位由高分事件帧填充，且跳过冗余帧（同一物体在短窗口内已有记录则跳过），确保因果性（仅使用 $t$ 之前的帧）。
  • 动作专家中的交叉注意力读取：记忆以原生 Backbone Token 形式存储（保留细节），通过正弦位置编码注入时间/空间信息。动作专家（Action Expert）的 Action Tokens 通过 Cross-Attention 读取记忆 Token，并通过 FiLM 调制层影响最终动作生成，无需修改骨干网络权重。

实验与结果

  • 仿真基准 (HuMeGo) 显著提升：在包含计数、永久性、参考等6类记忆任务的仿真环境中，WholeBodyMem 将基线策略 $\Psi_0$（无记忆）的平均成功率从 29.1% 提升至 72.6%。
  • 真机 Unitree G1 验证：在6个真实世界任务中（如咖啡座送饮料、转身取物等），成功率从基线的 36.7% 大幅跃升至 88.3%，证明了该方法在真实动态场景中的鲁棒性。
  • 标准基准 (SIMPLE) 的泛化增益：即使在不需要复杂记忆的标准全身操作任务（14个 SIMPLE 任务）上，引入固定7帧记忆的 WholeBodyMem 也将成功率从基线的 70.2% 提升至 86.9%，表明历史上下文对常规操作也有辅助作用。
  • 消融对比：相比“均匀采样记忆”（Uniform Memory），基于事件的自适应选择在 FlashPad（计数）和 BlinkPad（短暂线索）等任务上表现出显著优势（例如 FlashPad 成功率从 Uniform 的 ~70% 提升至 ~90%+，具体见 Table III 决策准确率差异），证明“保留正确的帧比保留更多的帧”更重要。

局限与可以继续做的

  • 依赖 SAM3 追踪质量：方法强依赖于 SAM3 对任务对象的准确分割与追踪。若物体被严重遮挡或外观剧烈变化导致 ID Switch，事件检测将失效。
  • 提示词工程依赖：虽然提示词由 LLM (Claude Opus) 生成并固定，但针对不同场景仍需人工定义“什么是任务对象”，缺乏全自动的开放世界目标发现机制。
  • 计算开销未详细披露：SAM3 逐帧推理（50Hz）及记忆 Token 的 Cross-Attention 增加了推理延迟，论文未给出实时性对比数据，可能在高速动态场景中受限。
  • 可跟进方向：
  • 探索轻量级追踪器替代 SAM3 以降低延迟。
  • 研究端到端学习“什么值得记忆”，而非依赖预定义的事件规则（如位移阈值）。
  • 将记忆机制与 π0.5 的 System 2 (VLM Planner) 结合，让高层规划也能访问历史关键帧。
实验设置
  • 平台：仿真使用 MuJoCo (物理) + Isaac Sim (渲染)；真机使用 Unitree G1 人形机器人。
  • 基线策略：主要基于 $\Psi_0$ (WholeBodyVLA) 进行微调对比，同时对比了 $\pi_{0.5}$, GR00T, ACT, DP 等在 SIMPLE 基准上的表现。
  • 数据集：
  • HuMeGo Benchmark：6个仿真任务（FlashPad, HideMug, ShellGame, LitLamp, BlinkPad, TouchPad）+ 6个真机任务。
  • 数据规模：每个仿真任务 100 条演示，90 个测试场景；真机通过遥操作采集。
  • 模型配置：
  • 追踪器：Frozen SAM3 (Segment Anything Model 3)。
  • 骨干网：Vision-Language Backbone + Flow-matching Action Expert (6层 DiT blocks)。
  • 记忆预算：$B_{max}=7$ 帧，每帧保留 77 个原生 Token。
  • 评测协议：SIMPLE 任务分为 L0/L1/L2 三个随机化等级，每级 10 episodes；HuMeGo 任务每级 30 episodes。
AI导读和推荐理由

与 π 系列（π0 / π0-FAST / π0.5 / OpenPI）的关系与启发

  • 互补而非替代：本文未直接修改 $\pi_{0.5}$ 或 $\pi_0$ 的骨干权重，而是作为一种“外挂记忆模块”集成到 VLA 架构中。这与 π0.5 强调的 System 1 (Fast) + System 2 (Slow/Reasoning) 分层架构有异曲同工之妙，但本文更侧重于感知层面的历史回溯，而非推理层面的逻辑规划。
  • 对 OpenPI 执行器的启示：OpenPI 目前主要关注动作执行的流畅性与泛化性。本文指出，在移动操作（Loco-manipulation）中，单纯的动作平滑不足以解决“目标丢失”问题。对于基于 π0/π0.5 开发的全身机器人应用，若涉及转身、遮挡等场景，必须引入类似 WholeBodyMem 的因果记忆机制，否则策略会因非马尔可夫性而崩溃。
  • 数据层面的借鉴：HuMeGo 基准提供了高质量的“记忆依赖”演示数据（Cue-Retention-Decision 结构），这对训练具备长程时序理解能力的 VLA 模型极具价值，可作为 π 系列后续版本在动态场景微调的重要补充数据集。

对 Austin 研究的启发

  • 解决“抓了但送错”的失败模式：Austin 研究中常见的失败是机器人抓取物体后，因转身导致目标位置线索丢失，最终放置错误。借鉴本文思路，可在 Austin 的策略中增加一个轻量级的关键帧缓存模块：在检测到“目标物体被遮挡”或“机器人开始转身”时，强制保存当前视觉特征向量，并在决策阶段通过 Cross-Attention 重新注入，而非仅依赖当前观测。
  • 事件驱动的监控机制：利用 SAM3 或类似分割模型实时监控任务对象的状态变化（如消失、移动），将其作为触发“记忆写入”的信号。这比固定频率采样更高效，能显著降低计算负载并提高关键信息的保留率。
  • 评测协议升级：在 Austin 的内部评测中，应增加“转身遮挡”、“物体短暂出现后隐藏”等非马尔可夫测试用例，以验证策略是否真正具备记忆能力，而不仅仅是拟合了静态场景下的操作分布。

一句话总结

MBZUAI 提出 WholeBodyMem，利用 SAM3 追踪物体事件并自适应选择关键历史帧注入 VLA 动作专家，在仿真和 Unitree G1 真机上将全身移动操作成功率分别提升至 72.6% 和 88.3%，有效解决了动态场景下的非马尔可夫决策难题。
