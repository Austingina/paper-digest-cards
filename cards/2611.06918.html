深读｜From Pixels to Actions - Towards Native Vision-Language-Action Policies

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 现有 VLA 通常先用 CLIP、SigLIP 或 DINOv2 等独立视觉编码器把图像压缩为最终特征，再由语言骨干和动作模块推理；这种固定接口隐藏了视觉层级中的中间计算。
  • 机器人操作依赖局部几何、物体边界、深度和细微状态变化，而这些信号可能在视觉抽象过程中被削弱；仅让动作头读取最终视觉端点，可能限制精细控制和分布外鲁棒性。
  • 论文研究的核心变量不是离散动作与连续动作之争，而是动作专家应读取视觉计算的哪个深度，以及移除独立视觉编码器后是否仍能形成有效、可迁移的控制表征。
  • 作者目标是构建从像素和语言直接进入共享骨干、可读取不同视觉层级的原生 VLA，并验证这种接口在冻结骨干、全量微调和分布偏移下是否优于编码器式结构。

方法

  • 输入与关节检查（Joint Checks）：原始多源机器人轨迹由关节读数 $q_t\in\mathbb{R}^{J}$、动作 $a_t$、传感通道及相机数据组成。图中首先按数据源执行关节合法性检验，识别超出物理范围、突变或不可能的 $q_t$，仅剔除对应关节样本，而非整段轨迹。
  • 通道与动作过滤（Channel/Action Filtering）：对各观测通道 $x_t^{(c)}$ 检测缺失、失真或不可靠信号，并依据动作分布识别离群值，例如偏离有效域 $\mathcal{A}$ 的 $a_t$。过滤粒度保持局部化，只移除受影响的通道或时间步。
  • 回合完整性与相机标定（Episode/Calibration Checks）：进一步检查回合 $\tau=\{(x_t,a_t)\}_{t=1}^{T}$ 是否损坏，并利用相机内参 $K$、外参 $[R\mid t]$ 的投影关系 $\tilde p\sim K[R\mid t]P$ 验证标定与投影一致性；投影检查同样针对具体数据源配置。
  • 最终语料保留（Final Corpus Pass）：各项质量标记汇入最终语料扫描阶段，由该阶段统一决定回合保留状态 $r_\tau\in\{0,1\}$。整体原则是“最小影响删除”：局部异常不自动导致整回合丢弃，只有最终扫描认定不可用的损坏回合才被排除，输出清洗后的训练语料。

  • 整体流程为：多视角历史/当前图像、相机几何、语言指令和机器人状态组成多模态前缀，经共享视觉—语言骨干处理；独立的窄型动作专家读取指定骨干层的 KV cache，并通过流匹配生成连续动作块。
  • NEO-VLA 不使用独立预训练视觉编码器、图像码本或自编码器。原始图像由两阶段轻量卷积 patch embedder 直接映射到骨干 token 空间，图像 patch 与语言 token 在整个骨干中共同演化。
  • 骨干采用模态感知注意力：文本 token 使用因果注意力，同一视觉块内的视觉 token 双向交互；Native RoPE 将位置分解为时间、高度和宽度坐标，保留图像的二维空间结构。
  • 动作专家通过 layer map 指定每一层读取哪个骨干层，可选择早期层、跨深度均匀采样、晚期层或全部层。前三种配置保持 28 层专家及隐藏宽度一致，以尽量隔离“读取深度”这一变量；全层配置因专家更深而单独视为高容量设置。
  • 专家将多模态前缀与带噪动作 token、流时间及 step/frame/identity embedding 联合处理，预测覆盖双臂和身体动作块的连续速度场；推理时积分该速度场得到动作轨迹。
  • 相对编码器式对照，论文主要改变视觉接口及动作专家能够访问的视觉层级；动作专家设计和机器人训练语料保持一致。全量微调时动作损失同时更新骨干与专家，冻结实验则只训练专家和条件模块。

实验与结果

  • 在冻结骨干的受控层级实验中，包含早期层的 readout 持续优于仅读取晚期表示的配置；全量微调后，联合早期和晚期特征的配置表现最好。所给原文未包含对应成功率或差值，无法核对具体数值。
  • attachment-point 干预显示，在不同观测之间交换早期层激活会造成比扰动晚期层更大的动作预测误差，支持“动作关键信号往往在最终视觉表示之前达到峰值”的结论；原文片段同样未给出误差绝对值。
  • 使用相同动作专家和机器人训练语料时，NEO-VLA 在 LIBERO 上优于编码器式 Qwen3-VL-2B 与 Gemma-3-4B，对冻结骨干设置的优势尤其明显；全量微调缩小但没有消除差距。由于提供内容未包含结果表，不能报告成功率及提升百分点。
  • 在 LIBERO、LIBERO-plus 和 RoboTwin 2.0 上，论文报告 NEO-VLA 在标准操作任务及视觉外观、语言和环境分布偏移下具有更强、更稳定的控制，摄像机扰动和图像噪声下的增益尤其突出；具体分任务数字未出现在所给正文中。
  • 论文还报告单纯增加模型规模不能恢复编码器式结构与原生结构之间的差距，但作者明确指出，不同骨干的预训练数据和模型容量并不完全匹配，因此不能把全部收益严格归因于“移除视觉编码器”。

局限与可以继续做的

  • 提供的正文在训练细节处截断，未包含主要结果表、逐任务成功率、评测 episode 数、随机种子、置信区间和失败案例；因此现有材料只能核对定性排序，不能判断增益大小及统计稳定性。
  • NEO-VLA、Qwen3-VL-2B 与 Gemma-3-4B 的预训练过程和容量存在差异。尽管动作专家和机器人语料相同，这仍不是只改变视觉编码器接口的完全等参、等预训练受控实验。
  • full-40 同时增加了可读取的骨干层数和动作专家深度，不能把其结果纯粹解释为多层视觉访问的收益；可补充固定专家参数量的全层融合、层选择门控和等 FLOPs 对照。
  • 当前证据集中在 LIBERO、LIBERO-plus 和 RoboTwin 2.0。可以进一步在真机闭环任务中分别施加相机位姿漂移、遮挡、光照变化和接触状态变化，并记录成功率、恢复能力、控制延迟与动作抖动，验证层级访问是否真正改善部署鲁棒性。
  • 可将每层干预扩展为在线诊断：监控动作对各深度 KV 的敏感度、跨视角一致性和状态变化响应，在检测到早层异常或相机噪声时动态调整读取层权重，而不是使用固定 layer map。
实验设置
  • 视觉—语言骨干：无独立视觉编码器的 40 层、约 2B 参数 backbone；其视觉—语言预训练采用图文预训练、中期多模态对齐和监督指令微调三个阶段。
  • 图像接口：两阶段卷积 patch embedder，总 stride 为 32，每个视觉 token 对应 \(32\times32\) 图像区域；每个视角最多使用 88 个视觉 token，并在固定预算下保留原始宽高比。
  • 输入：上一时刻与当前时刻的多视角图像，每个时间块最多三个相机视角；另含相机身份、内参与旋转、结构化控制提示，以及 Arm 0、Arm 1 和共享 body 的历史/当前状态 token。
  • 动作空间：双臂动作块形状为 \(2\times30\times26\)，共享身体动作块为 \(30\times8\)；每条轨迹预测 30 个时间步。
  • layer map：first-28 读取第 0–27 层；skip-28 从全部 40 层近似均匀采样 28 层；end-28 读取第 12–39 层；full-40 读取全部 40 层并配套 40 层动作专家。
  • 流匹配：\(\tau=0.999u\)，其中 \(u\sim\mathrm{Beta}(1,1.5)\)；训练目标预测动作与高斯噪声之差。末端运动与夹爪、机械臂关节、手部关节、身体动作四组损失权重为 \(2:1:1:1\)。
  • 推理：固定多模态前缀 KV cache，以 10 个 Euler 步从 \(\tau=0\) 积分到 1；不使用 classifier-free guidance。
  • 机器人预训练语料：9 个公开数据家族，共 2,231,583 episodes、928.40M rows、7,444 views；论文表中可统计部分合计 9,927.7 小时，覆盖 2,704 个场景。
  • 数据来源包括 AgiBot-World、Bimanual YAM、RoboCOIN、Open X-Embodiment、Galaxea Open-World、RoboMIND、RH20T、DROID 和仿真 InternData-A1。
  • 训练阶段 1：冻结视觉—语言骨干，只训练动作专家和条件模块；113,400 个优化步，全局 batch size 8192，峰值学习率 \(2\times10^{-4}\)。
  • 训练阶段 2：解冻全模型，在相同机器人语料上继续 75,000 步，全局 batch size 8192；动作专家和条件模块峰值学习率为 \(2\times10^{-4}\)，视觉—语言参数为 \(5\times10^{-5}\)，并混入多模态理解数据。
  • 评测基准包括 LIBERO、LIBERO-plus 和 RoboTwin 2.0；编码器式骨干对照为 Qwen3-VL-2B 与 Gemma-3-4B。所给片段未披露评测 episode 数、随机种子、硬件、控制频率及完整后续训练阶段。
AI导读和推荐理由
  • 推荐这篇的主要原因是它把 VLA 的研究重点从“换动作解码器”推进到“动作模块能访问哪些视觉计算阶段”：论文证据表明，最终视觉表示未必是控制所需信息的最佳端点。
  • 它对 OpenPI 类系统的直接价值不是提供可替换检查点，而是给出一个可验证的架构假设：精细几何和短时状态变化可能应通过中间层 KV 接口显式暴露给动作专家。

与π系列的关系

  • 所给原文没有声明 NEO-VLA 基于 π0、π0-FAST、π0.5 或 OpenPI，也没有报告与这些模型或检查点的直接实验对比，因此不能把它视为 π 系列的改版或性能替代。
  • 两者在连续动作建模上存在概念交集：NEO-VLA 采用独立流匹配动作专家和 action chunk，但其主要创新位于视觉侧——移除固定的独立视觉编码器，并允许动作专家读取多个骨干深度。
  • 论文没有修改或讨论 OpenPI 的执行器接口、π0-FAST 的动作表示、π0.5 的开放世界训练机制，也未涉及 G/A-F 条件接口或组合数据留出。
  • 对 π 系列最值得借鉴的是 layer-map 实验范式：在保持动作专家容量和机器人数据尽量一致时，分别读取早层、晚层与跨层特征，以判断性能瓶颈究竟来自动作生成器，还是来自固定视觉端点。
  • 关系强度应评为弱到中等：NEO-VLA 提供的是视觉层级访问的架构对照，而非 π 系列内部的直接改进证据。

对Austin研究的启发

  • 在 OpenPI 执行器前增加统一的多层 KV adapter，先冻结 backbone，仅训练 adapter 与动作头；比较 early-only、late-only、uniform-skip 和 early+late 四种读取策略，并严格固定专家参数量。
  • 为引导场 \(G\) 的条件遵循设计分层探针：分别测量各层对目标身份、局部几何、接触前状态变化和相机扰动的敏感度，避免只用最终层 embedding 判断条件是否被遵循。
  • 增加闭环层干预评测：交换相邻观测的早层或晚层表示，记录动作误差之外的任务成功率、恢复时间、碰撞率和末端轨迹偏差，以检验离线敏感度是否对应真实控制因果性。
  • 在真机监控中记录动作头对各层 KV 的梯度或注意力贡献；若早层贡献在模糊、遮挡或相机漂移时异常下降，可触发减速、重观测或安全停止。
  • 数据设计上应加入只改变局部边界、深度、物体状态或相机位姿的成对样本，使“早层保留精细信号”能够通过反事实对照验证，而不是仅由总体成功率间接推断。

一句话总结

NEO-VLA 以 40 层、约 2B 参数的原生视觉—语言骨干和跨层流匹配动作专家直接连接像素到 30 步连续动作，并在 LIBERO、LIBERO-plus 与 RoboTwin 2.0 上定性优于编码器式对照，但所给原文未披露可核对的成功率数字及作者机构。
