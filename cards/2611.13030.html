深读｜APS-VLA

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • VLA 策略在机器人运动过程中需要反复处理多相机产生的数百个视觉 token；即使下一步动作只依赖局部区域，稠密视觉序列仍会带来较高推理延迟。
  • 现有剪枝方法多依赖静态空间冗余、即时指令相关性、注意力或近期运动等在线启发式信号，未必能保留抓取接触、避障间隙及任务阶段切换所需的动态视觉线索。
  • 端到端微调完整 VLA 虽可让策略适应压缩后的输入，但训练与显存成本较高，也会改变原策略；本文研究的是冻结预训练 VLA、保持原生动作生成流程不变的外挂式压缩设定。
  • 作者目标是利用机器人示范中的动作及其后续视觉变化，学习一个跨 VLA 架构、固定 token 预算且部署开销较低的视觉选择器，在尽量维持任务成功率的同时降低闭环控制中的单步策略延迟。

方法

  • 视觉选择（Visual Selector）：输入当前多视角观测 $o_t=\{o_t^c\}_{c=1}^{C}$，经冻结编码器 $E_\omega$ 与投影器 $P_\omega$ 得到 $X_t^c$、$Z_t^c$；$S_\theta(Z_t,\ell,p_t)$ 按视角打分，在总预算 $K=128/512$ 下保留关键 token，淡化区域表示被丢弃 patch。
  • 动作监督（Action Supervision）：筛选后的共享视觉表示 $\widetilde X_t$ 连同指令 $\ell$、本体状态 $p_t$ 输入冻结 VLA 策略 $F_\omega$，对齐示范中的末端平移命令 $(\Delta x,\Delta y,\Delta z)$ 与夹爪命令 Grip.；底部阴影标出连续八步动作窗口。
  • 动作条件视觉转移监督（Action-conditioned Visual Transition）：训练期预测器 $H_\phi$ 以当前选定视觉上下文和八步示范动作为条件，预测 $t+8$ 的观测目标；中部每对图像分别对应外部相机与裁剪后的腕部视角，以未来真实帧计算 $\mathcal L_{\mathrm{pred}}$。
  • 联合训练与部署：仅更新选择器 $S_\theta$ 和预测器 $H_\phi$，冻结主干参数 $\omega$，总目标为 $\mathcal L=\mathcal L_{\mathrm{act}}+\lambda\mathcal L_{\mathrm{pred}}$。部署时移除未来目标与 $H_\phi$，仅执行一次硬选择和 token 打包，再由原生 VLA 生成动作。

  • 整体流程为：冻结视觉编码器与 VLA 策略，从当前多视角图像提取视觉 token；Decision Influence Estimator（DIE）结合局部 patch、全局视觉上下文、语言指令和归一化本体状态进行评分；训练时以可微门控构造稀疏表示，部署时改为每个视角一次 Top-K 硬选择并打包，再交给原策略生成动作。
  • 动作监督同时约束剪枝后的策略输出接近两类目标：完整视觉输入下冻结策略的输出，以及示范中的真实动作 chunk。随机动作生成时，完整输入与门控输入分支共享采样噪声。
  • 未来感知监督使用“所选当前视觉表示＋示范动作序列”预测后续观测的特征摘要。目标特征来自未来图像，经每视角 \(2\times2\) 网格池化、固定高斯投影至每格 64 维及非仿射层归一化得到；预测器仅有两层，并在部署时移除。
  • DIE 为每个 token 融合相机与 patch 位置嵌入，并通过各视角 token 的均值、最大值汇总视觉条件；语言条件来自冻结骨干的词嵌入，本体条件由独立 MLP 编码。输入到选择器的视觉、语言与本体特征均被 detach，梯度只更新选择模块。
  • 可微选择采用满足每视角固定预算的 Laplace-CDF 门控，阈值由预算约束求解，训练期间逐步退火温度；门控视觉特征与冻结的黑图参考特征混合，使动作损失和未来预测损失能共同训练同一组 token 分数。
  • 部署端只保留 DIE、Top-K 与打包接口：保留 token 恢复为原相机及 patch 顺序，位置标识、注意力掩码和动作输出索引按骨干规则同步调整；策略参数、语言与本体输入、动作头及原生动作生成过程均不改变。

实验与结果

  • 在 LIBERO 上，OpenVLA-OFT 未剪枝基线平均成功率为 97.00%，延迟为 107.95 ms。APS-VLA 剪除 75% token、保留 128/512 个 token 时，平均成功率为 95.75%，仅下降 1.25 个百分点；延迟降至 68.75 ms，对应 \(1.57\times\) 加速。
  • LIBERO 的速度—精度曲线显示：剪除 50% 时成功率为 96.58%、延迟 81.39 ms、加速 \(1.33\times\)；剪除 87.5% 时成功率为 93.92%、延迟 66.21 ms、加速 \(1.63\times\)。从 75% 增至 87.5% 剪枝只额外减少 2.54 ms，却再损失 1.83 个百分点，说明 75% 是文中更平衡的工作点。
  • 在 75% 剪枝下，LIBERO 四套件成功率分别为 Spatial 96.33%、Object 97.67%、Goal 96.00%、Long 93.00%；相较未剪枝基线的 98.00%、99.00%、97.00%、94.00%，各套件均有小幅下降，而非所有任务都无损。
  • 摘要报告 APS-VLA 在 RoboCasa365 上使用 \(\pi_{0.5}\) 与 XR-1，整体推理加速为 \(1.46\times\)；但所提供正文截断于 LIBERO 结果，未给出对应 token 预算、各模型成功率、延迟或分项表格，无法进一步核对。
  • 摘要还报告五项真实机器人任务、两种双臂平台上的平均推理延迟由 137.25 ms 降至 93.25 ms，即 \(1.47\times\) 加速；平均成功率为 61%，未剪枝基线为 60%。原文节选未披露各任务成功次数、方差或统计显著性，因此 1 个百分点的差异不应直接解释为剪枝提高了策略能力。

局限与可以继续做的

  • 证据完整性有限：所给正文只完整展示了 LIBERO 表格，RoboCasa365 和真机实验仅能依据摘要中的汇总数字，无法核对任务构成、剪枝率、试验轮数、硬件配置及逐任务表现。
  • LIBERO 表 1 明确说明 APS-VLA 与未剪枝 OFT 在 development panel 上评测，而其他方法的时间包含估计值和归一化参考值；因此横向方法排名未必来自完全一致的硬件与计时协议，最可靠的结论是本文内部的剪枝前后比较。
  • 方法学习的是固定的每视角预算，不能根据遮挡、接触阶段或场景复杂度动态增加 token；可以进一步测试“总预算固定、跨相机动态分配”以及按置信度自适应预算，并监控腕部视角是否在精细操作阶段获得更多 token。
  • 未来预测目标是后续视觉特征摘要，而不是显式几何、接触状态或任务完成度；可加入深度、光流、接触事件或关键点预测，比较这些目标能否减少 Long 类任务中的成功率损失。
  • 真实任务平均成功率仅比基线高 1 个百分点。后续应增加每任务试验次数、报告置信区间，并单独统计由剪枝导致的漏检、抓取偏移、碰撞和任务阶段切换失败，而不是只看平均成功率。
  • 可在未见任务、相机布局变化、动态干扰物和不同 token 预算下测试选择器迁移；同时测量 DIE、Top-K、打包、视觉编码和动作生成各自耗时，以确认加速是否能在不同加速器与 batch size 下保持。
实验设置
  • 仿真平台：LIBERO 和 RoboCasa365；真实实验覆盖五项任务及两种双臂机器人平台，所给节选未列出平台型号、相机规格和任务名称。
  • LIBERO 骨干：OpenVLA-OFT 7B，采用并行动作解码；输入来自两个相机视角，共 512 个视觉 token。
  • LIBERO 剪枝配置：剪除 50%、75% 和 87.5%，分别保留 256、128 和 64 个 token；四个任务套件为 Spatial、Object、Goal 和 Long。
  • RoboCasa365 骨干：\(\pi_{0.5}\) 与 XR-1，覆盖流匹配策略；所给节选未披露具体检查点、token 数及剪枝比例。
  • 模型状态：VLA 视觉编码器、投影器和动作生成策略冻结；训练 DIE、条件编码模块及辅助未来预测头；未来预测头不参与部署。
  • 默认训练配置：AdamW，学习率 \(10^{-4}\)，batch size 8，训练 5,000 次更新。
  • 默认未来预测跨度：\(h=8\)；辅助预测损失权重 \(\lambda=0.1\)。
  • 动作损失取原生策略输出中的前 \(h\) 步物理动作维度，并同时匹配完整输入策略输出和归一化示范动作。
  • 固定预算按视角分别约束；训练使用 Laplace-CDF 可微门控及温度退火，部署使用逐视角 Top-K 硬选择。
  • 延迟统计包含视觉编码、token 选择与打包、语言骨干计算及动作预测；LIBERO 加速由采样调用测得，并在四个套件上取平均。
  • LIBERO 中 APS-VLA 与未剪枝 OpenVLA-OFT 使用 development panel；所给节选未说明每项任务的 episode 数、随机种子、推理硬件和方差。
AI导读和推荐理由
  • 推荐这篇的核心原因不是它提出了新的 VLA 骨干，而是它把机器人示范轨迹转化为“哪些视觉 token 会影响动作与后续状态”的监督信号，可作为现有大模型策略的推理加速外挂。
  • 它同时覆盖并行动作预测和流匹配策略，并将训练期未来预测与部署期执行解耦；这对希望保留已有策略能力、又不愿重新微调整个骨干的系统更实用。

与π系列的关系

  • 本文在 RoboCasa365 上直接以 \(\pi_{0.5}\) 作为冻结骨干之一，保持其参数和原生动作生成流程不变；APS-VLA 只在视觉 token 进入策略前增加 DIE 评分、Top-K 选择与序列打包，因此不是新的 π 系列模型。
  • 对 \(\pi_{0.5}\) 的改动集中在视觉前缀接口：视觉 token 数量与对应的索引、掩码需要随打包结果调整，但流匹配动作头及其生成机制没有被替换。
  • 摘要给出 RoboCasa365 上 \(1.46\times\) 推理加速，但当前节选未提供 \(\pi_{0.5}\) 单独的成功率、延迟、剪枝预算或消融结果，不能判断该数字是否由 \(\pi_{0.5}\)、XR-1 分别取得，或是跨设置汇总。
  • 原文节选没有报告在 \(\pi_0\)、\(\pi_0\)-FAST 或 OpenPI 上的实验，也没有证据表明本文代码继承 OpenPI、针对 FAST 离散动作 token 做了专门适配，或与 π 系列团队存在直接合作。
  • 方法原则上位于动作生成器之前，因而具有接入不同 π 变体的可能性；但不同变体的视觉前缀布局、位置编码、KV cache 和动作采样机制是否兼容，仍需逐一验证，不能由 \(\pi_{0.5}\) 结果直接外推。

对Austin研究的启发

  • 在 OpenPI 执行器前增加统一的 visual_token_selector 接口，输入当前多相机 token、语言嵌入和本体状态，输出紧凑 token、原 patch 索引、相机标识、位置 ID 与 attention mask；先冻结策略，只训练选择器，隔离压缩对动作生成器的影响。
  • 为 π 策略建立三档闭环评测：未剪枝、固定比例剪枝、置信度自适应剪枝；除成功率与端到端延迟外，记录每个控制周期的选择器开销、各相机保留比例、动作分布偏移及流匹配轨迹偏差。
  • 若已有引导场 \(G\) 或条件遵循指标，可把它作为额外监督或安全监控：检查被保留 token 是否覆盖 \(G\) 指向的目标、接触区和通行区域；当覆盖不足或动作偏差超过阈值时，回退到完整视觉输入。
  • 复现时先采用文中的 \(h=8\)、双目标动作监督和未来特征预测，再做三项关键消融：仅稠密策略蒸馏、仅示范动作监督、两者加未来预测，以判断未来感知信号是否真正改善长时程任务，而非只增加训练约束。
  • 在 OpenPI 上应重点测试相机预算分配：固定每视角 Top-K 可能在接触操作中浪费外部视角 token，建议比较均匀预算、腕部优先预算和跨视角全局 Top-K，并按抓取前、接触、搬运、放置阶段分别报告失败率。
  • 真机安全评测应增加可观测回退机制：连续若干步 token 集中度异常、关键区域长期未被选中或动作输出相对完整输入分支显著漂移时，自动关闭剪枝；这比只汇报平均成功率更适合长期闭环运行。

一句话总结

APS-VLA 由同济大学、利兹大学、A*STAR 与伦敦布鲁内尔大学作者提出，以动作监督和动作条件未来视觉预测训练冻结 VLA 外部的 token 选择器，在 LIBERO 保留 128/512 token 时取得 \(1.57\times\) 加速与 95.75% 成功率，并在五项真实任务中将平均延迟从 137.25 ms 降至 93.25 ms、成功率为 61%。
