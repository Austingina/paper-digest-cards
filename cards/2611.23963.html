深读｜CoRA-VTLA

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • 预训练 VLA 主要依赖视觉、语言与本体状态；在精密插接等任务中，零件看似对齐却可能已经卡住，视觉难以区分自由运动、持续阻塞和重新接触，微小误差还可能造成卡死、变形或安全终止。
  • 单帧触觉存在时序歧义：相似的瞬时压力或腕部载荷，既可能对应正在建立接触，也可能对应持续卡住；正确恢复需要结合“执行了什么动作、接触随后如何变化”。
  • 直接把触觉 token 融入 VLA 并不充分：论文观察到其可能分散动作专家的视觉注意力，使模型减少对指尖接触区域的关注。
  • 论文研究闭环触觉后训练：以预训练 π0.5 为骨干，在仿真和真机上执行“预测动作块、只执行第一条命令、随后重规划”；骨干并未冻结，而是在联合后训练阶段与新增触觉模块一起更新。
  • 作者目标是以轻量触觉模块提升预训练 VLA 对接触变化的判断与阻塞恢复能力，同时保持对具体接触位置的视觉 grounding。

方法

  • 多模态输入与接触编码：在时刻 $t$，系统接收 RGB 图像、语言指令、机器人状态 $s_t$、近期运动历史、指尖压力图 $p_t$ 及腕部力/力矩 $f_t$。Contact Encoder（接触编码器）联合提取当前载荷，得到 $c_t=E_c([p_t;f_t])$，再经投影 $P_c$ 生成接触 token $C$：$z_t^c=P_c(c_t)$。
  • 动作–响应记忆模块：Action–Response Memory 保存已执行动作后的响应 $r_i=[\Delta p_i;\Delta f_i;f_i-f_0]$；其中差分描述瞬时载荷变化，$f_i-f_0$ 保留持续受力。Memory Encoder 从近期窗口检索交互历史并形成记忆 token $M$，用于区分外力阻塞与接触稳定等瞬时读数相似的状态。
  • VLM 前缀与动作专家后缀：语义 token $S$ 加入 VLM prefix，与视觉–语言特征融合，并通过 contact-guided gaze supervision 对齐对应图像区域；$C$ 与 $M$ 加入 Action Expert suffix，联合机器人状态和历史预测 action chunk。策略仅执行首个指令，随后重新观测并滚动规划。
  • 两阶段训练流程：Stage I 以 Response Prediction 预训练并初始化 Contact Encoder 与 Memory Encoder；Stage II 进行联合后训练，同时施加 action、semantic 和 gaze supervision，使动作生成、触觉语义表征及接触引导的视觉注意协同优化。

CoRA-VTLA architecture and training. (a) A semantic token $S$ joins the VLM prefix. The contact and memory tokens $C$ and $M$ join the action-expert suffix. (b) Response prediction initializes the contact and memory encoders, followed by joint post-training with action, semantic, and gaze supervision.
  • 整体流程为：RGB、语言、机器人状态与历史进入原 π0.5 上下文；当前指尖压力和六轴腕力/力矩被编码为接触 token；近期动作后的载荷变化写入动作—响应记忆并按当前接触与机器人状态检索；动作专家据此生成下一段动作，执行首条命令后闭环重规划。
  • 当前接触编码器 \(E_c\) 联合处理双指压力图和腕部 wrench，使单侧受力与平衡受力即使总压力相近，也能形成不同表示；投影后的接触 token 被放在 π0.5 动作专家后缀的噪声动作 token 之前。
  • 动作—响应记忆将每个事件表示为压力变化、腕部 wrench 的逐步变化及相对 episode 初始值的 wrench；时序 Transformer 编码近期事件，查询则由当前接触特征和机器人状态共同生成，从历史中选择与下一步纠正最相关的响应。
  • VLM 前缀额外接收触觉语义 token。该 token 汇总近期绝对压力与腕部读数，并通过三个头预测“是否接触、是否稳定、载荷是否变化”；对应词嵌入的加权平均提供语义锚点，残差投影保留三类标签之外的信息。
  • 接触引导注视监督把活跃指尖单元投影到主相机的 ViT patch 网格，在 VLM 倒数第二层约束触觉语义 token 分配给接触区域的注意力质量不低于阈值；达到阈值后损失为零，因此仍允许 token 关注夹具开口等邻近几何。
  • 训练分两阶段：先在同一批任务示范上，用“当前触觉 token、记忆 token、机器人状态和示范动作”预测下一步实际运动、压力变化与 wrench 变化，只初始化两个动作侧触觉编码器；随后丢弃预测头，以动作流匹配损失、触觉语义分类损失和注视损失联合后训练 π0.5 与全部新增模块。
  • 相比 Direct，CoRA-VTLA 没有增加新的传感器输入，而是把单个当前触觉 token 改为“当前接触 + 可查询响应记忆”，并增加 VLM 侧语义 token 与空间注视监督；它不是冻结 π0.5 的外挂推理器。

实验与结果

  • 三个 MuJoCo 任务共 150 次测试中，CoRA-VTLA 成功 110 次，平均成功率为 73.33%；Base π0.5、Direct 和适配后的 FTP-π0.5 分别为 31.33%、50.00% 和 44.00%。
  • 分任务结果为：CoRA-VTLA 在 Nail、Plug、Knob 上分别达到 78%、76% 和 66%；Base 为 74%、0% 和 20%，Direct 为 68%、32% 和 50%，FTP-π0.5 为 56%、4% 和 72%。CoRA-VTLA 并非每项都最佳，Knob 上 FTP-π0.5 的 72% 更高。
  • 在传感器输入匹配的条件下，CoRA-VTLA 相对 Direct 从 50.00% 提升至 73.33%，绝对提高 23.33 个百分点；差值的 95% 配对 bootstrap 置信区间为 14.67–32 个百分点，经 Holm 校正的 \(p_{\mathrm{adj}}=5.1\times10^{-6}\)。
  • 相比 Base，最显著的任务改善出现在 Plug insertion：成功率由 0% 升至 76%。CoRA-VTLA 还把超时数从 Base 的 96 次降至 36 次；其安全失败为 4 次，Base 为 7 次，且 CoRA-VTLA 的 4 次安全失败全部发生在 Nail。
  • 在使用光学触觉图像、不同物理引擎、机器人和动作接口的 UniVTAC Insert Tube 上，CoRA-VTLA 达到 67%，高于 Base 的 46%、Direct 的 51% 和 FTP-π0.5 的 57%，说明响应记忆可以适配到不同触觉模态。
  • 三个真机任务的平均成功率为 66.7%，每项均评测 50 次。所给原文在 UniVTAC 实现描述处截断，未包含真机逐任务成功率及后续消融表，因此不能据此核对更细的真机数字、注视损失单独增益或响应预训练的单独贡献。

局限与可以继续做的

  • 证据主要来自三个自建 MuJoCo 任务、一个 UniVTAC 任务和一套 UR5e 真机平台；尚不能证明该方法能直接迁移到其他机械臂、灵巧手、移动操作或更长时程的多阶段任务。
  • 真机只报告三个任务的 66.7% 平均成功率；当前节选缺少逐任务结果、方差或置信区间，也未给出完整真机失败类型，因而难以判断收益是否由某个任务主导。
  • 联合后训练会更新视觉骨干、VLM 和动作专家，并非参数高效或冻结骨干的适配方案；论文给出了较低的分组学习率，但当前节选未报告训练时间、显存、推理延迟及与仅训练触觉适配器方案的成本对比。
  • 记忆依赖已标定且时间同步的触觉、机器人状态和动作响应；接触区域监督还需要把活跃指尖单元准确投影到相机 patch。相机外参偏差、触觉漂移、软材料形变或被遮挡接触可能削弱这一监督。
  • 可继续做一个“冻结 OpenPI/π0.5 骨干、仅训练接触编码器与记忆模块”的对照，并分别消融响应预训练、状态条件查询、episode-relative wrench 和 gaze loss，统一记录成功率、安全失败、恢复耗时及额外推理延迟。
  • 可把测试场景按“无阻塞、首次卡住、退出后重新接触、持续高载荷”分层，报告每类恢复成功率与记忆注意力位置；再注入触觉噪声、相机—触觉标定误差和动作延迟，以验证系统是否真正利用动作—响应因果线索，而非训练分布中的载荷模式。
实验设置
  • 仿真器：MuJoCo；任务为 Nail insertion、Plug insertion 和 Knob operation。
  • 仿真触觉：双指尖法向压力阵列与六轴腕部力/力矩。
  • 仿真训练：一个策略联合训练三个任务；示范同时包含正常执行和受阻后的恢复轨迹，并在每个任务内改变场景初始条件与物理参数。
  • 骨干：同一个通用 π0.5 检查点；Base、Direct、适配后的 FTP-π0.5 和 CoRA-VTLA 分别独立初始化，并使用相同更新预算与采样调度。
  • 参数更新：联合后训练更新视觉骨干、VLM、动作专家及触觉模块，不冻结 π0.5；UniVTAC 适配中用于双指光学触觉图像的 ResNet-18 编码器冻结。
  • 峰值学习率：视觉骨干 \(2\times10^{-6}\)，VLM \(5\times10^{-6}\)，动作专家 \(2.5\times10^{-5}\)，新增触觉参数 \(7.5\times10^{-5}\)；均采用 warmup 后 cosine decay。
  • 响应记忆：MuJoCo 中保留最近 \(K=16\) 个事件，对应 0.8 秒历史。
  • 闭环频率：策略以 20 Hz 运行，物理仿真为 500 Hz；每次预测包含 50 条命令，使用 10 个 ODE steps，仅执行第一条命令后重新规划。
  • 仿真评测：每个任务使用相同的 50 个未见场景，其中正常与恢复初始条件各占一半；三个任务共 150 次，每个 episode 最多执行 600 条策略命令。
  • 成功判据：插入任务要求几何插入有效、完成释放、夹爪撤离，并连续 8 个观测保持稳定；Knob 要求达到目标转角、解除按压与抓持、夹爪撤离并满足同一稳定条件。
  • 安全判据：穿透超过 2 mm 或夹爪接触夹具记为安全失败；Knob 的按压行程另有安全上限。安全失败、超时和初始化失败均计入成功率分母。
  • 统计检验：配对成功结果使用双侧精确 McNemar 检验，并在各 benchmark 内进行 Holm 校正；Direct 与 CoRA-VTLA 的差异另报告配对 bootstrap 置信区间。
  • 真机平台：UR5e 机械臂、Robotiq 140 夹爪，双指安装 Xuanya electronic skin。
  • 真机任务：软质一次性纸杯堆叠、纸面盖章、试管插入架孔；每种方法在每个任务上评测 50 次，并共享示范、初始条件分布及任务成功与安全标准。
  • 公共 benchmark：UniVTAC Insert Tube；使用光学触觉图像而非压力阵列或腕力/力矩，且物理引擎、机器人和动作接口均不同于自建 MuJoCo 设置。
  • 当前提供的论文正文未披露示范数量、总训练步数、batch size、语义与注视损失权重调度，以及真机控制频率等复现细节。
AI导读和推荐理由
  • 这篇论文值得纳入 π 系列日报，因为它不是重新训练一个触觉基础模型，而是具体展示了如何围绕 π0.5 的 VLM 前缀与动作专家后缀设计触觉后训练接口。
  • 它同时处理了触觉 VLA 中两个容易被混淆的问题：动作侧需要知道“接触如何响应近期动作”，感知侧则需要知道“这次触觉对应图像中的哪里”；73.33% 对 50.00% 的同传感器比较为这一组合提供了直接证据。

与π系列的关系

  • 本文直接从预训练 π0.5 检查点出发：接触 token 和响应记忆 token 被加入 π0.5 动作专家后缀，触觉语义 token 被加入 VLM 前缀，动作仍由 π0.5 的流匹配动作专家生成。
  • 它属于 π0.5 的触觉后训练扩展，而不是新的 π 系列基础模型；联合训练时视觉骨干、VLM 和动作专家均被更新，因此也不能简单理解为冻结 π0.5 后外挂一个独立控制器。
  • 相比原始 Base π0.5，新增的是当前接触编码、可查询动作—响应记忆、触觉语义分支、接触区域 gaze loss 和响应预测初始化；语言、视觉、本体状态及动作块接口仍继承 π0.5 框架。
  • 所给原文没有报告对 π0、π0-FAST 或 OpenPI 实现的直接实验，也没有证明该模块能无修改移植到这些变体；FTP-π0.5 是把既有触觉编码与专家机制适配到共同传感器和动作接口后的比较方法，并不等同于 π0-FAST。
  • 对 π 系列的关键启发是：触觉不应只作为另一个即时观测 token。将“当前接触”和“近期动作引起的响应”拆开，并让查询受当前机器人状态约束，更适合闭环恢复；与此同时，触觉 token 对视觉区域的注意力也需要显式监控。

对Austin研究的启发

  • 在 OpenPI 执行器接口中增加结构化触觉状态：分别暴露当前接触 \(C_t\)、动作—响应事件 \(r_t\) 和查询记忆 \(M_t\)，不要只把整段触觉历史拼接成一个无语义向量。
  • 按论文的闭环协议先做最小复现：动作专家仍输出完整 chunk，但执行器每次只执行第一条命令；记录“卡住—撤回—重新接触—完成”的状态转换，避免仅用最终成功率掩盖恢复行为。
  • 若 Austin 的系统包含引导场 \(G\)，可以把当前接触和检索到的响应作为 \(G\) 的条件，分别测试其对撤回方向、重新对齐幅度和载荷上限遵循率的影响；对照组至少应包括无触觉、仅当前触觉、固定窗口池化和状态查询记忆。
  • 增加在线监控：记录记忆查询在各历史事件上的权重、触觉语义 token 落在接触区域内的注意力质量、腕部载荷峰值、安全终止和从首次阻塞到恢复所需的重规划次数。
  • 为验证接口鲁棒性，可系统注入传感器延迟、压力零漂、腕力偏置和接触区域投影误差；如果性能依赖精确同步或标定，应在部署前明确失败阈值，而不是只看干净条件下的平均成功率。
  • 若训练资源有限，优先验证“冻结 OpenPI/π0.5 主干，仅训练触觉编码器、记忆和投影层”，并与论文的全参数联合后训练比较；这能直接回答 CoRA 的收益是否需要改动通用视觉—语言表示。

一句话总结

大连理工大学、吉林大学、清华大学与 Enomind Technology 的作者以 π0.5 为骨干，通过状态查询的动作—响应记忆和接触引导注视监督进行触觉后训练，在三个 MuJoCo 任务上取得 73.33% 平均成功率，相比同传感器 Direct 基线的 50.00% 提高 23.33 个百分点，并在 UniVTAC 与三个真机任务上分别达到 67% 和 66.7%。
