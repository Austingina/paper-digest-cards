问题

  • 精密插入不仅要识别“哪个零件插入哪个接口”，还要满足约 \(0.1\!-\!0.3\,\mathrm{mm}\) 的典型配合间隙以及约一至两度的旋转容差；带键连接器还只允许特定朝向。现有基于图像块、标记、关键点或体素价值图的零样本操作方法，空间分辨率和三维对应精度不足。
  • 工业方案通常依赖每种零件的 CAD、夹具、人工示教位姿，学习式装配方法也往往需要针对单个装配或零件族训练策略，难以直接处理从未见过的零件。
  • 论文研究纯仿真零样本设定：系统仅接收三视角 RGB-D 观测和自然语言指令，不使用 CAD、示范或任务专属训练；VLM 在运行时生成几何条件，经典运动规划器与柔顺控制器闭环执行。
  • 关键失败模式有两类：远景相机难以测出亚毫米入口偏差；VLM 即使找对接口，也会误判 USB 等带键零件的轴向旋转，而柔顺与搜索无法补救错误接口或大角度朝向错误。
  • 作者目标是把语义判断、精确几何测量和插入控制解耦，在未见零件上实现可复用的零样本精密插入，并避免每次摆放都重复约 90 秒的 VLM 推理。

方法

  • 整体流程为：语言指令与多视角 RGB-D 场景输入 → VLM agent 选择对象和待测几何 → 深度几何工具生成 sketch → 规划器抓取 → 抓后近距离观察两个配合面并修正 sketch → 柔顺控制完成插入。已见任务可由 sketch memory 直接提供 sketch，绕过 VLM。
  • Sketch \(\mathcal S=(\mathcal S_A,\mathcal S_B)\) 用少量盒体或圆柱基元描述移动件，并用两个配合坐标系规定插入关系。移动件侧包含配合端中心、插入轴、旋转参考方向和旋转对称阶数；固定件侧包含入口中心、向外轴、旋转参考方向和插入深度。
  • VLM 不直接估计精密三维位姿，而是在工具循环中决定“测什么”：例如选择对象、孔口、平面、圆或参考特征。hole、top、fit、region 等工具在融合深度点云上返回毫米制几何量，check 检查草图的模式错误、基元覆盖率及其与观测的一致性。
  • Sketch memory 保存一次 agent 运行得到的两零件点云模板、对象坐标系下的 sketch 和颜色。零件换位置后，系统通过平面 \(x/y/\mathrm{yaw}\) 粗搜索与 ICP 配准迁移 sketch；任一零件的配准 fitness 低于阈值时才重新调用 VLM。
  • 抓取后，机器人把移动件配合端展示给桌面上视相机，恢复其在夹爪中的实际位姿和轮廓；腕部相机同时近距离生成固定件入口的高度图。系统搜索平面位移与轴向旋转，使移动件轮廓和固定件自由空间达到最佳形状互补，从而修正 VLM 的键位对应错误、远景测量偏差及记忆配准误差。
  • 最终执行器没有训练新的策略：RRT-Connect 负责无碰路径，任务空间阻抗控制器沿 sketch 轴线下降，受阻时执行螺旋与旋转搜索。相较 ReKep 和 MOKA，论文保持相同 VLM、规划器和控制器，主要替换其中间空间表示，并增加抓后 look-and-mate 几何校正。

实验与结果

  • 在 69 个开发集仿真插入 episode 上，SketchMate 有 61 个通过严格的运动学装配位姿测试，即 88%；在物理仿真中的成功率为 91%。
  • 在相同 VLM、规划器和控制器下移植的 ReKep 与 MOKA，在上述 69 个 episode 中严格装配成功数均为 0。论文将主要原因归结为其关键点、标记或图块没有精确描述实际配合特征，而不只是末端控制误差。
  • 对六类留出连接器共 18 个零件，完整方法在严格运动学测试和物理仿真中均实现 18/18 成功，表明方法能外推到未参与开发的连接器类型；但该结论仍限于论文构造的仿真零件与单轴直线配合协议。
  • 在八个任务的新摆放测试中，只复用每个任务的一次已存 agent 运行，即可通过配准完成 30/32 次插入；原文称其成功数与每个 episode 都重新调用 agent 相同。
  • Sketch memory 将新摆放时的 sketch 生成时间从约 90 秒 降至 3.4 秒。它省去重复 VLM 调用，但仍保留抓后形状匹配和后续规划控制。
  • 定性失败分析显示，VLM 能较可靠地选择正确零件和入口，却会把带键零件的旋转对应判断错，例如 NEMA 5-15 插头出现 \(90^\circ\) 偏差；look-and-mate 利用两配合面的形状互补恢复正确朝向，并同时修正低于远景相机分辨率的平移偏差。

局限与可以继续做的

  • 证据目前全部来自仿真。论文没有在真实机械臂上验证深度噪声、反光或透明连接器、相机标定漂移、柔性线缆、夹持滑移和真实接触摩擦，因此不能把 88% 或 91% 直接外推到真机。
  • 任务被限制为沿单一轴线直线插入开口或套上立柱，且固定件安装在桌面、移动件从桌面或简单支架起始。需要倾斜进入、多阶段卡扣、螺纹旋合、线缆约束或双臂协作的装配不在当前设定内。
  • Sketch memory 假设零件静置于桌面，因此只估计 \(x/y/\mathrm{yaw}\) 平面变换；若对象具有任意六自由度姿态、部分遮挡或近似对称外形，单次模板的 ICP 可能发生错误匹配。可进一步测试完整 SE(3) 配准、多个模板及带不确定度的检索。
  • Look-and-mate 依赖两个配合面可被近距离观察，并需要上视相机与腕部相机。可执行的扩展实验是遮挡部分键位、移除上视相机或加入反光深度缺失，分别测量旋转恢复率、平移误差和最终插入率。
  • 论文报告了中间表示误差和失败原因，但所给原文片段未完整披露 look-and-mate 消融、各组件独立成功率及统计置信区间。后续应分别关闭抓后旋转修正、亚毫米平移修正、记忆配准和柔顺搜索，以区分几何表示、感知校正与控制器各自的贡献。
实验设置
  • 平台：仿真机械臂装配；提供的原文未报告真机实验。
  • 任务来源：AutoMate 装配件、按公开尺寸构建的连接器、NIST 风格任务板、AI for Industry Challenge 零件，以及六类留出连接器。
  • 输入：自然语言任务指令、三台已标定场景 RGB-D 相机、腕部相机，以及桌面内嵌的上视相机。
  • 先验限制：不使用 CAD 模型、示范或任务专属训练；移动件初始位于桌面或简单支架，固定件安装在桌面，可存在盒状障碍物。
  • 配合范围：只评测沿单一轴线直线插入开口或套上立柱的任务；程序化零件的装配容差约为横向 \(0.2\!-\!0.45\,\mathrm{mm}\)、旋转 \(1.3^\circ\!-\!4.6^\circ\)。
  • 几何后端：融合多视角深度点云，移除机器人和桌面，并以欧氏聚类分割桌面对象；系统不使用学习式分割模型。
  • VLM：论文图示 episode 使用 GPT-6.1-Sol；提供的原文片段未明确说明全部 141 次 agent 运行是否都使用同一检查点，也未披露采样参数。
  • Agent 工具统计基于 141 次运行：region、hole、check 的运行调用率均为 100%，top 为 98%，view 为 97%，xyz 为 77%，fit 为 24%。
  • 近距离固定件观测中，一个腕部相机像素覆盖 \(0.16\,\mathrm{mm}\)；远景相机对开口的有效分辨率约为 \(0.4\,\mathrm{mm}\)。
  • 规划与控制：RRT-Connect 路径规划、任务空间阻抗控制、受阻后的螺旋与旋转搜索。
  • 主开发集：69 个插入 episode；另有六类留出连接器共 18 个零件。
  • 记忆复用评测：八个任务、32 次新摆放，每个任务只存储一次 agent 运行，并与逐 episode 重新调用 agent 比较。
  • 基线：移植后的 ReKep 和 MOKA；使用与 SketchMate 相同的 VLM、规划器和控制器。
  • 指标：严格运动学装配位姿测试、物理仿真成功率、各级中间表示精度、失败原因，以及 sketch 生成时间。
  • 配准：对象颜色与尺寸筛选、离散 yaw 粗搜索和 ICP；任一对象 fitness 低于阈值时回退到 VLM。具体 fitness 阈值未出现在提供的原文片段中。
AI导读和推荐理由
  • 这篇论文值得推荐的核心不是“VLM 能做插入”，而是它明确承认 VLM 的空间输出不够精，并把语义选择、几何条件和闭环执行拆成可测量的接口；其 0/69 基线结果也直接展示了粗条件表示在精密接触任务中的失败。
  • 它同时给出了条件生成、抓后条件修正、跨摆放复用和中间误差诊断，适合作为交互表示与组合泛化研究中的强案例，而不只是一个最终成功率更高的插入系统。

与本项目关系

  • SketchMate 与 Austin 的 G/A-F 接口直接相关：二者都把语言与视觉意图压缩成执行器可消费的几何条件。SketchMate 的移动件配合端与固定件入口可类比 A，其插入轴、旋转参考和深度进一步显式规定了 F；相比连续引导场 G，它更适合几何结构明确、容差极小的单轴装配。
  • 两者的主要差别在执行端：Austin 希望由 OpenPI 的 \(\pi_0/\pi_{0.5}\) 学习策略理解 G 或 A/F 并闭环完成接触与时序，而 SketchMate 没有验证 OpenPI，也没有训练 VLA；它把动作细节交给 RRT-Connect、阻抗控制和手工设计的螺旋/旋转搜索。
  • SketchMate 为“条件是否被真正遵循”提供了比只看训练损失更直接的证据链：逐级检查 sketch，抓后重新测量移动件，利用两配合面形状互补修正错误条件，再按严格装配位姿判定成功。不过论文没有实施 Austin 所强调的 G 置零、反向或交换消融，因此仍未隔离执行器究竟依赖哪些条件字段。
  • 其留出连接器和新摆放实验分别涉及类别外推与同任务重定位，但尚不是完整的“物体×目标×场景”组合矩阵：没有系统交换同类物体与多个目标，也没有检验熟悉的物体—目标关联是否主导 VLM 选择。
  • 对 Austin 当前“抓到了却没送到正确目标”和“是否持续跟随目标”的问题，最相关的是 SketchMate 的抓后再观测：系统不把抓取前生成的条件视为最终真值，而是在执行中重新测量对象—目标关系。差距在于其目标固定、插入轨迹结构化，不能直接证明动态放置过程中策略会持续跟随 G。

启发

  • 为 A/F 或 G 增加类似 mate-frame 的可审计字段：分别记录交互区域中心、期望运动轴、旋转参考、终止深度及对称性。除最终成功率外，逐项报告这些字段在抓取前、抓取后和接触前的平移与旋转误差。
  • 在 OpenPI 执行器上做因果条件消融：保持同一图像和语言不变，分别将 F 置零、轴向反转、交换两个目标的 F、旋转参考偏转 \(90^\circ\)，并比较物体轨迹、接触位置和最终目标误差；这样能区分“真正持续遵循条件”与“把条件当任务 ID”。
  • 增加抓后或接触前的条件刷新模块：由视觉重新估计被抓物体的实际位姿及目标局部几何，把更新后的 A/F 或 G 送回策略。可对照“仅抓取前条件”“抓后刷新一次”“每步闭环刷新”三种协议。
  • 构造物体×目标×场景的交叉覆盖：让同一物体对应多个兼容目标、同一初始场景指定不同目标，并留出未见物体—目标组合；分别评测目标选择、运输过程目标跟随、最终放置和失败恢复，避免只验证新摆放下的模板配准。
  • 借鉴 look-and-mate，把失败恢复建立在“观测到的几何不一致”上：当物体运动方向与 F 相反、目标距离不再下降或接触后停滞时触发重新感知和条件重估，而不是仅增加策略 rollout 长度。
  • 将 SketchMate 的显式控制器作为上界或诊断基线：在同一批精密插入任务中，让 OpenPI 与经典规划/柔顺控制消费同一 A/F 条件。如果经典执行器成功而 OpenPI 失败，问题更可能是条件遵循；若两者都失败，则优先检查条件提取和数据覆盖。

一句话总结

  • SketchMate 由 Jiaming Wang 提出（提供的论文原文未披露作者机构），以 VLM 构建、几何工具测量、抓后形状互补修正并可跨摆放复用的显式配合 sketch，在 69 个仿真插入 episode 上取得 61/69（88%）严格装配成功，而同 VLM 下的 ReKep 与 MOKA 均为 0/69。
