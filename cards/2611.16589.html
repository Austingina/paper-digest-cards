深读｜STVLA

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 现有 VLA 往往主要依据当前观测生成动作；在长时程、多步骤操作中，相似画面可能对应不同任务阶段，导致策略重复已经完成的步骤、遗漏步骤或停滞。
  • 仅保存外观特征的记忆容易受机械臂遮挡和视角变化影响；仅为当前帧补充深度或三维结构，又无法记录场景在执行过程中发生了哪些变化。
  • 论文同时覆盖 LIBERO、LIBERO-Mem、MIKASA-Robo、SimplerEnv Bridge 四类仿真评测，以及 AGIBOT G2 上的三项真机任务。仿真中采用动作分块并周期性重规划，属于闭环执行；VGGT-Ω 保持冻结，但策略与空间压缩器联合训练，并非冻结 π0.5 后外挂一个纯推理模块。
  • 作者的目标是把场景几何纳入有界时序记忆，使基于 π0.5 的策略在空间精确、需要追踪任务进度的操作中获得更高成功率，同时避免无限增长的历史上下文。

方法

  • 当前观测编码：RGB 窗口分别进入冻结的 SigLIP 与 $\mathrm{VGGT}\text{-}\Omega$（雪花）；前者输出当前视觉 token $\mathbf{v}_t$，后者借助历史帧上下文提取当前帧几何 patch 特征 $\mathbf{g}_t$。
  • 空间标记化：可学习查询通过 Pooling Cross-Attention 将 $\mathbf{g}_t$压缩为固定数量潜变量；Variational Bottleneck 采样 $\mathbf{z}_t=\boldsymbol{\mu}_t+\boldsymbol{\sigma}_t\odot\boldsymbol{\epsilon}$，再投影至语言模型宽度，得到 $N_s$ 个空间 token $\mathbf{s}_t$。辅助 Reconstruction 分支仅在训练时约束空间信息保真。
  • 有界视觉—空间记忆检索：当前 $\mathbf{v}_t$、$\mathbf{s}_t$作为 query，从容量受限的 Memory Bank 中检索历史视觉—空间特征；Score-Biased Cross-Attention 将记忆相关性分数注入注意力 logits，使高相关历史状态获得更大权重，输出检索特征 $\tilde{\mathbf{v}}_t,\tilde{\mathbf{s}}_t$。
  • 门控融合与动作生成：Gated Fusion 以可学习门值将检索结果注入当前表示，如 $\mathbf{v}'_t=\mathbf{v}_t+\alpha_v\tilde{\mathbf{v}}_t$。融合后的视觉、空间 token 与任务指令、机器人状态组成独立 Policy-Prefix 段，共同条件化 PaliGemma 与 Flow-Matching Action Expert，生成连续机器人动作。

Flame and snowflake icons denote trainable and frozen modules, respectively.
  • 整体流程：当前 RGB 观测分别经过 π0.5 原有的 SigLIP 视觉编码路径和冻结的 VGGT-Ω 几何路径，得到视觉 token 与压缩后的空间 token；两类 token 联合查询同一有界历史库，检索结果经门控融合后，与语言指令、机器人状态共同条件化流匹配动作专家。
  • 空间 token 化：VGGT-Ω 使用一个多帧 RGB 窗口提取当前帧的几何特征；可训练的 learned-query 交叉注意力压缩器将高分辨率 patch 特征聚合成固定数量的空间 token，并通过变分瓶颈投影到语言模型宽度。
  • 有界视觉—空间记忆：每个历史条目同时保存视觉 token 和空间 token。当前两类表示可以跨模态检索全部历史条目；记忆满后删除最旧条目，并在 episode 边界重置，因此存储和检索上下文不会随任务时长无限增长。
  • 无额外学习参数的条目评分：作者将当前表示与每个历史条目的余弦相关性，与归一化特征差异相乘，形成“相关且不冗余”的条目分数；标准化后的分数作为偏置加入 token 级交叉注意力，而不是硬删除低分历史或训练独立检索器。
  • 动作条件接口：检索结果通过逐元素可学习门控融合回当前视觉和空间表示。空间 token 使用独立的 policy-prefix 段；原有视觉、指令和状态前缀的注意力结构被保留，动作 token 则可访问全部前缀。
  • 训练目标：策略与空间压缩器联合优化流匹配动作损失、几何特征重建损失和 KL 正则；推理时使用变分后验均值。相对 π0.5，论文保留 PaliGemma/SigLIP 与流匹配动作专家这一主体路线，新增冻结几何编码器、空间压缩器、视觉—空间记忆及其检索与融合模块。

实验与结果

  • LIBERO：STVLA 在五个 suite 上平均成功率为 97.8%，高于作者同设置训练的 π0.5 基线 96.6% 和表中 MemoryVLA 的 96.5%。相对 π0.5 的平均提升为 1.2 个百分点；较明显的提升出现在 libero-goal（97.6% vs. 94.6%）和 libero-10（97.6% vs. 95.4%）。不过 STVLA 在 libero-object 上为 98.2%，低于 π0.5 的 99.2%。
  • LIBERO-Mem：十项历史依赖任务的平均成功率为 41.0%，π0.5 为 38.0%。在重复放置 B×5 和 B×7 上，STVLA 分别达到 70% 和 40%，均比 π0.5 高 30 个百分点；但并非所有任务都改善，例如“cream cheese → basket”为 25% vs. 55%。
  • MIKASA-Robo：五项任务平均成功率为 45.2%，高于 MemoryVLA 的 41.2% 和作者复现的 π0.5 的 32.4%。分任务上，STVLA 在 ShellGame 为 86%，略低于 MemoryVLA 的 88%；在 Touch、Intercept Medium、Remember Color5 和 Remember Color9 上分别为 38%、46%、32%、24%。
  • SimplerEnv Bridge：四项任务平均成功率为 74.0%，高于 MemoryVLA 的 71.9% 和 π0.5 的 66.7%。STVLA 在 Stack cube 上达到 54.2%，相对 π0.5 的 45.8% 提升 8.4 个百分点；但 Spoon on towel 和 Carrot on plate 均低于对应的最优单项基线。
  • 真机任务：在积木堆叠、物体整理和手机包装上，STVLA 相对 π0.5 分别提升 58.33、30.00 和 35.00 个百分点。所给原文节选未披露这三项任务的绝对成功率、试验次数和置信区间，因此不能据此还原更细的统计结论。

局限与可以继续做的

  • 基线可比性有限：LIBERO 表中除带 † 的结果外，多数数字来自 MemoryVLA 或原论文，并沿用各自评测设置；论文也明确说明，缺少 LIBERO-90 的四套件平均值与覆盖五套件的平均值不能直接比较。后续应在统一代码、输入模态、训练数据、随机种子和试验次数下复测 π0、π0-FAST、MemoryVLA 与 STVLA。
  • 提升并非任务级一致：虽然四个仿真基准的平均值均最高，但 STVLA 在部分 LIBERO-Mem、LIBERO、MIKASA 和 SimplerEnv 单项上退化。可以按遮挡程度、视角变化、几何精度需求和历史长度分桶，判断空间记忆在哪些场景提供帮助、又在哪些场景引入错误检索。
  • 检索分数只是特征空间代理：作者明确指出，相关性与归一化差异的乘积并不直接估计任务信息增益。可进一步比较纯注意力、最近邻、时间衰减、任务阶段预测、可学习检索器以及当前 relevance–non-redundancy 偏置，并报告错误历史被高权重召回时的动作失败案例。
  • 计算开销与部署证据不足：冻结的 1B 参数 VGGT-Ω 需要多帧 512 px 图像，并产生高维 patch 特征；节选未报告推理延迟、显存、控制频率或相对 π0.5 的吞吐下降。真机部署前应测量端到端控制周期，并尝试缓存几何特征、降低空间 token 数或蒸馏轻量几何编码器。
  • 消融和真机统计在所给节选中不完整：当前材料没有给出记忆容量、空间 token 数、评分偏置、重建/KL 损失和纯视觉记忆之间的完整消融，也未给出真机试验次数。后续应至少加入“π0.5 + 视觉记忆”“π0.5 + 当前帧几何”“视觉—空间记忆但无评分偏置”等受控组合，并使用多随机种子和置信区间报告结果。
实验设置
  • 仿真基准：LIBERO、LIBERO-Mem、MIKASA-Robo 和 SimplerEnv Bridge；统一报告任务成功率。
  • 真机平台与任务：AGIBOT G2；积木堆叠、物体整理、手机包装。原文节选未给出真机相机配置、控制频率、每项试验次数及绝对成功率。
  • 策略主体：基于 π0.5 的 PaliGemma 视觉—语言模型和流匹配动作专家；视觉编码使用 SigLIP。π0.5 与 STVLA 在仿真实验中使用相同数据和相同优化步数。
  • 几何模型：冻结的 1B 参数 VGGT-Ω；固定头部相机输入为 512 px，每帧输出 1024 个、宽度 2048 的 patch 特征；默认输入窗口包含 K=4 帧。
  • 策略图像输入：训练时调整为 224×224。LIBERO 环境渲染分辨率为 128×128。
  • 空间压缩器：一层 learned-query pooling cross-attention；输出 256 个空间 token，并投影至语言模型宽度。
  • 记忆与检索：记忆容量 16 个历史条目，交叉注意力检索深度 2 层；容量超限时删除最旧条目，每个 episode 开始时清空。文中另报告 sampler group size 为 16。
  • 损失权重：几何重建损失权重 \(\lambda_r=1\)，KL 损失权重 \(\lambda_{kl}=10^{-4}\)。
  • 训练硬件与批量：全部仿真和真机实验均使用 8 张 NVIDIA H100；每张 GPU 的 batch size 为 16。
  • LIBERO 协议：五个 suite 分别训练策略；前四个 suite 训练 40k 步，libero-90 训练 80k 步；每个任务评测 50 次，seed 为 7，每 8 个环境步重规划一次。
  • LIBERO-Mem 协议：十项任务联合训练 120k 步，使用 replay refinement 后保留的 961 条示范；每项任务评测 20 次，每 8 个环境步重规划。
  • MIKASA-Robo 协议：表中作者训练的 π0.5 与 STVLA 每项任务评测 100 次；所给节选未包含其训练步数等后续设置。
  • SimplerEnv Bridge 协议：作者训练的 π0.5 与 STVLA 每项任务评测 24 次。
  • 输入模态标注：LIBERO 表中的 STVLA 与作者 π0.5 基线带有 *，表示额外使用本体状态和腕部相机输入。
AI导读和推荐理由
  • 这篇论文与 π 系列日报直接相关：它不是重新设计动作生成器，而是以 π0.5 为主体，集中研究“几何表征应不应该进入长期历史，以及如何被动作专家读取”。
  • 论文的价值不只在平均成功率，而在于提供了可拆分验证的接口：冻结几何编码器、固定容量记忆、无参数条目偏置、门控融合和独立空间前缀，适合在现有 VLA 执行栈中逐项消融。

与π系列的关系

  • 与 π0.5：STVLA 直接采用 π0.5 的 PaliGemma/SigLIP 表征路径和流匹配动作专家，并以作者同数据、同优化步数训练的 π0.5 作为主要内部基线。它新增空间 token 化、视觉—空间有界记忆、分数偏置交叉注意力和门控融合；并未声称改变 π0.5 的基本流匹配动作生成范式。
  • 与 π0：π0 出现在 LIBERO-Mem 和 MIKASA-Robo 等表格中，但相关数字主要是报告基线，并非论文的直接架构基础。STVLA 也不是 π0 的官方后继版本。
  • 与 π0-FAST：LIBERO 表包含 π0-FAST 的外部报告结果，其平均成功率为 85.0%；但评测设置来源不同，不能把它与 STVLA 的 97.8% 视为严格受控的架构对比。论文没有把 FAST 动作 token 化机制接入 STVLA。
  • 与 OpenPI：所给原文没有说明使用 OpenPI 实现、发布兼容 OpenPI 的检查点，或在 OpenPI 训练栈中验证；因此 STVLA 应被视为基于 π0.5 思路的独立扩展，而非 π0、π0-FAST、π0.5 或 OpenPI 的官方成员。

对Austin研究的启发

  • 在 OpenPI 或自有 π0.5 执行器中先定义稳定的“额外条件前缀”接口：保持原视觉—语言前缀不变，将空间 token 放入独立 segment，并允许动作专家读取它们，从而降低修改主干注意力结构的风险。
  • 将记忆条目设计为统一的 {视觉特征, 空间特征, 时间戳, 任务阶段, 检索分数} 结构，并在 episode reset、容量溢出和相机丢帧时显式处理；先复现 FIFO 容量 16，再比较事件驱动写入、合并相似条目和时间衰减。
  • 针对引导场 \(G\) 或其他几何条件，增加可观测监控：记录每一步历史条目分数、交叉注意力质量、门控幅值和动作输出变化，检查策略究竟遵循了几何条件，还是仅依赖当前 RGB 与语言。
  • 把闭环评测拆成四类压力测试：遮挡后恢复、视角变化、重复计数/进度追踪、精确放置；同时加入“错误几何历史”和“过期任务阶段”干扰，测量错误记忆对动作的因果影响，而不只报告总体成功率。
  • 复现时优先采用受控的四路消融：原始 π0.5、仅当前帧空间特征、仅视觉记忆、视觉—空间联合记忆；之后再加入评分偏置与辅助重建损失，避免把 VGGT、记忆和训练正则的贡献混在一起。
  • 若目标是实时真机运行，应把 VGGT-Ω 的端到端延迟、显存和控制频率列为首要指标；在成功率之外，测试减少输入帧数、空间 token 数以及用轻量模型蒸馏后的性能—速度曲线。

一句话总结

AgiBot 的 STVLA 在 π0.5 上加入冻结 VGGT-Ω、可训练空间压缩器和有界视觉—空间记忆，使 LIBERO 平均成功率达到 97.8%、LIBERO-Mem 达到 41.0%，并在三项 AGIBOT G2 真机任务上相对 π0.5 提升 30.00–58.33 个百分点。
