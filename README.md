# paper-digest-cards

Static HTML deep-read cards for Austin's Feishu 论文推送 digests.

## GitHub Pages

Site root = repository root (`main`). Card URLs:

`https://austingina.github.io/paper-digest-cards/cards/<arxiv_id>.html`

## Layout

- `index.html` — index
- `cards/<arxiv_id>.html` — one card per paper
- Source markdown lives in the paper-digest box pipeline; HTML is generated by `render_card.py`.
