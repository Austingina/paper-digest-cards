深读｜ResWAM

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 现有 VLA 通常只用动作标签训练，缺少对“执行这段动作后世界会怎样变化”的显式监督；WAM 虽加入未来预测，但完整未来帧或特征中大量内容与当前观测相同，损失容易被静态背景复制主导，而非聚焦机械臂、末端执行器和被操作物体。
  • 现有 WAM 往往依赖大型视频生成模型、3D 视频 VAE，或在 VLA 外维护独立世界模型，训练与推理成本较高，不利于低延迟闭环控制。
  • 论文研究仿真与真机的分块闭环控制：策略一次预测未来 \(H\) 步动作，执行动作块后根据新观测再次查询；VLM 骨干端到端训练，只有用于构造视觉监督的 DINOv3 编码器被冻结。
  • 作者目标是以更聚焦于动作引起变化的世界监督，在不依赖额外机器人轨迹预训练的前提下，同时提高策略成功率并降低 WAM 的训练、推理与部署开销。

方法

  • 预测范式对比（a）：给定视觉观测与语言指令 $(o_t,l)$，VLA 直接预测动作 $a_t$；视频生成式 WAM 同时生成未来视频 $\hat{o}_{t+1:t+H}$ 与动作序列 $\hat{a}_{t:t+H-1}$；本文方法则预测未来视觉表征及其残差，使世界动态建模与控制输出协同。
  • 架构演进（b）：视频生成 WAM 依赖 Video Generation Model（VGM），由 Video DiT（V. DiT）和 Action DiT（A. DiT）分别处理视频与动作；外部世界模型 WAM 将 Vision-Language Model（VLM）与独立 World Model（WM）串联。本文以共享 VLM 为主干，并行设置 Residual DiT（R. DiT）残差分支与动作分支，输出残差特征 $r_t$ 和动作 $\hat{a}_t$。
  • 残差机制收益（c）：残差以 $r_t=z_{t+1}-\hat{z}_{t+1}$ 表征预测未解释的动态信息；相较原始特征 $z_t$，其有效秩更高，信息维度利用更充分，注意区域集中于机器人本体及被操纵物体，从而弱化静态背景并突出任务相关变化。
  • 性能概览（d）：LIBERO-Plus 的成功率—延迟曲线显示该结构兼顾控制精度与推理效率；在 RoboTwin 2.0 和 RoboDojo 上，其平均成功率优于对比方法。图中 “w/ Robot Pretrain” 与 “w/o Robot Pretrain” 分别表示下游训练前是否使用外部机器人动作数据预训练。

  • 整体流程为：输入当前多视角图像、机器人本体状态和语言指令，经 RynnBrain-1.1-2B VLM 编码；随后由相互耦合的 Action DiT 与 Residual DiT，分别生成动作块和当前到未来的视觉特征残差。
  • 论文不再把完整未来特征 \(\mathbf Z_{t+H}\) 作为世界预测目标，而使用冻结 DINOv3 特征空间中的残差 \(\boldsymbol\Delta_t=\mathbf Z_{t+H}-\mathbf Z_t\)，以抵消静态场景成分并突出机械臂及物体运动。
  • 动作分支和残差分支各有独立参数、噪声与 flow time，通过 conditional flow matching 联合训练；总损失为动作流匹配损失与加权残差流匹配损失之和。
  • 两个 DiT 分支分别交叉注意 VLM 输出和当前 DINOv3 token，并通过对动作 token 与残差 token 的双向联合注意交换信息，使动作预测能够利用场景变化监督。
  • DINOv3 的 \(16\times16\) patch 网格经 \(2\times2\) 空间平均池化，压缩为每个视角 64 个 token；模型只预测特征残差，不重建未来像素，也不在推理时解码未来视频。
  • 相比完整未来特征 WAM，ResWAM 改变了世界监督目标，并以 0.5B 双分支 DiT 替代大型视频生成器或独立世界模型；它没有冻结 VLM 策略骨干，也没有基于 π0、π0.5 或 OpenPI 修改执行器。

实验与结果

  • 在不使用 benchmark 演示之外机器人动作轨迹预训练的条件下，ResWAM 在 LIBERO-Plus、RoboTwin 2.0 上分别取得 81.1% 和 93.8% 的平均成功率；在 RoboDojo 上取得 9.40% 成功率和 13.41 score。
  • 在 RoboTwin 2.0 的同等计算量对照中，将完整未来特征监督替换为视觉残差监督，使平均成功率提高 2.9 个百分点，直接支持“学习变化优于复制完整未来特征”的核心主张。
  • 真机 FR3 的 Open、Put、Stack 任务平均成功率为 80.0%，比论文中的 π0.5 对照高 10.0 个百分点，推理延迟为 92.7 ms。
  • 论文报告 ResWAM 在全部评测 benchmark 中使用最低的训练计算量 2.7–4.0 TFLOPs、推理计算量 1.0–1.4 TFLOPs，推理延迟范围为 92.2–99.7 ms；这些是论文自身协议下的跨方法比较，不能脱离模型输入、硬件和计量口径直接外推。
  • 表征分析显示，LIBERO 上未来特征与残差的 effective rank 分别为 15.22 和 22.06，stable rank 分别为 3.08 和 5.48；RoboTwin 2.0 上对应为 18.79→22.28 和 3.67→4.56。可视化中，残差响应主要集中在机械臂、夹爪和被操作物体，而背景区域相对不活跃。

局限与可以继续做的

  • 所给论文原文在第 5.2 节训练公式处截断，未包含完整实验表、附录和实现细节，因此各 benchmark 的任务数、每任务 rollout 数、随机种子、硬件、优化器、训练步数及残差损失权重无法由当前材料核对。
  • “最低计算量”和跨方法性能领先依赖论文采用的 FLOPs、延迟及预训练分类口径；尤其不同方法的输入视角、动作块长度和外部预训练数据可能不同，当前材料不足以完成完全等预算比较。
  • 真机证据限于 FR3 上的 Open、Put、Stack 三类任务；对长时序任务、显著相机运动、动态背景、遮挡、失败恢复以及跨机器人形态的泛化仍缺少证据。
  • 残差会同时响应相机抖动、光照变化和背景中的动态物体，并不天然等价于“动作造成的变化”。可增加相机运动补偿、前景掩码或 action-conditioned residual，对比其在移动相机和动态场景下的鲁棒性。
  • 可在 OpenPI 中进行严格接口级消融：保持 π 系列 VLA 骨干、数据、动作块和执行频率不变，只增加残差分支，并分别比较 action-only、完整未来特征、stop-gradient residual 和联合注意 residual，以确认收益来自监督目标而非额外参数。
  • 可进一步记录残差预测误差、动作置信度与真实执行失败之间的相关性，将残差分支用作在线异常监控或触发重规划的信号，而不只作为训练期辅助损失。
实验设置
  • 仿真 benchmark：LIBERO-Plus、RoboTwin 2.0、RoboDojo。
  • 真机平台：Franka Research 3（FR3）；任务类别为 Open、Put、Stack。
  • 输入：当前多视角相机图像、机器人 proprioceptive state、自然语言指令。
  • 控制协议：一次预测包含未来 \(H\) 步动作的 action chunk；执行后从新观测重新查询策略，属于分块闭环执行。
  • VLM 骨干：RynnBrain-1.1-2B，所有骨干参数端到端训练。
  • 世界监督编码器：冻结的 DINOv3；未来帧与当前帧特征在训练时在线提取并作差。
  • DINOv3 token：原始 \(16\times16\) patch 网格经 \(2\times2\) 平均池化，每视角保留 \(N=64\) 个 token。
  • 生成模块：0.5B 双分支 DiT；ResWAM 总参数量为 2.3B。
  • 训练目标：动作与视觉残差分别采用 conditional flow matching，使用独立高斯噪声和独立 flow time，联合优化动作损失与加权残差损失。
  • 预训练口径：不使用 benchmark 演示之外的外部机器人动作轨迹预训练。
  • 当前所给原文未披露或未完整展示：动作块长度 \(H\)、动作维度、残差损失权重、优化器、学习率、batch size、训练步数、具体 GPU、任务数及每任务评测 episode 数。
AI导读和推荐理由
  • 推荐这篇的核心原因不是又增加了一个更大的世界模型，而是重新审视 WAM 的监督对象：完整未来观测高度冗余时，直接学习“发生了什么变化”可能比复现“未来看起来是什么样”更适合作为控制辅助信号。
  • 它同时给出表征秩、空间响应、同计算量消融和真机结果，形成了从监督性质到控制收益的较完整证据链；但完整复现实验仍需查阅论文未出现在所给文本中的后续章节与附录。

与π系列的关系

  • ResWAM 与 π0、π0.5 一样使用连续动作块和 flow-matching 范式，但其骨干是 RynnBrain-1.1-2B，而不是 π 系列模型；论文的主要改动是增加视觉残差分支及动作—残差联合注意，不是对 π0/π0.5 权重或架构的直接微调。
  • 论文在 FR3 的 Open、Put、Stack 真机任务上报告了与 π0.5 的直接结果对照：ResWAM 平均成功率 80.0%，高 10.0 个百分点。当前材料没有给出 π0.5 对照的完整训练数据、检查点、参数规模和 rollout 数，因而应将其理解为论文协议内结果，而非对 π0.5 普遍能力的结论。
  • 原文没有报告 π0、π0-FAST 或 OpenPI 实现上的实验，也没有证明视觉残差分支能够无修改接入这些模型；二者的关系主要是可迁移的训练思想与 action-expert 接口，而非代码或权重继承关系。
  • 对 π 系列而言，ResWAM 的关键启发是：无需在推理时生成视频，也可以通过训练期世界变化预测约束 action expert，从而避免大型视频模型对闭环频率的拖累。

对Austin研究的启发

  • 在 OpenPI 执行器中增加可选的 residual head：复用当前视觉 token 与 action expert 的条件表示，仅在训练时读取 \(t+H\) 帧并构造 stop-gradient DINO 残差，推理时可关闭残差采样，以测量“纯训练辅助”是否已足够。
  • 做四组等参数或参数匹配实验：action-only、完整未来特征、视觉残差、视觉残差但移除动作—残差联合注意；统一数据、动作归一化、chunk 长度和控制频率，分别报告成功率、推理延迟与 FLOPs。
  • 若系统包含引导场 \(G\)，可将预测残差投影为空间 saliency，并检查高响应区域是否覆盖 \(G\) 指定的目标、接触区域和预期运动路径；不一致时降低动作块长度或触发重新查询。
  • 为闭环部署增加 residual-consistency 监控：执行动作块后比较“预测变化”和“实际 DINO 特征变化”，以偏差阈值触发停止、重规划或切换恢复策略，并评估该信号对碰撞、抓取滑落和目标未移动等失败的提前检出率。
  • 增加移动相机、光照扰动、动态干扰物和机器人本体遮挡测试，区分由机器人动作造成的可控残差与外源视觉变化，避免模型把所有帧间差异都当成动作后果。

一句话总结

ResWAM 由论文列出的 Michigan State University、Cisco、University of Michigan 与 IBM Research 作者团队提出，以冻结 DINOv3 空间中的未来—当前残差监督轻量双分支 WAM，在无外部机器人轨迹预训练时取得 LIBERO-Plus 81.1%、RoboTwin 2.0 93.8% 和 FR3 真机 80.0% 平均成功率，并以 92.7 ms 真机延迟较论文中的 π0.5 对照高 10.0 个百分点。
