深读｜POKE

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • VLA 每次控制需要处理数百个视觉 token；若在早期层删除无关 token，可以减少后续 Transformer 计算，但错误删除与动作相关的区域会直接破坏闭环操作。
  • FastV、VLA-Pruner 等方法主要以注意力或跨帧注意力历史衡量重要性；注意力描述“模型关注了哪里”，却不直接回答“改变该 token 会让预测动作改变多少”。论文示例中，注意力掩码保留了碗和夹爪，却遗漏了目标盘子。
  • 在线计算动作敏感度并不经济：完整图探测需要在每个控制步额外执行一次未剪枝前向和反向传播；在剪枝图上复用梯度或注意力虽更便宜，却会产生“评分图锁定”，使已删除位置越来越难重新进入掩码。
  • 研究设定是 LIBERO 上的闭环控制，覆盖并行回归的 OpenVLA-OFT 与流匹配的 $\pi_{0.5}$；原策略权重保持冻结，只训练外挂 token 评分器。作者目标是在不在线反传、不依赖上一帧掩码的前提下，提高视觉 token 剪枝后的成功率—延迟权衡。

方法

  • 输入与冻结策略（Frozen Policy）：多相机图像经视觉编码器与 projector 得到 $X=[x_1,\ldots,x_N]\in\mathbb R^{N\times d}$，并与语言指令 $\ell$、本体状态 $p$ 输入策略，输出动作块 $a_\theta(X,\ell,p)\in\mathbb R^A$。
  • Stage I：动作敏感度教师（Full-graph Teacher）：以同相机均值 $b_c$ 替代 token，定义 $\delta_i=\operatorname{stopgrad}(x_i-b_{c(i)})$；由雅可比 $J_i=\partial a_\theta/\partial x_i$ 得到一阶动作扰动 $u_i=J_i\delta_i$，用单次反向传播离线生成重要性分数。
  • Stage II：紧凑评分学生（Compact Student）：将教师分数蒸馏到仅依赖当前观测的轻量网络，使其直接为各视觉 token 预测分数 $\hat s_i$，从而把昂贵的完整策略反传转化为前向评分。
  • 部署与保留（Token Selection）：每个控制步 $t$，学生对 $X_t$ 排序并按相机索引集 $\mathcal I_c$ 选择总计 $B$ 个高分 token；这些“抓取前保留 token”连同 $\ell,p_t$ 送入冻结策略，无需在线反传即可产生动作块。

What to score: retained tokens before grasping
  • 整体流程：离线用冻结的完整 VLA 对示范观测计算动作敏感度标签，再将标签蒸馏到轻量学生评分器；部署时学生根据当前视觉 token、语言和本体状态打分，经 top-$k$ 或 MMDP 多样性选择后，仅把保留 token 送入策略后续层。
  • 动作敏感度：把 token 替换为所属相机的平均 token，以保持序列长度和计算图不变；其重要性定义为该替换导致的预测动作一阶变化范数。相机内均值避免混合不同视角的表示。
  • 单探针估计：精确 Jacobian 计算分别需要 56 次（OpenVLA-OFT）或 70 次（$\pi_{0.5}$）反向传播。POKE 将完整动作块投影到一个共享随机方向，用一次反向传播同时估计全部 token 的敏感度；估计量平方对真实敏感度平方无偏，但单个幅值仍有较高方差，因此训练和选择更侧重相机内排序。
  • 完整图教师：标签始终在保留全部视觉 token 的计算图上产生，不受历史剪枝掩码影响。对于 $\pi_{0.5}$，作者固定初始动作噪声，并对完成全部 Euler 积分后的最终动作块反传，而非只探测某一步速度预测。
  • 轻量学生：每个 token 的输入包含低维 token 投影、相机均值、全局场景均值、语言特征、本体状态、空间与相机坐标及 token RMS 幅值；两层 MLP 输出相机内重要性分数。训练同时使用 KL、回归和成对排序损失。
  • 相关性与多样性分工：top-$k$ 直接保留最高分 token；MMDP 则先取每个相机得分最高的至多 $2b$ 个候选，再用 projector embedding 的余弦距离做 max–min 选择。分数负责动作相关性，距离负责减少冗余。策略骨干、动作头与原有训练过程均未修改。

实验与结果

  • 在每个控制步只保留 32/512 个视觉 token 时，POKE-MMDP 在 OpenVLA-OFT 上取得 95.15% 平均成功率和 1.85× 加速；对应未剪枝策略为 96.70%。四套件 Spatial、Object、Goal、Long 的成功率分别为 97.8%、97.6%、97.2%、88.0%。
  • 同样保留 32 个 token，$\pi_{0.5}$ 上 POKE-MMDP 达到 90.80% 和 1.26× 加速；未剪枝策略为 96.50%。四套件结果分别为 97.0%、96.2%、93.6%、76.4%，表明长时序任务仍是主要退化来源。
  • 与 VLA-Pruner 相比，32-token POKE-MMDP 在 OpenVLA-OFT 上为 95.15% 对 89.25%，高 5.90 个百分点；在 $\pi_{0.5}$ 上为 90.80% 对 75.05%，高 15.75 个百分点。
  • 评分图锁定得到直接验证：即使前一掩码是随机生成的，剪枝图分数仍会重新选中其中 59% 的 token，而随机期望仅为 6%；固定观测分析中，剪枝图只把 19% 的分数分配给旧掩码外 token，完整图则为 77%。
  • 单随机探针与精确敏感度的相机内 Spearman 相关系数为 0.80，每个相机敏感度最高的 16 个 token 承载 84% 的敏感度能量。将教师目标换成注意力标签会在论文测试的全部八种组合中降低成功率，但所给正文片段未列出这些组合的逐项数值；LIBERO-Plus 上更大的优势也仅有结论，未提供可核对表格数字。

局限与可以继续做的

  • 动作敏感度是一阶局部近似，而且训练时用“替换为相机均值”模拟信息删除，部署时却是在中间层真正删除 token；两种干预并不等价，强非线性和 token 间交互可能使一阶排序失真。
  • 单探针估计虽然只需一次反传，但单个敏感度估计噪声较大；论文主要以相机内排序集中性支持其可用性，尚未展示多探针标签的额外离线成本能否换来更稳定的长时序表现。
  • 学生只看当前观测，不使用历史掩码，从机制上避免锁定，但也放弃了显式时序记忆。可以测试“与掩码无关的短期状态记忆”，例如输入过去评分或未剪枝低维视觉摘要，而不是直接复用上一掩码。
  • 主要可核对结果来自 LIBERO 的两相机设置；原文声称还覆盖 LIBERO-Plus 和 SimplerEnv，但给定片段没有其协议和数字，也没有真机实验，因此对真实相机噪声、延迟和机器人形态变化的外推证据不足。
  • 可继续做的实验包括：对长时序任务动态提高 token 预算；监测候选集覆盖率与相邻控制步的掩码周转率；比较均值替换、遮挡、删除以及有限差分标签；在固定平均算力下评估“阶段自适应预算 + POKE”能否改善 $\pi_{0.5}$ 的 LIBERO-Long 结果。
实验设置
  • 基准：LIBERO Spatial、Object、Goal、Long 四个套件；每套件、每种方法评测 500 个 episode，不同方法使用匹配的初始状态。
  • 策略：OpenVLA-OFT 为并行回归模型，使用各套件独立检查点；$\pi_{0.5}$ 为 flow-matching 模型，四套件共用一个检查点。
  • 输入：两路相机，共 512 个视觉 token；总保留预算为 $B\in\{128,64,32\}$，并在两台相机之间平均分配。
  • 控制协议：每个控制步对新的相机帧调用一次策略，属于闭环 episode 评测；给定片段未披露具体仿真器版本、机器人形态和相机分辨率。
  • 教师标签：在策略微调示范中的观测上离线生成；策略保持冻结，每个观测使用一个共享随机动作方向。$\pi_{0.5}$ 标签固定一份初始噪声，并对完成积分后的最终动作块求导。
  • 标签开销：每个 LIBERO 套件的离线标注耗时少于 1 GPU 小时；给定片段未说明具体 GPU 型号。
  • 学生模型：两层 MLP，隐藏宽度 64；含输入投影后，OpenVLA-OFT 版本约 271K 参数，$\pi_{0.5}$ 版本约 140K 参数。
  • 训练目标：相机内对教师分数做对数变换与标准化，使用 KL 散度、回归损失和成对排序损失；给定片段未披露各损失权重、优化器、学习率和训练轮数。
  • 选择器：每个相机保留 $b=B/C$ 个 token；MMDP 从得分最高的至多 $2b$ 个候选中执行 max–min 多样性选择，选择成本为每相机 $O(b^2d)$，并计入报告延迟。
  • 预算迁移：表中所有预算均复用 POKE 的 $B=32$ 检查点，未针对 64 或 128 token 单独训练。
  • 在线完整图和剪枝图 Probe 仅作为诊断项；$\pi_{0.5}$ 的诊断反向传播运行于 eager mode，其速度相对 eager Vanilla 计算，不能直接与正常部署的 POKE 加速数字等同。
AI导读和推荐理由
  • 推荐这篇的核心原因不是又提出一个注意力剪枝规则，而是把 token 重要性明确落到“对最终机器人动作的影响”，并通过完整图离线教师规避闭环剪枝中容易被忽略的历史掩码偏置。
  • 它同时覆盖并行回归和 flow-matching VLA，说明外挂式动作敏感度蒸馏不依赖单一动作头形式；32/512 token 下仍能在 OpenVLA-OFT 与 $\pi_{0.5}$ 上分别保持 95.15% 和 90.80% 成功率。

与π系列的关系

  • 本文直接在 $\pi_{0.5}$ 上验证 POKE。对 flow-matching 策略，教师固定初始噪声，穿过完整 Euler 积分过程对最终动作块反向传播，因此监督信号包含视觉前缀对中间动作状态和最终动作的累积影响。
  • POKE 没有修改 $\pi_{0.5}$ 的骨干网络、flow-matching 目标或动作生成器，也不是对 $\pi_{0.5}$ 进行重新微调；它只在 Transformer 前端增加一个离线训练的评分器，并在指定层删除未选视觉 token。
  • 给定原文没有报告 $\pi_0$、$\pi_0$-FAST 或 OpenPI 的直接实验，也没有证明同一学生检查点可以跨这些变体迁移。其方法原则上只要求取得 projector token、语言/状态表示和最终动作梯度，但具体接口、切层位置与时延收益仍需分别验证。
  • $\pi_{0.5}$ 对激进剪枝明显比 OpenVLA-OFT 更敏感：32-token POKE-MMDP 为 90.80%，且 LIBERO-Long 降至 76.4%。这提示 flow-based 动作专家可能更依赖完整视觉上下文，不能直接沿用并行回归模型上的预算结论。

对Austin研究的启发

  • 在 OpenPI 执行器中把 token 选择器设计成独立接口：输入 projector token、语言 embedding、本体状态、相机与二维坐标，输出每相机固定预算的索引；保持策略参数和动作采样逻辑不变，以便单独替换 top-$k$、MMDP 或动态预算模块。
  • 增加闭环监控指标，而不只记录最终成功率：每步统计掩码周转率、旧掩码外分数占比、候选集空间覆盖率，以及关键目标区域是否重新进入掩码。随机前置掩码后仍大量重选旧 token，可作为评分图锁定的单元测试。
  • 对需要遵循引导场 $G$ 的任务，可把教师目标扩展为“最终动作敏感度 + 条件遵循敏感度”：分别测量 token 对动作块以及对 $G$ 约束误差的影响，再检查纯动作标签是否会删除用于约束验证、但对当前瞬时动作影响较小的视觉证据。
  • 在 $\pi_{0.5}$/OpenPI 上优先做预算曲线而非只测 32-token 极限：比较 128、64、32 token，并在接触、目标切换和长时序恢复阶段动态增大预算；重点验证这能否修复 LIBERO-Long 的退化，同时保持平均延迟优势。
  • 建议加入三组严格消融：完整图敏感度教师对注意力教师、无历史学生对带历史掩码学生、top-$k$ 对高分候选内多样性选择；同时固定初始状态与动作噪声，避免把采样差异误认为剪枝效果。

一句话总结

POKE 由韩国高丽大学团队提出，以完整图动作敏感度离线蒸馏出不足 0.3M 参数的外挂评分器，在仅保留 32/512 个视觉 token 时实现 OpenVLA-OFT 95.15%/1.85×、$\pi_{0.5}$ 90.80%/1.26× 的成功率与加速组合。
