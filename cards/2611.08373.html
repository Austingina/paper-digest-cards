深读｜SLA

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 现有 VLA 多继承二维图文预训练的视觉表征，机器人动作学习虽能建立语义到控制的映射，却缺少对深度、相对位置和三维结构的直接约束，因而在精细空间操作中可靠性不足。
  • 在下游阶段额外输入深度图或点云会受到噪声、缺失、相机标定和机器人传感器异构性的限制；大量公开机器人数据又没有深度信息，难以直接扩展到大规模预训练。
  • Spatial Forcing 等训练时表征对齐方法主要用于任务级后训练，使空间能力仍是下游附加项，而非可迁移的基础模型能力。
  • 本文同时覆盖仿真与真机：从预训练的 π0.5 初始化，在持续预训练和下游后训练中更新策略；OmniVGGT 教师保持冻结，训练辅助模块部署时全部移除，推理架构及计算路径与原 π0.5 相同。论文节选未明确将执行协议归类为开环或闭环。
  • 作者的目标是利用异构机器人经验扩展可迁移的三维空间表征，在不增加部署传感器与推理开销的前提下，提高跨场景、跨具身和低数据下游适应能力。

方法

  • 异构数据统一：将不同机器人本体与任务轨迹统一为多视角图像 $\mathcal V$、语言指令 $\mathcal L$ 和动作序列 $A_{gt}$；图像经 DINOv2/SigLIP 编码为视觉 token $\{\bm x_i^\mathcal V\}_{i=1}^N$，文本被离散为 $\{\bm x_j^\mathcal L\}_{j=1}^M$。
  • 二维 VLA 主干：以预训练 $\pi_{0.5}$ 为初始化，视觉与语言 token 进入因果注意力层，形成中间视觉嵌入 $\bm h^\mathcal V$；保留原有 backbone 与 action expert，避免破坏既有视觉—语言—动作生成能力。
  • 冻结三维监督：训练时由冻结的 3D 表征模型从对应场景提取空间特征 $\bm f^{3D}$，并将 $\bm h^\mathcal V$ 与 $\bm f^{3D}$ 对齐；梯度仅更新 VLA 分支，使二维视觉 token 注入几何、深度和空间关系知识，而三维教师保持不变。
  • 动作生成与持续预训练：action expert 在视觉、语言及历史动作条件下预测 $\bm x_t^\mathcal A\!\sim\!p_\theta(\bm x_t^\mathcal A\mid\mathcal V,\mathcal L,\bm x_{<t}^\mathcal A)$，联合动作损失 $\mathcal L_{\mathrm{action}}$ 与三维对齐目标优化；推理时移除冻结教师，直接输出机器人动作。

\method{} unifies heterogeneous robot data, aligns intermediate visual embeddings with frozen 3D features during training, and improves benchmark and real-world manipulation performance.
  • 整体流程为：多视角机器人图像与指令进入 π0.5；同一组图像及可用的深度、相机参数送入冻结的 OmniVGGT，产生像素级空间表征；VLA 中间视觉 token 经自适应多层聚合与投影后对齐教师特征，同时由原动作专家预测连续动作块。
  • 空间目标取自 OmniVGGT 最后一层特征，并加入位置编码；随后通过双线性重采样匹配 VLA 视觉 token 的空间分辨率，使每个 token 与同视角、同图像位置的教师表征对应。
  • 对多个 VLA 注意力层的视觉 token 共享一套 LayerNorm 和两层 MLP 投影器，再由依赖当前特征的 token 级、通道级门控进行加权聚合，避免为所有机器人、场景和视觉域固定选择同一中间层。
  • 训练目标为动作损失与空间对齐损失之和：空间项使用逐 token 的余弦距离，梯度更新 VLA、投影器和聚合门控，但不更新 OmniVGGT。
  • 作者将不同机器人数据的状态与动作统一为一致的末端执行器表示和坐标约定，并在持续预训练后继续于下游后训练阶段保留空间对齐，以防空间能力在任务适配时被削弱。
  • 概率状态丢弃会随机移除部分本体状态信息，降低策略对示范轨迹状态模式的过拟合，促使其更多依赖视觉线索。
  • 相对 π0.5，SLA 改变的是训练监督和数据处理，而不是动作生成接口：仍沿用 π0.5 的 flow-matching 动作专家及推理架构；OmniVGGT、投影器和门控只在训练时存在。

实验与结果

  • 在 LIBERO-Plus 的观察、语言和场景扰动下，SLA 总成功率为 87.4%，论文报告其超过所比较的基线；所给节选未列出各基线的逐项数字。
  • 在 RoboTwin 2.0 中，仅使用 clean demonstrations 训练后，Clean2Random 成功率为 72.3%；Clean2Clean 与 Clean2Random 的平均成功率为 79.2%，表明策略能够泛化到训练条件之外。
  • 在 RoboCasa-Panda 上，每个下游任务只使用 50 条示范，成功率达到 68.4%；论文称其超过每任务使用 300–3,000 条示范训练的对比策略，但节选未披露这些策略的名称和具体成绩。
  • 在真实机器人基准 RoboDojo-Real 上，跨三种具身训练的单一策略总体成功率为 33.9%，而本文复现或采用的 π0.5 对照为 12.8%，绝对提升 21.1 个百分点。
  • 在八种真实部署条件中，SLA 平均成功率为 83.8%，比 π0.5 高 24.0 个百分点，即 π0.5 对照平均为 59.8%；论文称 SLA 在每一种条件下均为所比较方法中的最高成绩。
  • 受控数据缩放实验显示，在全部已测试数据比例上，“持续预训练和下游后训练均进行空间对齐”始终优于只在其中一个阶段对齐；节选未给出各比例、样本量及对应绝对成功率。

局限与可以继续做的

  • 论文证明了训练时利用冻结三维教师的收益，但当前证据不能区分提升有多少来自空间对齐、异构数据持续预训练、状态丢弃或三者交互；需要在相同数据与训练预算下报告完整的逐组件消融。
  • OmniVGGT 虽不参与部署，持续预训练和后训练仍需额外教师前向、跨层特征缓存及对齐计算。所给节选没有报告训练 FLOPs、显存、吞吐或相对 π0.5 的训练成本，因而“可扩展”主要由数据覆盖与结果支持，尚缺系统效率证据。
  • 八种真实部署条件展示了较强结果，但节选未披露每项试验次数、置信区间、失败类型和机器人具体配置；83.8% 均值的统计稳定性及跨实验室复现性仍无法核对。
  • 可在固定 π0.5 检查点上做四组等预算实验：仅增加数据、仅持续预训练对齐、仅后训练对齐、双阶段对齐，并分别测量深度 probing、空间扰动成功率和动作精度，以验证表征改善是否真正传递到控制。
  • 可测试教师质量与几何标注缺失的鲁棒性：系统改变深度噪声、外参误差、可用标定比例及纯 RGB 数据占比，同时记录门控选择和失败率，判断方法能否适应真实数据中的不完整几何监督。
  • 可进一步迁移到未见相机布局、移动操作平台和更长时序任务，并加入遮挡、动态物体及恢复行为评测；当前结果主要支持操作任务，不能直接外推到视觉导航、SLAM 或长时程自主执行。
实验设置
  • 基础策略：预训练 π0.5，动作专家通过 flow matching 生成连续动作块。
  • 参数更新：持续预训练及下游后训练时更新 VLA；冻结外部三维感知模型 OmniVGGT。
  • 训练辅助模块：共享 LayerNorm、两层 MLP 投影器、特征依赖的多层聚合门控；这些模块均不用于部署。
  • 输入：VLA 使用多视角机器人图像、语言指令及可用状态；OmniVGGT 使用 RGB，并可利用部分数据中存在的深度图和相机参数。
  • 损失：动作预测损失加权结合逐视觉 token 的余弦空间对齐损失；权重记为 α，但所给节选未披露具体取值。
  • 数据处理：异构公共机器人数据覆盖不同具身、任务、场景和视觉外观；状态与动作被统一为一致的末端执行器表示和坐标约定。节选未给出数据集清单、轨迹总量及混采比例。
  • 仿真评测：LIBERO-Plus、RoboTwin 2.0、RoboCasa-Panda；其中 RoboTwin 使用 clean demonstrations 训练并评测 Clean2Clean 与 Clean2Random，RoboCasa-Panda 每任务使用 50 条下游示范。
  • 公开真机评测：RoboDojo-Real，使用一个跨三种具身适配的策略；节选未列出三种机器人型号。
  • 额外真机评测：八种部署条件，涉及双臂协作、空间与动态泛化、少样本跨具身适配和指令遵循。
  • 所给节选未披露优化器、学习率、batch size、训练步数、硬件、状态丢弃概率、门控层集合、动作块长度、每项评测 episode 数及随机种子。
AI导读和推荐理由
  • 这篇论文与 π 系列最直接的关联不是重新设计动作生成器，而是展示如何把 π0.5 当作可继续训练的基础策略，通过训练期三维教师监督获得空间能力，并保持部署接口不变。
  • 它同时给出了大规模持续预训练、低数据下游适配和真实部署结果，适合关注“如何在不改执行栈的情况下增强 OpenPI/π 系列空间表征”的研究者阅读。

与π系列的关系

  • SLA 直接从预训练 π0.5 权重初始化，保留其 VLA 骨干、flow-matching 动作专家和推理架构；训练过程中并未冻结整个 π0.5，而是让空间对齐损失反向更新 VLA。
  • 本文不是 π0、π0-FAST、π0.5 或 OpenPI 的官方新版本，而是在 π0.5 基础上进行空间能力持续预训练与下游后训练的研究扩展。
  • 它相对 π0.5 新增的是训练期 OmniVGGT 教师、多层特征门控聚合、空间对齐投影器、概率状态丢弃及异构机器人数据统一流程；部署时不新增深度输入、三维模型或额外动作头。
  • 论文相关工作提及 π0，但所给原文没有报告 SLA 基于 π0 或 π0-FAST 的实现，也没有给出与 π0-FAST 的直接实验对比。
  • 所给内容没有说明其代码是否基于 OpenPI，也未证明可直接加载 OpenPI 的所有 π 检查点；可合理关注接口兼容性，但不能据此断言存在直接技术依赖。

对Austin研究的启发

  • 若 Austin 使用 OpenPI 执行器，可先保持 observation schema、action chunk、flow-matching sampler 和部署循环不变，只在训练图中暴露若干视觉层，并外挂“冻结空间教师—共享投影器—门控聚合—余弦对齐”分支；导出检查点时删除全部辅助模块，验证原执行器能否无改动加载。
  • 将引导场 \(G\) 或任务相关几何场作为训练监督时，应同时检查“表征对齐”与“条件遵循”：除最终成功率外，记录视觉 token 与 \(G\) 的一致性、末端到目标的空间误差、遮挡后的恢复率，以及语言条件改变时轨迹是否同步改变。
  • 建议把闭环评测拆成空间扰动、相机扰动、状态缺失和动态物体四类，并与原始 π0.5 做成对等数据、训练步数和推理预算的配对实验；这能避免把异构数据扩充带来的收益误判为空间对齐收益。
  • 可加入训练期监控：分层门控权重与熵、各视角对齐损失、动作损失、状态丢弃前后性能差，以及不同机器人域的梯度规模。若门控长期塌缩到单层或单视角，应尝试门控正则、按域归一化或均衡采样。
  • 由于“Austin研究”在所给材料中没有进一步定义，上述建议仅针对 π/OpenPI 式 VLA 执行与空间引导接口，不能断言本文与 Austin 的具体项目、作者或机构存在直接关系。

一句话总结

SLA 由香港科技大学（广州）、OLA Dimensions、北京智源人工智能研究院和清华大学作者提出，通过在 π0.5 的持续预训练与下游后训练中加入仅训练期使用的 OmniVGGT 空间对齐，在八种真实部署条件下达到 83.8% 平均成功率并较 π0.5 提升 24.0 个百分点。
