深读｜UMI-Live for In-The-Wild Bimanual Robotics Data Collection

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 机器人模仿学习依赖带动作标签的示教；纯视频即使可用于世界—动作模型预训练，也不能替代机器人动作监督。
  • 传统遥操作必须把机器人、控制与安全设施部署到采集现场，扩展到新环境的运输和维护成本高；已有手持 UMI 系统又可能依赖固定跟踪装置、背包计算机、现场标定或繁琐的离线处理。
  • 双臂野外采集还面临跨设备时钟同步、两只夹爪轨迹重建、开合状态估计以及数据格式转换等问题；若逐段人工处理，会直接阻塞连续采集。
  • 本文面向真实世界双臂示教和真机策略评测：从公开检查点微调 π0.5 与 MolmoAct2，并在双 i2RT YAM 机械臂上执行自主动作块；π0.5 更新全部参数，MolmoAct2 仅训练部分模块。原文未披露动作块执行期间的重规划频率，不能进一步断言其具体开环或闭环调度方式。
  • 作者目标是建立一套无需外部跟踪设备或现场标定、可边采边处理并直接接入 LeRobot/VLA 训练与实体部署的可复现双臂数据系统。

Components used to assemble a \systemname{} gripper, including the LiDAR, camera, Raspberry Pi, LCD, printed parts, linear guide, gears, fasteners, and battery and power electronics.
  • 整体流水线为：两只手持夹爪同步记录腕部图像、LiDAR 和 IMU → 数据异步传至服务器 → 并行完成 SLAM、夹爪开度估计和时间对齐 → 验证并发布为 LeRobot 数据集 → 与机器人遥操作数据混合，用于 VLA 微调和双臂真机执行。
  • 每只夹爪将相机、LiDAR–IMU、Raspberry Pi 计算与存储、可拆卸电池、按键和 LCD 集成在本体上；操作者用一个按钮同时控制左右设备，无需机器人、三脚架相机或外部定位系统。
  • 服务器分别对左右设备运行 GLIM，通过固定的传感器到工具中心点变换得到 TCP 轨迹；夹爪开度由安装在活动指座上的两枚 ArUco 标签估计，缺失检测在相邻有效测量间插值。
  • 以主设备相机时间线对齐双手数据：位置线性插值、旋转采用四元数球面插值，从设备视频取不晚于目标时刻的最近帧；每只手用相对该 episode 初始位姿的 6D TCP 状态和归一化开度表示，合并为 14 维双臂状态。
  • 处理系统按依赖图并行调度不同手和不同 episode 的 LiDAR 解码、SLAM 与开度估计；数据写入串行化，并记录各阶段完成状态，使中断后可从已有中间结果恢复。
  • 策略接口统一使用左右腕部图像、当前夹爪开度和语言指令作为输入，输出查询时刻相对的双臂 TCP 动作块及绝对夹爪开度；本文没有修改 π0.5 的核心架构，而是通过共同的数据与动作接口完成微调和部署。

实验与结果

  • 在“双臂将 6 个橙子全部放入碗中”任务上，π0.5 使用 95% UMI / 5% 机器人遥操作混合数据微调后成功 9/10；把遥操作比例提高到 10% 后达到 10/10。
  • MolmoAct2 使用 75% UMI / 25% 遥操作数据微调后成功 8/10；其公开 MolmoAct2-BimanualYAM 检查点在同一评测中为 0/10，绝对提高 8 次成功，即成功率由 0% 提升至 80%。
  • 成功标准严格要求 6 个橙子全部进入碗中；评测允许重新抓取以及捡回掉落的橙子，因此结果同时覆盖一定程度的失败恢复，而非只统计首次抓取。
  • UMI 示教采自与机器人评测不同的地点和光照条件；少量目标场景遥操作数据补充了真实机器人外观和运动分布。结果支持“以 UMI 数据为主、以目标机器人数据作适配”的训练方案，但没有纯 UMI、纯遥操作或等规模数据对照。
  • 论文另发布约 40 小时、覆盖 3 项操作任务的数据；策略实体评测则只报告其中橙子入碗任务，不能把 9/10、10/10 和 8/10 外推为三项任务的统一表现。

局限与可以继续做的

  • 所给正文未包含独立的局限性章节；从实验设计看，实体策略验证仅涉及一种双臂取放任务、一套 dual-YAM 平台和每个条件 10 次试验，跨任务、跨机器人与长时序操作的泛化证据不足。
  • 每个训练条件只使用一个随机种子并评测最终检查点，未报告训练方差、置信区间或检查点选择敏感性；π0.5 也没有对应的未微调公开检查点结果。
  • 所有有效微调条件都混入了目标场景机器人遥操作数据，且未提供纯 UMI、纯遥操作及相同示教数量下的对照，因此无法独立量化 UMI-Live 数据和目标域适配数据各自的贡献。
  • 系统会剔除同步证据不合格或估计跨设备偏移超过 5 ms 的 episode，但正文未给出被剔除比例、SLAM 轨迹误差或夹爪开度估计误差，数据质量机制存在但定量证据仍不完整。
  • 可继续做的实验包括：加入纯 UMI、纯遥操作和不同比例混合的等预算曲线；在 OpenPI 中固定模型与训练步数，只替换数据来源；报告跨场景、遮挡、SLAM 退化和同步异常下的成功率，并把轨迹置信度、时间偏移和标签缺失率作为训练采样权重或在线监控信号。
实验设置
  • 平台：两台 i2RT YAM 机械臂组成双臂系统，安装与 UMI-Live 对应的夹爪手指。
  • 任务：从随机化位置抓取桌面上的 6 个橙子并放入碗中；机器人初始构型固定，橙子和碗的位置随机。
  • 成功标准：6 个橙子全部进入碗中；允许重新抓取及恢复掉落物体；每个条件评测 10 次。
  • 任务训练池：296 条 UMI 示教和 75 条机器人遥操作示教；完整公开数据约 40 小时、覆盖 3 项任务。
  • π0.5 条件：分别采用 95%/5% 和 90%/10% 的 UMI/遥操作混合比例；每次从公开基础检查点独立初始化，更新全部参数。
  • MolmoAct2 条件：采用 75%/25% 的 UMI/遥操作比例；从 MolmoAct2-BimanualYAM 检查点初始化，训练视觉—语言骨干中的 LoRA 适配器和完整 action expert，其余骨干参数冻结。
  • 所有微调条件均训练 12,000 次更新，全局 batch size 为 32；每个条件一个训练种子，并评测最终检查点。
  • 策略观测：两路超广角腕部相机图像、当前左右夹爪开度和任务指令；不输入 TCP 位姿或关节角。
  • 策略输出：查询时刻相对的双臂 TCP 位姿动作块与绝对夹爪开度；远程策略服务器返回动作块，本地 dual-YAM 客户端转换为关节和夹爪命令。
  • 单只采集器传感与计算：RoboSense Airy LiDAR及其集成 IMU、SVPRO AR0234 全局快门鱼眼 USB 相机、Raspberry Pi 5；相机分辨率为 800×600、30 fps。
  • 单只采集器含电池质量 1.42 kg，夹爪宽 80 mm，单次续航约 1.5 小时；一对硬件成本约 1,930 美元。
  • 同步与质检：Chrony 同步两台 Raspberry Pi，gPTP 同步 Airy 与对应 Pi；估计跨设备偏移超过 5 ms 或同步证据不可接受的 episode 被排除。
  • 数据格式：最终 episode 经过流完整性、同步、位姿、开度、帧数和一致性检查后写入 LeRobot 格式，并可同步至 Hugging Face；云端发布失败时保留本地数据。
AI导读和推荐理由
  • 推荐这篇的原因不是它提出了新的 VLA，而是它补齐了 π0.5 从野外双臂示教采集、自动重建、LeRobot 数据发布到真机执行的工程链路。
  • 论文尤其适合关注“数据接口是否能真正服务实体 VLA”的研究者：结果显示，异地异光照的手持示教配合少量目标机器人数据，可以支持两个不同 VLA 家族完成实体双臂任务。

与π系列的关系

  • 本文直接使用 π0.5 作为下游策略，从其公开基础检查点微调全部参数；它不是 π0、π0-FAST、π0.5 或 OpenPI 的新模型变体，也没有改变 π0.5 的骨干、损失或动作专家结构。
  • 论文正文提到 π0，但未报告以 π0 或 π0-FAST 为基线的实验；所给原文也未显示对 OpenPI 核心代码或架构的修改，不能把该系统表述为 OpenPI 扩展方法。
  • 与 π 系列最直接的连接是数据和执行接口：双腕图像、夹爪开度与语言指令进入策略，统一的查询相对 TCP 动作块再由 dual-YAM 客户端执行。这证明 UMI-Live 数据能够进入 π0.5/LeRobot 类训练流程，但尚未验证同一接口对其他 π 变体的效果。
  • π0.5 的 95%/5% 与 90%/10% 结果提示，少量目标机器人示教可能承担 embodiment 与场景适配作用；由于没有纯 UMI 和纯遥操作对照，这仍是待验证解释，而非论文已经隔离出的因果结论。

对Austin研究的启发

  • 可在 OpenPI 执行器前增加一个明确的“UMI 查询相对动作 → 机器人 TCP/关节命令”适配层，使数据表示、策略输出和机器人运动学解耦；先复现左右手独立初始坐标系与绝对夹爪开度，再比较是否需要统一世界坐标系。
  • 建议做 UMI/目标机器人数据比例扫描，并固定模型、训练更新数与 batch size；至少加入 100/0、95/5、90/10、75/25 和 0/100 条件，才能判断少量 embodiment 数据是否确实形成明显收益拐点。
  • 若研究引导场 \(G\) 的条件遵循，可把同步偏移、SLAM 置信度、ArUco 缺失率和动作可达性编码为额外条件或训练权重，检验策略是否会降低对低质量轨迹段的依赖。
  • 闭环评测除最终成功率外，应记录每次重抓、掉落恢复、动作块执行时长、重规划频率、TCP 不可达率和安全裁剪次数；这能区分“策略理解任务”与“执行器替策略纠错”。
  • Austin 与本文作者或机构之间不存在由所给原文支持的直接合作关系；可借鉴的是其采集—处理—训练—部署接口，而非宣称已有项目归属或共同成果。

一句话总结

  • 来自 Yale、Carnegie Mellon、AfterQuery、宾夕法尼亚大学和哈佛大学作者团队的 UMI-Live 以约 1,930 美元的自包含双夹爪系统打通野外采集到 LeRobot/VLA 真机部署，并使微调后的 π0.5 与 MolmoAct2 在双臂六橙入碗任务上分别达到最高 10/10 和 8/10。
