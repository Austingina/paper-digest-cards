深读｜What Can a VLA Learn from the Agent That Calls It? Task-Level Experience Distillation for Embodied Navigation

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 现有具身导航智能体常由前沿 LLM 规划器维护地点图、拆分子任务并反复调用 VLA；在本文测试中，完整智能体每回合 LLM token 中位数约为 70k，耗时超过 VLA 单独运行的两倍。
  • 智能体的成功会话不能直接当作普通 VLA 示范：只有 53.9% 的标注动作来自 VLA 执行原始指令，20.5% 来自规划器子指令下的 VLA 动作，24.6% 来自规划器工具；同时 23.3% 的步骤会远离目标。
  • 论文研究 Habitat/MP3D 上的 REVERIE-CE 连续导航。部署时是闭环策略：8B NavGPT 每次读取最近 16 帧四视角 RGB，预测 8 个航点，只执行第一个后重新推理；测试阶段不再调用 LLM。
  • 作者的目标是把 LLM 智能体成功会话中的任务级经验蒸馏进 VLA，在不增加测试时模块和 LLM 成本的前提下，提高未见场景中的导航成功率与停止准确性。

方法

  • 阶段(a)：成功轨迹采集：在训练场景中，前沿 LLM Planner 结合 Place Graph、完整历史等额外信息 $z_t$，调用基础 VLA $\pi$ 或自身工具移动；记录会话 $\tau=\{(p_t,o_t,\ell_t,c_t)\}_{t=0}^{T}$，仅保留到达目标 $g$ 的轨迹。
  • 阶段(b)-①：统一航点标注：对每个状态输入原始指令 $\ell$，无论该步由 VLA 还是 Planner Tool 产生，均以之后 $K=8$ 个位姿构造机器人坐标系标签 $y_t\in\mathbb{R}^{8\times3}$，每个航点包含平面偏移与朝向。
  • 阶段(b)-②：损失掩码与停止监督：若移动使测地距离 $d(p_t)$增大，该步以虚线表示并从损失中屏蔽，但仍保留在16帧历史 $h_t=(o_{t-15:t},\ell)$ 中；距目标1 m内的已访问状态标为全零停止序列。
  • 阶段(c)：VLA适配与独立推理：冻结 Vision Encoder 与 LLM，仅训练 LoRA Adapters 和 Waypoint Head，以 masked $L_1$ 回归 $\hat y_t=\pi(h_t)$；测试时移除 Planner 与 Place Graph，VLA循环执行首航点，连续两次输出全零即停止。

Overview of \method. (a)~On training scenes, a frontier LLM planner with a place graph and its own tools calls the base VLA. We keep the sessions that reach the goal. (b)~\method turns one kept session into labels. \ding{172}~Every step is labelled with the next 8 poses under the original instruction, whether the VLA or a planner tool moved. \ding{173}~Steps that move away from the goal are drawn dashed. They leave the loss but stay in the history. \ding{174}~Visited states within 1\,m of the goal are labelled as stops. (c)~The VLA keeps its vision encoder and LLM frozen. It trains LoRA adapters and the waypoint head with the masked $L_1$ loss and runs alone at test time.
  • 整体流程为：在训练场景运行“前沿 LLM 规划器 + 8B NavGPT VLA”智能体，只保留到达目标的成功会话；H2E 将整段会话重新标注为 VLA 数据；随后以 LoRA 和全量动作头训练 VLA，测试时仅部署更新后的 VLA。
  • 任务级重标注：无论一步动作原本由 VLA、规划器子指令还是规划器工具产生，都统一置于原始任务指令下，并把后续 8 个访问位姿转换成当前机器人坐标系中的航点目标。训练标签不再依赖动作来源或当时的子指令。
  • 进度屏蔽：若第 \(t+8\) 个位置相对当前点远离目标超过 0.25 m，则该步目标不参与损失；原始观测仍保留在历史中。原地转向以及窗口内进入停止区域的样本不会被屏蔽。
  • 停止重标注：所有距目标不超过 1 m 的访问状态均标为全零航点，包括策略曾经穿过目标附近却没有停止的状态；部署时连续两次输出全零即停止。
  • 使用带 mask 的 \(L_1\) 航点回归损失。作者指出，当给定历史下零目标的概率超过一半时，条件坐标中位数唯一为零，因此 \(L_1\) 配合密集停止标签可以直接学习精确零输出；平方损失通常会得到非零均值。
  • 相比基础 NavGPT，视觉编码器和 LLM 主体权重保持冻结，仅训练语言模型注意力/MLP 中的 LoRA 适配器以及完整动作头；没有新增测试时地图、审查器、停止头或 LLM harness。

实验与结果

  • 在 REVERIE-CE val-unseen 全部 3,189 个回合上，基础 8B NavGPT 的 SR/SPL/NE 为 35.0%/26.5/8.53 m；H2E 达到 44.9%/38.4/6.90 m，即 SR 提高 9.9 个百分点、SPL 提高 11.9 个百分点、NE 降低约 1.6 m。
  • H2E 的 OSR 为 50.1%，低于基础模型的 52.0%，但 SR 明显更高。这说明主要收益不只是“曾经走进过成功区域”，还来自把到达转化为正确停止；论文同时报告 H2E 能找到部分基础 VLA 从未到达的目标。
  • 使用相同场景、LoRA 配方和更新次数的受控比较中，仅加入 504 条智能体会话，H2E 已达到 43.2% SR；只使用 DART 与 R2R-CE 的 geodesic adaptation 为 34.9%，与基础模型 35.0% 基本相同。对应 SPL 分别为 38.2%、33.2% 和 26.5%。
  • H2E 在 10 个未见场景中的 9 个提高 SR。按起点到目标的测地距离分组后，它相对 geodesic adaptation 的优势从短距离组的 4.4 个百分点扩大到长距离组的 17.5 个百分点。
  • 在 3 个场景、861 个 val-unseen 回合的 LoRA 消融中，rank 16 的 H2E 为 45.6% SR，rank 64 仅为 33.2%；更大的适配器并未带来更好结果。
  • 与完整 LLM 智能体的比较使用额外 26 个场景中的 100 个回合。完整智能体为 53% SR、423 s/回合和 70k token/回合；论文称蒸馏 VLA 获得更高 SR、无需 LLM token，耗时约为完整智能体的四分之一，但所给正文在表 6 的 H2E 行之前截断，无法从当前原文核对其精确 SR 和时间数值。

局限与可以继续做的

  • 当前证据来自 Habitat/MP3D 中的 REVERIE-CE 仿真导航，传感输入为四视角 RGB；论文未给出真机、动态环境、传感噪声或机器人动力学变化下的验证，不能直接外推到真实移动机器人。
  • H2E 只保留成功会话，并在制备标签时使用目标测地距离进行进度屏蔽和 1 m 停止重标注。这些特权信息不在部署时使用，但训练数据生成依赖仿真器中的精确目标位置和可计算测地距离。
  • 训练教师是特定的 gpt-6-astra 前沿规划器，学生是 8B NavGPT；尚不清楚收益对规划器质量、VLA 架构、动作空间及不同语言模型是否稳定。本文也没有在 π0、π0-FAST、π0.5 或 OpenPI 上实验。
  • 完整智能体对比只有 100 个回合，而主要结果来自 3,189 个回合；且当前提供的原文截断了表 6 后半部分，因此“高于智能体且仅约四分之一耗时”的精确学生数值无法独立核对。
  • 可继续做的实验包括：纳入失败会话并分别标记纠错前后片段；用视觉可估计的进度或不确定性替代特权测地距离；跨多个规划器生成会话；在真机闭环中测量碰撞、停止误差、推理延迟和恢复能力。
  • 针对长程任务，可进一步按“首次进入 3 m 区域、进入 1 m 区域、正确停止、离开后恢复”拆分指标，以判断蒸馏究竟改善了探索、目标识别、局部控制还是停止决策。
实验设置
  • 仿真平台：Habitat；场景来源：Matterport3D；任务：REVERIE-CE 连续环境导航。
  • 训练会话：来自 57 个训练场景的 2,395 条成功会话，其中 1,538 条为首次 VLA 调用直接成功，857 条由规划器救援成功。
  • 会话数据共含 332,405 个标注步骤；其中 23.3% 被进度规则屏蔽。停止标签共 30,181 个。
  • 主评测：官方 val-unseen 全部 3,189 个回合、10 个训练数据未覆盖的场景；完整智能体比较另用 26 个场景中的 100 个回合。
  • 成功条件：策略停止时距目标不超过 3 m；每回合最多 500 步，并受官方评测脚本 2,400 s 时间限制。
  • 模型：8B NavGPT video VLA；输入最近 16 个时刻的四视角 RGB 与任务指令；每次预测 8 个机器人坐标系航点，执行第一个后重新查询。
  • 停止机制：模型没有独立 stop head；连续两次预测的所有航点均为零时停止。
  • 教师智能体：gpt-6-astra 前沿 LLM 规划器，维护地点图，可调用 VLA、下发子指令、直接移动、回溯及查看全景或地图。
  • 训练数据混合比例：智能体会话、DART、R2R-CE 分别为 0.60、0.25、0.15；DART 与 R2R-CE 数据也使用相同的 1 m 停止规则。
  • 进度 margin 为 0.25 m，停止标注半径为 1 m；成功判定半径为 3 m。
  • LoRA rank 为 16、scale \(\alpha=32\)，作用于语言模型的注意力与 MLP；视觉编码器冻结，LoRA 与动作头参与训练。
  • 每次更新 16 个样本；LoRA 学习率为 \(10^{-4}\)，动作头学习率为 \(2\times10^{-5}\)；预热 540 次更新，之后使用 cosine schedule，梯度裁剪范数为 1。
  • 共训练 9,000 次更新，约 28 小时；使用 4 张 NVIDIA L40、数据并行，并评测最终检查点。
  • 主表中的 geodesic adaptation 使用 DART + R2R 共 48k 样本，与 H2E 采用相同停止规则和 LoRA 设置。
AI导读和推荐理由
  • 推荐这篇的原因不只是“用 LLM 生成更多数据”，而是它把规划器工具动作、子指令动作和纠错轨迹统一投影回原始任务条件下的 VLA 动作学习问题，并明确处理了示范中的绕路与错误停止。
  • 论文展示了一条实用的系统压缩路线：先允许昂贵智能体在训练阶段借助地图、长历史和多次 LLM 调用完成任务，再将可迁移的闭环行为压回单一 VLA；在主评测上，9.9 个百分点的 SR 增益并非由普通测地专家微调复现。

与π系列的关系

  • 本文不基于 π0、π0-FAST、π0.5 或 OpenPI，也没有将这些模型作为实验基线；其学生模型是面向连续导航的 8B NavGPT，教师是带地点图和工具调用能力的 LLM 导航智能体。
  • 共同点在于都直接学习视觉、语言到动作的策略；但本文动作是 8 个二维位移加朝向的导航航点，依赖最近 16 帧历史，并以 \(L_1\) 回归和全零输出表达停止，与 π 系列常见的机械臂连续控制、动作分块或 flow matching 训练机制不同。
  • H2E 改的是训练数据接口和监督规则，而不是提出新的通用 VLA 骨干：视觉编码器与 LLM 主体保持冻结，训练 LoRA 和动作头；因此不能把本文结果解读为 π 系列模型能力或 OpenPI 实现的直接证据。
  • 对 π/OpenPI 更有价值的可迁移思想是“蒸馏调用者而非只蒸馏被调用模型”：将上层 agent 的工具动作、人工接管、恢复动作和子任务执行统一转换到原始长程任务条件下，再过滤明显破坏任务进度的片段。

对Austin研究的启发

  • 可在 OpenPI 执行器外增加统一的 experience schema，记录原始任务、局部子指令、动作来源、机器人观测历史、执行后状态、是否接管以及任务进度；训练时始终保留原始任务条件，而把动作来源作为分析字段而非必需输入。
  • 对引导场 \(G\) 可设计 H2E 式条件遵循实验：比较“只学习执行器自身动作”“加入规划器/安全控制器动作”“加入动作但屏蔽违反 \(G\) 的步骤”三种数据配方，分别报告任务成功、条件违反率和恢复成功率。
  • 将导航中的“1 m 内全部标零”迁移为操作任务的吸收状态标签：在满足夹持稳定、目标位姿容差或安全约束后，把后续动作统一标成 hold/stop，并比较 \(L_1\)、平方损失及离散终止头对稳定停止的影响。
  • 闭环评测不要只报最终成功率；应记录 oracle success 与 final success 的差距、首次进入目标区域后的离开率、接管次数、恢复时间、动作调用次数以及上层模型 token/延迟。本文基础模型 OSR 52.0% 而 SR 仅 35.0%，正说明“到过”与“正确结束”必须分开监控。
  • 建议先做一个小规模受控实验：固定 OpenPI 骨干、训练步数和基础数据，只增加同一批 agent 成功会话；再与几何专家、人工遥操作和失败恢复数据比较，以确认收益来自任务级经验而非单纯增加样本量。

一句话总结

H2E 将清华大学深圳国际研究生院作者团队的 LLM 导航智能体成功会话重标注并蒸馏进冻结骨干、LoRA 适配的 8B NavGPT，使其在 REVERIE-CE val-unseen 的 3,189 个回合上将 SR 从 35.0% 提升至 44.9%，测试时无需 LLM token。
