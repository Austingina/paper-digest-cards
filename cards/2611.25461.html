深读｜ActMem

问题

  • 长时程、部分可观测操作中，当前图像并不总能反映任务状态：物体被遮挡后的位置、已经完成的子目标、重复操作次数等，只能由交互历史推断。
  • 现有记忆增强 VLA 主要有两类缺口：MemoryVLA、MEM、MemER 等保留或检索历史观测，却把“历史意味着什么”的推理留给动作模块；SimpleMemVLA 等原生视频方法能推理历史，但历史与当前视觉共享上下文，长历史可能挤占执行动作所需的视觉细节。
  • 论文研究仿真与真机上的闭环、连续动作控制；策略以时间戳历史、当前腕部相机图像、语言指令和本体状态为输入，通过滚动时域反复规划，而非一次性开环完成整项任务。
  • 作者目标是把“依据历史决定现在该做什么”与“依据当前视觉决定具体怎么做”分离，在提高记忆任务成功率的同时，使长历史下的单次决策延迟仍适合在线控制。

方法

  • 历史输入（Timestamped History）：任务为“将饼干放入最上层抽屉，并将巧克力放入另一抽屉”。ActMem 将带时间戳的历史帧组织为 $\mathcal{H}_t=\{(o_{\tau_i},\tau_i)\}_{i=1}^{N_t}$，使视觉语言骨干能够从早期交互中恢复物体位置与任务进度。
  • 子任务推理（Subtask Generation）：在决策时刻 $t=61\,\mathrm{s}$，模型结合指令 $g$、历史 $\mathcal{H}_t$ 与当前观测 $o_t$，自回归生成子任务文本“close the middle drawer”；生成过程的隐藏状态构成 Latent Memory CoT，为后续动作预测保留历史条件化经验。
  • 历史注意力（Attention over Historical Frames）：绿色区域表示子任务 token 对历史 token 的因果注意力，即对注意力 logits 施加 causal softmax；图中权重进一步在全部子任务 token、注意力头及骨干网络第 $3,7,\ldots,31$ 层上取平均，并映射回各历史帧。
  • 记忆定位与动作依据：星标的 $33\,\mathrm{s}$ 帧包含任务相关事件，但该信息在 $61\,\mathrm{s}$ 的当前视野中已不可见。其高注意力表明 ActMem 能从长时历史中定位关键证据，并据此确定当前应关闭中层抽屉，最终条件化连续动作块 $A_t=(a_{t+1},\ldots,a_{t+H})$。

Attention over historical frames. History frames of the RoboMemArena task Put cookies into the top drawer and put chocolate into another drawer, overlaid with ActMem's attention (green) at 61\,s (predicted subtask: ``close the middle drawer''). Attention is the causal softmax from the generated subtask tokens to the history tokens, averaged over subtask tokens, heads, and backbone layers 3, 7, \ldots, 31. The starred frame (33\,s) contains the task-relevant event, no longer visible at the decision step.
  • 整体流程为：Qwen3-VL 读取带时间戳的前视相机历史、当前腕部相机图像和语言指令，生成当前子任务；子任务 token 的隐藏状态形成 Latent Memory CoT，当前视图 token 形成感知特征；二者与本体状态共同条件化流匹配动作专家，输出连续动作块。
  • Latent Memory CoT 不把完整历史 token 直接交给动作专家，也不只传递解码后的子任务文本，而是保留子任务生成位置的末层隐藏状态、token embedding 与 M-RoPE 位置信息。由于这些 token 位于历史和当前输入之后，其隐藏状态包含对完整上下文的推理结果。
  • Perception Attention 为动作专家提供独立的当前视觉通路：DiT 中间动作表示以当前视图的上下文化视觉 token 为键和值做交叉注意力，再通过零初始化的可学习门控残差注入，从而避免动作执行细节只能经由压缩后的子任务表示传递。
  • 训练联合优化视觉语言骨干与流匹配动作专家，并组合两项损失：对子任务标注的自回归交叉熵，以及对连续动作块的条件流匹配损失。原文没有采用“冻结 VLM、只训练外挂模块”的设定。
  • 部署采用闭环滚动规划：生成动作块后只执行前一部分动作，获取新观测、更新历史，再重新推断子任务和动作。
  • Efficient Memory CoT Inference 缓存两帧历史块的视觉特征及未变化历史前缀的 KV；同时把上一时刻子任务作为 draft，在一次并行前向中验证。若全部匹配则无需逐 token 解码，否则从首次不匹配处恢复贪心解码。作者称该机制在数值精度范围内不改变标准推理输出。

实验与结果

  • 在 RoboMemArena 上，ActMem 的任务成功率为 71.1%，完成成功率为 80.8%；相对该实验中最强基线分别提高 7.5 和 8.7 个百分点。给定原文节选未列出这两个指标对应的最强基线名称及逐任务结果。
  • 在 MIKASA-Robo 上，ActMem 的平均成功率为 73.8%，在论文比较的方法中最高；节选未提供各基线的具体平均值、方差或逐任务成功率。
  • 真机四项任务覆盖外源记忆、内源记忆和无痕记忆，ActMem 平均成功率为 68.8%，比最强记忆增强 VLA 高 10.0 个百分点。图中列出的真机对照包括 MemoryVLA、MEM-π0.5 和 SimpleMemVLA，但节选没有明确说明“最强基线”具体是哪一个。
  • 真机任务包括 Cup-and-Block、Tissue Counting、Cabinet Search 和 Scissor Retrieval，每项评测 40 次；这些任务分别考查遮挡后状态、重复次数、搜索进度等无法仅由当前图像恢复的信息。
  • Efficient Memory CoT Inference 使长历史条件下的单次决策延迟保持在 0.6 秒以内。节选仅给出该上界结论，未提供硬件、历史长度曲线、标准推理延迟或加速倍数，因此不能据此比较跨平台吞吐量。

局限与可以继续做的

  • 证据范围仍有限：仿真只报告 RoboMemArena 与 MIKASA-Robo，真机只有四类任务；尚不足以证明方法能外推到更长任务、更强环境变化、移动操作或双臂系统。
  • 论文联合优化 Qwen3-VL 与动作专家，性能提升无法直接等同于“任意冻结 VLA 都可获得的即插即用增益”。可以增加冻结骨干、仅训练 Memory CoT/Perception Attention，以及相同训练预算下的对照。
  • Latent Memory CoT 依赖生成出的子任务。若早期历史被误解、计数错误或 draft 被错误延续，动作专家可能持续接收错误的任务阶段条件；应报告子任务切换准确率、错误持续时长，以及强制重新解码能否恢复。
  • 当前高效推理利用了历史只追加、视觉编码按两帧块局部处理等结构条件。可进一步测试历史删除、摘要替换、相机掉帧、时间戳扰动和长时间回溯，验证缓存机制在非理想在线数据下是否仍保持等价。
  • 现有结果没有披露置信区间、仿真评测次数、硬件和完整延迟分解。后续可分别测量视觉编码、子任务生成、draft 验证、动作积分与机器人通信延迟，并报告不同历史长度下的均值和尾延迟。
  • 可增加“当前视觉与历史冲突”的干预实验，例如执行过程中移动被遮挡物体或替换目标，检验 Perception Attention 能否纠正过时记忆，而不是让历史推理压过实时观测。
实验设置
  • 仿真基准：RoboMemArena、MIKASA-Robo。
  • 真机任务：Cup-and-Block、Tissue Counting、Cabinet Search、Scissor Retrieval；每项 40 次试验。
  • 记忆类型：外源记忆、内源记忆、无痕记忆。
  • 视觉输入：带时间戳的前视相机历史视频，以及当前腕部相机视图。
  • 其他输入：语言指令和当前机器人本体状态。
  • 视觉语言骨干：Qwen3-VL，使用原生视频理解与多模态旋转位置编码 M-RoPE。
  • 动作模型：16 层流匹配 Diffusion Transformer；Perception Attention 插入第 3、7、11、15 层，门控参数初始化为零。
  • 训练方式：视觉语言骨干与动作专家联合优化；训练数据包含视觉观测、语言指令、子任务标注和连续机器人动作。
  • 训练目标：子任务自回归交叉熵与条件流匹配损失的加权和；给定节选未披露两项损失权重。
  • 流匹配训练：噪声时间变量采样自 Beta(1.5, 1.0)，目标速度为噪声与示范动作之差。
  • 闭环协议：每次预测 16 个动作，采用 10 个流匹配积分步；执行前 10 个动作后获取新观测并重新规划。
  • 推理优化：按两帧历史块缓存视觉特征，复用未变化历史前缀的 KV cache，并用上一决策的子任务进行并行 draft 验证。
  • 给定节选未披露机器人型号、控制频率、动作维度、训练数据规模、训练硬件、仿真 episode 数、随机种子、置信区间及完整检查点配置。
AI导读和推荐理由
  • 推荐这篇的核心原因不是它又增加了一个历史帧缓存，而是它明确区分了两种接口：Memory CoT 负责把长历史压缩成“现在该做什么”，Perception Attention 负责保留“具体如何执行”所需的当前视觉细节。
  • 它同时覆盖记忆推理、连续动作生成和在线推理效率，并在两个仿真基准及四项真机任务中给出结果，适合作为长时程 VLA 闭环架构与评测设计的参考。

与π系列的关系

  • ActMem 与 π0、π0-FAST、π0.5 和 OpenPI 同属连续机器人动作生成的 VLA 路线，在采用流匹配动作专家、动作块预测和滚动执行方面存在概念交集。
  • 本文不是 π0、π0-FAST、π0.5 的新版本，也不是 OpenPI 的插件或扩展：其视觉语言骨干是 Qwen3-VL，核心新增机制是历史条件子任务推理、Latent Memory CoT、Perception Attention 与跨决策缓存。
  • 真机图中包含 MEM-π0.5 对照，说明实验触及 π0.5 相关的记忆增强方案；但给定节选没有给出 MEM-π0.5 的架构、训练公平性或逐任务数字，也没有报告原生 π0、π0-FAST 或 OpenPI 实现上的消融。
  • 因而更准确的理解是：ActMem 提供了一种可供 π 系列借鉴的“记忆—感知双通路”设计，而不是已经验证可直接迁移到 π 系列的实现。

对Austin研究的启发

  • 在 OpenPI 执行器前增加显式的高层记忆接口：由历史推理模块输出子任务 token 的隐藏状态，而不是只输出自然语言子任务；比较文本条件、latent 条件和完整历史条件在成功率、延迟与显存上的差异。
  • 为当前相机特征保留独立的交叉注意力通路，并用零初始化门控接入动作专家。这样可以尽量保持已有动作分布，再逐步学习视觉增量，适合作为低风险架构消融。
  • 建立闭环监控项：记录子任务文本、Memory CoT 相似度、draft 接受长度、门控幅值、历史长度和重规划延迟；当子任务长期不变但场景发生显著变化时，触发完整重新解码。
  • 针对引导场 \(G\) 的条件遵循，可设计“历史决定目标、当前视觉决定轨迹”的冲突测试：保持当前画面相似但改变历史目标，或保持历史相同但移动当前目标，分别测量高层选择和低层落点是否按预期解耦。
  • 在效率评测中不要只报告平均延迟；应对比无缓存、仅 KV 缓存、仅 draft 验证和完整方案，并按历史长度报告 P50/P95 延迟、draft 拒绝率及子任务切换时的性能尖峰。
  • 在迁移到 π/OpenPI 前，先做冻结动作专家与联合微调两种协议。前者检验 Memory CoT 是否真能作为通用外挂接口，后者检验性能上限，避免把联合训练收益误归因于记忆模块本身。

一句话总结

ActMem 由北京航空航天大学与 Beta Infinity 团队提出，以 Qwen3-VL 的 Latent Memory CoT 和独立 Perception Attention 条件化流匹配动作专家，在 RoboMemArena 达到 71.1% 任务成功率、真机达到 68.8% 平均成功率，并将长历史下单次决策延迟控制在 0.6 秒以内。
