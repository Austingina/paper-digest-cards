SCAP: Stochastic Context for Action Expert Pretraining

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • VLA 通常在预训练 VLM 上接入随机初始化的动作专家；机器人示范中的场景—指令相关性容易形成视觉捷径，使策略仅凭场景预测动作、忽略语言，动作专家的联合反向传播还可能破坏原有 VLM 表征。
  • APT、BayesVLA 采用视觉—动作（VA）预训练，LA4VLA 采用语言—动作（LA）预训练。它们虽能控制模态竞争，却没有直接监督必须联合视觉与语言才能完成的计算，甚至可能关闭相应交互通路。
  • 论文研究两阶段 VLA 训练：第一阶段冻结 VLM、只预训练动作专家及动作侧投影；第二阶段恢复完整视觉—语言输入，解冻 VLM 并联合适配，推理时不使用遮蔽。
  • 作者目标是在抑制视觉捷径、增强指令依赖的同时，保留视觉—语言联合建模能力，并让该预训练策略适用于不同 VLA 架构与模型规模。

方法

  • 输入与随机上下文构造：图像经视觉编码器形成视觉 token $V=\{v_i\}$，指令分词为语言 token $L=\{\ell_j\}$；SCAP 随机遮蔽两类 token，得到随机上下文 $\tilde C=(\tilde V,\tilde L)$，使 Action Expert 学会在不同信息完备度下恢复动作生成能力。
  • Stage I—Action Expert Pretraining：冻结 Backbone，仅训练动作专家。专家以噪声动作 $a_t$、扩散/流时间步 $t$ 及 $\tilde C$ 为输入；其查询来自动作 token，而键和值读取自 Backbone 对应 Full-Attention Layer 的 $K_l,V_l$，通过跨层条件注入预测流速度 $\hat u_\theta(a_t,t\mid\tilde C)$。
  • 流匹配动作预测头：训练沿噪声动作与真实动作之间的概率路径 $a_t$，以目标速度 $u_t$ 监督 $\hat u_\theta$，最小化 $\mathcal L_{\mathrm{FM}}=\mathbb E\|\hat u_\theta-u_t\|_2^2$；推理时积分该速度场，将初始噪声逐步变换为动作序列。
  • Stage II—Joint Adaptation：移除随机遮蔽，输入完整上下文 $C=(V,L)$，并联合微调 Backbone 与 Action Expert；完整视觉—语言表征经各对应全注意力层的键值流入专家，最终输出任务条件动作轨迹。

SCAP training and model architecture. (a) The action expert is pretrained with randomly masked visual and language tokens and a frozen backbone, then jointly adapted with the backbone on complete inputs. (b) The expert reads keys and values from the corresponding full-attention layers of the backbone and predicts the flow velocity.
  • 整体流程为：视觉观测与语言指令进入冻结的 VLM 前先接受随机 token 遮蔽，动作专家读取 VLM 对应全注意力层的 key/value，并结合机器人状态预测 flow velocity；随后关闭遮蔽，以完整上下文联合训练 VLM 和动作专家。
  • 第一阶段 SCAP 从池化后的图像内容 token 与指令 token 中随机选择固定比例，将其完整 embedding 原位置零；位置保持不变，不引入 mask token，也不做数值重缩放。
  • 机器人状态始终可见；遮蔽是与内容无关的随机变量。第一阶段仅更新动作专家和动作侧投影，避免随机初始化专家直接扰动 VLM 骨干。
  • 第二阶段继承第一阶段权重，移除所有输入遮蔽并解冻 VLM，以相同动作目标进行完整视觉—语言联合适配；推理也始终使用完整输入。
  • VA、LA 和完整输入预训练可视为不同遮蔽分布下的特例。SCAP 的关键变化不是增加新推理模块，而是在动作专家预训练阶段让两种模态以多种可见组合出现。
  • 理论诊断模型将动作拆成可由视觉捷径替代语言的直接项，以及必须联合场景线索与关系指令求解的交互项。单模态预训练可能使交互门参数降至非正区间，并在后续完整输入训练中无法恢复；若视觉和语言线索独立保留概率为 \(q\)，联合线索出现概率为 \(q^2\)，在 \(\lambda(1+c)^2<q^2\) 时，模型中的联合通路不会关闭。
  • 同一模型还表明：只要进行有限时长的 SCAP 预训练，再切换到完整输入，其最终语言系数会高于直接完整输入训练、视觉系数会更低；当视觉捷径线索与语言指令冲突时，理论翻转损失也更小。

实验与结果

  • 在 RoboTwin 2.0 与 RoboCasa-GR1 的汇总评测中，SCAP→Full 达到 57.54% Overall，比同骨干的直接 Full 训练 44.53% 高 13.01 个百分点，也比未做动作专家预训练的 Qwen3.5-9B 路线 40.02% 高 17.52 个百分点。
  • 分数据集看，SCAP→Full 在 RoboTwin 2.0 上平均成功率为 56.48%，直接 Full 为 42.06%，VA→Full 为 50.16%，LA→Full 为 42.76%；在 RoboCasa-GR1 上 Overall 为 58.60%，对应三种对照分别为 47.00%、47.42% 和 46.58%。
  • 第二阶段若继续冻结 VLM，SCAP→Full 的跨基准 Overall 为 53.28%；解冻并联合训练后为 57.54%，高 4.26 个百分点，说明收益并非只来自冻结骨干下的专家训练，完整联合适配仍有贡献。
  • 与一般性的 50% VL-Mask→Full 相比，SCAP→Full 的跨基准 Overall 从 47.61% 提升至 57.54%；原文所给设置表明，两者并非仅以“是否遮蔽”区分，具体遮蔽比例和训练方式会显著影响结果。
  • RoboCasa-GR1 文本干预中，SCAP→Full 的原始指令成功率（OS）为 67.23%，改写指令成功率（PS）为 65.83%；直接 Full 分别为 54.03% 和 50.63%。SCAP 的 OG、NG、PC 指标分别为 12.24%、56.46% 和 47.93%，而 Full 为 32.09%、27.26% 和 21.45%，支持其对改写更稳健、对任务意图变化更敏感；所给节选未完整展示后三项指标的文字定义。
  • 三项真实机器人指令条件操控任务上，SCAP 平均成功率为 76.67%，比完整输入预训练高 25 个百分点。节选未披露各任务名称、逐任务成功率、试验次数或置信区间，因此不能进一步判断提升是否由个别任务主导。
  • 表 1 中外部方法的数字来源并不完全一致：FLARE 的 RoboCasa-GR1 分数直接引用原论文，带“∗”的结果则是按本文训练配置复现；因此与 SCAP 的横向排名应结合来源差异解读。

局限与可以继续做的

  • 理论结论来自人工构造的条件回归模型及连续时间梯度流：它清楚展示了交互门可能被关闭，但不能证明真实 Transformer 一定存在同样的不可逆门控动力学；附录只说明相应 flow-matching 实现具有经时间缩放后的等价定性动态。
  • “保留联合通路”的理论保证要求保留概率满足 \(\lambda(1+c)^2<q^2\)，而真实网络中的对应量无法直接测量；实验采用的遮蔽比例因而主要是经验选择，而非由该条件可验证地推导。
  • 所给正文声称覆盖四种 VLA 架构和多个模型规模，但节选只完整展示了 Qwen3.5-9B 加约 900M 动作专家这一配置及部分对照，无法核对其余架构、规模、训练预算和逐架构增益。
  • 真实机器人证据仅汇报三项任务的平均成功率，缺少逐任务次数、方差、置信区间、失败类型及跨机器人验证；目前不足以证明其对更长时序任务、分布外场景或不同本体同样稳定。
  • 可继续做的实验是固定数据、优化步数和总算力，对称扫描视觉/文本遮蔽率，并加入非对称保留率，以绘制“语言依赖—视觉鲁棒性—原始成功率”的 Pareto 曲线，而不是只比较单个遮蔽配置。
  • 可在闭环真机评测中加入三类成对干预：保持场景只改任务意图、保持意图只做同义改写、让视觉捷径与指令发生冲突；同时记录动作分歧、恢复成功率和失败阶段，从而直接检验论文理论中的 shortcut flip。
  • 可通过 attention、梯度归因或模态消融追踪第一阶段到第二阶段的视觉—语言交互强度，验证 SCAP 是否真的保留联合通路，而不只是产生了更强的数据增强效果。
实验设置
  • 任务范围：RoboTwin 2.0 多任务仿真、RoboCasa-GR1 仿真、RoboCasa-GR1 文本干预，以及三项真实机器人指令条件操控任务。
  • 主模型：mixture-of-transformers（MoT）架构，Qwen3.5-9B 视觉—语言骨干，约 900M 参数动作专家。
  • 动作专家接口：从骨干对应的全注意力层读取 key/value，并预测 flow velocity。
  • 第一阶段：冻结预训练 VLM，仅更新动作专家及动作侧投影。
  • 第一阶段输入：在视觉编码之后、语言骨干之前，对池化图像内容 token 和指令 token 做随机遮蔽；固定选择其中 30%，将完整 embedding 原位置零，保留 token 位置，不使用替代 mask token，不做重缩放。
  • 第二阶段：关闭输入遮蔽，继承第一阶段参数，解冻 VLM，并在完整视觉观测和指令上联合更新 VLM 与动作专家。
  • 推理协议：使用完整、未遮蔽的视觉—语言输入。
  • 训练目标：正文以动作目标和 flow velocity 描述实际模型；理论分析采用平方误差条件回归，并在附录中讨论与 flow matching 梯度流的对应关系。
  • 主要训练路线：Qwen3.5-9B、Full、LA→Full、VA→Full、VL-Mask (50%)→Full、SCAP→Full（第二阶段冻结 VLM）以及标准 SCAP→Full。
  • 表 1 指标为成功率百分比；RoboTwin 2.0 报告 Clean、Randomized 与平均值，RoboCasa-GR1 报告 Articulated、Pick-and-Place 与 Overall。
  • 文本干预指标包括 OS、PS、OG、NG、PC；节选明确给出 OS 为原始指令成功率、PS 为改写指令成功率，但未完整提供 OG、NG、PC 的定义。
  • 原文节选未披露训练步数、batch size、优化器、学习率、硬件、仿真 episode 数、随机种子、真机单任务试验次数及传感器配置。
AI导读和推荐理由
  • 这篇论文切中的不是“再设计一个更大的 VLA”，而是动作专家在接入预训练 VLM 前应该如何预训练：它把视觉捷径与视觉—语言交互通路受损放进同一个两阶段训练问题中。
  • 推荐关注其“理论诊断—文本干预—真机联合 grounding”三层证据链。尤其值得复用的是成对改写与意图变更评测，而不只是最终任务成功率。

与π系列的关系

  • SCAP 与 π0、π0-FAST、π0.5、OpenPI 所代表的“VLM 骨干＋动作专家”路线在模块形态上相关，但本文贡献是动作专家预训练策略，不是新的 π 系列模型或 OpenPI 官方组件。
  • 原文相关工作明确提到 π0.5，并在表 1 中列出其外部基线：π0.5 的跨基准 Overall 为 45.48%，SCAP 主配置为 57.54%。两者并非同一骨干和完全一致的训练路线，不能把 12.06 个百分点差距直接归因于 SCAP。
  • 所给正文没有显示基于 π0、π0-FAST 或 OpenPI 代码实现 SCAP，也没有报告在这些检查点上的严格同构消融；因此目前只能说该方法原则上适用于同类动作专家架构，不能声称已经验证了对整个 π 系列的普适收益。
  • SCAP 没有改变推理时输入输出接口，也没有增加额外在线模块：核心变化发生在训练阶段，先冻结 VLM、随机遮蔽视觉和文本 token 训练动作专家，再恢复完整输入联合适配。这使其具备迁移到 OpenPI 训练流水线的潜力，但仍需实际验证 token 接口、动作分块方式和 flow-matching 实现是否兼容。
  • 相比只做 VA 预训练或 LA 预训练，SCAP 的关键启发是不要通过彻底移除一种模态来治理捷径；对 π 类模型而言，更稳妥的做法可能是随机保留跨模态共现，使动作专家在获得单模态鲁棒性的同时仍持续接触联合线索。

对Austin研究的启发

  • 在 OpenPI 执行器或 π 类训练框架中增加一个仅作用于 Stage 1 的 stochastic-context hook：放在视觉 token 池化之后、VLM 主干之前，分别配置视觉和文本保留率，并确保推理路径完全不变。
  • 做严格的同初始化四路线实验：Full、VA→Full、LA→Full、SCAP→Full；固定数据顺序、训练步数、动作头和第二阶段预算，避免把额外训练量误判为遮蔽策略收益。
  • 若研究中包含引导场 \(G\) 或结构化条件，可把它作为第三类上下文单独控制保留率，测试视觉、语言和 \(G\) 任一信号缺失时的动作变化；同时设置语言与视觉冲突、语言与 \(G\) 冲突的闭环任务，检查执行器究竟遵循哪个条件。
  • 将论文的文本干预扩展到闭环监控：同一初始状态分别输入原指令、同义改写、意图反转和无关指令，记录动作块余弦差异、末端轨迹偏移、重规划次数、成功率及安全停止率。
  • 增加联合通路健康指标：在 Stage 1 定期用仅视觉、仅语言和完整上下文探针评测，并监控跨模态 attention、条件梯度与动作预测差异；如果完整输入优势持续消失，可提前停止或提高联合线索保留概率。
  • 对真实机器人应报告逐任务 trial 数、置信区间和失败阶段，并加入遮挡、场景重排与视觉诱饵。这样才能区分 SCAP 是真正增强条件遵循，还是只提高了特定训练分布上的平均成功率。

一句话总结

SCAP 由同济大学、北京大学、京东未来研究院和复旦大学作者提出，通过“冻结 VLM 的随机视觉—文本上下文动作专家预训练＋完整输入联合适配”抑制视觉捷径并保留跨模态通路，在三项真机任务上达到 76.67% 平均成功率，较完整输入预训练高 25 个百分点。
