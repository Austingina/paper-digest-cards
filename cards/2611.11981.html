深读｜Thermo-VLA

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 现有 VLA 主要依赖 RGB；当指令涉及温度这类不可见物理属性时，策略难以判断目标，更无法可靠完成后续抓取、搬运与放置。
  • 已有热感知机器人工作多集中于检测、分割、视觉问答或抓取显著热目标，对相对温度排序、条件选择和排除式推理研究不足；把热图当作普通图像直接输入，还可能干扰原有 RGB 表征，造成选错目标、双臂同时动作或抓取不稳定。
  • 既有系统多在固定视角、单臂平台上验证。本文改在 Unitree G1 双臂人形机器人上进行真实世界闭环操作，输入头部 RGB/热成像、腕部 RGB、语言与机器人状态，输出连续动作块；所给原文未说明是否冻结 π0.5 骨干或哪些权重参与训练。
  • 作者目标是在尽量保留 π0.5 原有 RGB 操作能力的同时，使策略能按语言选择任务相关的冷热属性，并提高复杂温度推理及场景变化下的操作成功率。

方法

  • 整体流程为：多视角 RGB 经视觉编码器生成 RGB token，头部热图经 ThermoRes Encoder 生成冷热属性 token，语言与机器人状态形成文本 token；温度残差注入 RGB 表征后，与腕部视觉及文本 token 一同送入 Gemma 多模态骨干和动作专家，生成连续动作块。
  • 热图先以场景背景为参照校准：从图像上边界附近采样多个 patch，以其平均强度的众数作为背景参考，将背景映射到固定灰度，再按相对背景的偏差分解为互补的 cold/hot 两个属性视图，降低绝对热强度随环境变化造成的歧义。
  • 冷、热分支共享一个基于 SigLIP 的热编码器，并复用 RGB projector，使热 token 与 RGB token 具有相同的布局和维度，能够进行逐 token 残差调制，而不是简单拼接额外模态。
  • 文本 token 分别对冷、热 token 做共享参数的交叉注意力；由池化后的文本、两路注意力输出及其与文本的差分，经 LayerNorm、轻量 MLP 和 softmax 产生动态权重 \(\alpha,\beta\)，按当前指令选择冷热信息。
  • 头部 RGB token 保留为 identity path，两路结果分别为 \(Z_{\mathrm{rgb}}^{\mathrm{head}}+\alpha Z_{\mathrm{cold}}\) 与 \(Z_{\mathrm{rgb}}^{\mathrm{head}}+\beta Z_{\mathrm{hot}}\)。这一设计只改变条件表征的融合接口，动作端仍沿用 π0.5 的 flow-matching 连续动作生成机制。
  • 推理时动作变量从高斯噪声初始化，沿动作专家预测的速度场演化为连续动作块；每个单臂动作含 7 个关节维度和 1 个手部开合维度，双臂动作空间写为 \(2d_a\)，其中 \(d_a=8\)。

实验与结果

  • 四个温度相关任务 II、IV、V、VI 上，Thermo-VLA 的成功率依次为 1.00、0.86、0.58、1.00，平均为 0.86；直接把热图作为额外视觉输入的 π0.5 (RGBT) 分别为 0.80、0.85、0.50、0.55，平均约 0.68，因此本文方法提高约 18 个百分点。
  • 优势随推理难度增大：简单温度选择任务 II 上为 1.00，对比 π0.5 (RGBT) 的 0.80；相对温度咖啡服务任务 V 上为 0.58，对比 0.50；排除式热推理任务 VI 达到 1.00，而 π0.5 (RGBT) 和 ThermoAct 分别只有 0.55 和 0.50。
  • 在 RGB-only 任务上，Thermo-VLA 仍保留较强能力，但略低于原始 π0.5：任务 I 平均成功率为 0.88 对 0.93，任务 III 为 0.76 对 0.84。相比其他 RGB–thermal 方法，它受到附加热模态的干扰较小，但并未完全消除 RGB 能力退化。
  • 失败案例显示，ThermoAct 会出现抓取不稳定和单侧手臂偏置；π0.5 (RGBT) 可能同时操作两个物体，或在任务 VI 中误选热响应最显著的对象。Thermo-VLA 的注意力则集中到指令要求的无热响应目标。
  • 摘要报告，在未见物体和场景变化下 Thermo-VLA 平均成功率为 0.78，并称其在所比较方法中最佳；还报告属性分解、文本门控残差注入的消融均支持完整设计，并且迁移到颜色属性后在仿真和真机中获得一致提升。但所提供正文截断于比较实验，未包含这些实验的分项数字、对照值和完整协议，无法进一步核对效应大小。

局限与可以继续做的

  • 证据主要来自一个 Unitree G1 双臂平台、六个任务和 1,307 条专家示范；其中只有四个任务真正依赖温度，尚不足以证明该接口能跨机器人形态、传感器布局或更长时程任务稳定迁移。
  • RGB 任务 I、III 相比原始 π0.5 分别下降 5 和 8 个百分点，说明残差式融合虽比直接加入热图更稳，但仍会扰动原有视觉操作能力。可增加“禁用热分支但保持其余结构不变”的逐任务评测，并监控门控值与 RGB 性能之间的关系。
  • 泛化结果虽报告平均 0.78，但当前原文片段没有给出未见物体、属性重组、光照和场景变化各自的划分、试验次数与基线数字；因此无法判断提升究竟来自属性接口，还是训练集中的外观与温度相关性。
  • 文中的门控和注意力图只能说明模型关注了哪些属性，不能证明执行过程中持续服从条件。可对冷热分支做置零、互换、强制反向门控及时间分段屏蔽，并观察目标选择、抓取、搬运和放置各阶段是否按预期改变。
  • 目前任务主要检验目标选择后的既有操作，尚未证明温度条件能组合出未训练过的接触或放置技能。后续可构造物体×目标位置×温度关系的正交训练划分，留出完整组合，并加入目标移动、抓取后温度变化及失败恢复测试。
实验设置
  • 平台：真实世界 Unitree G1 双臂人形机器人。
  • 传感器：刚性固定且相对位姿不变的头部 RGB 与热成像相机，以及左右腕部 RGB 相机；更详细硬件规格被指向项目网站附录，所给原文未列出。
  • 基础模型：π0.5；多模态骨干为 Gemma-based backbone，动作专家沿用 flow matching。
  • 输入：头部及双腕 RGB、头部热图、语言指令和当前机器人状态。
  • 输出：长度为 \(H\) 的连续双臂动作块；每臂 7 个关节维度加 1 个手部开合维度，\(d_a=8\)。原文片段未披露 \(H\) 的具体数值。
  • 数据：六个真实任务共 1,307 条专家示范；任务 I–VI 分别为 156、303、236、340、173、99 条。
  • 任务：位置引导瓶子选择、温度引导瓶子选择、身份引导物体选择、温度引导物体选择、温度感知咖啡服务、异常动物笼移除。
  • 对照：RGB-only 的 ACT、π0.5，以及 RGB–thermal 的 π0.5 (RGBT)、ThermoAct 和 Thermo-VLA；π0.5 (RGBT) 将热图直接作为额外视觉观察输入，其他基线采用其原论文超参数。
  • 协议：每条指令评测 20 次；各方法在同一轮试验中使用近似匹配的物体位置，不同轮次改变布局；操作员佩戴隔热手套复位，液体重量在同一测试组内保持一致。
  • 成功判据：任务 I–IV 要求把正确目标放到正确杯垫；任务 V 要求将糖倒入指定咖啡；任务 VI 要求把无热响应老鼠所在的笼子转移到危险标记箱。
  • 训练时哪些 π0.5 模块被冻结、优化器、学习率、训练步数、背景固定灰度 \(\mu\)、动作块长度和推理步数，在所提供原文片段中均未披露。
AI导读和推荐理由
  • 推荐点不只是“给 VLA 增加热相机”，而是展示了额外物理条件应如何接入预训练执行器：直接把热图当普通视觉输入的 π0.5 (RGBT) 在复杂任务中容易被显著热源误导，而语言门控、属性分解和残差注入能更有选择地修正 RGB 表征。
  • 论文同时保留了连续闭环操作评测，而非只报告温度识别准确率；四个温度任务平均成功率从 π0.5 (RGBT) 的约 0.68 提升至 0.86，是当前原文中最直接、可核对的接口有效性证据。

与本项目关系

  • 与 Austin 项目最直接的联系是“策略如何使用额外条件”：Thermo-VLA 没有把热图简单拼到 π0.5 输入，而是先分解成语义明确的冷热属性，再由语言门控，以残差方式调制 RGB token。这可类比为给 G 或 A/F 条件建立专用编码器、条件选择器与受控残差通道，而非假设 OpenPI 执行器会自行理解新输入。
  • 差距也很明确：冷热表示回答的是“选择哪个对象”，并未表达 A/F 所关心的接近区域和期望物体运动，也没有检验物体抓取后是否持续跟随目标、能否正确放置或恢复失败。论文的未见变化结果也不是严格的物体×目标留出组合证据。
  • 论文给出了真实闭环成功率和注意力案例，但当前材料没有置零、反向或交换冷热条件的因果干预；因此尚不能排除门控条件被当作任务 ID，或策略利用训练数据中的物体—温度关联捷径。

启发

  • 在 OpenPI 的 π0/π0.5 执行器中，把 G 或 A/F 编码成与视觉 token 对齐的 residual token，并保留原始 RGB identity path；对 A 与 F 分设分支，由语言、当前阶段或视觉状态预测门控权重，与“直接拼接 G”做同数据、同训练预算比较。
  • 建立条件遵循干预矩阵：正常 G/A-F、置零、方向反转、对象间交换、只保留 A、只保留 F，并分别统计选物、接近、接触、物体运动方向、送达目标和最终放置成功率，而不只看整段任务成功。
  • 检查持续条件遵循：在抓取前后动态切换目标或反转 F，记录策略是否只在起始时读取条件，还是会在闭环执行中持续修正；同时按时间绘制门控权重、物体轨迹与条件方向的一致性。
  • 数据划分采用物体×目标×运动方向×场景的交叉覆盖，并完整留出若干组合；为同一初始场景配置不同目标和相反 F，减少策略依赖熟悉的物体—目标共现关系。
  • 针对“抓到了但没送对目标”，把成功判据拆成抓取、持续持有、目标跟随、目标区域进入、稳定放置和失败恢复六段；若残差接口只改善前段目标选择，就不能宣称解决了组合执行问题。

一句话总结

Thermo-VLA 通过冷热属性分解和语言门控残差，把热信息接入 π0.5，在 Unitree G1 的四个温度相关真机任务上取得 0.86 平均成功率、较直接输入热图的 π0.5 基线提高 18 个百分点，但作者机构在所提供原文中未披露。
