深读｜SACQ

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • VLA 将视觉、语言理解和动作生成集成到单一策略中，但模型体量带来的显存与权重搬运开销，限制了其在资源受限机器人平台上的部署。
  • 直接沿用 LLM 的超低比特 PTQ 容易失效：相近的层内重建误差，出现在 query/key、value/output 或 SwiGLU 投影中时，会因下游运算不同而产生截然不同的策略误差。
  • 现有 GPTQ、GPTVQ、AQLM、QuIP# 等方法主要优化层内重建；QVLA、ActQuant、HBVLA、QuantVLA 已开始引入动作敏感度或 DiT 结构，但尚未同时覆盖投影功能角色、最终动作误差和超低比特码本优化。
  • 本文研究无需全量重训练的权重量化：在 GR00T N1.7 上压缩语言骨干与动作头权重，并用机器人任务成功率评估；提供的原文未披露完整 rollout 次数、是否真机执行以及全部闭环协议。
  • 作者目标是在平均约 1–2 bit/weight 的极低精度下维持 VLA 的动作质量和任务成功率，同时显著降低模型内存，并在进一步量化激活与注意力后获得实际推理加速。

方法

  • 整体流程分为三步：先按投影在下游计算中的功能角色拟合向量码本，再依据最终解码动作误差分配各层位宽，最后进行“索引重分配＋动作级校准”的两阶段量化后优化，输出可直接替代原权重的低比特表示。
  • 结构感知码本拟合不只重建单个线性层输出，而是近似其下游扰动：query/key 关注 attention logits，value 同时考虑注意力概率和输出投影，gate/up 考虑 SwiGLU 非线性及 down projection，DiT 动作头还针对交叉注意力、GELU 与 AdaLN 构造对应度量。
  • 为使码本优化可分解，方法保留每个四维权重向量内部的输入相关性，但舍弃跨输出通道及跨向量项；输出通道的敏感度以对角权重进入二次型，未建模的跨向量误差留给后续二阶补偿处理。
  • 动作感知混合位宽把每层限制在一组相邻精度状态中，包括 GPTQ 4/3 bit 和多个 2.75 至 1 bit 的向量码本状态；每次降低某层精度时实际运行模型，以最终动作相对误差增量而非层内重建误差决定单位存储节省的代价。
  • 两阶段 refinement 先利用二阶误差补偿重新分配码字索引，再固定索引，以解码动作作为目标校准码本和行组尺度；这不同于只优化权重或层输出重建误差的常规 PTQ。
  • SACQ 改变的是语言骨干与动作头权重的量化表示及精度分配，没有改写 GR00T N1.7 的策略架构，也不需要完整策略重训练；视觉编码器等未量化部分的具体处理在所给原文节选中未完整说明。

实验与结果

  • 在 GR00T N1.7 的四个 LIBERO 套件上，语言骨干与动作头平均压至 1.5 bit/weight 后，SACQ 的平均成功率为 93.85%，BF16 为 94.10%，绝对下降仅 0.25 个百分点。
  • 同一 1.5-bit 设置将 resident model memory 从 5.677 GB 降至 1.175 GB，即缩减 4.83 倍；该内存数字是整个模型驻留内存，而“1.5 bit”特指语言/动作权重，不能将两者简单视为全模型理论压缩率。
  • 在 1.5-bit 权重基础上加入 INT8 激活和低精度注意力后，四套 LIBERO 的平均成功率为 93.55%，相对 BF16 下降 0.55 个百分点，同时推理速度达到 BF16 的 1.51 倍。
  • 在 SimplER Google Robot 基准上，2-bit 语言/动作权重的 SACQ 在 Visual Matching 中达到 63.76%，高于本文 BF16 参考的 58.90%，绝对提高 4.86 个百分点；在 Variant Aggregation 中为 52.27%，BF16 为 53.45%，低 1.18 个百分点。
  • 原文称 SACQ 在较低 bit budget 下优于量化基线，但所给正文在混合位宽算法处截断，未包含完整结果表，因此无法可靠列出各量化基线的逐项名称、数值或消融差值。

局限与可以继续做的

  • 实验证据集中在 GR00T N1.7；正文背景虽讨论 OpenVLA-OFT，但给定原文没有提供 OpenVLA-OFT、π0、π0-FAST、π0.5 或 OpenPI 上的量化结果，跨架构泛化仍属于设定外推。
  • 结构感知度量为换取可计算性，丢弃了跨输出通道和跨权重向量的相关项；二阶 refinement 能部分补偿，但原文节选未给出它对不同投影或动作维度的残余误差分析。
  • LIBERO 与 SimplER 的成功率具有代表性，但提供的材料未披露完整评测次数、方差、随机种子、置信区间和失败类别，也未明确列出真机延迟、功耗及端到端控制频率，因此对部署稳定性的证据仍有限。
  • 可在 OpenPI 执行器中分别对视觉投影、语言骨干和动作 expert 做逐模块量化扫描，记录动作 chunk 的位置、旋转、夹爪误差以及任务成功率，检验“层内误差小但最终动作误差大”的层是否同样存在于 π 系列。
  • 可增加闭环压力测试：在观测噪声、语言改写、长时域恢复和分布外场景下比较 BF16 与 1–2 bit 策略，并监控 action norm、chunk 间跳变、饱和率和安全边界触发次数，避免平均成功率掩盖低频危险动作。
  • 若迁移到新机器人或引导场条件策略，可重新采集少量部署分布校准轨迹，并比较“仅层重建”“动作误差分配”“结构度量＋动作校准”三组消融，以判断额外校准成本是否真正转化为闭环收益。
实验设置
  • 基础模型：NVIDIA GR00T N1.7。
  • 量化对象：语言骨干和 DiT 动作头权重；SACQ 的核心设置为仅权重量化。
  • 权重表示：block-scaled vector codebook；每个尺度组包含 64 个连续权重，向量维度为 4，每层使用一个码本。
  • 尺度初始化：每个组内权重最大绝对值。
  • 码本拟合：在尺度归一化权重空间中优化，取每向量权重因子 \(\alpha(v)=1\)；先在抽样向量上拟合码本，再固定码本为该层全部向量重新分配索引。
  • 位宽候选：GPTQ 4 bit、GPTQ 3 bit，以及 2.75、2.5 直至 1 bit 的向量码本状态；1-bit 目标还允许使用 0.75-bit 状态，只允许相邻状态之间降级。
  • 位宽敏感度：在校准集上实际降低单层精度，测量最终动作相对误差增量，并对不同套件等权平均。
  • LIBERO：四个任务套件；主报告点为语言/动作权重平均 1.5 bit。
  • SimplER：Google Robot benchmark，包含 Visual Matching 与 Variant Aggregation；主报告点为语言/动作权重 2 bit。
  • 加速设置：1.5-bit 权重、INT8 激活及低精度注意力，与 BF16 比较成功率和推理速度。
  • 所给原文未披露校准样本数、每套件任务数、每任务 episode 数、随机种子、推理硬件、batch size、控制频率及完整低精度注意力格式。
AI导读和推荐理由
  • 这篇工作的价值不只是把 VLA 权重压得更低，而是展示了量化目标应从“线性层是否重建得像”转向“误差经过注意力、SwiGLU 和动作解码后是否仍会改变机器人行为”。
  • 1.5-bit 语言/动作权重下仅损失 0.25 个百分点的 LIBERO 平均成功率，并获得 4.83 倍模型内存缩减，为资源受限设备部署大型 VLA 提供了较强的可核查结果。

与π系列的关系

  • 本文实验对象是 NVIDIA GR00T N1.7，并非 π0、π0-FAST、π0.5 或 OpenPI；给定原文也没有报告与这些模型的直接对比，因此不能声称 SACQ 已适配或验证于 π 系列。
  • 二者具有方法上的潜在互补性：π 系列同样包含视觉—语言骨干与连续动作生成模块，SACQ 可作为不改变策略训练目标的部署后压缩层，用动作误差而非语言困惑度或单层重建误差指导精度分配。
  • 迁移时不能照搬 GR00T 的投影角色定义。GR00T N1.7 使用 DiT 动作头，而 π 系列的具体动作 expert、流匹配过程及 OpenPI 实现接口需要重新推导敏感度度量，并重新采集对应动作生成轨迹做校准。
  • SACQ 没有改变策略架构或训练数据，也不解决 π0.5 所关注的开放世界泛化、层级推理或数据混合问题；其贡献位于模型部署和数值表示层，而不是策略能力学习层。

对Austin研究的启发

  • 在 OpenPI 中增加可插拔量化执行器：对每个线性投影暴露模块角色、候选位宽、码本索引、尺度和未量化回退接口，使同一检查点可在 BF16、混合位宽和极低比特之间切换。
  • 将校准指标拆成 action chunk 的平移、旋转、夹爪及时间一致性误差，并同时记录最终闭环成功率；不要仅凭 hidden-state MSE 决定位宽。
  • 对引导场 \(G\) 或条件遵循任务，单独检查量化前后条件敏感度：固定视觉观测、改变语言或引导条件，测量动作方向、约束违反率及条件间可分性，防止低比特码本抹平关键条件差异。
  • 建立逐层降级扫描和在线监控：先定位降低一档精度后导致最终动作误差突增的层，再为这些层保留较高位宽；运行时监控动作跳变、越界、码本饱和和闭环恢复失败，必要时回退到高精度执行。
  • 复现实验应至少包含 BF16、统一位宽 PTQ、仅动作感知分配、完整 SACQ 四组，并在相同硬件上报告驻留内存、端到端延迟、控制频率、功耗和闭环成功率，而不只报告理论 bit/weight。

一句话总结

KAIST 的 SACQ 以结构感知码本、最终动作驱动的混合位宽和两阶段量化后校准，将 GR00T N1.7 的语言/动作权重压至平均 1.5 bit，在四套 LIBERO 上保持 93.85% 成功率并把模型内存缩减 4.83 倍，但尚未在 π0、π0.5 或 OpenPI 上验证。
