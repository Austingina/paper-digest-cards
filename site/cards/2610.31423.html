深读｜FocusVLA

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 多视角 VLA 的“视角依赖惯性”痛点：现有 VLA（如 $\pi_{0.5}$）通常将全局与局部视觉特征静态融合，导致策略在任务早期形成对特定视角（通常是腕部局部视角）的强依赖。这种依赖缺乏阶段感知能力，难以随任务从“全局规划/移动”切换到“局部交互/抓取”而动态调整，造成阶段-视角错配。
  • 现有方法的缺口：传统多视角方法多采用固定融合或通用注意力，未显式建模任务进度对视觉需求的影响；部分工作（如 BFA）虽引入权重预测，但多为当前帧分配且需修改策略输入前特征，缺乏对未来动作意图的显式引导。
  • 设定与目标：本文基于 $\pi_{0.5}$ 多视角骨干，在仿真（RoboTwin 2.0）和真机上验证。目标是提出一种非侵入式框架，通过预测未来交互意图来动态路由全局/局部视觉特征，提升策略在不同操作阶段的适应性和鲁棒性，而不改变核心 VLA 架构。

方法

  • 多模态输入与骨干编码：系统接收多视角图像、语言指令、机器人状态及动作历史，经 $\pi_{0.5}$ 骨干提取视觉-语言特征。这些特征作为上下文基础，同时流向意图预测分支与动作生成主干，为后续动态路由提供原始表征。
  • Future Intent Bridge（未来意图桥接）：利用跨模态注意力编码上下文，预测未来 $H$ 步动作意图序列 $I_t$。每个时间步意图值 $i_t^{(k)} \in [0,1]$ 量化局部交互导向概率。通过弱监督标签（基于夹爪闭合或低速运动自动生成）以 BCE 损失训练，并将意图聚合为 Chunk 级 Token $z_{\mathrm{intent}}$，经线性映射 $f_{\mathrm{route}}$ 生成全局/局部路由权重 $\alpha^{(k)} = [\alpha_g^{(k)}, \alpha_l^{(k)}]$。
  • Action-Side Dynamic Routing（动作侧动态路由）：在动作生成阶段实施非侵入式调制。动作特征作为 Query，分别与全局和局部视觉特征进行 Cross-Attention 得到上下文 $c_g^{(k)}$ 和 $c_l^{(k)}$。利用预测权重 $\alpha^{(k)}$ 加权融合为 $c^{(k)} = \alpha_g^{(k)} c_g^{(k)} + \alpha_l^{(k)} c_l^{(k)}$，并通过残差连接注入动作特征流，实现自适应多视角特征调制。

Architecture of FocusVLA. Given multi-view observations, language instructions, robot states, and action history, FocusVLA predicts future action intent and uses it to guide action-side dynamic view routing for adaptive multi-view feature modulation.
  • 整体 Pipeline：FocusVLA 由两个轻量级模块组成，挂载在 $\pi_{0.5}$ 骨干之上：Future Intent Bridge（未来意图桥接）和 Action-Side Dynamic Routing（动作侧动态路由）。输入为多视角图像、语言指令、机器人状态及短期动作历史。
  • Future Intent Bridge：
  • 意图预测：利用视觉-语言特征、状态和动作历史，通过跨模态注意力编码上下文，预测未来 $H$ 步的动作意图序列 $I_t$。每个时间步的意图值 $i_t^{(k)} \in [0,1]$ 表示该步需要“局部交互导向”视觉证据的概率（反之则为全局工作空间运动）。
  • 弱监督标签构建：无需人工标注阶段，而是从末端执行器轨迹自动生成标签。通过检测夹爪闭合信号或低速局部运动区间，将动作标记为“交互导向”（1）或“移动导向”（0），作为意图预测的 BCE 损失监督信号。
  • 路由权重生成：将意图序列聚合为 Chunk 级意图 Token $z_{\mathrm{intent}}$，并通过固定线性映射函数 $f_{\mathrm{route}}$ 将每步意图转换为全局/局部路由权重 $\alpha^{(k)} = [\alpha_g^{(k)}, \alpha_l^{(k)}]$。
  • Action-Side Dynamic Routing：
  • 非侵入式调制：不修改视觉编码器或语言模型。在动作生成阶段，动作特征作为 Query，分别与全局和局部视觉特征进行 Cross-Attention，得到 $c_g^{(k)}$ 和 $c_l^{(k)}$。
  • 动态融合：利用预测的路由权重 $\alpha^{(k)}$ 对上下文进行加权求和 $c^{(k)} = \alpha_g^{(k)} c_g^{(k)} + \alpha_l^{(k)} c_l^{(k)}$，并通过残差连接注入回动作特征流。
  • 训练目标：联合优化动作生成损失（MSE）和意图预测损失（BCE），采用 Warm-up 策略稳定意图分支训练。

实验与结果

  • 仿真主结果 (RoboTwin 2.0)：在全部 50 个任务上，FocusVLA 平均成功率达到 76.92%，相比最强基线 $\pi_{0.5}$ (66.82%) 提升 10.10 pp。
  • 长程/复杂任务显著增益：在 Long Horizon 任务组中，FocusVLA 平均成功率 85.60% vs $\pi_{0.5}$ 77.10%；在 Extra-Long/Dexterous 任务组中，76.50% vs 67.00%。
  • 具体案例：Stack Blocks Three 从 60% 提升至 69%；Place Cans Plasticbox 从 60% 提升至 90%。
  • 真机实验结果：在 6 个代表性操作任务上，FocusVLA 将成功率从 $\pi_{0.5}$ 的 71.7% 提升至 85.0%，绝对提升 13.3 pp。
  • 消融与诊断分析：
  • 视角掩码干预：在 Stack Blocks Three 任务中，若屏蔽全局视图，$\pi_{0.5}$ 成功率从 85% 降至 65%；若屏蔽局部视图，骤降至 20%。这证实了基线即使在需要全局规划的阶段也过度依赖局部视角（View-dependency inertia）。
  • 注意力分析：失败轨迹表现出更大的“主导性边际”（Dominance Margin）和更小的局部视角依赖时间变化率（$V_{\Delta L}$），即视角依赖僵化。

局限与可以继续做的

  • 意图定义的启发式局限：意图标签（交互 vs 移动）基于末端执行器速度和夹爪状态自动构建，可能无法涵盖所有复杂语义阶段（如“观察”、“等待”或精细力控调整）。若任务中“移动”与“交互”界限模糊，弱监督信号可能噪声较大。
  • 路由函数的简单性：$f_{\mathrm{route}}$ 被描述为固定的有界线性映射，这可能限制了模型学习更复杂的非线性视角组合策略（例如同时需要全局定位和局部对齐的混合阶段）。
  • 对骨干的依赖性：虽然声称非侵入式，但实验仅在 $\pi_{0.5}$ 上验证。对于其他架构（如自回归 VLA 或纯 Diffusion Policy），Cross-Attention 机制的插入点和意图 Token 的注入方式可能需要重新设计。
  • 可继续做的方向：
  • 扩展意图空间：尝试将二分类意图扩展为多阶段语义标签（如 Approach, Grasp, Lift, Place），或使用 VLM 在线生成更细粒度的子目标作为路由条件。
  • 跨架构迁移：在 OpenPI 的其他变体或 RT-2 类模型上测试该模块，验证“动作侧动态路由”的通用性。
  • 闭环鲁棒性测试：在存在严重遮挡或传感器故障的场景下，评估动态路由是否能通过切换视角来恢复策略性能（目前主要关注正常场景下的阶段适应）。
实验设置
  • 仿真平台：RoboTwin 2.0，包含 50 个操作任务，分为 Short, Medium, Medium-Long, Long, Extra-Long/Dexterous 五类。
  • 真机平台：6 个代表性操作任务，涉及不同物体配置、视角变化和交互需求（具体机器人型号未在正文详述，通常对应双臂或单臂机械臂）。
  • 基线模型：$\pi_{0}$, $\pi_{0.5}$ (多视角设定), RDT。FocusVLA 基于 $\pi_{0.5}$ 骨干构建。
  • 输入模态：全局相机图像、局部（腕部）相机图像、语言指令、机器人状态、短期动作历史。
  • 训练细节：
  • 损失函数：$L = \|V_t - U_t\|_2^2 + \lambda_{\mathrm{intent}} \frac{1}{H} \sum \mathrm{BCE}(i_t^{(k)}, y_t^{(k)})$。
  • 意图标签生成：基于轨迹自动标注，利用夹爪闭合信号或低速局部运动检测交互区间。
  • 训练策略：先 Warm-up 意图预测分支 $S_w$ 步，再联合优化；偶尔使用 Teacher Forcing。
  • 评测协议：仿真中报告各任务成功率及分组平均值；真机报告总体成功率。
AI导读和推荐理由

与 π 系列的关系

本文直接基于 $\pi_{0.5}$ 多视角版本进行改进，未修改其预训练权重或核心 Transformer 架构，而是外挂了一个轻量级的“意图-路由”模块。这与 OpenPI/π 系列强调的“通用骨干+任务适配”理念一致，但 FocusVLA 进一步指出 $\pi_{0.5}$ 在多视角融合上的静态缺陷。它没有重新训练 VLM 或 Action Expert，而是通过动作侧（Action-Side）的特征调制来解决问题，这种“非侵入式”设计使得该方法可以很容易地集成到现有的 π 系列部署流程中，只需微调路由模块和意图头。

对 Austin 研究的启发

  • G 条件遵循的动态化：如果 Austin 的研究涉及引导场（Guidance Field）或目标条件策略，可借鉴 FocusVLA 的“未来意图预测”思路。不要仅将当前观测作为条件，而是预测未来几步的“交互状态”（如接触概率、运动速度），并据此动态调整视觉特征的权重。这比固定的 G 条件更符合操作任务的时序特性。
  • 多相机路由监控：在 OpenPI 执行器或真机部署中，可以引入类似的“视角依赖惯性”监控指标（如 Attention Ratio 的方差）。如果发现策略在长程任务中过度依赖腕部相机导致失败，可尝试插入一个轻量级的动态路由层，根据预测的动作意图自动切换全局/局部特征的贡献度，而无需重新训练整个 VLA。
  • 弱监督标签工程：Austin 若需构建阶段感知数据，可参考 FocusVLA 从轨迹动力学（速度、夹爪状态）自动生成“交互 vs 移动”标签的方法，避免昂贵的人工阶段标注，快速为策略提供进度感知的监督信号。

一句话总结

FocusVLA 通过预测未来动作意图并动态路由全局/局部视觉特征，解决了 $\pi_{0.5}$ 等多视角 VLA 的“视角依赖惯性”问题，在 RoboTwin 2.0 上提升平均成功率 10.1 pp，真机提升 13.3 pp，提供了一种非侵入式的阶段感知增强方案。
