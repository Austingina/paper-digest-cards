深读｜ACiT

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 现有视觉运动策略常把本体状态与高维视觉特征并列、对称地输入动作生成器；论文认为低信噪比的视觉流可能压过本体感觉，诱发视觉捷径并降低扰动下的鲁棒性。
  • ACT 只使用当前关节状态；部分后续方法虽引入状态历史，却通常将全部关节压成一个向量或一维序列，使决定动作的跨关节耦合只能隐式存在。作者分析发现，双臂动作的有效维度远低于关节数，参与率（PR）为 1.44–4.42，说明动作具有明显低维耦合结构。
  • 论文覆盖 LIBERO、RoboTwin 2.0 仿真和双臂真机操作；策略预测动作块、执行其中前若干步后重新观测，属于闭环滚动执行。任务专用策略从头训练；π0 版本保留其主干架构，仅改变状态进入模型的方式，但原文所给片段没有说明是否冻结预训练权重。
  • 作者的目标是重构“本体历史—视觉—动作块”的条件接口，显式保留逐关节动态和跨关节协调关系，在不依赖更大视觉主干的情况下提高成功率、视觉扰动鲁棒性与 VLA 执行效率。

方法

  • 具身结构（Embodiment）：双臂机器人包含 $D=14$ 个关节，输入为关节状态历史 $\mathbf{S}_t\in\mathbb{R}^{H\times D}$。动作空间虽具有较低有效维度（参与率 PR 为 $1.44\!-\!4.42$），但关节间耦合显著，因此不能将全部状态压缩为单一共享向量，而应保留逐关节时序表征。
  • 生物启发（Biological Inspiration）：信息流具有固定非对称顺序：本体感觉先在 S1 形成身体中心先验 $p(\mathbf{b}_t\mid\mathbf{S}_t)$；视觉经 V1 到达 PPC，仅用于目标重映射与校准，得到后验 $p(\mathbf{b}_t\mid\mathbf{S}_t,\mathbf{V})$；随后 M1 基于该状态发出动作指令。
  • ACT 条件接口（Conditioning Interface）：ACT 将单帧状态 $\mathbf{s}_t\in\mathbb{R}^{D}$ 与视觉特征 $\mathbf{V}\in\mathbb{R}^{N\times d_v}$ 直接拼接，形成所有关节共享的统一条件；该设计弱化了各关节独立的历史与身体先验。
  • ACiT 条件接口：ACiT 以逐关节先验 $\mathbf{P}_t$ 为主条件，由每个关节 token 分别检索视觉证据，形成 grounded tokens $\mathbf{G}_t$；最终以可学习关节查询逐关节解码，输出动作块 $\mathbf{A}_t\in\mathbb{R}^{T\times D}$，即每个关节一条 $T$ 步轨迹。

Motivation. (a) Embodiment: a dual-arm robot has 14 joints, each with its own state history, while the action space has a much lower effective dimensionality (PR 1.44--4.42) and strong inter-joint coupling, the state therefore should not be compressed into one shared vector. (b) Biological inspiration: proprioception forms a body-centered prior in S1, vision reaches PPC via V1 only to remap and calibrate the goal, and M1 issues the command. The two modalities are not symmetric, and their order is fixed. (c) Conditioning interface: ACT concatenates a single-frame state with vision into one condition shared by all joints; ACiT keeps the per-joint prior as the primary condition, retrieves visual evidence per joint, and decodes one trajectory per joint.
  • 整体流程为：关节历史序列先形成逐关节本体先验，经跨关节自注意力建模协调关系；各关节 token 再分别查询多视角视觉证据，得到视觉校准后的关节表示；最后以关节而非时间步为输出 token，一次生成每个关节的完整轨迹。
  • Inverted State Encoding：对每个关节的完整历史独立施加沿时间轴的 depthwise 1D 卷积，再通过共享时间投影和可学习关节身份嵌入压成一个 token。自注意力在关节 token 之间运行，显式表达同臂及跨臂耦合，而不是先将所有关节展平。
  • State-Visual Grounding：以本体先验 token 为 query、视觉 token 为 key/value，让每个关节按自身运动需求检索视觉区域。视觉不直接与状态对称拼接，而被限定为目标定位和身体坐标校准证据。
  • Inverted Action Chunking：ACT 版本使用 \(D\) 个可学习关节 query 读取校准后的关节表示及 CVAE latent，每个输出 token 经共享线性头生成该关节未来 \(T\) 步轨迹；因此输出布局由“\(T\) 个时间步向量”倒置为“\(D\) 条关节轨迹”。条件 1D U-Net 版本也采用相同逐关节输出布局。
  • 论文以贝叶斯感觉线索整合作为解释框架：本体历史对应身体状态先验，视觉对应似然式校准证据，二者形成 posterior-like 表示后再生成动作。作者明确指出这只是确定性计算类比，并非显式概率模型，身体状态变量也不同于训练使用的 CVAE latent。
  • 相对 ACT，ACiT 改变的是条件表示、跨模态融合顺序和动作块布局；训练仍采用 ACT 式 CVAE 与动作重建目标。π0-ACiT 则保留 π0 的 PaliGemma 主干及总体架构，只替换状态进入模型的条件接口。

实验与结果

  • 汇总结果中，ACiT 在 LIBERO、RoboTwin 2.0 和真机任务上相对各设置中的最强基线，将平均成功率提高 5.7–10.8 个百分点。所给原文片段未包含完整图表数值，无法进一步核对每个任务的绝对成功率。
  • LIBERO 上的主要增益来自 Spatial；在接近饱和的 Object 上，ACiT 与强基线相当，LIBERO-10 中四种方法也较为接近。因此，LIBERO 平均提升主要由需要精确空间放置的任务贡献，并非所有套件均一致领先。
  • RoboTwin 2.0 上，ACiT 在强调双臂协调的 Pick Dual Bottles 和 Place Dual Shoes 中领先；对依赖速度与动作相位的 Shake Bottle、Move Can Pot，其相对最强基线的优势在随机化 hard split 下进一步扩大。原文片段未披露这些任务的具体百分点。
  • 将相同条件设计迁移到 VLA 后，π0-ACiT 相对 π0 的平均成功率提高 26.9 个百分点，同时推理延迟降低 20.2%。这是论文报告的总体差值；片段没有给出 π0 与 π0-ACiT 的绝对成功率、毫秒延迟或逐任务分解。
  • 注意力分析显示，关节自注意力集中于少量关键关节对，其中包括跨越两条机械臂的非相邻关节；关节到视觉的交叉注意力则落在与该关节运动相关的物体上，例如待抓取瓶子，或鞋子及其目标盒。该可视化在 5 个 episode、每个 episode 10 帧上取平均，但只能提供机制层面的定性证据。
  • 论文展示了真机闭环抓取失败后的恢复案例；然而提供的正文在该案例说明处被截断，因此无法可靠复述恢复步骤、成功次数或与基线的定量差异。

局限与可以继续做的

  • 论文将本体感觉视为先验、视觉视为校准证据，但实现本质上是确定性注意力网络，没有显式估计先验、似然或后验的不确定性；贝叶斯表述目前主要是结构解释，而非经过校准检验的概率模型。
  • 证据集中在 LIBERO、RoboTwin 2.0 和一套双 reBot Arm 平台。真机仅含 4 个任务，所给片段也没有评测次数、置信区间和逐任务结果，尚不足以判断提升对不同机器人形态、长时任务及接触丰富操作的稳定性。
  • LIBERO 排除了需要语言指令的 Goal 套件；因此，当前结果没有验证“语言目标—视觉证据—本体先验”三者同时存在时，非对称融合是否仍优于 π0 等 VLA 的原始 token 接口。
  • 可直接补做接口消融：在同一 OpenPI/π0 训练与执行栈中分别替换“逐关节历史编码”“状态查询视觉”“逐关节动作头”，并加入对称拼接、单帧状态和展平历史对照，以确定 26.9 点提升来自哪一层，而非训练或采样差异。
  • 可增加闭环压力测试：系统扫描视觉遮挡、相机偏移、状态延迟、关节噪声、历史窗口错位和抓取后物体滑移，记录恢复率、恢复步数、轨迹抖动及失败类型，检验“视觉只做校准”在本体先验错误时是否会阻碍快速纠正。
  • 面向跨形态迁移，可将关节身份嵌入替换或补充为运动学图、关节轴和父子链描述，并在 7-DoF 单臂、12/14-DoF 双臂间测试零样本或少样本迁移，区分逐关节 token 的普适收益与固定关节编号记忆。
实验设置
  • 仿真平台：MuJoCo，经 RoboTwin 框架运行；另使用 LIBERO。
  • RoboTwin 2.0：双臂，14-DoF 状态与动作；1 个顶部相机和 2 个腕部相机。
  • RoboTwin 任务：Lift Pot、Pick Dual Bottles、Handover Block、Move Can Pot、Place Dual Shoes、Shake Bottle。
  • RoboTwin 协议：每项任务包含 easy split 与随机化 hard split；hard split改变物体位姿、颜色和背景。所给片段未披露每项任务的评测 episode 数。
  • LIBERO：单臂，7-DoF 动作、8-DoF 状态、2 个相机；评测 Spatial、Object 和 LIBERO-10，排除需要语言指令的 Goal。
  • 真机平台：两台 reBot Arm B601-DM；每台机械臂 6 DoF、负载 1.5 kg、重复定位精度 ±0.2 mm；使用 1 个全局相机和 2 个腕部相机。
  • 真机任务：单臂 pick cube、stack cube；双臂 lift pot、handover cube。片段未给出示范数量和评测轮数。
  • 小模型基线：ACT、Diffusion Policy（DP）和 flow-matching（FM）基线。DP 与 FM 使用相同观测编码器和 1D U-Net，分别采用 DDPM 与 flow matching 目标及对应采样器。
  • 训练框架：任务专用策略通过 LeRobot、PyTorch 从头训练，共享 ResNet-18 视觉主干，优化器为 AdamW。
  • VLA 设置：π0-ACiT 保留 π0 的 PaliGemma 主干和总体架构，仅改变状态输入接口；片段未说明具体 π0 检查点、微调范围及权重冻结策略。
  • 动作协议：输入长度为 \(H\) 的状态历史，预测长度为 \(T\) 的动作块，并执行其中前若干步后重新规划；片段未给出 \(H\)、\(T\) 和实际执行步数。
  • 状态编码超参：逐关节 depthwise 1D 卷积默认核大小 \(\kappa=3\)，两端零填充；时间投影在关节间共享，并加入可学习关节身份嵌入。
  • 训练目标：ACT 式 CVAE；动作采用按时间和关节平均的 L1 重建损失，加权 KL 正则；推理时令 latent \(z=0\)。片段未给出 KL 权重 \(\lambda\)。
  • 注意力可视化：对 5 个 episode、每个 episode 10 帧的注意力取平均。
AI导读和推荐理由
  • 推荐这篇的核心原因不是又提出一个更大的 VLA，而是把问题定位到容易被忽略的条件接口：状态历史如何编码、视觉何时介入，以及动作块按时间还是按关节组织。
  • 它同时在小型 ACT 类策略和 π0 主干上验证同一设计，并报告 π0-ACiT 成功率提升 26.9 个百分点、推理延迟降低 20.2%，因而适合用于判断结构先验能否比单纯扩大视觉—语言模型更有效地改善低层控制。

与π系列的关系

  • 本文明确构建并比较了 π0-ACiT：保留 π0 的 PaliGemma 主干和总体 VLA 架构，只改变本体状态进入模型的方式，使历史状态先形成逐关节先验，再由关节表示检索视觉证据。
  • 它不是对 π0 的语言模型、视觉编码器或动作知识进行全面重训式替换；贡献集中在状态条件接口和逐关节动作组织。原文片段未说明 π0 的哪些预训练参数被冻结，因此不能将其描述为纯外挂、零训练适配器。
  • 提供的正文没有报告与 π0-FAST、π0.5 或 OpenPI 的直接实验，也没有证明该接口已兼容这些版本的 tokenizer、flow-matching action expert 或推理执行器；对这些系统的适用性仍是待验证迁移方向。
  • 与 π 系列常见的视觉、语言、本体 token 联合条件化相比，ACiT 强制加入模态顺序：本体历史先构造身体中心表示，视觉和语言目标随后用于校准。这种归纳偏置可能更适合动态协调任务，但在纯视觉语义主导或语言长程规划任务上的收益尚无证据。

对Austin研究的启发

  • 在 OpenPI 执行器中增加可切换的 state_interface：保留原始拼接接口，同时实现 history → joint tokens → inter-joint attention → visual grounding，确保两种接口共享数据、视觉主干、训练步数和动作采样器，做严格配对实验。
  • 将引导场 \(G\) 分解为逐关节条件，而不是使用单个全局视觉向量；监控每个关节对图像区域、语言目标和其他关节的注意力，并检查其是否随接触阶段、双臂交接和失败恢复而变化。
  • 在闭环评测中除成功率外增加动作块执行延迟、重规划频率、关节间相位误差、轨迹 jerk、失败后恢复率和视觉扰动敏感度，避免仅凭离线动作误差判断接口优劣。
  • 优先选择能区分方法的任务，而非只测接近饱和的套件：双臂交接、两物体同步抓取、摇晃、动态插接，以及需要在视觉目标改变后快速重校准的任务更能检验逐关节先验。
  • 加入“本体先验失真”测试：人为注入编码器延迟、关节偏置或历史缺帧，观察视觉校准能否推翻错误先验；若不能，可增加置信度门控或残差式全局视觉通道，避免非对称接口变成信息瓶颈。

一句话总结

南京理工大学 Haixiang Wu、Zhihao Guan、Yang Yang 提出的 ACiT 以逐关节历史先验、关节查询视觉和逐关节轨迹解码重构动作条件接口，报告相对最强基线平均成功率提高 5.7–10.8 个百分点，并使 π0-ACiT 相对 π0 提高 26.9 个百分点且推理延迟降低 20.2%。
