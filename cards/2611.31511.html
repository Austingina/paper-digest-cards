深读｜Near-Zero Forgetting Is Not Enough

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • 预训练 VLA 在经验回放持续学习中可以实现域内近零遗忘，但已有研究主要检查训练分布内的旧任务保持，没有回答同一旧任务遇到视角、光照、布局或机器人初始状态变化时是否仍然稳健。
  • 经验回放仅保存训练分布中的示范，可能在维持域内成功率的同时收窄策略表征，使模型逐渐丧失原本来自大规模预训练的分布外泛化能力。
  • 论文在 LIBERO 仿真操作任务上顺序微调 Pi0，并通过闭环任务成功率评估 LIBERO 域内任务及其 LIBERO-Plus 扰动版本；原文未说明冻结策略骨干，不能将其视为仅训练外挂模块。
  • 作者的目标是验证“域内近零遗忘是否等价于部署鲁棒性”，并定位持续训练过程中 OOD 能力退化所对应的表征瓶颈。

  • 矩阵输入与坐标定义：Figure 1 以持续学习序列中的任务 $T_i$ 为列、完成第 $k$ 个任务训练后的检查点 $\theta_k$ 为行；每个单元格 $C(k,i)=\mathrm{SR}(\theta_k,T_i)$ 输出对应成功率（Success Rate, SR）。仅展示满足 $k\ge i$ 的有效下三角区域，表示模型学会任务后及其后续阶段的表现。
  • ID 评测模块：第一行子图汇总 LIBERO 与 LIBERO-Plus 四个任务套件的 In-Distribution（ID）结果。沿主对角线可读出任务刚学完时的性能，而下对角线单元格反映后续学习后的保留能力；整体密集且高亮的高 SR 下三角表明灾难性遗忘接近于零。
  • OOD 扰动聚合模块：第二行采用相同的 $(k,i)$ 布局，但每个单元格先在多个分布外扰动类别上求均值，即 $\bar C_{\mathrm{OOD}}(k,i)=\frac{1}{|\mathcal P|}\sum_{p\in\mathcal P}C_p(k,i)$，从而衡量视觉或环境变化下的平均鲁棒成功率。
  • OOD 遗忘判读：与 ID 的稳定下三角形成对照，OOD 区域中多数 $C(k,i)\approx0$；仅少数下对角单元格出现 $\mathrm{SR}>0$ 的孤立尖峰。该结构说明“参数记住 ID 任务”并不等价于保持 OOD 泛化，后续任务训练会显著侵蚀早期任务的分布外鲁棒性。

ID and OOD success rate matrices for LIBERO and LIBERO-Plus (mean across perturbation categories). Each cell $C(k,i)$ reports the success rate of checkpoint $\theta_k$ (row) on task $T_i$ (column); only valid cells with $k \geq i$ are shown. For the first row of subplots, the ID cells are shown; for the second, the mean of the cells across the OOD categories is shown. For ID, the dense, high-SR lower triangles indicate near-zero forgetting across all four suites, whereas for OOD the lower-triangular regions show a clear drop in performance: most cells are close to zero, while some isolated spikes of active cells (under-diagonal cells with SR $> 0$) remain, revealing OOD forgetting.
  • 整体流程：在每个 LIBERO 套件内顺序学习任务，完成任务 \(T_k\) 后保存检查点 \(\theta_k\)；随后用同一检查点分别评估原始 LIBERO 场景和 LIBERO-Plus 的七类域偏移，构建“检查点 × 已学任务 × 扰动域”的成功率矩阵。
  • 持续学习机制：复现 Liu 等人的 Pi0 经验回放基线；回放缓冲区逐任务累积旧示范，训练新任务时以当前任务样本和回放样本混合微调。本文没有提出新的抗遗忘损失或网络结构，主要贡献是扩展 OOD 评测与诊断。
  • 遗忘度量：用平均累积准确率 ACA 衡量截至当前检查点的整体任务表现；用负向后向迁移 NBT 比较任务刚学会时与后续检查点的成功率，并分别在 ID 和 OOD 域计算。
  • 表征漂移分析：从视觉编码器输出、VLM 多模态表示和动作专家第一次流匹配步骤三个位置提取特征；统一在 \(\tau=0\) 的联合前向过程中取特征，并对非 padding token 做均值池化。
  • 表征诊断指标：用线性 CKA 比较同一任务在不同持续学习检查点上的表征漂移，用 MMD 衡量 ID 与 OOD 特征分布间距，再比较不同扰动类别的漂移结构是否一致。
  • 可读性检验：冻结提取出的多模态与动作特征，分别线性回归末端执行器三维位置和被操作物体三维位置；比较 ID 域交叉验证、ID 训练后直接迁移至 OOD、以及 OOD 域内交叉验证，以区分“信息消失”和“信息仍在但读出错位”。

实验与结果

  • 域内结果复现成功：Spatial、Object、Goal 和 LIBERO-10 的 ID NBT 分别为 \(0.026\)、\(-0.005\)、\(-0.017\) 和 \(-0.036\)。后三者出现轻微后向迁移，Spatial 仅有小幅遗忘，支持“经验回放下域内近零遗忘”的既有结论。
  • 任务刚学会时已经存在域差距：相对于 ID，OOD 获取阶段的平均成功率分别下降约 \(0.27\)、\(0.27\)、\(0.25\) 和 \(0.38\)；在此基础上，后续任务学习还会继续侵蚀旧任务的 OOD 表现。
  • OOD 遗忘远高于 ID：四个套件的平均 OOD NBT 分别达到 \(0.40\pm0.13\)、\(0.48\pm0.17\)、\(0.42\pm0.15\) 和 \(0.16\pm0.09\)，其中均值和标准差按七类 LIBERO-Plus 扰动统计；旧任务的 OOD 成功率经常在继续学习一到两个任务后降至约 0。
  • 不同扰动呈现共同失败位置：Spatial 和 Object 中，不同扰动成功率向量的平均 Pearson 相关系数分别为 \(0.73\) 和 \(0.82\)，所有两两相关均大于 \(0.5\)，最小值分别为 \(0.53\) 和 \(0.60\)；控制 ID 成功率后的偏相关仍为 \(0.72\) 和 \(0.81\)。这说明失败结构并非仅由某一种扰动触发。
  • 共同结构也出现在表征空间：不同扰动之间，ID–OOD MMD² profile 的平均相关系数在 Spatial、Object、Goal、LIBERO-10 上分别为 \(0.67/0.76/0.76/0.77\)，CKA profile 则为 \(0.64/0.75/0.72/0.84\)。即使 Goal 和 LIBERO-10 的行为成功率大面积归零，内部表征仍保留一致的漂移结构。
  • 漂移主要发生在后段模块：视觉编码器的 ID–OOD CKA 差距最多约 \(0.02\)，且处于任务间波动范围内；多模态层出现较小但稳定的 OOD 额外漂移，动作专家的域间差距最大、方差也更高。
  • 更像读出错位而非信息完全丢失：线性探针中，ID 训练后直接测试 OOD 的 \(R^2\) 始终最差，而在 OOD 特征上重新训练探针可以部分恢复，说明末端执行器与物体位置等任务相关信息仍可线性访问，但相对原有 ID 读出发生了错位。所给原文未披露图 4 的逐套件具体 \(R^2\) 数值。

局限与可以继续做的

  • 设定外推有限：证据来自 Pi0、LIBERO 仿真任务和 LIBERO-Plus 的受控扰动，尚不能直接外推到真机长期部署、跨机器人形态或非视觉域偏移。
  • 方法覆盖有限：论文主要分析经验回放基线，没有在所给原文中系统比较正则化、参数隔离、LoRA、OOD 回放或表征对齐等持续学习策略，因此尚不能判断哪类干预能修复该问题。
  • 统计细节披露不足：给出的正文未说明随机种子数、每个单元格的评测 episode 数、优化器、训练步数及硬件；OOD NBT 的标准差来自七种扰动，而不等同于多次独立训练的方差。
  • 因果证据仍有限：CKA、MMD 和线性探针支持“表征错位”解释，但主要是相关性诊断；可以进一步冻结视觉/VLM/动作专家的不同组合，或只对指定层施加对齐正则，以验证哪个模块的更新真正导致 OOD 崩溃。
  • 可执行改进实验：在回放缓冲区中加入同一轨迹的视角、纹理、光照、语言改写与传感器噪声增强，分别比较 ID NBT、逐扰动 OOD NBT 和最终 ACA，检验多域回放能否在不损害新任务学习的情况下保持旧任务鲁棒性。
  • 部署侧监控：除常规域内成功率外，可在线记录多模态层及动作专家的参考特征距离、跨检查点 CKA 或轻量 probe 指标；当旧任务 ID 表现稳定但特征距离持续扩大时，触发 OOD 回放、停止更新或回滚检查点。
实验设置
  • 平台与任务：LIBERO 仿真机器人操作基准，包括 LIBERO-Spatial、LIBERO-Object、LIBERO-Goal 和 LIBERO-10 四个套件。
  • 模型：Pi0，由预训练 PaliGemma VLM 骨干和流匹配动作专家组成。
  • 持续学习协议：每个套件中的任务按顺序学习；训练完 \(T_k\) 后保存检查点 \(\theta_k\)，只评估当前及此前已学习任务。
  • 经验回放：每个任务向缓冲区保留 1,000 帧；学习后续任务时，训练 batch 中当前任务样本与回放样本比例为 1:1。
  • 域内评测：使用原始 LIBERO 任务，以闭环任务成功率构成检查点—任务矩阵，并计算 ACA 和 NBT。
  • OOD 评测：使用 LIBERO-Plus 的七类扰动——背景纹理、机器人初始状态、外部相机视角、物体布局、光照条件、语言指令改写和传感器噪声。
  • 特征提取点：视觉编码器之后、VLM 多模态层之后、动作模块第一次流匹配步骤之后。
  • 特征提取方式：锁定流匹配时间为 \(\tau=0\)，在一次联合前向中提取特征，并对非 padding token 做均值池化，每帧得到一个向量。
  • 表征指标：线性 CKA、MMD²，以及以 \(R^2\) 为指标的线性回归探针。
  • 探针目标：末端执行器三维位置和被操作物体三维位置；比较 ID-CV、ID→OOD 和 OOD-CV 三种协议。
  • 未披露信息：所给正文未提供优化器、学习率、训练步数、硬件、随机种子数、每个评测单元的 episode 数，也未明确说明具体冻结了哪些 Pi0 参数。
AI导读和推荐理由
  • 这篇论文的价值不在于再提出一种持续学习算法，而在于揭示一个容易被标准指标掩盖的失败模式：旧任务的域内成功率几乎不变，并不意味着预训练 VLA 保留了原有的 OOD 能力。
  • 论文把行为矩阵、跨扰动相关性、模块级表征漂移和线性探针串联起来，使“OOD 遗忘”从单纯的成功率下降变成了可定位、可监控的表征问题。

与π系列的关系

  • 本文直接研究 Pi0：沿用其 PaliGemma 多模态骨干和流匹配动作专家，并在 LIBERO 上以经验回放进行顺序微调。
  • 本文没有改变 Pi0 的动作生成机制，也没有提出新的 π 系列模型；新增的是 LIBERO-Plus OOD 持续学习评测，以及 CKA、MMD 和线性探针组成的诊断流程。
  • 所给原文没有使用或比较 π0-FAST、π0.5 或 OpenPI，因此不能把结果直接视为这些模型或开源实现上的实证结论。
  • 不过，结论对 π 系列评测具有直接警示意义：只报告 LIBERO 域内旧任务成功率或 NBT，可能把“训练分布记得牢”误判为“持续学习后仍有泛化能力”。

对Austin研究的启发

  • 在 OpenPI 或其他 π 系列执行器的持续微调流水线中，将评测单元从“任务 × 检查点”扩展为“任务 × 检查点 × 域偏移”，至少覆盖相机位姿、初始状态、背景、光照、语言改写与传感器噪声。
  • 对引导场 \(G\) 或条件遵循机制，不应只检查域内指令成功率；应固定任务语义并系统改变视觉域，分别记录条件遵循率、动作成功率和 OOD NBT，判断后续微调是否让策略忽略或误读原有条件。
  • 在执行器接口中暴露视觉编码器、多模态层和动作专家的中间特征，保存任务刚学会时的参考统计；后续检查点若出现动作层或多模态层显著漂移，即使域内成功率不降，也应标记为潜在 OOD 回归。
  • 可做一个最小消融：比较纯 ID 回放、带视觉增强的回放、ID/OOD 双缓冲回放，以及仅对多模态层或动作专家施加特征对齐约束；统一报告新任务成功率、ID NBT、七类 OOD NBT 和最终 ACA。
  • 真机闭环验证应加入恢复行为与安全指标，因为仿真成功率归零只说明任务失败；部署时还需要区分可恢复的视觉误差、持续错误动作和不可逆碰撞等不同后果。

一句话总结

KU Leuven、Computer Vision Center、Universitat Autònoma de Barcelona 与 IDEAS Research Institute 的作者通过 LIBERO-Plus 证明，经验回放微调的 Pi0 虽取得 \(0.026/-0.005/-0.017/-0.036\) 的近零 ID NBT，四个套件的 OOD NBT 却升至 \(0.40/0.48/0.42/0.16\)，其根因更符合多模态层与动作专家中的可读性错位，而非视觉信息完全消失。
