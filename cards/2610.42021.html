深读｜Nexus-VLA

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 大规模第一视角人类视频包含丰富且易扩展的操作经验，但人与机器人在外观、运动学结构和动作空间上的差异，使人类动作无法直接转化为机器人控制信号。
  • 现有方法通常采用“人类视频预训练—机器人数据适配”的多阶段流程，或只对齐任务意图、空间可供性、末端轨迹等单一语义层级；前者让人类知识只能间接影响策略，后者难以保持不同语义粒度之间的一致性。
  • 显式预测可供性图、轨迹等中间表示虽然可解释，却会增加推理计算与决策延迟，而且结构化或离散语义并不适合作为连续动作生成的直接接口。
  • 本文同时覆盖 RoboCasa-GR1 仿真、OOD 场景和真实机器人实验；策略采用连续动作块生成，但所给原文未明确将执行协议称为开环或闭环，也未说明是否冻结视觉—语言骨干。
  • 作者目标是用未配对人类视频和机器人示范进行单阶段端到端联合训练，使人类经验直接参与机器人动作学习，并提升数据利用效率与跨场景泛化能力。

方法

  • 整体流程：共享视觉—语言骨干接收当前视觉观测、任务指令和一个可学习语义 token，得到视觉—语言隐藏序列及 Hierarchical Semantic Latent；动作生成器再结合该序列、机器人本体状态、噪声动作块和 flow timestep，预测连续动作的条件速度场。
  • 四级跨具身语义监督：作者将共享操作知识组织为 Intent、Spatial、Motion 和 Interaction 四层，分别对应“做什么”“操作什么及在哪里”“如何移动”“如何接触并影响物体”。监督目标包括局部任务描述、操作物体与目标区域的二维位置、未来双腕轨迹，以及未来接触位置和接触状态。
  • 共享层次语义潜变量：模型把可学习的语义 token 放在多模态序列末尾，其最终隐藏状态作为统一 Semantic Latent。四个轻量投影头从同一个潜变量预测四级语义，使不同粒度的监督共同约束一个内部表示，而不是分别建立彼此独立的中间模块。
  • 推理时不显式生成语义：结构化操作专家只离线产生训练标签；部署时无需输出任务描述、二维位置、轨迹或接触状态，动作 token 直接对包含 Semantic Latent 的多模态隐藏序列做交叉注意力。
  • 双空间动作表示：训练动作由机器人专属关节动作和跨具身共享的双腕/双末端运动组成。人类视频只在共享运动维度计算动作损失，机器人示范同时监督共享运动和关节控制维度；推理时执行机器人关节动作部分。
  • 单阶段联合目标：使用 embodiment-specific mask 在有效动作维度上计算 conditional flow-matching loss，并与四级语义损失联合优化，使语义潜变量既保持人机共享语义，又直接服务于连续动作生成。相较多阶段预训练或简单混合数据，核心改动是把跨具身语义对齐与机器人动作学习放进同一优化过程。

实验与结果

  • 在 RoboCasa-GR1 的 24 个任务上，Nexus-VLA 的五组任务非加权平均成功率为 80.5%；各组结果分别为 Close 70.3%、Cuttingboard 89.6%、Placemat 80.0%、Tray 83.6%、Plate 81.0%。
  • 在表 1 所列方法中，ACE-Ego-0 的平均成功率为 72.8%，ZR-0 为 69.3%，JoyAI-RA 0.1 为 63.2%；Nexus-VLA 的 80.5% 是该表最高结果。
  • 同表中的基础 VLA 方法 GR00T-N1.6 和 ABot-M0 分别取得 47.6% 与 58.3%；语义增强方法 VP-VLA、IntentVLA 分别为 53.8% 与 57.0%；人类经验方法 DyPES-VLA 为 59.3%。
  • 摘要和正文称模型还在光照变化、视觉噪声、新空间配置等 OOD 条件及真实机器人平台上表现出较强泛化能力，但所提供原文在表 2 开头即被截断，未给出这些实验的完整任务、基线和数值，因此无法核对或进一步量化。
  • 当前节选没有提供消融表，因而无法从原文核实四级语义各自的贡献、共享潜变量相对显式语义推理的速度收益，或人类数据比例与最终成功率之间的关系。

局限与可以继续做的

  • 证据不完整：所给正文只完整展示了 RoboCasa-GR1 主表；OOD、真实机器人、数据效率、学习效率和推理延迟的具体数据均未包含在节选中，因此这些主张目前只能按作者定性陈述记录。
  • 语义标签依赖外部专家：Intent、二维空间位置、未来腕部轨迹及接触标签由离线 Structured Manipulation Experts 自动生成。潜变量训练质量可能受伪标签偏差影响，但节选未报告专家准确率、标注成本或噪声鲁棒性。
  • 共享动作空间仍依赖人工接口设计：方法假设人类腕部与机器人末端运动能够映射到统一坐标系和参数化；对不同相机视角、非双臂形态、灵巧手以及移动操作机器人的可迁移性尚无充分证据。
  • 潜变量可解释性尚未闭环验证：虽然四类预测头约束同一 latent，但推理时不输出这些语义。可以增加在线 probe、语义一致性监控和失败前兆检测，验证 latent 是否在遮挡、接触失败或指令歧义时仍保留预期层次结构。
  • 可继续做的实验：在统一训练预算下比较仅机器人数据、直接混合人机数据、单层语义监督、四层独立 latent 和本文共享 latent；同时报告成功率、训练收敛速度、推理延迟、专家标签噪声敏感性，以及不同人类/机器人采样比的 scaling curve。
实验设置
  • 仿真基准：RoboCasa-GR1。
  • 任务规模：共 24 个任务，归入 Close、Cuttingboard、Placemat、Tray 和 Plate 五个任务组。
  • 主指标：任务成功率；先在每个任务组内汇总，Avg. 为 24 个任务上的非加权平均。
  • 主结果检查点：表 1 使用训练至 150K steps 的 Nexus-VLA checkpoint。
  • 训练数据：未配对的人类视频与机器人示范；二者在单阶段内混合训练。人类/机器人总体采样比例被显式控制，各具身来源内部的数据集按规模比例采样。
  • 输入与状态：视觉观测、任务语言指令，以及动作生成阶段使用的 embodiment/机器人本体状态；节选未披露具体相机数量、图像分辨率和传感器配置。
  • 语义监督：局部任务描述、操作物体与目标区域的二维位置、未来 \(H\) 步双腕轨迹、未来接触位置与状态；标签由仅用于离线标注的 Structured Manipulation Experts 构造。
  • 动作与训练目标：机器人关节动作加统一参数化的双腕/双末端运动；采用带具身有效维度 mask 的 conditional flow matching，并联合多级语义损失。
  • 推理：不运行 Structured Manipulation Experts，也不显式生成四级语义；模型生成连续动作块并执行其中的机器人关节动作部分。
  • 未在节选披露：人类与机器人数据集名称及规模、混合采样比例、动作块长度、\(H\) 的取值、各语义损失权重、flow 采样步数、优化器、batch size、硬件、真实机器人型号、评测 episode 数，以及骨干是否冻结。
AI导读和推荐理由
  • 推荐这篇的核心原因不是它提出了新的 π 系列骨干，而是它回答了一个与 VLA 扩展直接相关的问题：如何让没有机器人关节标签的人类视频，在同一次策略训练中直接贡献给连续机器人动作生成。
  • 四级语义监督只在训练期塑造共享 latent、推理期不显式解码的设计，为“引入结构化监督但不增加部署链路”提供了一个清晰方案；RoboCasa-GR1 上 80.5% 的平均成功率是当前节选中最直接的实验证据。

与π系列的关系

  • Nexus-VLA 与 π0、π0-FAST、π0.5 和 OpenPI 同属视觉—语言—动作策略研究方向，也采用连续动作生成及 flow-matching 风格的训练目标，但本文是独立的跨具身联合学习框架，并非 π 系列模型或官方扩展。
  • 所给原文没有说明其继承 π0、π0-FAST、π0.5 的模型权重、网络实现、action tokenizer 或 OpenPI 训练代码，也没有报告以上述模型为骨干的实验。
  • RoboCasa-GR1 表 1 中没有 π0、π0-FAST、π0.5 或 OpenPI 对照，因此不能据此判断 Nexus-VLA 相对 π 系列的成功率、训练效率或推理速度优势。
  • 与 π 系列最相关的可迁移思想是外挂式训练监督：保留 VLA 的视觉—语言条件动作生成主路径，用一个共享 semantic token 接收意图、空间、运动和交互监督，再让动作损失反向塑造该 token；其作用更接近训练期表示约束，而不是替换 VLA 动作执行器。

对Austin研究的启发

  • 可在 OpenPI 执行器上加入单个 semantic token 和四类轻量 probe，先冻结或保持原有 action expert 配置，只比较“无语义监督、单层监督、四层共享 latent”三种设置，避免同时改变骨干与数据配方。
  • 为引导场 \(G\) 建立条件遵循测试：分别扰动目标区域、未来末端运动和接触状态标签，检查生成动作是否按语义层级产生可预测变化，从而判断 latent 是真正参与控制，还是仅作为辅助损失改善视觉表征。
  • 在闭环评测中记录语义 probe 置信度、动作 flow 残差、末端轨迹偏差和接触状态错误，并测试这些信号能否提前预测抓空、错物体、错目标区域和接触后滑落。
  • 数据设计上可先使用无需机器人关节标注的人类腕部轨迹扩充共享动作维度，再以少量机器人数据监督关节维度；同时扫描人类/机器人采样比例，绘制成功率与机器人示范量的曲线，验证人类数据是否真正降低机器人数据需求。
  • 为防止离线专家伪标签成为瓶颈，应加入标签置信度加权、随机坐标噪声、轨迹缺失和接触误标实验，并单独报告 ID、视觉 OOD、空间 OOD 与真实机器人迁移结果。

一句话总结

Nexus-VLA 由西安交通大学、中国科学院自动化研究所、中国科学院大学和北京邮电大学团队提出，通过四级跨具身语义共同塑造可直接驱动连续动作的共享潜变量，在 RoboCasa-GR1 的 24 个任务上取得 80.5% 平均成功率，但并非 π0、π0-FAST、π0.5 或 OpenPI 的官方继承工作。
