问题

  • 潜空间规划通常用候选未来图像与目标图像的特征距离选择动作，但这一距离未必对应操纵物体离目标还有多远；背景和机器人本体占据大量 patch，容易淹没小物体的位置信号。
  • 规划失败可能来自未来预测不准，也可能来自代价函数本身没有衡量任务进展。若只看端到端成功率，很难区分这两类原因；同时，机械臂与被抓物体同步运动，视觉表征还可能只是在追踪机械臂。
  • 物体放置需要带方向、带米制尺度的空间表示，而直接采集物体三维位姿或深度标注成本较高；冻结的动作无关视觉编码器也没有被显式训练去描述“动作如何改变物体状态”。
  • 论文在 RoboCasa 模拟厨房中研究已稳定抓持物体的运输与放置，并用模拟器执行候选未来来隔离预测误差；目标是仅依靠机器人关节角和正向运动学，学习可用于规划的物体中心、度量化视觉表示。

方法

  • 输入帧与候选状态：规划器接收当前观测帧 $I_t$ 与候选未来帧/目标帧 $I_{t+k}$，比较两帧中目标物体的位置变化；Figure 1 从左到右对照两种代价构造方式，核心问题是视觉特征距离能否充当物体位移的“尺子”。
  • (a) Pretrained Encoder 特征距离：预训练编码器将每帧映射为全部图像块特征 $F_t=\{f_t^i\}_{i=1}^{N}$ 与 $F_{t+k}$，规划代价由跨帧 patch feature distance 聚合得到，如 $\sum_i\|f_t^i-f_{t+k}^i\|_2$。由于背景和机器人像素占比更大，该距离主要反映二者变化，而非目标物体位置。
  • (b) Object Token 坐标读取：模型从专门的 object token $o_t$ 中读取物体坐标 $\mathbf{p}_t=(x_t,y_t,z_t)\in\mathbb{R}^3$，并对另一帧得到 $\mathbf{p}_{t+k}$；该紧凑表示将目标实体与背景、机械臂特征解耦。
  • 米制规划代价：最终直接以真实空间中的坐标差定义代价 $c=\|\mathbf{p}_{t+k}-\mathbf{p}_{\mathrm{goal}}\|_2$，单位为米。规划器据此选择使目标物体更接近期望位置的候选轨迹，避免把高维表征相似度误当作几何距离。

Feature distance is not a ruler for object location. (a) Planners with pretrained encoders compare all patch features of the two frames, a distance dominated by background and robot. (b) We read the object's coordinates from an object token and compare them in meters as the planning cost.
  • 整体流程为：图像经预训练 ViT 编码为 patch 特征，利用物体 mask 加权池化得到 object token；同一 token 分别送入空间读出器和动作条件动力学预测器，前者输出物体坐标并构造规划代价，后者预测动作作用后的 object token。
  • “what”分支不比较整幅图像，而是在 DINOv3 或 V-JEPA 2 的 patch 网格上按物体覆盖比例池化，得到 1024 维 object token，减少背景和机器人区域对代价的支配。
  • “where”分支用三层 MLP 将 object token 映射到三维坐标，并约束两帧读出坐标之差等于由正向运动学得到的夹爪位移。它只监督相对位移，因此不需要绝对物体位置标签，坐标原点可以自由平移。
  • 运动学监督成立于稳定抓持、物体不与环境接触且夹爪旋转较小的片段：作者把夹爪位移视为物体位移的代理，并由机器人连杆几何获得米制尺度。
  • “how”分支是因果 Transformer，以视觉历史、九维本体状态和七维已实现动作为条件预测下一时刻 object token；训练同时采用 teacher forcing 与自回归 rollout，目标来自停止梯度的 EMA teacher。
  • 空间 ruler、动力学预测器及视觉编码器最后八个 block 联合训练；但主要规划评测用模拟器执行候选动作得到真实未来图像，再用固定的 ruler 距离打分，因此重点验证的是表示与规划代价，而不是 learned dynamics 的端到端预测能力。

实验与结果

  • 表征诊断中，每个状态执行 300 条候选动作序列。预测特征代价与模拟器真实未来上的特征代价相关性为 \(0.711\)，但二者与物理 oracle 代价的相关性仅为 \(0.006\) 和 \(0.026\)；在同时含成功与失败候选的 87 个状态上，模拟器未来特征代价的成功判别 AUC 为 \(0.514\)，95% 区间为 \([0.483,0.545]\)，接近随机。
  • DINOv3 的全图特征差异中，背景、机器人和物体区域分别贡献 64.12%、33.09% 和 2.80% 的代价；物体对候选间分数变化的协方差贡献仅为 0.31%，支持“全图距离主要没有追踪被操纵物体”的判断。
  • 冻结特征读出在 reach、pick、place 上的组内秩相关差异明显：MLP 分别达到 0.940、0.218 和 0.010；这说明高 reach 解码能力可能来自机械臂构型，而不代表能准确定位待放置物体。
  • 在 21 个放置任务的无机械臂图像上，冻结编码器的全图特征距离与真实物体目标距离的最高秩相关仅为 0.111，物体池化最高为 0.346，mask 质心为 0.868；DOCK-DINOv3-L 和 DOCK-V-JEPA 2-L 分别达到 0.915 和 0.894。
  • 无机械臂闭环规划中，两种 DOCK 均成功 15/21，与读取真实物体位置的 oracle 的 15/21 持平；最好 mask 几何为 10/21，最好冻结特征距离为 9/21。DOCK-DINOv3-L 的最终距离为 \(15.48\pm0.05\) cm，oracle 为 12.56 cm。
  • 当未见过的机器人手臂出现在图像中时，DOCK-DINOv3-L 仍完成 12/21，DOCK-V-JEPA 2-L 完成 9/21；对应最好 mask 几何为 8/21，最好冻结特征距离为 5/21。不过 DOCK-DINOv3-L 的秩相关由无机械臂时的 0.915 降至 0.435，显示机器人外观仍会明显干扰表示。
  • 原文还报告其候选排序可零适配迁移到留出的布局、未见物体实例和类别；但给定正文片段没有包含该部分的分项表格与具体数值，因此不补写未披露结果。

局限与可以继续做的

  • 运动学代理依赖“稳定抓持时物体随夹爪平移”的假设；训练位移对排除了物体—环境接触，并限制夹爪旋转，因此尚未覆盖推、拨、开门、插入、滑动以及抓持内相对运动等接触动力学。
  • 论文主要评估已抓取物体的运输与放置。15/21 的结果不能证明系统能够学习新的接触技能，也不能证明能组合“接近—接触—驱动”全过程；抓取前的目标选择和接触建立仍在设定之外。
  • 主要结果借助模拟器执行候选未来，刻意隔离了 world-model 预测误差。这有利于诊断代价函数，但也意味着尚未证明 DOCK 的动作条件预测器在纯 learned rollout、长时闭环规划或真机误差下能保持同等收益。
  • object token 的构造依赖模拟器物体 mask；迁移到真实场景需要检测、分割和跨帧跟踪，同时处理遮挡、错误 mask、多个相似实例及目标物体选择错误。
  • 可继续做的实验包括：在真机稳定抓持数据上直接用编码器关节角和标定后的正向运动学训练；逐步加入旋转、接触和释放阶段；并分别报告 mask 噪声、遮挡、相机变化和抓持滑移对米制读出误差与闭环成功率的影响。
实验设置
  • 平台：RoboCasa 模拟厨房，共 21 个场景；机器人基座与相机固定。
  • 数据：9,951 条持物运输轨迹、309 万个有效帧；每步记录 \(256\times256\) 图像、物体 mask、关节角和接触信息，并渲染有机械臂与无机械臂两个视图。
  • 轨迹类型：随机游走、持续及定向运输、反向路径、专家路径、旋转和表面 sweep；训练使用无机械臂视图。
  • 位移数据：从稳定抓持且无物体—环境接触的片段构造；两帧都需看到物体，平移至少 5 mm，旋转至多 \(2^\circ\)。训练集含 404,397 对，位移范围从 0.5 cm 到超过 90 cm。
  • 时序数据：82,405 个窗口；每个窗口含 8 帧，间隔 0.25 秒，允许稳定抓持下的夹爪旋转。
  • 划分：整条轨迹按 80%/10%/5%/5% 划为训练、验证、读出拟合和测试分区；未见布局、物体实例和类别另行评测。
  • 视觉模型：ViT-L/16，采用 DINOv3 或 V-JEPA 2；输出 \(16\times16\) patch 网格，object token 维度为 1024。V-JEPA 2 将同一图像重复两次组成一个 tubelet。
  • 空间损失：坐标尺度 \(\ell=0.10\) m；Huber 阈值 \(\delta=0.05\)，对应 5 mm。
  • 动力学输入：九维本体状态包含夹爪三维位置、四元数方向和两个手指关节位置；七维动作包含平移、旋转向量及手指关节位置和的变化。
  • 联合训练：更新空间读出器、动力学预测器、编码器最后八个 block 和最终归一化层；每次更新采样 256 个位移对和 64 个时序窗口，场景均匀采样。
  • 优化：AdamW，最多 20,000 次更新，按验证损失选择检查点；两个损失用停止梯度的运行均值归一化，运行均值衰减为 0.99。
  • 表征诊断：360 个状态，每个状态执行 300 个候选动作序列；主要规划基准含 21 个放置任务，每个任务在初始决策处比较 300 个模拟器生成候选。
  • 规划对照：冻结 DINO/V-JEPA 特征距离、不同 mask 区域的特征距离、物体池化特征、mask 质心及“质心+尺寸”、真实物体距离 oracle；同时评测无机械臂和机器人可见渲染。
  • 主模型的距离结果报告三次评测的标准差；三次评测中的成功任务数一致。
AI导读和推荐理由
  • 这篇论文的价值不只是提出一种新视觉表征，而是用“模拟器真实未来”把预测误差与代价函数错误拆开，直接检验视觉条件是否真的按物体到目标的物理距离排序候选动作。
  • 它给出了一条不依赖物体三维位姿标注的度量监督路径：把机器人自身可测的运动学信号转化为物体中心表示，适合交互表示与组合泛化研究中对条件接口进行可核验的几何 grounding。

与本项目关系

  • DOCK 与 Austin 的 A/F 接口直接相关：其 object token 加三维 spatial ruler 可以作为 F 的一种实现，即用视觉表示“物体应沿哪个方向、移动多远”，也可直接作为目标持续跟随的闭环代价；相比用末端执行器未来运动监督，它只在稳定抓持条件下把夹爪位移视作物体位移，并通过无机械臂图像降低策略走机械臂捷径的风险。
  • 论文的 simulator-future 诊断可对应 Austin 对 G/F 条件遵循的关注：不能因为预测特征与真实未来特征一致，就认定代价理解了目标。Austin 可进一步加入 G/F 置零、反向和交换测试，检查候选排序与闭环行为是否随物体运动条件发生可预测变化，而不是把条件当成任务 ID。
  • 两者的差距也很明确：DOCK 使用模拟器 mask、研究已抓持物体的运输与放置，并未接入 OpenPI、π0 或 π0.5，也没有证明从语言和视觉获得交互意图、学习未见接触技能，或在物体×目标留出组合上实现策略级组合泛化。

启发

  • 将当前 G/F 评测拆成两层：先用真实或模拟器执行的候选未来评测 F 代价与真实物体—目标距离的 Spearman 相关、成功判别 AUC 和选中候选 regret；再接入 π0/π0.5 做闭环评测，以区分“接口没有表达正确目标”和“执行器没有遵循接口”。
  • 对同一初始场景构造至少四组条件：正确 F、置零 F、反向 F、与另一目标交换的 F。除最终成功率外，逐步记录物体位移在 F 方向上的投影、到目标距离是否单调下降，以及策略在中途偏离后能否重新纠正。
  • 可在 LIBERO 或真机稳定抓持片段中，用正向运动学产生弱监督，但应同时利用物体跟踪估计实际位移，筛除滑移、碰撞和释放帧；比较“末端位移监督”“物体轨迹监督”和二者一致性过滤后的表示迁移能力。
  • 组合数据应显式交叉覆盖物体×目标×方向×场景，并留出未见组合；DOCK 已展示未见实例、类别和布局的排序迁移，但这不同于把熟悉物体送往反常目标，后者需要同一初始场景配多个目标来排除物体—目标关联捷径。
  • 针对“抓到了但没有送到正确目标”，可把 DOCK 式 ruler 作为 π0/π0.5 外部监控器：持续估计物体到目标的度量距离，在距离连续上升或横向偏离 F 时触发重规划，并单独统计运输失败、错误目标放置、提前释放和失败恢复。

一句话总结

  • 明尼苏达大学的 DOCK 用稳定抓持下的机器人运动学自监督学习物体中心的米制度量表示，在 RoboCasa 21 个放置任务中完成 15 个、与真实位置 oracle 持平，但其证据主要覆盖模拟器中的持物运输与放置，尚未验证 OpenPI 执行器和新接触技能的组合泛化。
