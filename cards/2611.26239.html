深读｜Teaching Vision-Language-Action Models to Stop Safely

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • 现有 VLA 安全编辑或任务抑制通常从初始状态评测；但机器人先由原策略执行、再在中途交给编辑后策略时，后者仍可能继续完成已被禁止的任务。
  • “任务未完成”不足以代表安全：机器人在接管时可能已经抓住物体，后续虽然没有完成放置，却可能松爪、掉落物体或输出触及控制器裁剪边界的动作。
  • 本文研究 LIBERO 与 BadLIBERO 中的闭环中途接管：原 OpenVLA-OFT 策略先执行，适配后的策略从匹配恢复的早期或中期状态继续控制；适配并非冻结全部策略，而是对语言模型层使用 LoRA，并联合更新原有动作头。
  • 作者目标是让策略在不同执行阶段均停止被禁止行为，转而保持当前抓持状态，同时尽量保留其他允许任务的操作能力。

方法

  • 阶段I／Fallback Target Construction（后备目标构造）：对禁止任务示范集 $\mathcal D_{\mathrm p}$ 中每个策略输入 $x$（相机观测、本体感知与任务指令），将原动作块 $A\in\mathbb R^{H\times d}$ 替换为保持动作目标 $A_{\mathrm{hold}}$；并从候选接管状态执行脚本化 hold，确认其既阻止任务完成，又满足任务特定的物理事件约束。
  • 阶段II／Joint Policy Adaptation（联合策略适配）：将禁止样本 $(x,A_{\mathrm{hold}})\in\mathcal D_{\mathrm p}$ 与保留任务样本 $(x,A)\in\mathcal D_{\mathrm r}$ 混合训练同一 VLA 策略；前者监督模型在任务开始及执行途中停止，后者保留原始动作块监督，从而同时优化行为抑制与原能力保持。
  • Calibration（校准与检查点选择）：对训练过程中各 checkpoint 进行双重筛选：先要求禁止任务的完成率被充分压低，再要求 retained-task performance 达到保留阈值；在合格模型中选择保留任务成功率最高者，避免仅凭训练损失确定最终策略。
  • Response Audit（响应审计）：从 initial states 与 takeover states 两类起点比较该方法和基线，分别检验禁止任务是否仍被完成，以及停止后的真实物理结果；审计同时覆盖 task completion 与 physical outcomes，以排除“未完成任务但产生碰撞、掉落或其他不安全替代响应”的伪安全策略。

Overview of \method. We construct holding targets across prohibited-task demonstrations and jointly learn them with the original actions of retained tasks. Calibration filters checkpoints by task suppression and retained performance, then selects the one with the highest retained success. The response audit compares \method with baselines from initial and takeover states, examining task completion and physical outcomes.
  • SAFI（State-Aware Fallback Imitation）包含两阶段：先把被禁止任务的演示动作转换为“持续持握”后备目标，再将这些目标与保留任务的原始动作联合用于策略适配。
  • 后备目标保留每个样本原有的相机观测、本体状态和任务指令，但将动作块中的机械臂位姿变化统一替换为静止命令，并把动作块首个夹爪命令复制到整个动作块，避免停止时意外松爪。
  • 该后备监督覆盖被禁止任务演示中的初始及中间状态，因此不是只教模型在任务开始前拒绝，而是显式训练其从已经移动或抓持物体的状态切换为持握响应。
  • 在训练 SAFI 前，作者会从候选接管状态执行脚本化持握；只有当该响应既能阻止目标完成、又满足任务定义的物理事件标准时，才对该任务应用 SAFI。
  • 联合适配采用动作块平均绝对误差：被禁止任务拟合后备持握动作，保留任务继续拟合原始演示动作，两个损失等权相加并从原策略初始化。
  • 相较 GA、GradDiff、NPO-RT、RMU、Refusal FT 和 VLA-Forget，SAFI 没有另加运行时安全审查器或规划器，而是直接改变策略的动作输出；其中 Refusal FT 学习返回 home 的动作，SAFI 则学习与当前抓持状态相容的静止后备动作。

实验与结果

  • 在三个 LIBERO 设置的等权平均结果中，原始策略接管后的目标成功率为 99.7%，物理事件率为 12.1%；SAFI 将目标成功率降至 1.3%，且实验未记录到物理事件或动作饱和。
  • LIBERO 上，Refusal FT 的目标成功率和物理事件率分别为 11.6% 和 4.1%；GA、GradDiff 虽将目标成功率降至 12.2% 和 11.7%，动作饱和率却分别达到 100.0% 和 99.4%。SAFI 在三项接管指标上分别为 1.3%、0.0% 和 0.0%。
  • BadLIBERO 中，SAFI 的攻击目标成功率、物理事件率和动作饱和率均为 0.0%，与 RMU 的三项结果相同；NPO-RT 虽也实现 0.0% 攻击目标成功率，但物理事件率为 22.5%、动作饱和率为 100.0%。
  • 消融显示后备模仿是停止正在执行任务的关键：移除该项后，Spatial/Object 的目标成功率分别为 99.7%/100.0%；完整 SAFI 分别为 3.4%/0.3%，且两套任务均未记录物理事件。
  • 仅训练后备动作会破坏通用能力：移除保留任务模仿后，Spatial 和 Object 的保留任务成功率均降至 0.0%；完整 SAFI 分别保持 96.9% 和 93.1%，说明等权联合训练承担了主要的能力保持作用。
  • 物理响应分析以接管时所持物体的位置为参考；论文报告 SAFI 在早期和中期接管条件下均保持较低平均位移，并与脚本化持握进行比较，但所提供正文片段未给出该图的具体位移数值。

局限与可以继续做的

  • SAFI 的适用前提是“原地持握”本身安全。作者会进行脚本化适用性检查，因此该方法不能直接覆盖需要立即放下危险物、撤离、释放受困对象或执行急停制动的场景。
  • 证据主要来自 OpenVLA-OFT、LIBERO 与 BadLIBERO；所给正文未展示真实机器人实验，也没有验证 π0、π0-FAST、π0.5 或 OpenPI 策略上的迁移效果。
  • “未记录到物理事件”只针对论文预先定义的掉落、跌落等事件及动作饱和标准；它不能证明长时间持握的热安全、碰撞安全、夹持力安全或对人交互安全。
  • 所给正文片段没有披露每项评测的 episode 数、完整任务数量、LoRA 配置、训练步数、学习率及检查点筛选阈值，因而无法仅凭该片段核对置信区间或完整复现成本。
  • 可继续将单一持握目标扩展为状态条件化后备动作集合，例如“保持抓持”“安全放置”“回撤”“急停”，并用对象属性、接触状态和风险等级选择后备模式，而不是默认所有中间状态都静止。
  • 可在真机上增加长时接管、视觉遮挡、夹爪滑移、外力扰动与指令切换测试，同时分别报告禁止任务完成、物体掉落、碰撞、动作裁剪、恢复时间和允许任务能力，避免用单一成功率替代安全评估。
实验设置
  • 基座策略：公开发布的、按 LIBERO suite 训练的 OpenVLA-OFT 连续动作块策略。
  • 策略输入：相机观测、本体状态与语言任务指令；输出为包含机械臂运动坐标和夹爪坐标的归一化动作块。
  • 参数更新：语言模型层使用 LoRA，继承的动作头同时更新；所给正文未列出 LoRA rank、学习率、训练步数或其他优化器超参。
  • 数据划分：LIBERO 中每次指定一个被禁止任务，其余同 suite 任务作为保留任务；BadLIBERO 中分别使用投毒演示和干净演示，两者可以共享任务指令。
  • 基准：LIBERO-Goal、LIBERO-Spatial、LIBERO-Object，以及 GoBA 的 poisoned-object BadLIBERO 设置；具体任务数和演示规模在所给正文中未披露。
  • 接管协议：原始策略先开始执行，再从匹配恢复的早期或中期状态切换到编辑后策略；保留任务成功率则从正常初始状态评测。
  • 指标：Target Success Rate、Physical Incident Rate、Action Saturation Rate 和 Retained Success Rate；LIBERO 主结果对 Goal、Spatial、Object 三个设置等权平均。
  • 基线：原始 OpenVLA-OFT、GA、GradDiff、NPO-RT、RMU、Refusal FT、VLA-Forget（OFT）。
  • 检查点选择：先按任务抑制和保留性能进行校准过滤，再从合格检查点中选择保留任务成功率最高者；具体阈值位于未提供的附录 C.4。
  • 硬件：LIBERO-Goal 与 BadLIBERO 实验使用 NVIDIA RTX A6000；其他设置的硬件、训练时长和评测次数未在所给正文片段中说明。
  • 评测环境属于 LIBERO/BadLIBERO 基准；所给正文未报告真实机器人平台、具体机器人型号或额外力觉传感器。
AI导读和推荐理由
  • 推荐这篇论文的核心原因不是提出了更强的通用 VLA，而是指出了一个容易被常规成功率掩盖的安全缺口：从初始状态拒绝任务，不代表策略能在已经抓取或移动物体后安全停止。
  • SAFI 将“停止”定义成与当前物理状态相容的动作目标，并同时评测禁止目标、物理事件、动作饱和与保留能力，适合作为 π 系列安全微调和中途接管评测的参考协议。

与π系列的关系

  • 本文实验基座是 OpenVLA-OFT，并非 π0、π0-FAST、π0.5 或 OpenPI；正文也未报告与这些模型的直接技术继承、同协议数值对比或兼容性验证。
  • SAFI 修改的是策略适配数据与训练目标：把禁止任务轨迹中的原动作块替换为状态一致的静止机械臂、持续夹持动作，再与允许任务原动作联合训练。它没有修改 π 系列的流匹配/动作专家结构，也不是外挂式运行时审查器。
  • 对 π0/π0.5 一类动作块策略，最可迁移的部分是“覆盖中间执行状态的后备动作监督”；但夹爪编码、动作归一化、动作块长度及低层执行语义必须按各自策略重新定义，不能直接复用 OpenVLA-OFT 的标签构造。
  • 对 OpenPI，SAFI 更适合作为安全适配与评测配方：在现有数据管线中生成 fallback action chunk，并在执行器层加入 early/mid takeover 回放，而不是宣称已经证明 SAFI 能在 OpenPI 检查点上达到相同结果。

对Austin研究的启发

  • 在 OpenPI 执行器中增加可复现的中途接管接口：保存原策略 rollout 的观测、本体状态、动作历史和环境状态，从早期、抓取后、搬运中及放置前等节点恢复，再切换到安全适配策略闭环运行。
  • 将“禁止任务成功率低”拆成至少四项指标：禁止目标完成率、物体掉落/碰撞率、动作饱和率和保留任务成功率；对持握任务再记录接管后物体位移、夹爪状态变化与稳定保持时长。
  • 若研究引导场 \(G\) 的条件遵循，可把“继续任务”和“安全后备”设计成显式条件，测试策略在相同视觉—本体状态下能否随条件切换，而不是只从不同初始状态比较最终成功率。
  • 构造多后备动作数据，而非只复制静止持握标签：根据接触状态和对象风险分别监督保持、缓慢安全放置、回撤及急停，并先用脚本控制器验证每类后备动作的适用区间。
  • 增加动作块级监控：检查预测动作是否与当前夹爪接触状态冲突、是否连续触及裁剪边界，以及后备模式下物体位移是否持续增大；触发时交给低层安全控制器，而不是完全依赖 VLA 微调。
  • 做一组最小可行复现：选择一个 OpenPI 支持的抓取—放置任务，比较原策略、仅禁止任务反向优化、返回 home 监督和 SAFI 式持握监督，并按初始、早期接管、中期接管三个条件分别报告结果。

一句话总结

University of Notre Dame、Georgia Tech 与 MIT 的作者提出 SAFI，通过在禁止任务各执行状态监督“机械臂静止且夹爪持续保持”并联合保留任务模仿，使 OpenVLA-OFT 在所评测 LIBERO 任务的接管后目标成功率降至 1.3%，且未记录到物理事件或动作饱和。
