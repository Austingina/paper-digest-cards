深读｜Zero-Shot VLA Adaptation with Retrieved Guidance

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 预训练 VLA 在相机视角、背景、物体身份、目标位置乃至机器人形态发生变化时仍容易失效；而大型机器人数据集中的候选示范通常也与目标场景存在明显域差异，不能直接回放。
  • 现有机器人检索方法往往要求同具身、同域示范，或依赖任务微调；直接把检索示范拼入上下文，又受 VLA 上下文窗口限制，并要求模型自行消化视觉域差。
  • 仅按轨迹几何距离检索不足以保证可执行性：几何上相近的路径可能迫使当前策略显著偏离自身动作先验，导致不平滑或不稳定控制；稀疏 VLM 目标点还可能遗漏接触过程等连续约束。
  • 本文研究真机、仿真、仿真到真机及跨具身操作，在完全冻结基础策略权重的前提下进行闭环测试时适配；目标是利用跨域示范提高 VLA 成功率，同时不扩展上下文、不收集目标域训练数据，也不更新模型参数。

方法

  • 阶段(a) 语义任务类别过滤（Semantic Task-Category Filtering）：从大规模真实机器人数据集中读取语言指令标签，以 “pick”“place”等语义关键词筛选运动学轮廓相近的任务，形成与目标任务结构兼容的源轨迹候选池 $\{i\}$。
  • 阶段(b) 跨域轨迹扭曲（Trajectory Warping）：输入目标场景图像与任务实体描述，利用 Grounding DINO 的语义框检测定位功能角色对应物，提取目标航点 $W'$；再依据源航点 $W$ 与 $W'$ 的对应关系平滑变形源轨迹，适配视角、几何及机器人本体差异。
  • 阶段(c) 策略兼容检索（Policy-Compatible Retrieval）：先以动态时间规整（DTW）匹配粗筛 Top-$N$ 候选，再结合 VLA 预测的笛卡尔轨迹 $X_t$，选择 $i^\star=\arg\min_{i'\in[N]}\|\nabla_{A_0}\mathcal{C}_{i'}(X_t)\|_2$，避免仅按轨迹距离选到策略难以执行的示例。
  • 阶段(d) 能量引导去噪（Energy-Guided Denoising）：测试时将 $i^\star$ 构造成引导能量场 $\mathcal{L}_{\mathrm{warp}}\approx\|X_t-i^\star\|_2$，其梯度持续修正扩散/流匹配去噪方向，在不更新 VLA 权重、不占用上下文窗口的条件下实现零样本跨域适配。

Overview of \methodname pipeline. (a) We filter real-world datasets using semantic keywords for broad task categories with similar kinematic profiles, such as pick-and-place via language instruction labels in the datasets. (b) Task-relevant objects in the target scene are identified using semantic bounding box detection to extract target waypoints \( W' \), allowing the source trajectories to be smoothly adapted despite visual shifts. (c) Retrieval candidates $i$ are coarsely pruned to the top-$N$ using Dynamic Time Warping (DTW)-based matching. We then select the optimal trajectory $i^\star$ from pruned trajectories $i^{'} \in [N]$ that minimizes the guidance gradient norm ($||\nabla_{A_0} \mathcal{C}_{i^{*}}(X_t)||_2$), retrieving the demonstration best aligned with the VLA's expected Cartesian trajectory $X_t$. (d) At test time, the chosen reference $i^\star$ defines an energy field ($\mathcal{L}_{\text{warp}} \approx ||X_t - i^\star||_2$), steering diffusion denoising for zero-shot adaptation.
  • RAGu 的整体流程是：按语言关键词过滤出运动结构相近的示范，利用目标场景中的语义实体对轨迹做几何校准，再通过“DTW 粗筛＋策略兼容性细选”检索参考路径，最后把该路径转化为能量场，引导流匹配 VLA 的动作去噪。
  • 跨域变换不要求源场景和目标场景包含同一物体实例或类别，而是用 Grounding DINO 定位承担相同任务功能的实体，并以其包围框提取目标航点；源轨迹随后按照源、目标关键点之间的位移平滑变换到目标坐标系。
  • 一级检索以语义过滤池中的一个任意有效示范——通常是第一条——作为参考，通过动态时间规整（DTW）将已经变换的候选轨迹裁剪到 top-\(n\)，减少在线策略感知检索的计算量。
  • 二级检索先让基础 VLA 产生动作块，经可微前向运动学转换为笛卡尔末端路径；对每条候选路径计算序列匹配代价，并选择对初始噪声动作 \(A_0\) 的代价梯度范数最小者。该量用于估计策略需要偏离原始意图的程度，而不只是衡量轨迹几何距离。
  • 选中的参考轨迹定义 \(\mathcal{L}_{\text{warp}}\)，并通过 \(v_{\text{guided}}=v-\gamma\nabla\mathcal{L}_{\text{warp}}\) 修改流匹配去噪速度；每次推理只在第一个去噪步选择一次候选，之后的去噪步骤固定使用该轨迹。
  • RAGu 没有修改或重训 π0.5、GR00T 等骨干，也没有把示范图像或轨迹 token 拼入上下文；变换后的轨迹只是笛卡尔空间先验，具体闭环动作仍由基础 VLA 生成，因此也不需要在不同机器人之间显式映射关节或直接执行逆运动学轨迹。

实验与结果

  • 五项真机任务上，冻结的 π0.5 基线平均成功率为 20%，RAGu 提升到 80%；使用相同 100 条变换后 DROID 示范的 RICL 为 0%，Omniguide 为 40%。在接触丰富的 Wipe Table 中，RAGu 为 100%，Omniguide 为 30%，论文将差异归因于稠密轨迹能维持台面接触，而稀疏目标点可能使机械臂抬起毛巾。
  • RoboLab 的三项表列任务中，π0.5、RICL、VLS 和 RAGu 的平均成功率分别为 5.33%、1.33%、12% 和 25.33%；正文将后两者取整描述为 12% 与 25%。同一实验中 GR00T-N1.7 的表列平均值为 1.33%。
  • 从真实 DROID 到 RoboLab 的跨域实验中，RAGu 将 π0.5 的平均成功率从 5.33% 提升到 25.33%；在 MetaWorld Sawyer 到真实 Franka 的 Banana-to-Plate 多阶段迁移里，Cabinet→Shelf 子设置下 π0.5 与 Omniguide 均为 0%，RAGu 达到 60%。
  • 以 Franka DROID 轨迹引导 29-DoF Fourier GR-1 人形机器人时，100 条候选使未微调 GR00T-N1.5 的五任务平均成功率从 33.6% 提升到 47.2%，即绝对增加 13.6 个百分点；对微调版本则从 36.8% 提升到 48.8%，增加 12.0 个百分点。
  • 人形实验也显示引导并非逐任务都单调获益：只用 1 条轨迹时，未微调模型在 PlateToPlate 上由 56% 降至 44%，微调模型在 TrayToPlate 上由 44% 降至 40%；增加到 100 条候选后，两项分别变为 60% 和 48%，说明候选多样性及策略感知选择会影响结果。

局限与可以继续做的

  • 所给论文原文在“Visual and Environmental Diversity”段落处截断，未包含后续完整消融、延迟表、附录及作者明确列出的局限；因此无法从该节选核对 guidance strength、DTW 的 \(n\)、控制频率、硬件配置、置信区间数值或全部任务结果。
  • 真机结果每项仅 10 次 rollout，成功率以 10 个百分点为最小粒度；论文称置信区间在项目网站提供，但当前原文节选没有给出具体数值。可继续增加随机种子、场景扰动和 rollout 数，并统一报告置信区间与配对失败案例。
  • 语义校准依赖 Grounding DINO 正确定位承担功能角色的实体。遮挡、细粒度功能歧义或包围框中心不能代表有效接触点时，变换路径可能系统性偏移；可单独测量检测误差，并比较包围框、分割掩码、6D 位姿和人工关键点的影响。
  • 一级 DTW 使用任意有效示范作为参考，通常直接取过滤池第一条，可能对示范排序或异常轨迹敏感。可加入多原型聚类、medoid 参考或覆盖度采样，并报告候选召回率、最终成功率与在线延迟之间的关系。
  • 当前证据覆盖 π0.5-DROID 和 GR00T 系列，但没有给出 π0、π0-FAST 或 OpenPI 实现上的验证。可在统一 OpenPI 执行器中固定观测、动作块和控制频率，对比无引导、随机候选、仅 DTW、最小几何误差和最小梯度范数检索，确认收益究竟来自轨迹先验还是策略感知检索。
  • 梯度范数小只表示参考轨迹较少违背当前策略先验，不保证它一定通向任务成功；当基础策略本身存在错误偏好时，该准则可能保守地选择同样错误的轨迹。可加入任务进度、碰撞距离、接触保持和不确定度监控，并在执行中触发重检索或降低引导强度。
实验设置
  • 迁移设置：DROID Franka 真机→真机，5 项任务；DROID→RoboLab 仿真，9 项任务；MetaWorld Sawyer 仿真→真实 DROID/Franka 的多阶段 Banana-to-Plate；DROID 7-DoF Franka→RoboCasa 中 29-DoF Fourier GR-1，5 项桌面任务。
  • 评测次数：真机每项任务 10 次 rollout，仿真每项任务 25 次 rollout。
  • 真机任务包括 Open Drawer、Open Cabinet、Close Microwave、Towel to Plate 和 Wipe Table。
  • 除仿真到真机实验使用 100 条 MetaWorld Sawyer 专家轨迹外，其余设置以 DROID 作为源示范；RICL 与 RAGu 使用相同的 100 条变换后 DROID 示范池。
  • 基础策略：真机使用 π0.5-DROID；仿真使用 GR00T-N1.7；GR-1 人形实验同时使用开源 GR00T-N1.5 预训练与后训练检查点。
  • 所有实验中的模型在测试时均不更新权重；RAGu 也不扩展基础模型上下文。
  • 检索基线为 RICL，使用其已针对上下文适配训练的公开检查点，但测试时不更新权重；稀疏目标引导基线为真机 Omniguide 和仿真 VLS。
  • 主指标为任务成功率；额外轨迹指标包括末端执行器 SPARC，数值越高表示轨迹越平滑，以及另外两项在当前节选中未列明名称的末端轨迹指标。
  • 论文还测量每个 episode 的平均墙钟推理时间，但当前节选没有提供 Table VI 的具体延迟值。
  • 当前节选未披露 DTW 保留的 top-\(n\)、引导系数 \(\gamma\)、动作块长度 \(H\)、去噪步数、控制频率及运行硬件。
AI导读和推荐理由
  • 这篇论文直接回答了“冻结的大型 VLA 如何利用外部机器人数据”这一 π 系列相关问题：它没有继续扩充参数或上下文，而是把检索结果变成流匹配推理过程中的可微引导场。
  • 其价值不只在 20%→80% 的真机结果，还在于把跨域轨迹变换、策略感知检索和动作去噪接口拆成可独立验证的模块，适合用于分析 π 系列在域偏移下究竟缺少数据、几何先验还是执行约束。

与π系列的关系

  • 本文真机及部分 RoboLab 实验直接采用冻结的 π0.5-DROID 作为基础流匹配 VLA；RAGu 利用 π0.5 的动作去噪过程和可微前向运动学施加外部梯度，但不改变 π0.5 的网络结构、训练目标、参数或上下文。
  • RAGu 是外挂式检索与推理时引导框架，不是 π0、π0-FAST、π0.5 或 OpenPI 的新版本。所给原文没有报告基于 π0、π0-FAST 或 OpenPI 的实验，也没有证据表明本文与这些项目存在作者或机构上的技术传承关系。
  • 与依靠上下文示例的 RICL 相比，RAGu 不要求 π0.5 从跨域视觉 token 中自行推断动作对应关系，而是把示范压缩为目标坐标系下的稠密笛卡尔约束；与 Omniguide/VLS 相比，它沿完整轨迹持续引导，而不是只提供离散目标点。
  • 该方法依赖基础策略具有可被梯度修正的流匹配推理过程，因此向 π0-FAST 等不同动作表示或解码机制迁移时，不能直接假定同样有效，需要重新定义可微轨迹代价及其注入接口。

对Austin研究的启发

  • 在 OpenPI 执行器外增加独立的 guidance harness：读取当前动作块，将关节动作经可微前向运动学映射到末端轨迹，计算参考场 \(G=\nabla\mathcal{L}_{\text{warp}}\)，只修改采样速度而不动检查点；同时保留开关，以便同一策略做配对评测。
  • 建立四级消融：无引导、随机轨迹、DTW top-\(n\) 后按几何误差选择、按梯度范数选择。记录成功率、梯度范数、参考轨迹距离、动作平滑度和每个控制周期的额外延迟，以验证“策略兼容性”是否确实是主要收益来源。
  • 为引导场加入条件遵循监控：当梯度范数突增、末端偏离参考路径、接触丢失或连续若干步任务进度不增加时，触发重新检索、降低 \(\gamma\) 或退回无引导策略，避免错误示范持续支配闭环执行。
  • 评测应专门加入相机外参变化、目标物替换、功能相同但几何不同的容器，以及 Franka→人形等形态迁移；同时把“检测失败、变换失败、检索失败、控制失败”分开标注，而不是只汇总二元成功率。
  • 对接触任务可把单一末端位置轨迹扩展为位置、姿态、夹爪状态和接触阶段的组合能量，并测试稠密引导是否仍优于稀疏 waypoint；这比只复现 pick-and-place 更能检验 RAGu 的核心主张。

一句话总结

  • 宾夕法尼亚大学的 Subin Kim、Anh-Quan Pham 与 Dinesh Jayaraman 提出 RAGu，以跨域轨迹变换、DTW 粗筛和最小引导梯度范数细选为冻结 π0.5 等流匹配 VLA 提供测试时稠密轨迹引导，并将五项真机任务平均成功率从 20% 提升到 80%。
