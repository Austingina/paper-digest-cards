问题

  • 大规模机器人遥操作数据受机器人数量、场地和操作者设备约束；手持夹爪示范可以由多人并行采集，却不包含机器人执行、失败与恢复过程，存在明显的手到机器人分布差异。
  • 仅使用双腕相机时，策略看不到完整工作区；相似的局部画面可能对应长任务的不同阶段，容易引起步骤混淆、重复执行或提前结束。
  • 手持数据来自大量操作者与不同地点，而机器人通常部署在未见场地；背景、物体布局和机械臂本体变化都可能使依赖场景外观或机器人坐标系的策略失效。
  • 本文研究真机、双臂、闭环操作：策略根据连续更新的腕部视觉执行分钟级精细任务；预训练骨干并未冻结，而是与新增模块共同训练，训练阶段不使用遥操作、强化学习、机器人纠正数据或仿真。
  • 作者目标是建立一条从可扩展手持示范直接到多种机器人执行的完整路径，使同一策略兼顾长时程进度判断、精细接触、场景变化响应和跨机械臂迁移。

方法

  • 输入与 $\pi_{0.5}$ 主干（浅灰）：模型接收双腕部图像、语言指令与本体状态。两路腕部图像先经 SigLIP encoder 编码；指令、状态与编码后的视觉特征一并送入 Gemma 2B backbone，再由 Action expert（flow matching）输出动作块（action chunk）。这一路径对应公开 $\pi_{0.5}$ 主干。
  • 预训练新增——Visual budget gate（浅蓝）：在 SigLIP 特征进入主干之前，加入视觉预算门，并同时接收指令条件。该门决定哪些视觉信息被保留，体现论文的 See Less, Specify More 目标：压缩冗余观测、把容量留给任务相关区域。
  • 预训练新增——Subtask prediction（浅蓝）：Gemma 2B 另分出子任务预测头，在预训练中学习从当前观测预测细粒度子任务文本，为长程操作提供阶段语义监督。
  • 后训练新增——Stage head 与 Proprioceptive memory（深蓝）：Stage head 从主干预测当前阶段，并把预测结果以文本形式（stage as text）条件化 Action expert；同时，最近十步状态经过本体感觉记忆后再进入 Gemma 2B，为长时程任务提供进度与刚发生过的动作记忆。图例用颜色区分 $\pi_{0.5}$ 主干、预训练新增模块与后训练新增模块。

The A-0 model. Pre-training adds the visual budget gate and subtask prediction to the π0.5 backbone. Post-training adds the stage head, whose prediction conditions the action expert as text, and the proprioceptive memory.
  • 整体流程为：YUBI 双手手持示范采集与清洗、重定时 → 基于 π0.5 骨干的统一预训练 → 针对目标任务的手持数据后训练 → 推理 harness 将动作块连续解码并交给机器人控制器。
  • 将状态与动作定义在夹爪坐标系，而非机器人基座、关节或世界坐标系。每个动作都是相对于当前观测时夹爪位姿的独立目标位姿，并包含双夹爪开合命令，从而让人手持夹爪与不同机械臂共享同一种表示。
  • 在 π0.5 的 SigLIP、Gemma 2B 与流匹配动作专家上加入指令条件的视觉预算门控：门控学习为腕部图像 token 分配保留权重，并用预算损失约束平均权重，无需目标框、掩码或显式视觉区域标注。
  • 采用任务指令与子任务指令两级语言进行预训练；当输入整项任务指令时，语言骨干还通过辅助损失预测当前子任务。该预测只用于塑造训练表征，不直接作为动作专家的输入。
  • 后训练增加阶段预测头，将多个连续子任务组织成较粗的任务阶段；模型先从当前观测预测阶段，再把预测结果作为文本条件传给动作专家，以消解局部腕部视图中的阶段歧义。
  • 后训练还加入近期本体运动记忆；部署时对阶段预测进行平滑，并以作者提出的非均匀噪声调度持续重解码动作流，使新观测能够修正运动，同时避免动作块切换造成明显不连续。
  • 相对 π0.5，A-0 保留其视觉—语言—动作骨干和流匹配动作专家，但重定义机器人接口，并加入视觉预算门控、子任务辅助目标、阶段头、本体记忆及流式推理 harness；它不是冻结 π0.5 后仅外挂执行层。

实验与结果

  • 在十项 Franka 双臂任务上，A-0 的平均成功率为 78%；同一批任务示范后训练的 π0.5、Xiaomi-Robotics-1、GR00T N1.7 和 MolmoAct2 分别为 27%、23%、16% 和 14%。A-0 比最强对照 π0.5 高 51 个百分点，约为其 2.9 倍。
  • A-0 在十项任务上均取得最高成功率：颜色分拣 97%、燃料支架 93%、橙子金字塔 90%、字母积木 84%、零件配套 83%、杯子金字塔 80%、毛巾折叠/扫地机器人维护/笔袋均为 73%，耳机任务为 30%。耳机任务是其最明显的剩余短板。
  • 数据效率方面，十项任务中六项后训练只使用 3–6 小时左右的任务示范；例如毛巾折叠使用 3.3 小时并达到 73%，颜色分拣使用 4.1 小时并达到 97%。使用最多数据的耳机任务为 25.8 小时，但成功率仍只有 30%，说明示范时长并非唯一瓶颈。
  • 对照模型在每项任务上搜索动作 horizon 4–16、多种动作频率以及 60,000/80,000/100,000 次更新，并报告每项任务的最佳结果；A-0 则对全部十项任务使用同一后训练配方。因此 78% 对 27% 并非来自对 A-0 逐任务挑选最优超参。
  • 场景扰动案例中，人在机器人放置途中移动整排颜色箱并交换箱子位置，A-0 能依据最新腕部画面连续转向新的正确颜色箱，而不是按原位置回放轨迹；但正文给出的是定性案例，没有报告系统化扰动成功率。
  • 跨本体展示中，同一任务权重无需重训或针对机器人调整，即可运行于双臂 Franka、TX-G2、OpenArm 和双 UR 工业臂。正文列出了各平台完成的任务，但未提供 Franka 之外平台的重复试验次数或成功率。
  • 预训练数据规模实验显示，更多手持数据带来的优势在后训练后仍然存在；拟合关系为 \(L=0.063D^{-0.035}\)，\(R^2=0.98\)，其中 \(D\) 为预训练小时数。从约 1,000 小时扩展到约 16,000 小时的区间内，数据每翻倍，后训练后的动作损失约下降 2.4%。

局限与可以继续做的

  • 十项定量任务全部在同一 Franka 评测平台和同一未见场地完成；TX-G2、OpenArm 与 UR 只提供任务展示而无成功率，因此“跨本体”已经证明可运行，但尚不足以证明不同本体上具有一致可靠性。
  • 每项任务仅评测 15 次，并允许按任务完成程度给部分分；原文节选没有给出置信区间、完整成功与部分成功的拆分，也没有说明评分者一致性，78% 平均值的统计不确定性仍需补充。
  • 场景变化响应只有移动和交换颜色箱的定性案例。训练数据不包含机器人失败恢复，因此不能据此推断系统能普遍处理夹取失败、物体滑落、遮挡、碰撞或阶段判断错误。
  • 视觉预算门控、子任务辅助损失、阶段头、本体记忆和非均匀流式解码同时构成系统；所给正文未展示这些组件在真机成功率上的逐项消融，暂时难以判断 51 个百分点优势分别来自数据规模、表示方式还是新增模块。
  • 耳机任务即使使用 25.8 小时示范也只有 30% 成功率。可以按失败类型标注抓取、插入、线缆/小件遮挡和阶段错误，并分别增加近接触视觉、触觉或失败恢复片段，而不是单纯继续增加同分布示范时长。
  • 可继续做跨平台统一协议：在 Franka、TX-G2、OpenArm 和 UR 上对同一组任务各运行相同次数，同时记录成功率、控制延迟、逆运动学失败、碰撞和动作目标不可达率，以区分策略层跨本体能力与底层控制器差异。
  • 可增加闭环压力测试：随机移动目标、交换容器、打断阶段、拿走已操作物体，并比较普通 chunk 执行、均匀流式解码与非均匀流式解码，量化恢复率、反应时间和轨迹连续性。
实验设置
  • 数据：16,151 小时 YUBI 双手手持示范，覆盖一百余项任务；共 1,065 万个子任务片段，平均每段 5.5 秒。
  • 数据时间步：17.4 亿个、30 Hz；每条数据包含两个腕部视图、双夹爪位姿与开合状态，以及任务级和子任务级语言指令。
  • 训练数据不包含机器人遥操作、强化学习、机器人执行纠正或仿真数据；所有预训练和后训练数据均来自手持 YUBI。
  • 模型初始化：公开 π0.5 base checkpoint；视觉编码器为 SigLIP So400m/14，视觉语言骨干为 Gemma 2B，动作专家约 300M 参数并采用流匹配训练。
  • 预训练：骨干与视觉预算门控共同训练 300,000 步，batch size 为 2,048。
  • 输入：两路 \(224\times224\) 腕部图像、语言指令和本体状态；无头部相机或场景相机。
  • 预训练动作输出：20 Hz 网格上的 32 步未来动作块；每步双臂动作共 20 个数，包括平移、6D 旋转及夹爪命令。
  • 本体状态：一只夹爪在另一只夹爪坐标系中的位姿，加两个夹爪开合量，共 11 个数。
  • 主评测平台：双臂 Franka；评测地点未出现在任何训练示范中。
  • 主评测：十项双臂任务，每项由一句任务指令启动；每个成功率取 15 次试验平均，并允许部分完成获得部分分。
  • 任务后训练数据量：3.3–25.8 小时；十项任务合计包括毛巾折叠、字母积木、橙子金字塔、零件配套、颜色分拣、扫地机器人维护、燃料支架、笔袋、杯子金字塔和耳机。
  • 基线：π0.5、Xiaomi-Robotics-1、GR00T N1.7、MolmoAct2，均从各自公开预训练检查点出发，并使用与 A-0 相同的任务示范后训练。
  • 基线搜索：动作 horizon 为 4、6、8、10、12、14、16，并搜索多种动作频率及 60,000、80,000、100,000 次更新；表中报告每项任务的最佳设置。
  • A-0 对全部十项任务使用统一后训练配方；作者称单项任务后训练可在单节点 8 张 H200 GPU 上于 4 小时内完成。
  • 跨本体平台：双臂 Franka、TX-G2、OpenArm 和双 UR 工业臂；同一任务权重在不同机器人之间不重训、不调整。
  • 数据缩放实验：使用完整预训练数据的 100%、50%、25%、12.5% 和 6.25%；预训练验证集含 3,072 个来自留出录像的动作块。
  • 数据缩放后的后训练比较覆盖 16 个任务集，各模型取预训练 100,000 步检查点，在相同任务数据与设置下后训练。
  • 所给论文节选在后训练章节中途结束，未披露阶段平滑、本体记忆长度和非均匀噪声调度的完整超参数。
AI导读和推荐理由
  • 推荐这篇的核心原因不是又一个更大的 VLA，而是它把 π0.5 骨干放进一条完全由手持夹爪数据驱动的训练与部署链路，并在无机器人训练数据的条件下取得十项长时程真机任务平均 78%。
  • 它同时提供了可复查的工程接口：夹爪中心坐标动作、双腕视觉、显式阶段条件和流式动作解码。这些设计直接对应跨本体迁移、长任务步骤歧义与闭环修正，而不只是扩大模型参数量。

与π系列的关系

  • 本文明确基于 π0.5：使用其公开 base checkpoint、SigLIP So400m/14、Gemma 2B 和约 300M 的流匹配动作专家。它不是与 π 系列无关的独立架构，也不是只把 π0.5 当作外部报告数字。
  • A-0 相对 π0.5 的主要修改包括：以夹爪为中心的跨本体状态/动作接口、指令条件视觉预算门控、子任务文本辅助损失、后训练阶段预测头、本体运动记忆，以及非均匀流式推理 harness。
  • 原有骨干并未冻结；论文称骨干与视觉门控在 16,151 小时语料上共同训练。因此其提升不能简单归因于一个无需重训的外挂控制层。
  • π0.5 也是主实验的直接基线：双方使用相同任务示范后训练，π0.5 经逐任务超参搜索后的平均成功率为 27%，A-0 使用统一配方达到 78%。
  • 所给原文没有报告 π0、π0-FAST 或 OpenPI 实现的直接实验，也没有证明这些新增模块可无改动迁移到 OpenPI；与它们的关系应理解为可借鉴的接口和训练设计，而不是已经验证的兼容性。
  • A-0 没有引入文中可独立消融的 G/A-F 引导条件；其显式控制信号是由模型预测并作为文本送入动作专家的任务阶段。因此不能把结果直接解释为对引导场 \(G\) 条件遵循能力的验证。

对Austin研究的启发

  • 在 OpenPI 执行器中增加“夹爪锚定动作”适配层：策略统一输出相对观测时刻 TCP 的目标位姿，各机器人分别通过 IK 或笛卡尔控制器执行；先在两种机械臂上测同一检查点，记录策略误差与控制器不可达误差。
  • 将长任务评测从最终成功率拆成阶段序列：为每个 episode 记录预测阶段、真实阶段、停留时间和回退次数，检查策略是感知失败、阶段判断失败，还是动作专家未遵循阶段条件。
  • 若研究引导场 \(G\)，可以把 A-0 的预测阶段作为显式 \(G\) 输入，与“无阶段条件”“真值阶段”“模型预测阶段”三组比较；指标同时报告阶段遵循率、动作成功率和错误条件下的恢复能力。
  • 在 OpenPI 中复现流式执行时，应显式记录观测到动作生效的延迟、动作块重叠区的不连续度及重规划频率，并用移动目标和中途交换容器测试闭环能力，而不只在静态场景回放离线损失。
  • 数据路线可采用“手持视觉示教提取意图 + 统一夹爪动作接口 + 各本体执行器”的分层设计，但应先验证相机位置、夹爪几何和控制带宽变化；本文的跨本体成立条件是各机器人挂载同一 YUBI 夹爪及其腕部相机。
  • 针对视觉门控，应保存 token 权重与失败轨迹，比较其在新背景、遮挡和小物体任务中的稳定性；耳机任务的低成功率提示，压低背景信息可能不足以解决小尺度接触和遮挡问题。

一句话总结

A-0 由所给原文未披露机构的作者团队基于 π0.5 构建，以 16,151 小时纯 YUBI 手持数据和夹爪中心跨本体接口，在十项 Franka 长时程任务上达到 78% 平均成功率，对比同数据后训练的 π0.5 为 27%。
