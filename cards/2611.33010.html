深读｜Embodied AI Fails the Mirror Test

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • 通用机器人策略在常规视觉条件下取得较高成功率，并不代表其能正确区分真实物体与镜中倒影；倒影保留目标外观并随真实物体变化，却不对应可操作的物理位置，可能诱发“抓取虚像”或真实目标定位偏移。
  • 现有鲁棒性基准主要覆盖视角、光照、背景、传感器退化和相机时延等扰动；镜面不是普通外观变化，而是在满足确定几何关系的位置复制任务相关视觉证据，同时还引入实体障碍，二者需要被区分。
  • 论文在 RoboDojo 仿真框架中进行闭环操控评测：保持任务目标、成功判据、初始状态、策略检查点及观测/动作接口不变，仅比较无镜、单镜、双镜和镜面桌面；另在真实机器人上测试 π0.5 与 FastWAM。
  • 作者目标是建立可复现的 RoboDojo-Mirror 基准，量化反射导致的成功率下降，并通过非反射面板、轨迹和接触记录判断失败究竟来自物理碰撞，还是来自反射引起的视觉—空间错配。

方法

  • 匹配任务布局（Matched Task Layouts）：首先固定机器人初态、目标物体位姿与相机参数，构造相同布局 $\ell$；各条件共享同一任务实例，使后续差异仅来自场景外观干预，而非任务难度或几何配置变化。
  • 四类场景条件（Four Scene Conditions）：同一布局 $\ell$ 分别渲染为四种条件 $c\in\{c_1,c_2,c_3,c_4\}$，得到视觉观测 $I_t^{(c)}$；其中镜面条件会把机器人、物体及环境的反射引入图像，但不改变真实状态 $s_t$ 与任务目标 $g$。
  • 策略闭环评测（Policy Evaluation）：策略接收观测 $o_t^{(c)}=(I_t^{(c)},q_t,g)$，其中 $q_t$ 为本体状态，并输出动作 $a_t\sim\pi_\theta(\cdot\mid o_t^{(c)})$；动作驱动环境转移 $s_{t+1}\sim P(\cdot\mid s_t,a_t)$，最终按任务成功率比较四种条件下的性能退化。
  • 非反射面板对照（Non-reflective Panel Controls）：对部分策略额外加入与镜子具有匹配位置、尺寸和遮挡关系但不产生反射的面板，将“镜像视觉干扰”与“新增平面、遮挡或布局占用”解耦；镜面与面板条件的性能差 $\Delta_{\mathrm{mirror}}$ 用于定位反射本身造成的策略失效。

  • 整体流程为：从 RoboDojo 的相同任务布局和初始机器人/物体状态出发，加入不同镜面配置，向策略提供原有视觉、语言和机器人状态输入，由策略闭环生成动作，再以原任务成功判据及轨迹、接触日志评估结果。
  • 为每个任务构造四种配对场景：原始无镜场景、桌边单块竖直镜、相邻两侧相互垂直的双镜，以及将桌面材质替换为反射表面的镜面桌面；各条件之间不改变任务指令和目标。
  • 对每个策略固定检查点、观测接口、动作接口与推理设置；Astra 的相机流、机器人状态接口、运动工具和推理预算也保持一致。因此本文没有重新训练或修改策略骨干，而是对现有策略施加统一的外部评测条件。
  • 针对“镜子也是障碍物”这一混杂因素，作者为 WALL-OSS 和 Awomo-0.5 设置与单镜、双镜几何尺寸一致的非反射面板对照，并将面板接触独立记录，而不把接触本身作为 episode 终止条件。
  • 除总体成功率外，作者记录视觉观测、机器人状态和动作轨迹，并将典型行为归纳为三类：与镜面碰撞、把倒影当成可操作目标的 phantom targeting，以及未明确追逐倒影但对真实目标产生空间误定位。
  • 论文还设计了三个定向诊断：镜面桌面附近的抓取、推动与倒影轮廓相连的物体，以及主相机中真实目标受遮挡、主要依靠反射线索行动；所给正文节选未完整包含这些诊断的全部协议和数值结果。

实验与结果

  • 五种仿真策略的无镜总体成功率为 60.8%–72.5%；三种镜面条件均降低了所有策略的总体成功率。按三种镜面条件等权平均后，各策略相对自身无镜基线下降 10.8–56.7 个百分点。
  • 镜面桌面造成了最极端的单条件下降：VPP2 从 72.5% 降至 27.5%，下降 45.0 个百分点；Rex-M1 Preview 从 66.7% 降至 4.2%，下降 62.5 个百分点。
  • 各策略三种镜面条件的平均成功率降幅分别为：WALL-OSS 46.9 个百分点，VPP2 40.6 个百分点，Awomo-0.5 50.0 个百分点，Rex-M1 Preview 56.7 个百分点，Astra 10.8 个百分点。对应的 95% 配对布局簇 bootstrap 区间分别为 [38.3, 55.3]、[34.2, 46.9]、[42.2, 58.1]、[48.3, 65.0] 和 [1.7, 20.0]。
  • Astra 在单镜下仅从 65.0% 降至 62.5%，双镜和镜面桌面下分别为 52.5% 与 47.5%；其单镜、双镜机器人—镜面接触率却达到 55.0% 和 85.0%。高接触率与较小成功率降幅并存，说明“是否发生碰撞”不足以单独解释性能变化。
  • 在每个设置 120 组配对 episode 的镜面—面板比较中，镜面特异失败明显多于面板特异失败：双镜条件下，WALL-OSS 为 25 对 2，Awomo-0.5 为 42 对 3。镜面特异失败中，有 50.0%–87.5% 在镜面和面板条件下均未记录到机器人—面板接触，支持反射造成空间误定位、而非仅增加实体障碍的解释。
  • 在无镜基线成功且镜面与面板条件都发生接触的双镜子集中，非反射面板相对镜面的成功率优势分别为 29.4 个百分点（WALL-OSS）和 41.2 个百分点（Awomo-0.5）。进一步看镜面特异失败且两边均接触的 episode，镜面下平均接触时间占比分别是面板下的 1.85 倍（WALL-OSS，n=6）和 6.83 倍（Awomo-0.5，n=7），与策略持续尝试接近倒影位置的 phantom targeting 行为一致。
  • 真实机器人上的 π0.5 与 FastWAM 在直立镜和镜面桌面条件下也表现出总体成功率下降；当前提供的正文节选未给出真实机器人平台、任务数量、绝对成功率或置信区间，因此不能据此报告更具体数字。

局限与可以继续做的

  • 不同策略使用的执行预算并不相同，作者明确指出总体结果不能被解释为严格受控的跨策略排行榜；可靠结论是各策略相对自身无镜基线的配对变化。
  • 非反射面板对照仅用于 WALL-OSS 和 Awomo-0.5，且没有镜面桌面的对应非反射控制，因此“反射效应与物理结构效应”的分离尚未覆盖全部策略和全部镜面类型。
  • 主实验只有八个共享任务；Astra 每个布局仅执行一次，而其他四种策略每个布局使用三个策略种子。尽管采用布局簇 bootstrap，任务覆盖范围和 Astra 的重复次数仍限制了统计外推。
  • 真实机器人结果只验证了 π0.5 与 FastWAM 的总体下降趋势；所给节选没有披露足够的任务级数字和硬件细节，也没有证明仿真中的失败分类及镜面—面板因果关系能够完整迁移到真实环境。
  • 可以继续做的实验包括：在 OpenPI/π0.5 执行栈中加入镜面区域分割、深度不一致或射线几何检查；对同一检查点进行原始输入、镜面 mask、反射校正视图三路配对评测，分别测成功率、空抓率、末端轨迹偏移和持续接触时间。
  • 可进一步建立运行时反射监控：当视觉目标位置与深度、双视角三角化或机器人接触反馈不一致时，暂停当前动作块并触发重新观测或换视角；随后在单镜、双镜、镜面桌面及透明/高光表面上评估恢复率和误触发率，而不只报告最终成功率。
实验设置
  • 基准：RoboDojo-Mirror，构建于 RoboDojo。
  • 仿真策略：WALL-OSS-1.0-Lite、VPP2、Awomo-0.5、Rex-M1 Preview、GPT-6-Astra，共覆盖 VLA、World Action Model 与 agentic policy。
  • 真实机器人策略：π0.5 与 FastWAM；所给节选未披露机器人型号、传感器配置和任务级评测次数。
  • 任务：共享的 8 个操作任务；任务清单位于论文补充材料，当前节选未列出具体名称。
  • 场景条件：无镜、单块竖直镜、两块相邻且相互垂直的竖直镜、镜面桌面。
  • 面板位置：单镜和双镜相对初始构造位置向远离机器人的方向平移 5 cm；面板固定，但不保证执行中完全无碰撞。
  • 物理障碍对照：WALL-OSS 与 Awomo-0.5 使用几何匹配的非反射单面板和双面板；镜面桌面没有相应对照。
  • 主评测协议：WALL-OSS、VPP2、Awomo-0.5 和 Rex-M1 Preview 每个任务使用 5 个布局、每个布局 3 个策略种子，即每种场景条件每个策略共 120 个 episode；Astra 使用 5 个布局、每个布局 1 次 rollout，即每种条件 40 个 episode。
  • 执行方式：闭环 episode；任务成功判据和任务特定终止规则沿用 RoboDojo，任务终止或执行预算耗尽时结束。
  • 固定项：任务指令、任务目标、成功判据、初始物体和机器人状态、策略检查点、观测与动作接口以及推理设置。
  • 指标：任务成功率、八任务等权总体成功率、0–100 归一化原生任务分数、相对无镜基线的百分点变化、机器人—面板接触 episode 比例及接触时间占比。
  • 统计：95% 布局簇 bootstrap 区间；在固定任务内重采样布局，并保留全部策略种子和场景间配对关系。
  • Astra 额外约束：执行预算包含模型调用次数上限；具体调用上限在所给节选中未披露。
AI导读和推荐理由
  • 推荐这篇论文的原因不是它提出了新的 π 系列模型，而是它展示了一个训练分布外但结构明确的视觉失败源：策略可能识别出正确类别，却把镜中视觉实体映射到不存在的动作空间位置。
  • 相较仅加入噪声、光照或背景变化，镜面测试同时检验视觉语义、三维几何、动作可达性和闭环恢复能力；几何匹配的非反射面板对照又使“看错”与“撞到障碍”能够被部分拆分。

与π系列的关系

  • 本文不是 π0、π0-FAST、π0.5 或 OpenPI 的方法论文，也没有修改 π 系列的网络结构、训练目标或动作表示；其核心贡献是基于 RoboDojo 的反射鲁棒性评测协议。
  • 论文在真实机器人实验中包含 π0.5，并报告直立镜和镜面桌面会降低其总体成功率，但所给节选没有提供 π0.5 的具体绝对成功率、任务配置或动作分块参数。
  • 五种主要仿真策略不包含 π0、π0-FAST 或 π0.5；当前材料也没有显示对 OpenPI 执行器或 π0-FAST 进行直接实验，因此不能把仿真表中的 10.8–56.7 个百分点平均降幅直接归因于任何 π 系列实现。
  • 对 π 系列最直接的启发是：仅固定检查点并做标准任务回放不足以验证视觉—动作 grounding。OpenPI 或 π0.5 的评测应加入与初始状态、随机种子和任务成功判据严格配对的反射条件，并将模型输出与执行器接触日志联合分析。

对Austin研究的启发

  • 在 OpenPI 执行器侧增加可插拔的“反射安全 harness”：保留原策略权重与动作接口，只读取 RGB/RGB-D、末端轨迹和接触信号；当目标视觉位置缺少一致深度或对应动作持续指向不可达平面时，触发重观测、换视角或动作块中止。
  • 针对引导场 \(G\) 的条件遵循，可构造真实目标与倒影同时可见的成对样本，检查策略究竟遵循语言指定目标、可达空间约束，还是被更显著的倒影吸引；指标应包括真实目标接触率、空抓率、朝倒影方向的轨迹比例和恢复后成功率。
  • 将 RoboDojo-Mirror 的四条件协议迁移到同一 π0.5/OpenPI 检查点：每个布局固定初始状态和随机种子，分别执行无镜、非反射面板、镜面面板和镜面桌面，避免用不同 episode 的总体均值掩盖镜面特异失败。
  • 为闭环评测增加“第一次定位错误后的恢复”指标：记录策略是否能在抓空、碰撞或目标未移动后重新定位真实物体。本文已表明接触率与成功率下降并不单调一致，仅监控碰撞无法覆盖 phantom targeting。
  • 数据侧可以加入带镜面 mask、镜面平面参数和真实/虚像对应关系的轨迹，但应先比较零训练诊断、输入级反射校正与少量反射数据微调，确认收益来自几何理解，而不是简单记住某类镜面外观。

一句话总结

北京大学团队提出 RoboDojo-Mirror，在固定任务与策略检查点的配对闭环评测中发现五类策略的三种镜面条件平均成功率下降 10.8–56.7 个百分点、单项最大下降 62.5 个百分点，并以非反射面板对照表明大量失败无法由直接碰撞解释。
