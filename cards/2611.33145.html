问题

  • 现有空间推理评测多基于静态图像、预采集视频或室内仿真：模型可以依赖“冰箱通常在厨房”等语义先验，而不必真正估计距离、朝向与动作后果。
  • 既有户外导航平台也存在缺口：合成城市缺少真实视觉变化，街景数据通常限制在离散拓扑图上，难以评估连续运动、精细控制及长程闭环纠错。
  • 论文关注真实校园户外场景中的闭环具身空间推理：VLM根据目标图像和前、左、右三个自我中心视图反复输出动作，环境执行后再返回新观测，而非只对固定轨迹做开环问答。
  • 作者目标是建立一个同时覆盖“推理是否正确”和“推理能否转化为有效行动”的统一基准，并定位导航失败背后的具体空间能力瓶颈，而不是提出新的导航策略。

🧭 模型结构图逐模块详解（AI 精读）
  • 真实校园环境构建（Outdoor 3DGS Environments）：由实地校园采集的多视角图像重建大规模、照片级室外场景；每个三维高斯表示为 $G_i=(\mu_i,\Sigma_i,\alpha_i,c_i)$，经相机位姿 $T_t\in\mathrm{SE}(3)$ 渲染智能体当前观测 $o_t$，形成可交互的具身环境。
  • 空间指令输入（Spatial Instructions）：任务向视觉语言模型提供语言指令 $x$、初始观测 $o_0$ 与目标条件 $g$；不同指令类型要求模型联合理解地标、方向、相对位置及路径关系，并将语言空间约束映射为内部状态 $z_t=f_\theta(o_{\le t},x)$。
  • 闭环交互导航（Closed-loop Interactive Navigation）：策略 $\pi_\theta(a_t\mid z_t,x)$ 在每个时刻输出前进、转向或停止动作 $a_t$；环境据此更新位姿 $s_{t+1}=F(s_t,a_t)$ 并返回新观测 $o_{t+1}$，构成“感知—推理—行动—再感知”的闭环轨迹 $\tau=\{o_t,a_t\}_{t=0}^{T}$。
  • 导航落地问答与诊断（Navigation-grounded QA）：模型依据执行轨迹 $\tau$ 和终止场景生成答案 $\hat y$，与真值 $y$ 共同计算导航及问答指标；结果进一步投影为六项具身空间推理能力得分 $\mathbf c=(c_1,\ldots,c_6)$，用于细粒度区分空间理解缺陷与动作执行误差。

Overview of the Lost on Campus benchmark. The evaluation is built upon large-scale photorealistic outdoor 3DGS environments reconstructed from real-world campus captures. This benchmark leverages closed-loop interactive navigation using different spatial instructions, integrating spatial understanding with action execution. Through navigation-grounded QA in an embodied context, it provides a fine-grained probe of six diagnostic ESR capabilities.
  • 整体流程为：采集真实校园全景视频与厘米级RTK/GPS位姿 → 重建可连续移动的户外3DGS环境 → 自动采样起点—目标图像对 → VLM闭环输出动作序列 → 根据执行轨迹计算导航指标并生成诊断问答。
  • 环境采用改进的Octree-GS：加入外观与瞬态嵌入以处理跨视频的光照和动态干扰，使用三角形图元改善几何恢复与碰撞检测，并通过天空掩码和独立神经场减少天空漂浮伪影。
  • 导航统一表述为Image-Goal Navigation。模型根据目标图像及当前多方向RGB观测选择平移、旋转或停止动作；环境更新连续相机位姿并渲染下一轮观测，形成感知—推理—行动闭环。
  • 诊断QA不是独立收集的静态题库，而是从不同VLM完成的导航轨迹中自动生成，共覆盖六类能力：动作落地、空间预判、度量感知、目标导向规划、自我—世界坐标定位及时空一致性。
  • 六类任务分别检查视觉变化与自运动的对应关系、动作后的视图预测、远近和趋近趋势判断、中间子目标选择、自我中心视角到BEV坐标的转换，以及物体暂时不可见时的空间记忆。
  • 相对被评测VLM，论文主要增加的是外部环境、动作接口和诊断harness；所给正文未描述针对该基准训练新策略，也未报告对基础模型进行微调或权重更新。

实验与结果

  • 在1,500个常规Image-Goal案例上，Gemini-3-Flash取得最高的严格成功率：SR@2.5为25.73%，SR@5为49.60%；对应SPL@2.5和SPL@5分别为17.29%和31.16%，说明即使表现最好的模型，在2.5米阈值下也只有约四分之一任务成功。
  • 开源模型中，Qwen3.5-27B的SR@5为34.07%、SPL@5为31.91%、最终DTG为9.48米；其路径效率接近并略高于Gemini-3-Flash的SPL@5，但严格SR@2.5仅为9.93%，反映“向目标推进”与“准确抵达并停止”并不等价。
  • InternVL3.5-8B在2.5米阈值下的OSR为29.60%，但SR只有5.33%；在5米阈值下OSR为48.60%、SR为13.73%。模型经常曾经进入成功区域，却未能在正确位置停止，是显著的闭环终止或定位失败案例。
  • 停止后进行3DGS位姿后优化、且不改变已执行动作序列时，Gemini-3-Flash的SR@2.5提高10.00个百分点、SR@5提高2.33个百分点；GPT-5-Mini分别提高6.40和3.80个百分点。这表明严格成功率的一部分损失来自终点位姿或局部定位误差，但不能解释全部规划失败。
  • 论文报告户外环境下现有VLM整体表现较差，并将空间预判、自我—世界坐标定位识别为主要诊断瓶颈；但给出的正文片段未包含六类QA的逐模型准确率，也没有提供与室内基准同协议的数值对照，因此该结论在此只能按作者的定性分析引用。

局限与可以继续做的

  • 这是单一校园域的预印本基准。虽然包含15个场景和约20万平方米，但建筑风格、道路结构、天气、季节、人车密度与地理区域仍有限，不能直接代表一般城市、自然环境或跨洲户外导航。
  • 仿真视觉来自真实采集，但交互发生在3DGS重建中，不等同于真机运行；重建伪影、碰撞几何误差、相机高度固定及缺少真实动力学，都可能改变VLM的感知与控制难度。
  • 主导航表只覆盖1,500个常规案例；正文还介绍了255个复杂指令案例和6,000道诊断题，但所给原文片段没有披露这些设置的完整量化结果，也未报告置信区间、多次随机运行或统计显著性。
  • 后续可在保持相同起终点和动作接口的前提下，分别加入显式拓扑图、度量地图、视觉里程计与回环检测，比较纯VLM、VLM+SLAM和分层规划系统，从而分离感知定位、全局规划和局部控制的贡献。
  • 可将OSR与SR之间的差距直接用于失败驱动训练：收集“进入目标区域后又离开”的轨迹，训练独立的到达判定器和停止控制器，并按路口、长距离、视角差异及重建质量分层报告结果。
  • 为检验跨场景泛化，可采用按建筑或校园留出的评测协议，并增加昼夜、天气、季节和动态遮挡重采集；若迁移到真机，还应同步记录RTK、视觉惯性里程计和安全接管事件。
实验设置
  • 平台：由真实校园采集重建的户外3D Gaussian Splatting仿真环境，支持任意连续相机位姿下的视图渲染。
  • 采集设备：Insta360 X4全景相机；每个全景帧拆分为四个透视视图，共同覆盖水平视场。
  • 位姿与尺度：使用移动RTK设备为图像采集厘米级GPS坐标，用于跨视频标定、重叠区域稠密重建及统一米制尺度。
  • 数据规模：超过50,000个已标定视频帧，覆盖15个教学楼和道路交叉口场景，总面积约20万平方米。
  • 场景组成：11个建筑级场景、4个三岔或四岔路口级场景；每个场景平均重建面积约12,700平方米，平均可导航面积约6,500平方米。
  • 常规导航集：每个场景100个案例，共1,500个；起点—目标距离在5–25米范围内均匀分布。
  • 复杂指令集：另有255个挑战案例，包含长距离导航和交叉路口等复杂情形；所给正文未进一步列出三种空间指令的具体模板与各自数量。
  • 诊断集：六项任务各1,000题，共6,000个QA样本；问题由不同VLM的已完成导航轨迹自动生成。
  • 输入：每个导航决策接收前方、左侧+90°和右侧−90°三个自我中心RGB视图，每幅分辨率为512×512，并提供目标图像。
  • 动作空间：前进或后退1米、左转或右转45°、左转或右转15°、停止；一次模型调用可以返回多个原子动作。
  • 终止协议：模型输出停止动作即终止，episode最大长度为100步；正文片段没有进一步说明该上限如何统计多原子动作序列。
  • 导航指标：SR、OSR和SPL均在2.5米与5.0米成功阈值下报告；辅助指标包括DTG、DINOv2终点视图相似度、进展分数、轨迹长度、推理调用次数和原子动作数。
  • 被测闭源模型：Gemini-3-Flash、GPT-5-Mini。
  • 被测开源模型：Qwen3.5-9B/27B、Qwen3-VL-8B/32B-Instruct、Gemma-4-31B、InternVL3.5-8B。
  • 所给正文未报告具体推理温度、提示词全文、采样随机种子、计算硬件或模型量化设置，也未描述基准专属训练或微调。
AI导读和推荐理由
  • 推荐这篇的首要原因不是它提出了更强的导航智能体，而是它把真实户外视觉、连续闭环控制和轨迹级能力诊断放进同一评测体系，能揭示静态空间问答分数掩盖的执行失败。
  • 其OSR—SR差距和停止后位姿优化实验尤其有工程价值：导航失败不能只归结为“规划错了”，还需区分是否曾到达、是否识别到达、是否准确定位以及是否及时停止。

与现有VLN/SLAM对比

  • 相对REVERIE、NavBench等离散VLN设置，本基准允许连续相机位姿和米制平移、旋转动作，因此能测试细粒度朝向控制、终点误差和动作累积后果。
  • 相对OVON、GOAT-Bench、LHPR-VLN、OctoNav和NavSpace等以室内HM3D或MP3D为主的连续导航基准，它转向尺度更大、语义密度更低的真实户外校园，减少依赖房间布局与物体共现关系完成任务的空间。
  • 相对Touchdown的街景拓扑图，它保留真实户外外观，同时不把智能体限制在离散全景节点；相对EmbodiedCity，它使用真实采集和3DGS重建，而不是纯合成城市。
  • 相对传统SLAM，该工作不提出新的定位、建图或回环算法。RTK、GPS和3DGS主要用于环境构建、米制真值和评测，不能视为被测智能体已经获得完整SLAM能力；BEV地图只明确出现在自我—世界坐标定位诊断任务中。
  • 工程权衡是用3DGS获得高保真、可重复且可连续渲染的视觉环境，但代价是仍需处理重建伪影、几何碰撞精度和仿真到真机的差距；三方向视图和离散动作原语也简化了真实机器人的传感与动力学问题。

对Austin启发

  • 空间表示上，可将当前纯视觉历史显式投影到局部SE(2)占据图或稀疏拓扑—度量混合图，并分别评测自我中心预测、BEV定位和目标图像匹配，避免端到端SR无法说明几何表征究竟错在哪里。
  • 分层接口上，可让VLM只输出航点、方向约束和停止置信度，由视觉里程计或SLAM负责姿态跟踪，局部控制器负责执行；再与原始“VLM直接输出原子动作”协议对照，量化高层推理和低层控制解耦后的收益。
  • 监控指标上，应同时保留SR、OSR、SPL、DTG和停止位置误差。尤其要自动标记“曾到达但最终失败”的episode，并将其拆成定位漂移、目标确认失败和停止策略失败三类。
  • 数据设计上，可沿用轨迹自动生题的思想，从同一真机或仿真rollout生成动作后视图预测、趋近/远离判断、子目标选择和遮挡后物体方位题，让导航训练数据同时监督世界模型与长时空间记忆。
  • 泛化评测上，可按场景留出并引入昼夜、天气与季节变化；若使用3DGS预训练或调试策略，应确保测试校园的几何与图像未泄漏到地图构建或导航模型训练阶段。

一句话总结

UVA主导的Lost on Campus以15个真实校园3DGS场景统一评测闭环Image-Goal导航和六类轨迹诊断，在1,500个常规案例上最佳Gemini-3-Flash仅达到25.73% SR@2.5和49.60% SR@5，显示空间预判、坐标转换及准确停止仍是户外具身VLM的核心短板。
