深读｜Allocentric Memory, Egocentric Acting

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • 城市语言目标无人机导航要求 UAV 根据目标外观、周边地标及空间关系，在目标通常不处于当前视野内的情况下完成长距离飞行；仅依赖当前第一视角观测，容易在视点和航向变化后丢失早期关键证据，形成“导航失忆”。
  • LLM/VLM 驱动的自中心规划难以长期维持一致的空间参照；已有地图式策略虽然保存环境信息，却多在黑盒网络中隐式融合地图特征，未必能把历史视觉证据显式锚定到固定物理位置并用于最终目标预测。
  • 论文研究连续城市仿真环境中的闭环导航：每次动作后更新观测、位姿、运动历史和地图，再重新预测目标；预训练多模态骨干保持冻结，仅训练外围的空间记忆、查询和目标回归模块。
  • 作者目标是把稳定的地图坐标推理与随位姿变化的机体坐标执行解耦，以更稳定、低开销的方式完成城市尺度语言目标定位和飞行控制。

方法

  • LLM-driven Planning（LLM 驱动规划）：输入语言指令 $\mathcal{I}$ 与当前第一视角观测 $\mathbf{o}_t$，直接生成导航决策；由于缺少固定空间参照，同一地标的方位会随无人机位姿 $\mathbf{s}_t$ 变化，推理易受视角漂移影响。
  • Map-based Policies（地图策略）：将历史观测累积为地图记忆 $\mathcal{M}_t$，再与视觉、状态等特征送入黑盒网络隐式融合；地图虽提供全局信息，但空间查询、目标定位与动作生成之间缺少显式坐标语义。
  • CityNav-VLA 空间推理：策略 $\pi_\theta$ 以 $\mathcal{X}_t=(\mathcal{I},\mathbf{o}_t,\mathbf{s}_t,\mathcal{H}_t,\mathcal{M}_t)$ 为输入，用动态 egocentric context 查询持久化 allocentric spatial memory，输出固定地图坐标系 $\mathcal{F}_M$ 中的归一化航点 $\hat{\mathbf{w}}_t$。
  • 坐标变换与执行：执行策略选取 $\mathbf{w}^{\mathrm{exec}}_t$，结合当前位姿经 $\mathcal{T}_{M\rightarrow B_t}$ 转为机体坐标系 $\mathcal{F}_{B_t}$ 下的位移，再由控制器生成有界指令 $\mathbf{a}_t=\mathcal{C}(\mathcal{T}_{M\rightarrow B_t}(\mathbf{w}^{\mathrm{exec}}_t,\mathbf{s}_t))$。
查看论文原图英文题注（Figure 1 Caption）
\small Language-goal aerial navigation paradigms (\S). (1) LLM-driven planning uses instructions and egocentric observations, with pose-dependent bearings to the same landmark. (2) Map-based policies fuse map features implicitly within black-box networks. (3) CityNav-VLA queries persistent allocentric spatial memory with dynamic egocentric context to predict a map-frame waypoint, then converts it into body-frame commands using the current pose.
  • 整体流程为：自然语言指令、当前局部 RGB、累积全局地图视图、UAV 状态和运动历史 → 动态导航查询 → 检索持久的地图坐标系记忆 → 预测最终目的地的地图坐标 → 确定性控制器按当前位姿转换为机体坐标动作。
  • 系统维护固定朝北、位置与尺度在整段 episode 内不变的九通道地图，包含累积 RGB、地形高度、全部地标、指令相关地标、当前可见区域、累计探索区域和访问轨迹。已观察区域离开视野后仍保留在原地图位置。
  • 空间记忆将全局 RGB 视觉特征、九通道导航地图特征、可学习网格位置嵌入和显式度量坐标编码对齐到同一 \(14\times14\) 网格；每个 token 同时携带外观、导航线索及物理位置。
  • 动态查询由冻结骨干产生的多模态上下文、MLP 编码的 UAV 状态和 GRU 编码的近期运动历史相加形成，再通过多层交叉注意力检索地图记忆，回归归一化的平面坐标及相对地面高度。
  • 训练时在轨迹的每个时间步监督同一个最终目的地，采用换算到米制误差后的加权 Smooth-\(L_1\) 损失；CityBot-4B 骨干不更新，训练投影层、状态与历史编码器、地图及坐标编码器、解码器和回归头等外挂模块。
  • 推理阶段使用早期目标承诺 EGC：前 \(K\) 次仍执行当前预测，随后把这些预测的逐坐标中位数固定为余下过程的执行目标。EGC 不增加可训练参数；地图和观测仍持续更新，但固定目标不会再随新预测波动。

实验与结果

  • 在 CityNav 的 Test Unseen 上，摘要报告相对既有最佳结果，导航误差 NE 降低 21.2%，成功率 SR 提升 15.8%，SPL 提升 30.9%；所给正文片段没有列出这些指标的绝对值，也未给出对应基线名称。
  • 对精炼后的 CityNav 数据，摘要报告 NE 降低 6.2%、SR 提升 5.6%、SPL 提升 23.2%，均为相对此前最佳结果的变化，原文片段同样未披露绝对数值。
  • 原文内部存在一处需要核对正式表格的数字不一致：摘要称原始 Test Unseen 的 SPL 提升 30.9%，引言末尾则写为 26.1%；在未提供实验表格的片段中，无法判断哪一个是最终口径，因此不应将两者混用。
  • 累积消融的定性结论是：导航地图特征贡献最大，显式度量坐标进一步改善终点精度，EGC 继续提供增益；但当前论文片段没有给出各消融项的绝对指标或逐项差值。
  • 4B 规模模型在单张 NVIDIA A100 上平均每次决策耗时 0.68 秒，峰值显存为 8.6 GB；这是单步模型推理开销，不等同于包含仿真渲染、地图更新和飞控执行在内的端到端系统时延。

局限与可以继续做的

  • 证据完整性有限：提供的正文止于方法部分，缺少实验表格、任务数量、episode 上限、随机种子、置信区间和失败案例，因而无法核验绝对 NE、SR、SPL，也无法判断改进是否具有统计显著性。
  • 结果目前来自城市仿真协议。地图使用仿真器提供的配准俯视 RGB、地形高度、地标轮廓和地理坐标，现实部署中这些先验可能不完整、过时或存在配准误差，论文片段未验证真机飞行及定位噪声下的鲁棒性。
  • EGC 在第 \(K\) 次预测后锁定目标，可以抑制长程抖动，但也会限制后期纠错：如果早期观测不足、目标被遮挡或早期定位有偏差，中位数承诺可能稳定地锁定错误目标。可补做不同 \(K\)、基于预测方差的自适应承诺，以及检测到新证据后解除承诺的实验。
  • 方法依赖准确 UAV 位置、航向及地图到世界坐标的变换。可系统注入 GNSS 漂移、航向偏差、尺度误差和地图错位，分别报告目标定位误差、SR 与 SPL，以确定显式度量坐标何时由优势变为脆弱点。
  • 面向 Austin，可把固定先验地图逐步替换为在线 SLAM 或语义建图结果，并分别测试跨城市、跨季节和跨高度迁移；同时保留“地图坐标目标—机体坐标控制”的接口，以隔离感知、定位、规划和控制误差。
实验设置
  • 平台：CityNav 连续城市无人机导航仿真环境；正文明确使用仿真器提供的已配准俯视 RGB 图像，未报告真机实验。
  • 任务：根据自然语言描述寻找城市中的最终目的地；每个时间步闭环更新 RGB 观测、UAV 状态、近期运动历史和持久地图。
  • 地图输入：固定北向画布；预置地理坐标、地形高度、全部地标轮廓及指令相关地标掩码，并在线更新当前可见区域、累计探索区域、累积 RGB 和飞行轨迹。
  • 局部视觉输入：与当前航向对齐的观测，以及一个北向裁剪视图；累积 RGB 地图作为全局地图视图。
  • 骨干：CityBot-4B，由 Qwen3-VL-4B 适配而来；训练 CityNav-VLA 时骨干冻结。
  • 可训练部分：输入投影、状态 MLP、运动历史 GRU、地图与坐标编码器、位置嵌入、特征融合权重、交叉注意力解码器及目标回归头。
  • 空间记忆：\(14\times14=196\) 个 token，特征维度 \(D=256\)；视觉、导航地图、位置和度量坐标特征共享同一空间网格。
  • 坐标编码：使用地图单元中心相对地图中心的 \(x\)、\(y\) 偏移及径向距离，固定归一化尺度 \(s_c=400\,\mathrm{m}\)。
  • 输出：归一化地图平面坐标和相对地面高度；高度归一化尺度 \(s_z=100\,\mathrm{m}\)。
  • 损失：米制误差上的加权 Smooth-\(L_1\)；误差尺度 \(\delta=20\,\mathrm{m}\)，垂直项权重 \(\lambda_z=0.25\)。
  • 执行：确定性控制器依据当前 UAV 位置与航向，将地图坐标目标旋转、转换为前向、侧向和垂直机体坐标命令，并进行幅值约束。
  • EGC：使用前 \(K\) 次目标预测的逐坐标中位数；当前片段未披露 \(K\) 的具体取值。
  • 评测：报告 CityNav Test Unseen 及精炼 CityNav；当前片段未披露任务数、episode 时限、重复评测次数、成功距离阈值和具体对照检查点。
  • 效率测试：4B 模型、单张 NVIDIA A100；平均决策时间 0.68 秒，峰值显存 8.6 GB。
AI导读和推荐理由
  • 推荐这篇的核心原因不是简单地“给 VLA 加地图”，而是把历史视觉证据、最终目标预测和飞控命令分别放在明确的参考系中：地图坐标负责长期记忆与目标定位，机体坐标负责实时执行。
  • 它提供了一个工程上较清晰的分层接口：学习模块输出具有物理意义的三维目标，传统控制器负责坐标变换和有界动作；冻结 4B 骨干、只训练外挂模块，也降低了针对导航任务进行适配的训练负担。

与现有VLN/SLAM对比

  • 相比主要利用当前或近期视频上下文的 VLN/VLA，CityNav-VLA 将离开视野的观测保存在固定地图位置，并通过指令和当前状态构成的查询主动检索，而不是要求模型仅从短期时序上下文中维持长程记忆。
  • 相比传统 GoalNav 或分层导航，方法预测的不是离散动作或短程局部子目标，而是整段 episode 的最终地图坐标目标；局部动作由确定性控制器根据当前位姿持续重算，因此全局推理与局部执行的职责边界更明确。
  • 相比经典 SLAM，论文重点不在同时估计位姿和几何地图，而是在已有地理配准及地图先验上组织视觉—语言证据。它使用 UAV 状态和仿真器地图变换，不能视为对未知环境 SLAM 的替代。
  • 相比已有地图式 VLN，核心增量是把视觉 token、导航地图通道和米制度量坐标对齐到统一网格，并直接回归地图坐标目标；代价是依赖高质量全局定位、北向地图和可靠的地理配准。
  • EGC 类似对高层目标增加低通稳定机制：无需重新训练即可减少目标抖动，但固定承诺牺牲了后期根据新观测大幅修正目标的能力。

对Austin启发

  • 可将现有导航栈的高层输出统一为带坐标系标识的度量目标，而不是直接输出控制动作；明确记录 map/world/body 变换链，并分别评测目标定位误差与控制跟踪误差，避免两类问题在端到端 SR 中相互掩盖。
  • 在在线 SLAM 地图上建立与本文相似的空间对齐 token：每个单元同时编码外观、可见性、访问历史、语义地标、坐标及其不确定度；查询端再融合语言指令、当前位姿和运动历史。
  • 将固定 EGC 改为不确定性感知的分层调度：目标预测方差足够小时才承诺；出现闭环重定位、地图更新或与新证据冲突时允许撤销，并记录承诺前后目标漂移及错误锁定率。
  • 跨场景泛化评测应拆分地图先验强度：分别使用完整地理先验、仅几何底图、在线构建地图和存在配准噪声的地图，检验性能来自可迁移的空间推理，还是来自仿真器提供的高质量先验。
  • 可增加“关键地标已离开视野”的专门测试集，按回看距离和时间间隔分桶统计 NE、SR、SPL，从而直接验证持久外部记忆是否真正缓解导航失忆。

一句话总结

CityNav-VLA 由国防科技大学团队主导、浙江大学参与，以固定地图坐标记忆连接动态机体坐标执行，在 CityNav Test Unseen 上报告 NE 降低 21.2%、SR 提升 15.8%，而 SPL 提升值在摘要的 30.9% 与引言的 26.1% 之间存在待核对的不一致。
