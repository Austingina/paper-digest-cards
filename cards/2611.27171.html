Learning from Incomplete Actions: Interval Motion Supervision for Vision-Language-Action Policies

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • 第一视角示范中的遮挡与跟踪失败会造成连续动作标签缺失；直接保留上一可靠位姿会产生“零运动后突然跳变”，插值会强行假设缺口内部路径，掩码训练则完全浪费缺口两端已知的净位姿变化。
  • 论文研究端执行器位姿增量学习：局部可靠动作仍可提供逐步监督，而缺口两端的可靠位姿只能确定整体平移与旋转，无法唯一确定内部轨迹、接触时机及缺失的夹爪动作。
  • 设定覆盖 LIBERO 仿真、Ego-informed RoboTwin 双臂任务和五个真机任务；策略从通用 π0.5 初始化继续微调，并非冻结策略权重。推理保持固定动作分块和闭环重规划形式，训练时才引入可变长度区间。
  • 作者目标是在不伪造逐点动作标签的前提下，同时利用可靠局部动作和端点净运动，使 VLA 能从动作标签连续缺失、甚至缺口长于策略动作视野的示范中有效学习。

方法

  • 共享动作—区间专家（Shared action-interval expert）：主调用与辅助 LIBERO 调用共享参数，均读取区间起点观测；动作 token 与区间 token 分别经 $W_A$、$W_D$ 嵌入。动作分支可关注上下文、动作及 $D_H$，区间分支仅关注上下文与自身。
  • 可靠动作监督 $L_A$：对掩码 $M_{b,i}=1$ 的动作，以 $x_{\tau,i}=(1-\tau)a_i+\tau\epsilon_i$ 加噪，并回归流速度 $u_i^A=\epsilon_i-a_i$；缺失动作不参与逐点损失。
  • 区间运动监督 $L_D$：主调用预测长度为 $H$ 的整体运动，辅助调用利用未占用的动作输出预测可变长度区间；两者共同学习由可靠端点确定的累计位姿变化。
  • 组合约束与推理 $L_B$：将一个或多个窗口内动作估计组合为 $\widehat B_X$，并与停止梯度的区间预测 $\operatorname{sg}(\widehat D_X)$ 对齐；该约束覆盖六维运动坐标而不监督缺失夹爪指令，推理时仅保留主调用。

  • 整体训练包含三个目标：可靠动作上的流匹配损失 \(L_A\)、可靠端点之间区间运动的流匹配损失 \(L_D\)，以及把缺口内动作按时间顺序组合后约束其净运动的损失 \(L_B\)；总损失为 \(L_A+L_D+\lambda_B L_B\)。
  • 对可靠动作保留原有逐位置流匹配目标；缺失位置不施加逐点动作损失。组合监督只约束六维平移与旋转净变化，因此不会假定缺口内部必须走线性轨迹，缺失夹爪动作也仍无直接监督。
  • 区间分支从区间起始观测、持续长度和带噪六维净运动中预测区间流；动作与区间使用独立 token 和投影，但共享同一个预训练 action expert。动作 token 可读取主区间 token，区间 token 只能读取上下文和自身。
  • 主方法把区间分支在当前流时间下得到的预测作为组合目标，并对该目标停止梯度：\(L_D\) 训练区间预测，\(L_B\) 则把监督传给缺口内动作估计，避免两端通过组合损失相互追逐。
  • 缺口长于固定动作视野时，方法不扩大动作块，而是用多个固定长度窗口覆盖同一缺口；各窗口读取自己的起始观测，窗口中的动作估计在同一计算图内按时间拼接，并共同满足一个跨窗口端点约束。
  • 缺失动作 token 可采用归一化零值、纯噪声或端点线性参考作为流输入；线性参考只提供输入路径，不作为逐点真值。部署时不再调用可变长度辅助分支，只联合去噪固定视野的动作和主区间 token。

实验与结果

  • 在 LIBERO 的 40 个任务上，仅使用 20% 示范且有 70.5% 动作缺失时，主方法三次训练平均成功率为 87.9%；论文摘要报告，在匹配观测暴露和训练成本的一组配对比较中，比 Mask 基线高 10.5 个百分点。
  • 单次训练的高缺失率组合实验中，“线性参考输入＋预测区间组合”达到 88.4%，对比 blocked-key Mask 的 76.4%、仅区间流匹配的 78.6% 和完整标签 Clean 的 92.4%。作者明确指出，较 Mask 的 12.0 个百分点增益同时包含注意力可见性、辅助观测和组合监督等多项变化，不能全部归因于 \(L_B\)。
  • 固定缺失输入后，组合约束具有稳定收益：三种输入下，预测区间目标较无组合损失提高 6.4–9.1 个百分点；观测端点桥接目标提高 6.0–7.5 个百分点。预测区间组合的三次训练均值分别为零参考 85.5%、纯噪声 85.6%、线性参考 87.9%。
  • 组件消融中，在零参考且缺失 token 可读的统一设定下：仅动作监督为 78.8%，加入观测端点组合为 84.5%；仅加入区间预测为 80.3%，区间预测与组合同时使用达到 87.8%。区间分支在已有组合监督时贡献 3.3 个百分点，而无组合监督时仅贡献 1.5 个百分点。
  • 跨域结果同样优于掩码：Ego-informed RoboTwin 缺口上的成功率为 45.4%，Mask 为 40.3%；五个真机任务平均成功率为 59.6%，高于仅区间流匹配的 54.8% 和 Mask 的 48.8%。所提供正文未展开这些实验的逐任务结果和方差。

局限与可以继续做的

  • 端点监督只确定净平移和净旋转，不能恢复缺口内唯一轨迹、接触顺序或夹爪时机；在存在绕障、接触切换或多解操作路径时，不同内部动作可能满足同一个端点约束却产生完全不同的控制结果。
  • 方法要求区间两端位姿可靠、位于一致坐标系，并且能读取区间起点观测；若视觉标注存在端点漂移、错误重捕获或跨相机坐标系误差，组合损失可能把错误净运动传播给整个缺口。
  • LIBERO 主结果来自人为构造的 1.2 秒连续位姿缺口和固定事件清单。虽然 RoboTwin 使用了来自 Ego 数据的双臂缺失模式、真机实验包含自然标注缺口，但给定原文没有披露端点噪声分层、不同缺口形态或真实标注误差强度下的完整统计。
  • 计算量并非完全不变：长缺口需要辅助区间调用和多个分组动作窗口。论文给出了匹配观测暴露与训练成本的配对结果，但所提供正文未列出实际显存、吞吐量和训练时长。
  • 可继续做的实验包括：对端点平移与旋转注入可控偏差以绘制鲁棒性曲线；按自由空间、接触阶段和夹爪切换分别统计成功率；比较单一净运动约束与多个中间锚点约束；在 OpenPI 中将区间 token 做成可插拔条件接口，并检查增益能否迁移到不同动作分块长度及不同 π 系列检查点。
实验设置
  • LIBERO：40 个任务，固定使用 20% 数据，共 339 条示范；所有方法共享视觉观测、普通动作窗口采样列表、缺口事件清单、初始化和评测器。
  • 初始化：所有 LIBERO 方法从同一个通用 π0.5 初始化进行微调；原文未将策略骨干描述为冻结。
  • 动作接口：单臂物理动作包含三维平移、三维旋转和一维夹爪命令；保留预训练动作接口及其填充维度，动作视野固定为 \(H=10\)。
  • 缺口构造：主实验使用 1.2 秒位姿缺口，12 个不可用位姿对应 13 个受影响动作差分；缺口频率被设为产生 70.5% 的动作缺失。
  • LIBERO 坐标与尺度：采用世界坐标平移和左乘旋转增量；动作组合中的平移、旋转尺度分别为 0.05 和 0.5。
  • RoboTwin：在刚体运动群 \(SE(3)\) 中进行局部坐标组合；每只机械臂遮蔽六维位姿动作，但保留原始夹爪标签。
  • 训练：LIBERO 训练 5,000 次更新，每次更新采样 256 个普通动作窗口；区间损失权重为 1。
  • 组合权重：预测区间目标在 LIBERO 上使用 \(\lambda_B=1\)，在 RoboTwin 上使用 \(\lambda_B=0.1\)；LIBERO 的观测端点目标变体使用 \(\lambda_B=1\)。
  • 推理：动作和主区间状态从独立高斯噪声开始，联合执行 10 个 Euler 去噪步骤；可变长度辅助区间调用仅在训练时使用。
  • 评测：每个仿真模型评测 800 个 episode，不同方法共享任务与初始化 key。正文表 1–6 及补充表 S4 每个设定为一次训练；补充表 S2、S5 为两次训练均值，S3 为三次训练均值。
  • 真机部分：覆盖五个任务，混合使用机器人示范和视觉标注的 Ego 示范；给定原文未披露机器人型号、传感器配置、每任务试验次数和逐任务结果。
AI导读和推荐理由
  • 这篇论文关注的不是新 VLA 骨干，而是 π0.5 一类动作分块、流匹配策略在“不完整动作标签”下如何训练；它把通常被掩码丢弃的端点信息转化为可微的整体运动约束。
  • 推荐价值在于其监督假设较贴近 Ego 示范转机器人数据的真实瓶颈：视觉仍可用，但连续动作标签因遮挡或跟踪失败而缺失。论文同时给出高缺失率仿真、双臂迁移和真机证据，并通过组件消融区分区间预测与动作组合的作用。

与π系列的关系

  • 论文明确在 LIBERO 上从同一个通用 π0.5 初始化微调，并保留预训练动作接口、固定 \(H=10\) 动作块和流匹配训练方式；新增的是区间 token、区间投影、注意力连接及组合损失，而不是替换视觉—语言骨干或重新设计动作生成器。
  • 动作与区间分支共享预训练 action expert，原有动作投影被保留；新增区间投影负责嵌入带噪净运动和持续长度。训练和推理中的模型权重会继续更新，不能把本文描述成“冻结 π0.5、只外挂无训练模块”。
  • 给定原文没有报告 π0、π0-FAST 或其他 π0.5 变体的直接对比，也没有说明已在 OpenPI 中实现。其思想原则上适用于采用动作分块和流匹配的 π0、π0-FAST、π0.5/OpenPI 策略，但当前证据只直接支持论文所用的 π0.5 初始化与实现。
  • 与简单线性补标签相比，本文的线性参考仅决定缺失 token 的流输入，真正监督来自整段动作组合后的端点一致性；因此它允许 π0.5 利用视觉上下文选择非线性的内部轨迹。

对Austin研究的启发

  • 在 OpenPI 数据接口中把监督拆成 action_mask、可靠局部动作和 (start, duration, relative_pose) 区间记录；不要在数据预处理阶段直接把连续缺口全部插值成伪真值。
  • 在执行器或训练 harness 中实现可微的动作组合算子：平移按动作接口反归一化后累积，旋转必须按时间顺序在 \(SO(3)\) 或 \(SE(3)\) 上组合，不能直接对旋转向量求和。
  • 为引导场 \(G\) 增加“区间净运动条件遵循”监控：分别记录预测区间误差、动作组合端点误差和闭环任务成功率，以判断模型是在真正利用条件，还是只学会满足端点而牺牲接触路径。
  • 复现实验可先做四格消融：无区间/无组合、仅区间、仅观测端点组合、区间＋组合；固定缺口清单、观测曝光和训练计算量，避免把缺失 token 可读性或额外前向调用的收益误算成组合损失收益。
  • 闭环评测应按缺口长度是否超过动作视野分层，并单独统计接触动作、夹爪切换和多解轨迹任务；同时加入端点噪声扫描，以检验真实 Ego 标注误差下是否仍优于 Mask。

一句话总结

北京理工大学 Yunpeng Mei、Chenyu Wang 等提出共享动作—区间分支和跨窗口组合监督，使 π0.5 初始化的 VLA 在 LIBERO 仅用 20% 示范且 70.5% 动作缺失时达到三次训练平均 87.9% 成功率，并在 RoboTwin 与五项真机任务上分别达到 45.4% 和 59.6%。
