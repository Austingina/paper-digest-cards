Beyond Linear Decodability: Understanding and Improving Instruction Following in World Action Models

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • 世界动作模型（WAM）虽然能完成复杂操作，却常在测试时忽略新语言指令，转而执行训练数据中更熟悉的物体选择或行为；仅证明目标信息“被编码”并不能说明它实际控制了动作。
  • 既有 VLA 方法多通过重新分配共享自注意力中的语言注意力缓解该问题，但本文研究的 Wan 系 WAM 通过交叉注意力向视觉表征注入语言，失败机制不能直接套用上述解释。
  • 作者关注的核心失败模式是视觉/行为先验压过指令信号：同一初始观察配上不同指令时，模型仍偏向固定目标，而不是依据语言改变操作对象或放置目的地。
  • 论文覆盖 LIBERO-CF、LangGap、RoboTwin-IF 仿真评测以及真机任务；LDS 训练会更新 WAM 参数，而机制验证采用不更新模型参数的表征干预。评测以完整操作成功率和目标定位率为主，属于闭环任务执行；原文节选未披露各平台的具体控制频率与动作接口。
  • 作者目标是解释 WAM 中“编码但不遵循”的机制，并以无需补采反事实动作轨迹的辅助监督显著提高指令遵循能力及跨场景泛化。

方法

  • (a) 辅助线性解码监督（Auxiliary LDS）：世界动作模型接收观测/历史与指令，形成隐表示 $h_t$ 并输出动作 $\hat a_t$；训练时附加线性头从 $h_t$ 解码指令相关信息。尽管推理时完全移除该头，指令跟随成功率仍由 $5.1\%$ 跃升至 $65.1\%$，说明收益来自表征重塑而非线性头本身。
  • (b) 先验—指令竞争（Prior--instruction Competition）：在动作决策特征中，较弱的指令信号 $I$ 与先验关联信号 $P$ 竞争，共同决定输出动作。无需训练地增强 $I$，或削弱/操控 $P$，均可显著改善指令执行，表明失败并非模型没有编码指令，而是 $I$ 在决策阶段被强先验压制。
  • (c) LDS 生效机制（Why LDS Works）：反事实落地监督（Counterfactual Grounding Supervision）通过改变指令而保持其他输入近似不变，构造特征更新 $h_t'=h_t+\Delta h_t$。该监督主要放大已有指令分量 $\|I\|$，同时基本保持其方向，即 $\cos(I_{\mathrm{before}},I_{\mathrm{after}})\approx1$，从而提升指令信号对动作输出的控制权。

Overview. (a) A surprising phenomenon. Auxiliary LDS improves instruction-following success from 5.1\% to 65.1\%, despite removing the linear head at inference. (b) Prior--instruction competition. A weak instruction signal $I$ competes with a prior-associated signal, and manipulating either signal substantially improves instruction following without training. (c) Why LDS works. Counterfactual grounding supervision amplifies the existing instruction signal $I$ while largely preserving its direction.
  • 整体流程为：给定图像观察与语言指令，WAM 通过交叉注意力将语言注入视觉 token；训练时在若干 DiT 中间层外挂线性头，从视觉 token 预测指令指定目标的空间区域；推理时移除这些线性头，仅保留经过训练的 WAM 生成视频与动作。
  • 作者先构建非遵循模型（NF）与指令遵循模型（IF）的受控对照：RoboTwin-IF 为同一场景和完全相同的初始视觉观察配置不同指令及对应专家行为，使仅依赖观察的捷径不足以拟合训练数据。
  • 诊断性线性探针冻结 WAM，只训练共享线性分类器，判断每个视觉 patch 是否属于指令指定目标；它用于比较 NF 与 IF 模型中目标信息的线性可解码性，不直接参与动作生成。
  • 线性可解码性监督（LDS）把诊断探针改成训练辅助目标：每个视觉 patch 再细分为 \(4\times4\) 单元，线性头预测细粒度目标图，并分别平衡指令目标、其他候选物体和背景区域的二分类损失。
  • 总损失由原始数据上的 flow-matching 损失与目标定位辅助损失组成。用于 LDS 的反事实样本只需“已有观察＋替代指令＋目标 mask”，不要求替代指令对应的动作或未来视频，因此不必重建原始环境并重新采集成功轨迹。
  • 作者提出“先验—指令竞争”机制：视觉 token 中存在附着于模型惯常目标的先验标签 \(P\) 和附着于语言指定目标的指令标签 \(I\)，两者都能影响动作，但 NF 模型中 \(P\) 占优。由此导出两种免训练干预——增强 \(I\)，或把 \(P\) 从先验目标迁移到指令目标——用于检验这些表征是否会因果性地改变行为。
  • LDS 没有更换 WAM 主干或增加推理模块；作者将其解释为放大已有 \(I\) 信号，而不是创造全新的表征方向：训练后 \(I\) 的幅值增大，\(P\) 仅小幅变化，两者方向总体保持近似不变。

实验与结果

  • 在 256 个 RoboTwin-IF 场景、515 条指令组成的探针面板上，跨层和计算位置平均的双向分类准确率由 NF WAM 的 51.5% 提升到 IF WAM 的 77.5%，相差 26.0 个百分点；探针准确率与指令成功率呈正相关，最小二乘拟合斜率为 2.07，但该相关性本身不构成因果证据。
  • 仅用反事实专家示范和 flow-matching 微调构建 IF 对照时，OpenWAM 在 RoboTwin-IF 留出场景上的成功率由 11.05% 提升到 47.76%，说明让同一观察对应不同指令行为可以削弱观察捷径。
  • 在 LIBERO-CF 上，OpenWAM 加入 LDS 后，成功率由 5.1% 升至 65.1%，目标定位率由 14.4% 升至 90.3%；辅助线性头在推理时已被移除，因此增益来自 WAM 表征和行为本身的变化，而非额外定位器参与决策。
  • InternW0-\(\Delta\)+LDS 在 LIBERO-CF 达到 74.6% 成功率和 89.2% 目标定位率，分别比文中最强基线高 26.8 和 42.9 个百分点。所给原文节选没有列出该“最强基线”的名称及绝对结果，不能据此进一步还原。
  • 在更广的任务上，InternW0-\(\Delta\)+LDS 于 LangGap 和 RoboTwin-IF 分别取得 71.4% 和 47.4% 成功率，覆盖物体选择与放置目的地定位；论文还报告在 LIBERO-CF、LangGap 留出划分以及真机任务上保持有效，但所给节选未提供这些实验的逐项数字。
  • 在 LIBERO-CF 拾取目标子集上，对冻结的 OpenWAM 做免训练表征干预：增强 \(I\) 将成功率/定位率从 3.8%/7.0% 提高到 53.0%/80.0%，迁移 \(P\) 则达到 50.8%/84.0%。两种相反侧重点的干预都能把行为转向指令目标，为“先验与指令信号竞争且二者均可控制行为”提供了比探针相关性更强的因果证据。

局限与可以继续做的

  • 机制分析主要针对以 Wan 为生成骨干、通过交叉注意力注入语言的 WAM；Cosmos Policy、ImageWAM 等采用不同生成骨干的模型是否存在相同的 \(P/I\) 分解，尚无直接证据。
  • LDS 依赖指令目标的空间 mask。它省去了反事实动作和未来视频采集，但仍需要生成或标注“替代指令—目标区域”配对；目标区域自动提取的噪声敏感性及标注成本在所给原文节选中未量化。
  • 当前监督和主要机制证据集中在目标物体及放置目的地的空间定位。它没有证明线性目标监督能表达接触点、运动轴、作用方向、阶段切换等交互几何，也没有证明模型能由此获得训练中从未出现的接触技能。
  • 两种表征干预的明确数字来自 LIBERO-CF 拾取子集；能否在长时序放置、抓取后持续跟随目标、失败恢复以及真机闭环中稳定生效，仍需逐阶段干预和更细的轨迹级指标。
  • 可以在同一初始场景中系统交叉物体、目标区域与指令，并留出“物体×目标”组合；除总成功率外，分别记录首次接触、抓取保持、目标持续跟随、正确释放及失败恢复，以区分“找对物体”与“完成正确变化”。
  • 可以把 LDS 从二值目标 mask 扩展到 Austin 项目的 A/F 接口：分别探测并监督接近区域 \(A\) 与期望物体运动场 \(F\)，再对 \(F\) 做置零、反向和跨样本交换，检验其线性可解码性提升是否真正改变闭环物体运动，而不只是充当任务 ID。
实验设置
  • 模型范围：主要研究采用 Wan 作为生成骨干的 WAM，包括 OpenWAM 与 InternW0-\(\Delta\)；论文明确指出机制结论首先适用于 Wan 系架构。
  • 任务与域：LIBERO-CF、LangGap、基于 RoboTwin2.0 构建的 RoboTwin-IF，以及真机任务；给定节选未披露真机机器人形态、相机配置、任务数和评测次数。
  • RoboTwin-IF 数据：反事实示范共享同一场景及完全相同的初始视觉观察，但使用不同语言指令并执行对应目标行为；训练场景与留出评测场景互不重叠。
  • IF 对照模型：从预训练 NF WAM 出发，在反事实专家示范集 \(\mathcal D_{\mathrm{CF}}\) 上用 flow-matching 损失微调。
  • 探针数据：256 个 RoboTwin-IF 场景、515 条指令；每个场景的固定观察与多条目标选择指令配对。
  • 探针输入：使用头部相机 patch 对齐的视觉 token；WAM 激活冻结，仅训练共享线性探针。
  • 探针位置：每个 block 读取 9 类位置，包括自注意力的 query/key/value 投影、SA 与 CA 注意力输出、Post-SA 与 Post-CA 残差状态、门控 FFN 更新及 block 输出。
  • 探针指标：双向准确率为目标召回率与非目标拒绝率的平均值。
  • LDS 空间粒度：每个视觉 patch 细分为 \(4\times4\) 网格，线性头输出 16 个 logit。
  • LDS 读取位置：在第一次去噪步，从 DiT 浅层、中层和深层各选择一层的 block 输出，共使用 3 个层位。
  • LDS 标签区域：指令目标、其他候选物体与背景；各区域损失按其空间覆盖归一化，并使用区域平衡系数。
  • 训练目标：原始数据上的 flow-matching 损失加 grounding 数据上的 LDS 辅助损失；WAM 和辅助头共同更新，辅助头在推理时丢弃。
  • LDS grounding 数据只提供观察、替代指令与目标 mask，不提供相应动作或未来视频。
  • 所给原文节选未披露损失权重的具体数值、优化器、学习率、训练步数、控制频率、每项任务的 episode 数及硬件配置。
AI导读和推荐理由
  • 推荐这篇的首要原因不是“线性探针准确率更高”，而是作者进一步用免训练表征干预证明：弱指令信号并非一定处于行为读取器不可见的无效子空间，它可能已经能控制行为，只是被更强的视觉/行为先验压制。
  • 论文同时给出一种实用的数据替代方案：无需为每条反事实指令补采完整动作轨迹，只需在已有观察上增加替代指令和目标 mask，便可显著改善 WAM 的指令遵循。

与本项目关系

  • 这与 Austin 已观察到的“把 \(G\) 喂给策略不等于策略理解并遵循 \(G\)”直接对应。论文把问题进一步拆成“条件是否可解码”和“条件信号能否在与先验竞争时支配动作”，可作为 \(G\) 或 A/F 接口闭环消融之外的内部诊断框架。
  • RoboTwin-IF 的同一初始观察配不同指令，正对应项目需要的反事实组合数据：固定场景与物体布局，只改变目标物体、目的地或 \(F\) 的方向，可迫使 OpenPI 执行器使用条件，而不是依赖熟悉的“物体—目标”关联。
  • 差距也很明确：本文主要验证语言指定目标的物体选择和放置目的地定位，研究对象是 Wan 系 WAM，并未在 π0、π0.5 或 OpenPI 上验证；二值目标区域也弱于 A/F 中包含的接近区域、运动方向与交互阶段，不能证明模型会组合出未见接触技能。

启发

  • 为 OpenPI 的 \(G\)/A/F 条件建立分层线性探针：分别预测目标交互区域 \(A\)、物体运动方向 \(F\) 和执行阶段，并同时报告探针准确率与闭环阶段成功率，避免把“可读出”误当成“被遵循”。
  • 在固定初始图像上构造反事实条件组：保持物体和场景不变，交换目标区域、反转 \(F\)、置零 \(F\)，以及在样本间交换 A/F；训练和测试都留出部分“物体×目标×方向”组合，以排除任务 ID 和数据共现捷径。
  • 仿照 \(I/P\) 干预，在 OpenPI 中定位由 A/F 条件引起的表征差分，并进行增幅、符号反转或目标间迁移；只有当干预能相应改变物体运动和最终放置位置，才能说明该接口进入了动作控制链。
  • 将评测拆为目标定位、接触、抓取、运输中的持续目标跟随、正确释放和失败恢复。这样可以判断 LDS 式监督解决的是“选对对象”，还是也能缓解“抓到了却没送到正确目标”。
  • 可先以视觉真值 mask 或物体轨迹训练 A/F 辅助头，验证表示干预和闭环收益；确认有效后再替换为视觉模型预测的 A/F，并单独测量感知误差与条件遵循误差，避免两类失败混在总成功率中。

一句话总结

  • 中国人民大学、北京人形机器人创新中心与复旦大学的作者提出 LDS，以细粒度目标区域辅助监督增强 WAM 的指令信号，使 InternW0-\(\Delta\) 在 LIBERO-CF 达到 74.6% 成功率，并通过将 OpenWAM 拾取子集从 3.8% 提升到 53.0% 的免训练表征干预支持“先验—指令竞争”机制。
