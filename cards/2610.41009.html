深读｜STAR

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 预训练 VLA 虽能将视觉、语言与本体状态映射为动作，但可能没有充分利用任务相关视觉线索：目标物被遮挡后，动作表征的变化在早中层逐渐增大，却在接近动作输出的后层下降，说明视觉 grounding 在深层发生衰减。
  • 现有免训练干预多作用于扩散/流轨迹、动作解码或视觉 token；它们没有直接处理 Transformer 后层动作隐藏状态中的视觉信息流失，部分方法还需要额外前向传播。
  • 本文面向闭环机器人操作，在不收集额外数据、不训练参数、不修改模型权重与架构的前提下，对冻结 VLA 的单次推理过程进行干预；策略仍按 action chunk 预测并执行其中前若干步。
  • 作者目标是让后层动作表征保留早中层形成的目标感知信息，同时避免在旋转、接触变化和精细调整阶段过度干预原策略，从而提高冻结 VLA 的任务成功率。

方法

  • 整体流程为：VLA 接收图像、语言指令和当前本体状态，正常通过前部 Transformer 层；STAR 在最后一段层中混合跨层残差更新，再由原动作头输出 action chunk。模型参数、动作头和原有输入输出接口均保持不变。
  • STAR 将每个 Transformer block 的输出视为残差更新 \(\Delta h_t^k\)，在后层沿网络深度维护指数移动平均 \(m_t^k=\beta_t m_t^{k-1}+(1-\beta_t)\Delta h_t^k\)，并以该平滑更新替代当前层原始残差更新。
  • 这种跨层“动量”把较早、目标感知更强的更新方向带到靠近动作输出的层；STAR不修改注意力图，也不是通过裁剪视觉 token 或重新采样动作来实现引导。
  • 混合强度由近期末端执行器轨迹自适应控制。作者从位置和朝向历史构造方向连续性、平移幅度、类似加速度的运动突变以及旋转变化四类因果信号。
  • 各本体信号先用仅包含过去状态的滑动窗口做 z-score 标准化，再线性组合成混合分数；该分数继续以历史中位数和四分位距进行稳健归一化，降低瞬时尖峰的影响。
  • 归一化分数经 sigmoid 映射为 \(\beta_t\)：稳定、方向一致的运动使用更大的系数，以更多保留跨层更新动量；旋转、接触切换或局部精调时使用更小的系数，使后层更多服从当前残差更新，保守地偏离原策略。

实验与结果

  • 论文摘要及所给正文报告：STAR在主实验中的平均任务成功率相对原生推理提高了 4.0 个百分点。这里是成功率的绝对百分点变化，不应解读为相对提高 4.0%。
  • 层级探针显示，原生 \(\pi_0.5\) 的目标感知分数在早中层上升、后层下降；加入 STAR 后，后层目标感知增强。该分数定义为目标区域被均值 RGB 遮挡前后隐藏状态差异的相对范数，是视觉依赖程度的启发式指标，并非任务成功率本身。
  • 正文明确称 STAR 在 LIBERO-PRO 上提升了 \(\pi_0.5\) 与 GR00T-N1.5 的表现，并在 SimplerEnv 与 LIBERO-PRO 上评估冻结策略；但提供的原文截断于主结果表之前，无法核对各模型、各 split、各任务的原生成功率和 STAR 成功率。
  • 主实验还将 STAR 与免训练视觉 token 剪枝方法 DTP 对照。正文指出 DTP 需要额外一次前向传播来获取剪枝所需的注意力信号，而 STAR 为单次前向推理；节选未给出两者的具体成功率、延迟或算力数据，因此不能进一步量化优劣。
  • 所给节选没有披露失败/恢复案例、统计方差、置信区间或显著性检验，也未给出消融实验的具体数值；这些结论不能从“平均提高 4.0 个百分点”外推。

局限与可以继续做的

  • 证据完整性有限：提供的正文缺少主结果表和后续消融部分，因此无法核验 4.0 个百分点由哪些模型与任务贡献，也无法判断是否所有 backbone、任务和 split 均获得提升。
  • 目标感知分数依赖“用图像均值遮挡目标像素”这一人工干预，而且作者将其定位为启发式估计。隐藏状态对遮挡更敏感不必然等价于视觉 grounding 更正确，仍需结合目标选择错误率、注意区域或因果干预测试验证。
  • STAR的调度依赖可取得且语义一致的末端位置与朝向。跨机器人形态、不同控制频率、关节空间策略或缺少可靠末端位姿时，四类信号及其归一化是否仍有效，现有节选没有提供证据。
  • 可继续做的实验是将动态本体调度与固定 \(\beta\)、仅位置调度、仅旋转调度及不做稳健归一化逐项对照，并按接近、抓取、接触、旋转、放置等执行阶段分别统计成功率和干预幅度。
  • 面向 OpenPI，可将 STAR 实现为可开关的 Transformer residual hook，记录每个控制步的 \(\beta_t\)、本体分数、动作变化量和安全约束触发情况；随后在相同随机种子下开展闭环 A/B 评测，并专门检查动态切换时的动作抖动、碰撞及 action-chunk 延迟。
实验设置
  • 平台与基准：仿真操作基准 SimplerEnv 和 LIBERO-PRO；所给正文未报告真机实验。
  • SimplerEnv：使用 6 个 Fractal/Google Robot 任务，分别为 Open Drawer、Place in Drawer、Pick Coke Can、Move Near、Close Drawer 和 Pick Object。
  • LIBERO-PRO：评估 LIBERO-10-lan、LIBERO-10-object、LIBERO-10-swap、LIBERO-10-task、LIBERO-10-env 五个 split；每个 split 含 10 个任务。
  • LIBERO-PRO 上的 \(\pi_0.5+\)STAR：每任务评估 50 个 episode，即每个 split 500 个、五个 split 合计 2,500 个 episode。
  • 模型：GR00T-N1.5、OpenVLA-7B 和 \(\pi_0.5\)。GR00T-N1.5 采用 NVIDIA Eagle VLM 与 flow-based action head；OpenVLA-7B 使用 DINOv2、SigLIP、投影模块和基于 Llama-2 的语言骨干；\(\pi_0.5\) 使用 PaliGemma 风格 VLM、SigLIP 视觉编码器、Gemma 系语言 Transformer 和 flow-matching action expert。
  • 冻结设置：每个 backbone 均比较原始冻结策略与叠加 STAR 的同一策略；评估期间所有模型权重保持冻结，STAR仅在推理时生效。
  • 协议：遵循各基准官方评测协议，以任务成功率为主指标，同时报告单任务和平均成功率。
  • 干预层：相对起始深度设为 \(\rho=2/3\)，前 \(2/3\) Transformer 层不变，仅在最后 \(1/3\) 层混合残差更新。
  • 本体输入：末端执行器三维位置和朝向；调度量仅使用当前及过去观测，未使用未来状态或 oracle 任务信息。
  • 正文给出滑窗长度 \(W=f_{\mathrm{ctrl}}T_w\) 以及 \(\beta_{\min}\)、\(\beta_{\max}\)、\(\kappa\)、\(w_c\)、\(w_v\)、\(w_j\)、\(w_\omega\) 等参数形式，但所给节选未披露其具体数值，也未给出硬件、推理延迟和 SimplerEnv 每任务 episode 数。
AI导读和推荐理由
  • 推荐这篇的原因在于，它没有再训练一个新 VLA，而是从层级探针出发，把“后层动作表征丢失任务相关视觉信息”转化为可插拔的推理时控制问题。
  • 对 π 系列研究而言，STAR提供了一种成本较低的诊断—干预链路：先用目标遮挡测量各层视觉敏感度，再只在退化明显的后层施加由闭环本体状态调节的 residual steering。

与π系列的关系

  • 本文不是 \(\pi_0\)、\(\pi_0\)-FAST、\(\pi_0.5\) 或 OpenPI 的新基础模型；它是叠加在预训练 VLA 上的免训练推理模块，不改变原模型权重、架构、flow-matching 目标或 action expert。
  • 论文直接使用 \(\pi_0.5\) 作为实验 backbone，并在 LIBERO-PRO 对其进行每个 split 500 个 episode 的闭环评估；STAR干预的是后层 Transformer 残差更新，而不是重新训练 \(\pi_0.5\) 的视觉编码器或动作头。
  • 正文相关工作提到 \(\pi_0\)，但所给节选没有显示 STAR 在 \(\pi_0\) 或 \(\pi_0\)-FAST 上的实验，也没有证明其已集成或正式对比 OpenPI。不能把对 \(\pi_0.5\) 的结果直接视为对所有 π 系列实现均有效。
  • 相比需要额外前向传播并依据动作 token 注意力裁剪视觉 token 的 DTP，STAR保持单次前向并直接修改 residual stream；但节选缺少二者的完整结果和运行时测量，尚不能断言 STAR 在端到端吞吐或成功率上全面占优。

对Austin研究的启发

  • 在 OpenPI 执行器中增加独立的 residual-hook 接口：按层启停、限制干预范围，并保证关闭 hook 时逐 token、逐动作复现原生策略，先验证实现没有改变基础推理路径。
  • 为引导场 \(G\) 或类似条件遵循模块增加层级 grounding 监控：在离线回放中遮挡目标区域或替换无关区域，比较各层 action hidden state 的相对变化，先定位视觉条件开始衰减的深度，再决定干预起点，而不是固定照搬 \(\rho=2/3\)。
  • 开展原生 OpenPI、固定 EMA、STAR 式本体调度三组闭环对照；除成功率外，同步报告动作抖动、碰撞率、末端轨迹长度、控制周期延迟，以及旋转和接触切换阶段相对原始动作的偏移。
  • 给动态调度增加安全边界：当朝向变化、运动突变或策略输出与安全控制器冲突时，下调 \(\beta_t\) 或直接旁路 STAR；同时保存触发前后的 action chunk，检查“增强视觉保持”是否以削弱快速纠偏能力为代价。
  • 论文作者来自北京大学、理想汽车、BIGAI 与威斯康星大学麦迪逊分校；所给内容未显示作者与 Austin 存在直接合作或机构隶属关系，因此更适合作为可复现实验思路，而非现成的 Austin 项目成果。

一句话总结

STAR由北京大学、理想汽车、BIGAI和威斯康星大学麦迪逊分校作者提出，以本体状态调节最后三分之一 Transformer 层的跨层残差 EMA，在冻结 VLA、无需训练和改权重的条件下增强后层目标感知，并在主实验中将平均任务成功率提高 4.0 个百分点。
