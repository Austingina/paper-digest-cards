深读｜Game-Enhanced Embodied Learning with Event and Foresight Pretraining

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 人类游戏录像同时包含视觉观察、键鼠动作及其后果，是潜在的大规模具身预训练信号；但游戏事件与机器人连续控制的动作空间不同，不能直接把键鼠指令当作机械臂动作。
  • 训练样本需要按真实时间对齐历史、未来一秒事件和未来画面，同时避免教师强制提供的未来动作泄漏到视觉预见特征中，否则训练条件与推理条件不一致。
  • 论文研究的是“额外游戏预训练后再做机器人微调”的仿真迁移设定：Wan 视频模型冻结，InternVLA-A1.5 的视觉编码器、多模态骨干、expert 和预见模块参与训练；迁移时保留原生机器人控制路径，不学习键鼠到机器人动作的映射。
  • 下游在 LIBERO 中进行闭环执行：策略一次预测 50 步动作，每执行 8 步后重新规划。作者目标是在不改变原生机器人接口和下游微调协议的前提下，验证游戏事件与视觉后果能否改善机器人策略初始化。

方法

  • 阶段 I／游戏数据构建（Recorded Human Gameplay）：将人类游戏轨迹切分为近期多模态历史 $H$、下一步离散动作 token $Y$ 与未来视频标签；$H$ 汇集屏幕观测及既往交互，$Y$ 提供事件级行为监督，后续帧则形成视觉前瞻目标。
  • 联合训练／事件预测与视觉前瞻（Event Prediction & Visual Foresight）：多模态模型由 $H$ 自回归预测 $Y$，并通过前瞻查询 $Q$ 预测未来视频潜变量。注意力矩阵以行为查询、历史与 $Q$ 为行列分组，三角区域表示因果可见性；关键约束为 $Q\nrightarrow Y$，避免未来分支读取动作答案。
  • 冻结视频监督模块（Frozen Video Modules）：未来视频经冻结的视频模块编码为目标潜表示，与 $Q$ 输出对齐形成视觉前瞻损失；视频模块参数保持冻结，但条件路径的梯度仍反传至可训练的多模态主干，使事件预测与未来动态建模共同塑造表征。
  • 阶段 II／原生机器人策略（Native Robot Policy）：以游戏预训练权重初始化机器人策略，将真实机器人观测映射为长度 $50$ 的动作序列；部署时仅执行前 $8$ 个动作，随后重新观测并规划，构成滚动闭环控制，以降低长时预测误差。

Game-enhanced embodied training. (a) Recorded human gameplay supplies recent history $H$, next-action tokens $Y$, and future video labels. (b) Event prediction and visual foresight jointly train the multimodal model. In the attention inset, rows are query groups and columns are key groups; $Q$ denotes foresight queries, triangles denote causal access, and $Q$ cannot access $Y$. Frozen video modules supervise the future latent and pass conditioning gradients to trainable modules. (c) Game-pretrained weights initialize the native robot policy, which predicts 50 actions and executes eight before replanning. Screens and the robot are schematic.
  • 整体流程为：从人类游戏记录构造“最近历史—未来一秒键鼠事件—未来画面”样本，联合训练事件预测和视觉预见，再通过 checkpoint bridge 将所得权重迁移回 InternVLA-A1.5 的原生机器人前向路径，最后使用机器人示范微调。
  • 事件分支使用扩展到 250,416 行的词表，把键盘和鼠标事件序列化为 token，并以因果 next-event prediction 损失预测锚点后 (t,t+1 s] 内的事件；游戏阶段关闭连续机器人动作目标。
  • 样本选择先按 250 ms 间隔稀疏选取合法屏幕锚点，减少高度重复的起点，再恢复能够覆盖遗漏动作的合法锚点；这一过程保留原始事件载荷和时间戳。
  • 50 个可学习 foresight queries 仅访问锚点前最多一秒的历史。注意力掩码禁止它们读取目标动作 token，位置索引也固定在目标后缀之前，以阻断未来动作泄漏。
  • 视觉监督取 [0, 0.25, 0.50, 0.75, 1.00] 秒的五帧视频，由冻结的 Wan VAE 和 Wan2.2 TI2V-5B 去噪模块提供 flow-matching 监督；梯度仅通过条件输入回传到可训练的预见路径及主模型。
  • 总损失为等系数的事件损失与视频损失。相对公共 InternVLA-A1.5-base，作者增加的是游戏数据上的联合预训练和转接步骤；没有改变下游机器人动作接口，也没有增加键鼠到电机控制的映射器。

实验与结果

  • 在四个 LIBERO 套件共 2,000 次 rollout 中，Base 为 1,718/2,000（85.90%），游戏预训练初始化为 1,811/2,000（90.55%），绝对提高 4.65 个百分点，即多成功 93 次。
  • Spatial 从 417/500（83.4%）提高到 463/500（92.6%），增加 9.2 个百分点；Object 从 460/500（92.0%）提高到 494/500（98.8%），增加 6.8 个百分点。两者合计贡献 80 次净新增成功，占总净增 93 次中的大部分。
  • Goal 仅从 442/500（88.4%）变为 443/500（88.6%），增加 0.2 个百分点；Long 从 399/500（79.8%）变为 411/500（82.2%），增加 2.4 个百分点，说明总体收益并非各套件均衡。
  • 40 个任务中，24 个提高、10 个下降、6 个持平。Long 中，“将两个杯子放到各自盘子上”由 14/50 升至 30/50（+32 个百分点），但“将 alphabet soup 和 tomato sauce 放入篮子”由 42/50 降至 24/50（−36 个百分点）。
  • 这些数字比较的是完整游戏预训练阶段与直接从 Base 微调的差异；两组下游机器人训练预算相同，但总训练预算不同，因此不能把 4.65 个百分点归因于游戏数据、事件目标、视觉预见目标或额外计算中的某一个因素。

局限与可以继续做的

  • 论文没有分别消融“仅事件预测”“仅视觉预见”“事件与预见联合训练”，也没有设置等额外计算但不使用游戏数据的控制组，因而证据只支持完整预训练流程有效，不能确定各组成部分的独立贡献。
  • 每个初始化只产生一组套件专属策略，没有跨训练随机种子的重复实验，也未报告显著性或等价性检验；50 次任务 rollout 不能替代独立训练复现，Goal 的 +1/500 尤其应视为很小的观察差异。
  • 数据划分是同一批游戏内部按来源 session 分组的 90/10 划分，不是 held-out-game 测试；下游也仅覆盖 LIBERO 仿真，尚不能外推到未见游戏、其他 VLA 架构或真实机器人。
  • 任务级结果存在明显回退。可以针对 10 个下降任务记录预见特征、动作置信度和重规划前后的失败轨迹，检查游戏先验是否引入与精细操作、物体语义或长程组合不一致的偏置。
  • 可执行的下一步是加入“等更新步数的机器人数据继续训练”“打乱事件—视频对应关系”“仅历史视频无事件”“不同预见时域”等控制实验，并在真机或另一套操作基准上用多随机种子复验迁移收益。
实验设置
  • 基础模型：公共 InternVLA-A1.5-base；游戏预训练后采用 step-12,400 checkpoint，通过 bridge 恢复原生机器人前向路径。
  • 冻结模块：Wan VAE 与 Wan2.2 TI2V-5B 去噪器冻结；可训练模块包括视觉编码器、多模态骨干、expert、50 个 foresight queries 和投影层，并非冻结策略骨干。
  • 游戏数据：D2E 的人类记录子集，含 20 款游戏、394 段录像、22,646,179 条原始事件；录像时间戳跨度合计 223.36 小时，索引有效区间合计 197.85 小时。
  • 样本构造：11,118,648 个合法密集样本经 250 ms 锚点选择后得到 2,356,278 个样本，另恢复 3,038 个锚点以覆盖 6,681 个原本遗漏的动作序号；最终训练集 2,072,084 个锚点，验证集 287,232 个锚点。
  • 数据划分：按来源 session 分组并按游戏分层，训练集为 349 段录像、171 个 session group，验证集为 45 段录像、23 个 group；这是 within-game 划分。
  • 游戏预训练：全局 batch size 为 8×1×16=128，AdamW 学习率 2×10⁻⁵，warmup 200 次更新，随机种子 42；训练 12,400 次更新，共呈现 1,587,200 个样本，约为名义一轮的 76.6%。
  • 游戏监督窗口：历史最长一秒，事件目标覆盖未来一秒；视频帧偏移为 [0, 0.25, 0.50, 0.75, 1.00] 秒。视频调度器含 1,000 个噪声级，shift 为 5.0。
  • 下游数据与平台：LIBERO 仿真基准的 Spatial、Object、Goal、Long 四个套件；每个初始化分别训练四个套件专属策略。
  • 机器人微调：每套件训练 20,000 次更新，batch size 32，学习率从 5×10⁻⁵ 调度到 5×10⁻⁶，有效 warmup 400 次更新；两组共享机器人示范、训练代码、超参数和评测协议。
  • 机器人目标：10L_action + L_language + L_video；20 Hz 下预测 50 步动作，动作目标覆盖 0–2.45 秒，五帧视频监督覆盖 [0, 0.60, 1.25, 1.85, 2.50] 秒。
  • 评测协议：每套件 10 个任务、每任务 50 个 episode，即每套件 500 次、每组共 2,000 次；评测种子 7，图像缩放到 224，开始时等待 10 步，每执行 8 个动作即重规划一次。
AI导读和推荐理由
  • 推荐这篇的核心原因不是它提出了新的机器人动作表示，而是它给出了一个可核对的接口范式：让非机器人交互数据训练 VLA 的因果事件表征和视觉后果预测，同时保持原生连续控制出口不变。
  • 论文同时报告总体提升和完整任务级异质性，明确承认额外优化预算及消融缺失，适合用来讨论“预训练数据有效”与“因果归因成立”之间的区别。

与π系列的关系

  • 本文不属于 π0、π0-FAST、π0.5 或 OpenPI 系列，也没有采用或评测这些模型；其直接基础是 InternVLA-A1.5，并继承了该模型的 robot expert、foresight queries 和冻结视频模型监督。
  • 与 π 系列相关的仅是研究问题层面的联系：两者都需要把大规模视觉—动作经验迁移到连续机器人控制。FAST关注连续动作的高效 tokenization，而本文在游戏阶段预测离散键鼠事件，迁移时仍使用 InternVLA-A1.5 的原生连续动作路径，不能将其视为 FAST 的实现或改进。
  • 本文改动的是预训练数据、事件头、因果注意力约束和 checkpoint bridge；没有改写下游机器人执行接口，也没有证明同样的游戏预训练收益能直接迁移到 π0、π0.5 或 OpenPI。

对Austin研究的启发

  • 可在 OpenPI 外围实现独立的 game-event pretraining harness：复用视觉骨干或增加 foresight query 接口，但保持 π 策略的 action expert、动作 chunk 格式和执行器 API 不变，以便在同一机器人微调协议下只比较初始化差异。
  • 若引入视觉预见或引导场 G，应在 attention mask 层明确禁止预见查询访问教师强制的未来动作，并为每个 query 记录可访问 token 范围；这比仅在数据管线中删除未来帧更容易审计信息泄漏。
  • 闭环评测应同时报告套件均值、逐任务差值和失败回退，而不是只看聚合成功率；可沿用“预测完整 action chunk、执行固定短前缀、再规划”的接口，并监控预见误差是否能提前预警动作失败。
  • 最小可执行实验可采用四臂设计：公共 OpenPI 初始化、等计算继续预训练、仅事件目标、事件加视觉预见；每臂使用多个训练随机种子，并固定机器人数据、动作 horizon、执行间隔和评测初始状态。
  • 还应检查游戏预训练时的一秒视觉目标与机器人阶段更长物理时域之间的错配。本文下游五帧目标跨度是游戏阶段的 2.5 倍，但没有估计这一变化的影响，可将预见时域作为独立变量扫描。

一句话总结

北京心影随行科技有限公司的作者在 InternVLA-A1.5 上联合进行因果游戏事件预测与历史条件视觉预见预训练，使 LIBERO 总成功率由 85.90%（1718/2000）升至 90.55%（1811/2000），但该收益尚未通过目标消融、等计算对照、多随机种子或 π/OpenPI 实验加以分解验证。
