AtomicRL：面向长程机器人操作的原子强化学习

利用原子任务结构优化VLA策略的信用分配与探索

针对现有VLA模型在长程操作任务中因轨迹级稀疏奖励导致信用分配延迟及子任务掌握不均的问题，本文提出AtomicRL强化学习后训练框架。该方法引入语义感知策略优化（SAPO），通过门控机制防止失败原子子任务的TD残差跨边界传播，缓解信用污染；同时采用瓶颈自适应目标探索（BATE），根据子任务掌握程度动态协调采样与探索以突破性能瓶颈。结合Real2Sim2Real流程实现仿真到实机的有效迁移。实验表明，AtomicRL在LIBERO-LONG和CALVIN基准上显著优于PPO基线，并在真实机器人任务中平均提升21.3%的性能，有效增强了VLA策略的学习效率与操作能力。

3.50机器人 RL / 后训练具身推理与规划强化学习VLA模型2610.28589

AgenticRoboRL：将编码智能体后训练引入具身机器人

通过多轮强化学习后训练提升机器人规划器性能

现有具身机器人系统依赖强大的闭源模型作为规划器，缺乏对规划器自身能力的优化。受编码智能体通过模型后训练显著提升性能的启发，本文提出AgenticRoboRL框架，旨在通过后训练增强机器人规划器。该方法结合监督微调与多轮强化学习，利用特定于执行机制的适配器连接规划交互与任务结果，统一了VLA技能调用与控制代码生成等不同执行模式的训练流程。在LIBERO-PRO基准测试中，该方法将9B参数规划器的成功率从18.1%提升至71.0%，接近拥有外部记忆的GPT-5.5水平，证明了后训练在提升机器人规划能力方面的有效性。

3.20机器人 RL / 后训练人形机器人强化学习仿真与Sim2Real2610.30080

地球训练的人形控制器能在月球行走吗？重力、地形与土壤迁移

研究人形机器人在地月重力及复杂土壤下的跨域迁移能力

本文探讨人形机器人在月球低重力、崎岖地形及松软土壤环境下的运动控制迁移问题。通过在仿真环境中训练Unitree G1策略，系统评估了重力、地形几何及接触模型（刚性或3D RFT）对策略泛化性的影响。研究发现重力迁移具有不对称性：地球训练策略在月球平坦地面表现尚可，但月球训练策略无法适应地球重力；通用控制器SONIC在月球表现极差。粗糙地形训练显著提升存活率，而土壤建模的影响取决于具体场景。实验表明，结合重力随机化和粗糙3D RFT地形的策略在地月两域均能保持高稳定性，为地外天体机器人部署提供了重要参考。

迈向物理AI的递归自我改进

探讨机器人学习中递归自我改进的路径、条件与评估原则。

本文探讨将递归自我改进（RSI）机制引入物理世界的挑战与路径。针对数字代理在物理环境中面临的部分观测、高成本试验及不可逆后果，文章定位了RSI在机器人学习中的位置，梳理了从提升机器人能力到优化其生成过程的路径。研究指出，只有当反馈解决剩余学习需求、组件能利用变化、价值跨任务/硬件保持且持续实践安全经济时，增益才能延续。现有操作领域研究支持行为改进及后续学习收益，但尚未隔离出纯粹由递归带来的增益。文章综合发现，提出了针对安全自我改进机器的评估原则与研究方向。

距离场驱动的强化学习实现反应式鲁棒避障

EDF观测空间增强RL，实现机械臂零样本Sim2Real动态避障

针对强化学习策略在真实机器人上部署时面临的仿真到现实迁移困难及碰撞避免挑战，本文提出一种将欧几里得距离场（EDF）直接集成至观测空间的强化学习框架。该方法利用EDF提供的连续几何线索，简化了奖励函数设计，支持稳定且响应迅速的避障行为。研究在7自由度冗余机械臂上验证了该方法，尽管仅使用随机静态物体进行训练，策略仍实现了从仿真到真实硬件的零样本迁移，并能泛化至未见过的环境及动态障碍物。结果表明，基于EDF的表征能有效缩小Sim2Real差距，支持复杂环境中可靠实时的碰撞感知行为。

3.20机器人 RL / 后训练仿真与Sim2Real强化学习导航2610.28953

GGraph：用于机器人部署与学习的GPU加速图库

GPU加速图库支持大规模并行强化学习训练，提速十倍。

针对现有图结构库在大规模强化学习训练中因CPU构建瓶颈导致扩展性差的问题，本文提出GGraph，一个开源的GPU加速图库，旨在统一机器人部署与大规模学习。GGraph通过ROS 2接口支持真实机器人，并利用向量化GPU技术实现并行策略训练，涵盖3D导航、探索等任务。实验表明，单机器人场景下图更新仅需毫秒级；在多机器人并行训练中，相比基线方法将墙钟时间缩短一个数量级。该工作为大规模机器人学习与部署提供了统一的基础设施支持。

3.20机器人 RL / 后训练人形机器人强化学习2610.28925

一种策略多种风格：人形机器人可控控制中偏好聚合的位置选择

探究人形机器人RL中不同层级偏好聚合对行为可控性的权衡

针对现代机器人需支持运行时调整行为风格的挑战，本文研究偏好条件强化学习在人形机器人控制中的应用。尽管条件化提供了接口，但难以保证行为改变的强度、隔离性及任务性能。作者提出结合偏好奖励响应度（PRR）与覆盖/效用指标进行评估，对比了奖励级、优势级、损失级及PCGrad聚合策略在两种人形控制框架下的表现。研究发现无单一最优层级：早期聚合产生更宽的行为响应范围但易引发非目标行为泄漏；晚期聚合提升控制精度但牺牲部分响应性。该工作为设计可控的人形机器人策略提供了关于偏好注入位置的实证指导。

3.20机器人 RL / 后训练灵巧手模仿学习强化学习2610.28628

AdaDex：通过混合灵巧模仿学习可适应的灵巧技能

结合运动跟踪与目标RL，从单段人类动作生成可泛化灵巧手技能

现有方法在灵巧手学习中面临权衡：纯强化学习缺乏人类先验导致策略不自然，而运动跟踪无法偏离参考轨迹。本文提出AdaDex框架，通过混合灵巧模仿机制，将单段短人类手部动作转化为可适应的灵巧技能。该方法并行训练两类环境：一类利用密集奖励注入人类运动先验，另一类通过噪声初始状态和稀疏目标奖励强制泛化能力。实验表明，AdaDex在功能抓取、手内重定向等任务上优于基线，具备优异的泛化性与真实世界迁移能力。
