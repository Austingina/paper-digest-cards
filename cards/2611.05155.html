深读｜Asynchronous Robot Policies

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 现有 VLA 通常把高层视觉—语言推理与动作生成串行放在主控制环中，单次感知到动作的延迟约为 \(t_{\mathrm{VLM}}+t_{\mathrm{AE}}\)；VLM 越大，机器人闭环控制频率越容易受到推理延迟限制。
  • 这种延迟在准静态任务中可能只拖慢执行，但在目标突然移动、接触状态变化或机器人受到扰动时，会造成观测过时、动作继续开环执行以及无法及时重规划等失败。
  • 论文同时覆盖 LIBERO 与 Robosuite 仿真、RoboLab 评测和 Franka 真机；重点不是重新证明大模型的语义能力，而是研究如何在保留大 VLM 的同时获得高频闭环动作控制。
  • 作者的目标是把控制环延迟从依赖 VLM 与动作专家之和，降为主要依赖轻量动作专家自身的执行时间，并允许语义模型以显著更低频率运行。

  • 观测输入（Robot Observation）：在控制步 $t$，机器人接收视觉图像 $I_t$ 与本体状态 $s_t\in\mathbb{R}^{D_s}$，组成观测 $o_t=(I_t,s_t)$；两类输入分别送入低频语义路径与高频动作路径，形成解耦的异步数据流。
  • 慢速语义环（Slow Semantic Loop / Semantic Expert）：高容量视觉语言模型（VLM）周期性处理较早时刻 $\tau(t)$ 的观测，将场景、任务及物体关系压缩为固定维度潜在语义记忆 $M_{\tau(t)}$。其更新受 VLM 推理延迟 $d_{\mathrm{VLM}}$ 限制，但不阻塞实时控制。
  • 记忆异步缓存（Semantic Memory）：最新完成的 $M_{\tau(t)}$ 被持续缓存并供快速环复用，其中 $\tau(t)\le t$；图中的跨环连接体现“写入较慢、读取较快”的机制，记忆陈旧度显式表示为 $d_t=t-\tau(t)$，使动作专家能够感知语义信息的时效性。
  • 快速动作环（Fast Action Loop / Vision-Action Expert）：轻量策略 $\pi_{\mathrm{VA\text{-}E}}$ 融合实时 $I_t$、$s_t$、缓存记忆 $M_{\tau(t)}$、$d_t$ 及自身延迟 $\ell_t$，输出动作序列 $a_{t:t+H-1}\in\mathbb{R}^{H\times A}$。该路径不包含随 VLM 参数规模增长的计算，因此可独立维持高频闭环控制。

Asynchronous Robot Policies
  • ARP 将策略拆成两个独立异步进程：低频“语义专家”读取图像与语言指令、更新语义记忆；高频“视觉—动作专家”读取当前视觉、机器人本体状态和最近一次语义记忆，输出长度为 \(H\) 的动作轨迹。
  • 语义专家不只使用文本输出，而是抽取 VLM 多个 Transformer 层的 KV-cache 激活，经 LayerNorm、线性投影和位置编码压缩为固定宽度记忆 \(M_\tau\)。该接口的尺寸不随 VLM 参数规模变化，使动作环不必执行随语言骨干扩大的计算。
  • 视觉—动作专家是双向 Transformer，输入包括实时视觉 token、本体状态 token、可学习 register token 和动作轨迹 token；它在每一层通过交叉注意力读取语义记忆，而不是把记忆直接拼接进输入序列。
  • 系统显式建模两类时延：语义记忆陈旧度 \(d_t=t-\tau(t)\) 和动作专家执行延迟 \(\ell_t\)。陈旧度被编码进语义记忆，两类时延还通过 AdaRMS 调制动作专家；AdaRMS 同时接收 flow-matching 时间步。
  • 训练时将当前观测 \(I_t\) 与同一示范轨迹中的历史观测 \(I_\tau\) 配对。陈旧度从“零延迟点质量 + \(1\) 至 \(d_{\max}\) 的离散均匀分布”混合采样，执行延迟则从实测运行时延分布采样，使专家学习在语义信息过时的情况下继续闭环控制。
  • 相比标准的串行 VLA，ARP 改变的是 VLM 与动作专家的进程边界、通信接口和时延训练方式；它并非仅做异步 action chunking。实验中视觉编码器保持一致并冻结，但不同规模的 InternVL 语言骨干通过 LoRA 更新，因此不能概括为“冻结整个策略、只外挂调度器”。

实验与结果

  • 在 LIBERO 四套件上，ARP-1B、2B、8B、14B 的平均成功率分别为 84.8%、86.6%、89.3% 和 89.1%；同文复现的 \(\pi_0\)-style 1B、8B 基线分别为 80.2% 和 82.7%。其中 ARP-8B 在 Spatial/Object/Goal/Long 上分别为 92.8%、98.6%、90.4% 和 75.2%。
  • 表中外部报告的原版 \(\pi_0\) 平均成功率为 94.2%，高于本文所有 ARP 变体；因此论文支持的是“相对同文复现的、受控视觉编码器设置，异步架构带来收益”，而不是 ARP 在标准 LIBERO 上超过已发布 \(\pi_0\) 的最高结果。
  • 随语言骨干从 1B 扩至 8B，ARP 的 LIBERO 平均成功率总体上升；14B 为 89.1%，没有继续超过 8B 的 89.3%，说明该表并不支持性能随参数量严格单调增长。
  • 作者汇总报告：在 Franka 准静态操作任务上，ARP 的成功率约高 18%，所需执行时间约少 20%；在动态仿真环境中达到基线的 3–5 倍表现。所给正文片段未包含对应完整表格、逐任务数字及“倍数”指标定义，因而无法进一步核对其绝对成功率。
  • 在频率鲁棒性实验中，作者称 VLM 可按名义频率的约 \(1/10\) 运行而无显著性能损失；LIBERO-Perturb 和 Dynamic Bump 则专门测试目标位移或运动方向突变后的重规划能力。所给片段未披露“无显著损失”的置信区间或显著性检验。

局限与可以继续做的

  • 论文证明了受控实验中的异步收益，但提供的原文截断于实验结果开头，未包含作者完整的局限性讨论、消融表和附录；\(p_0\)、\(d_{\max}\)、动作专家层数、实际控制频率及硬件延迟等关键复现值无法从当前材料确认。
  • ARP 依赖历史语义记忆仍足以描述任务。如果语言条件发生变化、目标身份被替换，或场景出现必须重新语义解析的新对象，高频动作专家可能依据已经失效的任务语义继续执行；当前扰动基准主要改变空间位置或运动方向，尚不足以覆盖这类语义突变。
  • LIBERO 中冻结统一视觉编码器有利于隔离语言骨干规模，但也限制峰值表现，并使其与经过大规模机器人数据预训练的外部 \(\pi_0\) 数字不完全可比。后续应在相同数据、视觉骨干、参数规模和训练预算下比较同步与异步版本。
  • 可以增加“语义记忆失效检测器”：监控当前视觉 token 与记忆的跨模态一致性，在对象消失、指令切换或置信度突降时立即触发 VLM 更新，而不是只按固定频率刷新。
  • 可以系统扫描 VLM 频率、动作环频率、推理抖动和通信延迟，报告成功率—响应时间—算力/能耗的 Pareto 曲线；同时加入安全停止、最大记忆年龄和动作幅度限制，以验证真机长时间运行时的故障边界。
实验设置
  • LIBERO：四个任务套件，共 40 个任务、2,000 条示范；单一多任务策略联合训练，每个套件评测 500 个 episode。
  • LIBERO-Perturb：从 Spatial 和 Object 套件选取 10 个任务；末端执行器距目标小于 10 cm 时，将目标沿接近方向的正交方向确定性平移 5 cm。
  • Dynamic Bump：基于 Robosuite；机器人跟踪并抓取滚动球体或圆柱体，场景含静态视觉干扰物；中途速度脉冲可将目标航向改变至最高 \(\pm100^\circ\)，脉冲以论文所设概率 \(p\) 发生。
  • DROID：使用经标准轨迹过滤的真实机器人数据，原始轨迹采集频率为 15 Hz；训练后的策略在 RoboLab 仿真和遵循 DROID 硬件配置的 Franka 真机上评测，真机包含 3 个挑战任务。
  • 视觉输入：VLM 只接收第三人称 agentview 单视角，以符合单图 VLM 的预训练分布；动作专家融合 agentview 与腕部相机。
  • LIBERO 模型：所有变体统一使用 InternVL-4B 的 ViT 视觉编码器并在训练中冻结；ARP-1B 至 ARP-14B 使用相应规模的 InternVL LLM，骨干通过 LoRA 更新。
  • 对照：Diffusion Policy、外部报告的 \(\pi_0\)，以及本文在受控设置中复现的 \(\pi_0\)-style 1B 和 8B 基线。
  • 陈旧度训练分布为 \(p_0\delta_0+(1-p_0)\mathcal U\{1,\ldots,d_{\max}\}\)；动作专家执行延迟从实测运行时延分布采样。当前原文片段未给出 \(p_0\) 和 \(d_{\max}\) 的具体取值。
  • 当前片段未披露动作专家参数量、Transformer 层数、动作预测 horizon、VLM/动作环绝对频率、训练步数、优化器及部署 GPU 型号。
AI导读和推荐理由
  • 这篇论文的价值不在于提出新的通用机器人预训练数据或更强的 π 系列权重，而在于把“大 VLM 语义能力”和“高频闭环控制”拆成两个可独立扩缩容的系统组件。
  • 对部署型 VLA 尤其有参考意义：它将模型推理延迟从单纯的工程问题提升为训练变量，让策略直接学习应对陈旧记忆和动作执行延迟。

与π系列的关系

  • 论文在 LIBERO 中纳入了原版 \(\pi_0\) 的外部报告结果，并构建了 1B、8B 的 \(\pi_0\)-style 同文复现基线；受控比较中，ARP 的平均成功率高于这两个复现基线，但仍低于表中原版 \(\pi_0\) 的 94.2%。
  • ARP 本身基于 InternVL 视觉—语言骨干和独立视觉—动作专家，不是对 \(\pi_0\)、\(\pi_0\)-FAST 或 \(\pi_0.5\) 权重的直接改造，也没有把 OpenPI 作为训练或部署框架。
  • 所给原文没有报告 \(\pi_0\)-FAST、\(\pi_0.5\) 或 OpenPI 的直接实验，因此不能断言这些模型采用 ARP 后会获得相同的 18%、20% 或 3–5 倍收益。
  • 与 π 系列更直接的连接是执行架构：可以把 π/OpenPI 的高层视觉—语言表征视为低频发布者，把轻量动作专家视为高频订阅者；需要新增固定宽度语义接口、时间戳、记忆年龄编码及延迟感知训练，而不是简单提高 action chunk 的发送频率。
  • 本文与 π 系列的 G/A-F 条件遵循、组合数据设计或模型发布路线没有直接关系，主要启发集中在实时执行、闭环重规划和系统监控。

对Austin研究的启发

  • 在 OpenPI 执行器中加入双频接口：语义进程发布 {memory, observation_timestamp, instruction_id}，动作进程记录当前时间、记忆年龄和推理耗时，并设置最大允许年龄；超过阈值时减速、停止或强制刷新语义记忆。
  • 对同一个 π/OpenPI 检查点做严格配对实验：保持训练数据、视觉编码器和动作专家不变，只比较串行执行与异步执行；分别扫描 VLM 更新频率、通信延迟和随机推理抖动，报告成功率、扰动恢复时间、执行时长和算力占用。
  • 将“时间错配”加入数据管线：当前观测与历史语义表征随机配对，同时注入实测动作推理延迟；单独消融陈旧度数值编码、延迟编码、历史 action prefix 和跨层记忆交叉注意力。
  • 对引导场 \(G\) 或其他条件遵循任务，不能默认低频语义记忆始终有效。应构造条件中途改变、目标替换、目标遮挡和冲突指令测试，测量从条件变化到动作纠正的时间，而不只看 episode 最终成功率。
  • 真机监控应至少记录 VLM 更新时间、动作环周期、memory age、丢帧、动作队列深度和安全停止原因，以区分语义判断错误、记忆陈旧和控制执行延迟三类故障。

一句话总结

INSAIT（Sofia University St. Kliment Ohridski）的 Sombit Dey、Luc Van Gool 与 Danda Pani Paudel 提出的 ARP 以低频 VLM 语义记忆驱动高频视觉—动作专家，作者报告 Franka 准静态任务成功率约高 18%、执行时间约少 20%，动态仿真达基线 3–5 倍，并可将 VLM 频率降低约 10 倍而无显著性能损失。
