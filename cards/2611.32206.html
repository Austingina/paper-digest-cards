深读｜Seeing Is Not Reaching

📐 原版模型结构图详解🤖 向 AI 提问本篇论文原文 ↗

问题

  • VLA 通常继承视觉语言模型的目标定位能力，但在 LIBERO-PRO 等位置扰动中，即使目标已被移动，机械臂仍可能返回该目标在训练演示中的原位置；仅观察最终动作，无法判断模型是没有看见目标、没有使用视觉定位，还是视觉信号被其他捷径覆盖。
  • 现有研究发现两类相关现象：策略可能依赖场景线索执行原任务，也可能由指令检索熟悉的轨迹或位置。但“表征中可解码目标身份”并不能证明模型能从名称定位当前图像中的目标，更不能证明该定位实际参与动作控制。
  • 论文在 LIBERO 仿真环境中诊断六种 VLA，通过目标位置扰动与同场景指令扰动区分“场景捷径”和“指令捷径”；重点分析冻结的已训练 π0.5 策略，并在闭环重规划的 flow-matching 动作采样过程中实施无需再训练的推理时干预。
  • 作者的目标是确认 π0.5 的视觉落地究竟是否参与控制，并在不提供目标坐标、不增加训练的条件下，降低指令捷径对移动目标触达和任务成功的影响。

方法

  • 输入与评测设置：模型接收主相机/腕部相机图像与语言请求，组成观测 $\mathbf{o}_t=(I_m,I_w,\ell)$，再输出机械臂动作块。图中以五组 scene–request 为单位，对比训练分布与 Task-paired 设置；后者保持同一场景，仅更换目标物体请求，用于分离场景线索和指令线索。
  • 视觉注意与目标定位：指令中的物体名称词元 $N\subset\ell$ 与主相机图像词元 $I_m$ 发生跨模态注意。$\pi_{0.5}$ 的 image-average-normalized attention 明显落在被请求物体上，说明模型“看见”并定位了正确目标，但注意对齐并不保证后续动作受该视觉证据约束。
  • 快捷路径驱动动作：在 Task-paired 条件下，OpenVLA-OFT 主要沿用 scene shortcut（场景捷径），趋向当前场景训练时对应的位置；$\pi_0$ 与 $\pi_{0.5}$ 则采用 instruction shortcut（指令捷径），移动到该目标名称在训练数据中的惯常位置，而非其当前可见位置。
  • 输出与统计指标：图右侧以 First-close rate 衡量末端执行器首次接近哪个位置，并将其与归一化注意热图并列汇总。结果揭示“视觉注意正确、到达行为错误”的解耦：$\pi_{0.5}$ 虽关注请求物体，动作生成仍被语言到训练位置的直接关联覆盖。

  • 整体流程为：输入主相机、腕部相机图像与自然语言指令 → 分别切断两条“指令到动作”注意力路径并比较 flow velocity → 得到视觉落地效应与直接指令效应 → 在每个 Euler 采样步中放大前者、抑制后者 → 输出动作块并继续闭环重规划。
  • 作者区分两条路径：视觉落地路径由图像 token 读取物体名称 token，再由动作 token 读取图像 token；直接路径则允许动作 token 绕过图像、直接读取完整指令。
  • Pathway-Separated Guidance（PSG）在同一 noisy action 和 flow timestep 下计算原始速度 \(v\)、切断主相机图像到名称 token 路径后的速度，以及切断动作 token 到完整指令路径后的速度，由差分估计 grounding effect \(v_g\) 和 direct effect \(v_d\)。
  • PSG 将采样速度改为 \(\tilde v=v+a v_g-b v_d\)。论文固定 \(b=1\)，即完整减去直接路径效应，并通过 \(a\) 放大模型自身已有的视觉落地效应；这不同于把“有指令”和“无指令”整体相减的 CAG/RSS，因为后者会混合两条方向相反的路径。
  • 名称 token 来自指令中所有名词短语，由固定文本规则识别；视觉落地切断只限制主相机图像 token 读取名称 token，其余注意力连接保持不变。
  • PSG 不更新 π0.5 参数，也不使用目标坐标、检测器、分割掩码或外部目标方向；它只修改六个运动维度，不修改夹爪速度。相对原始策略，每个动作块增加一次 prefix 计算，每个 Euler 步增加两次 action-expert 前向计算。

实验与结果

  • 六种 VLA 呈现不同捷径：OpenVLA-OFT、TurboVLA 和 SmolVLA 在 Task-paired 扰动下倾向返回原场景任务位置，表现为场景捷径；π0、π0-FAST 和多数情况下的 π0.5 则前往新指令所指物体的训练位置，而非其当前图像位置，表现为指令捷径。
  • 在较宽松的触达定义下，π0.5 在 200 个 Position 扰动 episode 中有 42 次触达移动目标；为排除“移动目标恰好位于另一任务训练位置”的混淆，作者采用保守判据后，原始 π0.5 的触达数为 29/200。
  • 路径切断给出因果证据：切断视觉落地路径后，移动目标触达从 29/200 降至 0/200；切断动作 token 直接读取指令的路径后，触达反而从 29/200 增至 64/200，并使训练位置处的闭合次数接近减半。这说明视觉落地已经参与动作控制，但常被直接路径承载的指令捷径压制。
  • 在原始、未移动目标的场景中，切断直接路径后仍有 199/200 个 episode 触达目标；因此熟悉场景会掩盖该捷径，因为视觉落地与训练位置检索在原场景中指向同一地点。
  • 注意力分析显示，PaliGemma 与 π0.5 的物体名称注意力会随目标移动；示例中的 wine bottle 被移动后，π0.5 对新位置的名称注意力由 0% 升至 30%。跨两个任务套件的九个物体上，LIBERO 微调后的 π0.5 对移动目标的名称注意力达到图像平均值的 6.4 倍，而 π0 和 π0-FAST 仍接近图像平均水平。
  • 在 LIBERO-PRO Object 的 Position 扰动上，PSG 将 π0.5 的 Reach 从 22.0% 提高到 52.6%，任务成功率从 16.6% 提高到 40.8%，两项指标均超过翻倍；论文称原始任务性能基本得到保持，但所提供正文在表格处截断，无法核对其具体原始任务数值。

局限与可以继续做的

  • 核心因果干预与 PSG 主要围绕 π0.5 展开。π0 的两种路径切断都不能产生对移动目标的触达，与其较弱的名称注意力一致；因此 PSG 依赖模型已经保留可用视觉落地，不能直接修复 grounding 已在机器人预训练阶段退化的模型。
  • 证据来自 LIBERO 系列仿真任务，重点结果是五个 LIBERO-Object 任务及其位置扰动；尚无真机、不同机器人形态、动态目标、遮挡或更长时程任务的证据，不能直接外推到开放世界操作。
  • PSG 的额外推理成本不可忽略：每个动作块多一次 prefix 计算，每个 Euler 步多两次 action-expert 计算。正文未在所给片段中报告端到端控制频率、延迟、显存占用或实时性影响。
  • 注意力跟随目标是重要诊断信号，但注意力本身并不等价于可靠空间定位；本文通过路径切断补充了因果证据，后续仍可加入目标框、三维位置误差、动作终点误差和跨层 causal tracing，检验 grounding effect 是否稳定对应真实目标几何。
  • 可继续做的实验包括：在 OpenPI 执行器中记录每次重规划的 \(v_g\)、\(v_d\) 范数及夹角，以“二者持续冲突”作为在线告警；联合扫描 \(a\) 与推理步数，绘制 Reach、成功率、延迟和原任务退化的 Pareto 曲线；再用目标位置反事实、同场景换指令和新增未见物体组合构造训练集，比较推理时 PSG 与反事实数据训练能否互补。
实验设置
  • 环境：LIBERO、LIBERO-PRO 和 LIBERO-Plus 仿真操作基准；核心捷径分析使用五个 LIBERO-Object 任务。
  • 被测模型：OpenVLA-OFT、TurboVLA、SmolVLA、π0、π0-FAST、π0.5，共六种 VLA。
  • π 系列视觉语言骨干参考：PaliGemma；作者比较原始 PaliGemma、机器人预训练 base model 与 LIBERO 微调后策略的名称注意力。
  • 输入：主相机图像、腕部相机图像、自然语言指令；π0.5 通过 flow matching 生成动作块，并在重规划时从高斯噪声经 Euler 步积分得到动作。
  • 扰动协议：Position 将请求目标与另一物体交换位置但保持指令不变；Task/Task-paired 保持场景不变、改为请求场景中的另一物体。
  • 行为指标：记录夹爪第一次闭合的位置；在请求目标上闭合记为 Reach。保守判据排除移动目标落在另一任务训练位置、因而可能由捷径造成的闭合。
  • 路径诊断：Position 条件下共测试 200 个 episode；原始场景下另报告直接路径切断后的 199/200 触达结果。
  • 注意力分析：检查物体名称 token 到主相机图像 patch 的注意力；跨两个任务套件、九个物体比较预训练前后及 LIBERO 微调后的变化。
  • PSG 参数与接口：\(b=1\)，\(a\ge 0\)；每个 Euler 步在相同 noisy action 和 flow timestep 上执行三种 velocity 预测，仅修改六个运动维度，保持夹爪速度不变。
  • 训练状态：PSG 是冻结策略上的推理时方法，不更新任何模型参数，也不需要额外训练数据或外部目标位置。
  • 所给论文正文在 Table 1 开头截断，未披露可核对的具体检查点名称、每任务 episode 分配、Euler 步数、\(a\) 的最终取值、仿真硬件与运行时延迟。
AI导读和推荐理由
  • 推荐这篇的主要原因不是它又提出一个新的 VLA，而是它把“模型看见了目标却仍伸向旧位置”拆成可干预的两条因果路径，避免把所有位置扰动失败都笼统归结为视觉 grounding 丧失。
  • 对 π 系列尤其有价值的是，论文指出 π0.5 与 π0/π0-FAST 的差异在 LIBERO 微调前已经出现：π0.5 仍保留类似 PaliGemma 的名称—图像落地，而前两者在机器人预训练后已明显弱化。这提示基础训练阶段决定了后续推理时纠偏是否还有可利用的视觉信号。

与π系列的关系

  • 本文直接分析 π0、π0-FAST 和 π0.5，并以共享视觉语言骨干 PaliGemma 作为机器人训练前的参照；它不是 π 系列原作者提出的新基础模型，也没有改变 π0.5 的训练目标、骨干结构或参数。
  • 三种 π 模型在 Task-paired 中都表现出由指令检索训练位置的倾向，但只有 π0.5 明显保留移动目标的名称注意力，并在部分 episode 中实际触达移动目标；因此作者将主要路径因果实验与 PSG 干预放在 π0.5 上。
  • π0 与 π0-FAST 的问题更接近 grounding 本身已弱化：两种路径切断都不能让它们触达移动目标。π0.5 则属于 grounding 尚在、但被直接 instruction-to-action 路径覆盖，因而适合用 PSG 做冻结模型的推理时纠偏。
  • 论文与 OpenPI 的关系主要是基于其 π 系列模型实现和评测接口开展诊断与采样干预；PSG 是外挂在 flow-matching sampler 上的 inference-time harness，并非 OpenPI 或 π 系列训练框架的新版本。所给正文也未显示 PSG 已在 OpenPI 的所有机器人平台或真机配置上验证。
  • 相比 instruction-free guidance，PSG 不把整条语言条件统一增强，而是分别估计图像介导的 grounding effect 与动作直接读取指令的 direct effect；这对 π0.5 很关键，因为两者在目标移动后可能指向相反位置。

对Austin研究的启发

  • 在 OpenPI 执行器中增加三路可切换前向接口：原始 attention、main-image ↛ noun-token、action-token ↛ instruction，确保三路共享 noisy action、flow timestep 和观测，从而复现论文的路径差分而不是比较不同随机采样。
  • 将 \(v_g\) 与 \(v_d\) 做成闭环监控量：记录每次重规划中的范数、夹角及其对末端位姿六维速度的影响。当二者长期反向且 direct effect 占优时，可触发 PSG、降低动作幅度或请求新的相机观测。
  • 评测不能只看原始任务成功率。至少建立“原场景、位置交换、同场景换指令、位置与指令联合反事实”四组协议，并同时记录首次闭合位置、目标触达率、完整成功率、训练位置误触率和恢复轨迹。
  • 对引导场 \(G\) 或类似条件遵循模块，可把“增强语言条件”改为“增强经图像验证的语言条件”：只有名称 token 对当前图像目标形成稳定 grounding effect 时才放大；如果 π0/π0-FAST 式 grounding 已消失，应转向反事实数据或表示训练，而不是盲目提高 PSG 系数。
  • 在部署前扫描 \(a\) 并保留 \(a=0\) 与 direct-cut-only 两个对照，分别回答收益来自“去除指令捷径”还是“进一步放大视觉落地”；同时测量额外 action-expert 前向对闭环控制频率的影响。

一句话总结

澳大利亚国立大学、CSIRO 与 GE Research 的作者发现 π0.5 虽能视觉定位移动目标却常被直接指令路径拉回训练位置，并以无需训练和外部坐标的 PSG 将 LIBERO-PRO Object Position 上的 Reach 从 22.0% 提至 52.6%、成功率从 16.6% 提至 40.8%。
