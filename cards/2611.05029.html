深读｜DRAP

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 物理 AI 的持续学习不仅面临参数层面的灾难性遗忘：策略每一步的微小动作误差会改变后续状态与观测，使机器人偏离专家数据分布，并在闭环轨迹中逐步放大为任务失败。
  • 经验回放通常有较强保持能力，但需要保存或重新生成旧任务观测；扩展与路由方法会增加模块和路由机制；EWC 等参考点正则方法则需要限制参数相对旧解的位移，可能妨碍新任务学习。
  • 论文研究严格无回放的顺序适配：同一个 OpenVLA 检查点依次学习 LIBERO Spatial、Object、Goal，仅允许 KappaTune 预先选出的固定子网络更新，其余参数冻结。
  • 作者目标是在不保存旧套件示范、也不扩展模型结构的条件下，依据历史行为对物理扰动的敏感程度调节参数可塑性，从而兼顾旧行为保持和新套件习得。

方法

  • 专家示范输入（Expert Demonstrations）：图中数据流由左向右展开，首先读取日志轨迹中的状态—动作转移 $\{(s_t,a_t,s_{t+1})\}_{t=1}^{T}$；每个样本既保留当前状态与控制量，也提供下一时刻状态，作为局部动力学辨识的监督信号。
  • 滑动窗口局部线性化（Local Linear Dynamics）：以时刻 $t$ 为中心构造滑动窗口 $\mathcal W_t$，汇集邻近转移并拟合 $s_{k+1}\approx A_t s_k+B_t a_k+c_t$。其中 $A_t$ 描述局部状态演化的雅可比近似，窗口随轨迹移动，从而刻画随状态区域变化的动力学。
  • 扰动放大风险（Perturbation Amplification）：对 $A_t$ 进行奇异值分解，取最大奇异值定义一步风险分数 $r_t^{\rm raw}=\sigma_{\max}(A_t)$。该值衡量最不利方向上的微小状态扰动经一步动力学后被放大的最大倍率，数值越大表示局部行为越敏感、越不稳定。
  • 鲁棒归一化与样本对齐（Risk Weight Alignment）：将全部 $r_t^{\rm raw}$ 通过鲁棒归一化得到风险权重 $w_t=\operatorname{RobustNorm}(r_t^{\rm raw})$，抑制异常尺度影响；随后按时间索引与原训练样本 $(s_t,a_t)$ 一一对齐并存储，形成可直接用于后续风险加权训练的样本级标量权重。
查看论文原图英文题注（Figure 1 Caption）
Dynamics-risk computation from expert demonstrations. Local linear dynamics are estimated over sliding windows of logged state-action transitions. The largest singular value $\sigma_{\max}(A_t)$ defines a local one-step perturbation-amplification score, which is robustly normalized and stored as a sample-level risk weight aligned with the training dataset.
  • 整体流程为：从专家状态—动作轨迹估计局部动力学风险 → 用风险加权样本级动作损失梯度 → 将结果累积为张量级历史重要性 → 在后续任务中用该重要性缩放各张量的 AdamW 有效学习率。
  • 固定适配范围：KappaTune 在视觉、语言和动作头各架构组中，根据预训练权重矩阵的正则化条件数选择固定预算的低条件数张量；选择只执行一次，未选参数始终冻结。KappaTune 决定“哪里能更新”，DRAP 决定“还能更新多少”。
  • 局部动力学风险：在单条 episode 内的滑动窗口上，对鲁棒标准化后的状态和动作拟合岭回归模型

\(s_{t+1}\approx A_t s_t+B_t a_t+c_t\)。以 \(A_t\) 的最大奇异值 \(\rho_t=\sigma_{\max}(A_t)\) 衡量固定记录动作下的一步状态扰动放大，再按当前套件的中位数归一化并裁剪为样本风险权重 \(r_t\)。

  • 风险加权重要性：任务结束后，对确定性抽取的示范样本逐个反向传播；损失仅覆盖离散动作 token，不包含图像、语言提示、padding 等位置。每个可训练张量的重要性取 \(r_i^2\|\nabla_T\ell_i\|_F^2/n_T\) 的样本均值，避免不同样本梯度先求和造成方向抵消，也避免大张量仅因参数更多而获得更高重要性。
  • 跨任务记忆：新任务张量重要性先以所有正值张量的重要性中位数归一化，再与历史重要性相加；该记忆只保存每个可训练张量的标量重要性，不保存旧示范，也不需要保存一份旧参数作为位移参考。
  • 直接控制优化器步长：后续任务中，张量 \(T\) 的可塑性乘子为

\(s_T=(1+\beta\bar I_T)^{-1/p}\)，有效学习率为 \(\eta_T=\eta s_T\)。因此 DRAP 抑制的是 AdamW 的实际有效步长，而不是仅缩放原始梯度；与 EWC 不同，它不添加相对旧检查点的二次位移惩罚。

实验与结果

  • 论文采用单一检查点按 Spatial → Object → Goal 顺序训练，并在每个阶段评测当前及全部已见套件，形成下三角成功率矩阵，以同时衡量新套件习得和向后保持。
  • 作者报告，DRAP 相比普通 AdamW 顺序微调和 EWC，能够显著改善先前套件的行为保持，同时维持较强的新套件学习能力。
  • 正文目录说明实验包含 KappaTune 选择消融和动力学风险加权消融，但所提供的论文原文截止于方法部分，未包含结果表、成功率矩阵或消融数值，因此无法核对或列出 DRAP、AdamW、EWC 的绝对成功率及提升幅度。
  • 文中引用的 OpenVLA-OFT 数字是不同协议下的外部结果：四个套件分别微调的平均成功率为 97.1%，四套件联合训练的单策略为 96.8%。这些数字不属于 DRAP 的无回放顺序学习结果，不能与其直接作等协议比较。
  • 论文还引用另一项研究指出，\(\pi_0\) 与 GR00T N1.5 配合经验回放时遗忘较少，而零回放 Sequential 与 EWC 在 LIBERO-Object、LIBERO-10 上仍有明显负向后向迁移；所给原文没有列出该研究的具体数值。

局限与可以继续做的

  • 风险不是稳定性证书：当前分数只使用直接状态敏感项 \(A_t\)，没有纳入策略反馈项 \(B_tJ_{\pi,t}\)。即便使用闭环 Jacobian，也仍是专家轨迹附近的一阶局部近似，不能覆盖高阶非线性、接触模式切换、观测混叠或离开示范邻域后的行为。
  • 局部模型可能存在估计误差：风险依赖滑动窗口岭回归以及状态、动作标准化；窗口内数据不足、接触动力学突变或状态日志缺失都可能使最大奇异值不能可靠反映真实失败风险。
  • 证据范围有限：评测只覆盖 OpenVLA 上固定 KappaTune 子网络及 LIBERO Spatial、Object、Goal 的单一顺序。原文未报告顺序置换、Long-Horizon、真实机器人、不同 VLA 骨干或全参数微调结果，因而不能据此断言方法可普遍迁移。
  • 张量级保护较粗：每个张量只有一个重要性标量，计算和存储较轻，但可能同时抑制张量内部与旧任务无关、仍适合学习新任务的参数方向。可进一步比较元素级、低秩子空间级或模块级保护的稳定性—可塑性权衡。
  • 可执行后续实验：补做多种套件顺序和随机种子；按高、中、低风险区间统计闭环失败；将 \(A_t\) 风险与 \(A_t+B_tJ_{\pi,t}\) 风险对照；在相同可训练参数预算下比较 DRAP、EWC、纯 KappaTune、无风险梯度重要性及少量回放，并报告最终平均成功率、后向迁移和新任务学习速度。
实验设置
  • 模型：OpenVLA，原文描述其为具有离散动作 token 和预训练视觉—语言骨干的 7B VLA。
  • 适配范围：由 KappaTune 从视觉、语言和动作头各组中选择固定预算的低条件数张量；选择在预训练检查点上执行一次并贯穿整个任务序列，其余参数冻结。
  • 数据与顺序：LIBERO Spatial → Object → Goal；每一阶段只能访问当前套件，不保存旧套件示范。
  • 训练协议：单一检查点连续更新；每阶段结束后，在当前及所有已见套件上进行闭环成功率评测。
  • 对照方法：普通 AdamW 顺序微调、EWC；正文还说明进行了 KappaTune 选择和动力学风险加权消融。
  • 重要性估计：任务结束后使用确定性选取的 \(N_k\) 个示范样本；batch size 为 1；损失只在专家动作对应的输出 token 位置计算。
  • 动力学模型：在 episode 内滑动窗口拟合带截距的岭回归局部线性模型；状态和动作使用套件级统计量进行鲁棒标准化。
  • 风险归一化：\(\sigma_{\max}(A_t)\) 除以当前套件的中位数并裁剪；本实验裁剪范围设为 [0.25, 4]，作者明确称该范围为任意设定。
  • 历史重要性：默认衰减参数 \(\gamma=1\)，即保留所有先前任务的归一化重要性贡献。
  • 所给原文未披露滑动窗口长度、岭回归系数、KappaTune 张量预算、基础学习率、\(\beta\)、\(p\)、\(N_k\)、训练轮数、评测 rollout 次数、随机种子、机器人形态、传感器配置及计算硬件。
AI导读和推荐理由
  • 推荐这篇论文的原因不在于提出了新的 VLA 骨干，而在于它把具身策略的灾难性遗忘与闭环轨迹中的扰动放大联系起来，并提供了一个可外挂到优化器的无回放可塑性控制接口。
  • 对 π 系列研究而言，它提供了一个值得验证的假设：旧数据不一定要等权保护，位于高动力学敏感区域的动作决策可能更值得占用有限的稳定性预算。

与π系列的关系

  • DRAP 不是基于 \(\pi_0\)、\(\pi_0\)-FAST、\(\pi_0.5\) 或 OpenPI 实现；本文实际载体是使用离散动作 token 的 OpenVLA，也没有报告与这些 π 系列模型的同协议直接实验对比。
  • 论文仅在相关工作中引用了一项包含 \(\pi_0\) 的持续学习研究：该研究在每个 LIBERO 套件内部顺序学习十个任务，并发现预训练 VLA 配合少量经验回放可以降低遗忘；DRAP 则跨完整套件顺序迁移，且严格不保存旧套件数据，两者协议和模型架构均不同。
  • DRAP 没有修改 VLA 的视觉—语言骨干、动作表示或推理结构；其主要变化位于训练侧，包括固定可训练子网络、离线动力学风险估计、张量重要性记忆以及张量专属 AdamW 学习率。
  • 因为 OpenPI 常使用连续动作或动作块，而本文的重要性损失针对 OpenVLA 的离散动作 token，迁移时需要重新定义样本级动作损失，但风险加权梯度与优化器步长缩放的思想本身不依赖 token 化动作。

对Austin研究的启发

  • 在 OpenPI 执行器中增加独立的 plasticity_multiplier 接口：保持模型前向与动作解码不变，只让优化器按模块或张量读取历史重要性并缩放有效学习率，以便与普通 AdamW、EWC 和冻结策略做严格同初始化对照。
  • 对连续动作块逐时间步计算 imitation loss，并比较三种重要性：等权梯度、DRAP 的 \(A_t\) 风险加权梯度、包含执行器反馈近似的闭环风险加权梯度；检查高风险时刻是否确实对应抓取接触、窄容差放置或失败前状态。
  • 将风险监控接入闭环 rollout，而不只看离线动作误差：按风险分位数记录动作偏差、离轨距离、恢复率和最终成功率，验证“高局部奇异值 → 更高闭环失败概率”这一核心假设。
  • 对引导场 \(G\) 的条件遵循实验，可分别记录与 \(G\) 相关模块和动作执行模块的重要性，测试 DRAP 是否保护了旧条件映射却过度抑制新条件学习；同时加入组合留出集，避免仅凭已见任务保持率判断泛化。
  • 先做最小消融矩阵：固定同一 OpenPI 可训练子网，比较普通 AdamW、仅 KappaTune/冻结、无风险张量重要性、DRAP，以及少量回放上界；至少报告新任务成功率、旧任务成功率、平均后向迁移和每阶段训练成本。

一句话总结

DRAP 在固定 KappaTune 子网络的 OpenVLA 上，以局部动力学最大奇异值加权动作梯度并按张量缩放 AdamW 学习率来改善 LIBERO 三套件无回放顺序学习，但所给原文未提供可核对的 DRAP 成功率数值，且作者 Oswaldo Ludwig 的机构信息未披露。
