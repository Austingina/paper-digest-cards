问题

  • 上下文模仿学习（ICIL）希望机器人在测试时仅凭示教适应未见任务配置、不更新权重；但一条多视角传感—动作轨迹即使下采样后仍需数千 token，限制了上下文能容纳的示教数量，过长提示还可能超出策略训练时的长度分布。
  • 现有压缩方法通常只通过动作预测损失训练压缩器，容易保留粗粒度任务身份，却丢失物体操作顺序、抓取高度、接近方向等阶段相关的执行过程；仅报告任务成功率也无法证明策略真正使用了示教条件。
  • 论文同时考虑仿真和真实机器人：仿真在未见的 LIBERO 与 RLBench 任务配置上闭环执行，真机进一步接受人手视频示教；测试时策略权重固定，不进行在线微调。
  • 作者的目标是把每条示教压缩成可独立缓存的少量潜在槽，在支持 many-shot 上下文的同时，保留足以决定下一执行阶段的任务与过程信息。

\textbf{Overview of \methodname{}.} (1) A compressor maps each demonstration to $k$ latent slots, which are cached in a demonstration bank. (2) The slots are trained to predict the next keyframe of the query episode in the embedding space of a frozen \vjepa{} encoder, with task and process negatives. (3) The predictor ranks the demonstrations in the bank, and only the policy runs in the control loop. (4) Post-training on 10 tasks uses equal shares of human-hand and dual-arm robot demonstrations with the same objective; unseen tasks are executed from human-hand context without test-time weight updates.
  • 整体流程为：逐条编码并压缩示教 → 缓存潜在槽 → 用槽预测查询回合的下一阶段关键帧表示 → 按预测一致性选择上下文示教 → 流匹配策略读取当前观测、语言和槽并闭环生成动作。
  • 每条示教独立经过 Perceiver 压缩器，得到 \(k\) 个潜在槽；多个示教的槽直接拼接。槽带有槽位索引，但没有示教编号，因此示教重排只会重排对应的槽块，并且压缩结果可在示教库中复用。
  • 论文以抓手开合、末端速度局部极小值和回合终点划分阶段。预测器结合示教槽、查询回合当前图像与本体状态，预测下一关键帧两帧片段在冻结 V-JEPA 2.1 空间中的 patch 表示，而不是重建像素。
  • 为避免预测器只根据当前画面猜测未来，JEDI 加入 margin-based 反事实约束：任务负样本来自同场景中的另一任务，用于保留目标物体和目标；过程负样本来自同一任务的不同执行方式，用于保留操作顺序、抓取位置与高度、接近方向。
  • 与 ContextFlow 式动作损失压缩相比，JEDI没有改变“压缩槽供流匹配策略注意”的基本接口，而是增加 JEPA 预测目标、任务/过程反事实和预测式示教选择。预测预训练后的槽在策略训练阶段冻结；策略本身由 \(\pi_0\) 初始化并通过 LoRA 适配，并非直接采用 \(\pi_0.5\) 或完整 OpenPI 执行栈。
  • 测试时未知查询回合的未来，因此选择器把示教库中的其他轨迹当作伪查询，计算某条示教的槽预测其他示教关键帧的误差，优先选择低误差示教；若同一任务包含多种过程，还可在查询完成一个阶段后重新选择，使上下文继续匹配已经开始的执行过程。
  • 真机阶段增加跨人手与机器人共享的关键点 token，包括手腕、拇指尖、食指尖、捏合开度、对应机器人末端关键点及物体关键点；后训练让人手示教槽预测机器人回合的下一关键帧，从而在部署时用纯人手视频作为上下文。

实验与结果

  • 在表 1 的未见配置评测中，JEDI 的成功率分别为 LIBERO-Spatial 92.7%±1.6、LIBERO-Object 83.6%±2.9、LIBERO-Goal 63.0%±2.3、RLBench 82.1%±2.0；对应 ContextFlow 为 85.6%±2.8、76.4%±3.2、56.5%±2.2、73.6%±1.3，即分别提高 7.1、7.2、6.5 和 8.5 个百分点。
  • 使用 \(N=16\) 条示教时，上述四项成功率进一步达到 95.4%±1.0、86.2%±1.1、69.1%±2.5 和 86.3%±1.7，支持“独立压缩与缓存可利用 many-shot 上下文”的主张。
  • 在用于隔离压缩目标影响的 LIBERO 客观控制实验中，预测预训练后冻结的压缩槽取得 75.4% 成功率；这一结果针对冻结槽设定，不应与表 1 的完整 JEDI 数字直接混为同一协议。
  • 在配对上下文测试中，论文交换示教目标，并另行构造“终点相同、执行过程不同”的上下文；JEDI 遵循被交换示教的比例比仅用动作损失训练的压缩方法高 40.8 个百分点，说明收益不只是识别任务类别，还包括使用示教中的过程条件。
  • 预测误差选择在相同示教数量 \(N\) 下优于随机选择；当示教库较为多样时也优于基于图像相似度的检索。论文明确以相同 \(N\) 比较，避免把“选得更好”和“使用更多示教”混为一谈。
  • 真机实验在双臂平台上展示了五类任务可由人手视频示教驱动执行，部署时不更新权重；所给正文片段未披露这些真机任务的逐任务成功率、试验次数或置信区间，因此不能据此量化其稳定性和失败恢复能力。

局限与可以继续做的

  • JEDI 的未见设定是“未见物体、布局与目标配置，但所需运动 primitive 在训练中出现过”。因此现有证据不能说明潜在槽可以创造训练数据未覆盖的接触方式或全新技能。
  • 潜在槽强调保留可预测的执行信息，但不是可解释的 G 或 A/F 几何接口；论文通过交换上下文证明条件遵循有所增强，却没有直接说明每个槽对应哪个交互区域、物体运动方向或执行阶段。
  • 预测式选择假设示教库中的多数轨迹表达预期配置；若库中错误示教、多个互相冲突的目标或不同过程占比接近，库内一致性分数可能偏向多数模式，而不一定符合用户当前意图。
  • 真机部分只提供五类任务的展示性证据，所给原文没有逐任务统计、失败类型或恢复协议；需要增加抓取失败、放置偏差、遮挡和执行中目标移动等扰动，分别报告无恢复与允许重规划时的闭环成功率。
  • 可继续做一个严格的组合泛化矩阵：按物体×目标×过程划分训练组合，完整留出部分交叉组合，并同时报告任务成功、目标持续跟随、过程遵循和接触失败；这比仅留出场景配置更能检验表示是否支持真正重组。
  • 可将 JEDI 槽作为 OpenPI \(\pi_0/\pi_0.5\) 的外挂条件，与显式 A/F 或 G token 在同一执行器、同一数据和同一上下文预算下比较；再做槽置零、跨任务交换、过程反向和阶段中途替换，判断强预训练策略究竟使用条件还是依赖熟悉的物体—目标先验。
实验设置
  • 仿真基准：LIBERO-Spatial、LIBERO-Object、LIBERO-Goal 和 RLBench；评测对象为训练中未见、但由已见运动 primitive 组成的任务配置。
  • 输入示教：多视角图像、本体状态和动作；每条示教下采样为 8 帧图像以及 128 个本体状态/动作时间步。
  • 压缩器：4 层 Perceiver，以 \(k\) 个可学习查询产生 \(k\) 个、宽度与策略 token 一致的潜在槽；每条示教独立压缩并缓存。
  • 视觉编码：示教侧使用策略的 SigLIP 编码器且保持冻结，查询侧 SigLIP 可微调；预测目标由冻结的 V-JEPA 2.1 离线计算。
  • 关键帧：抓手开合事件、末端执行器速度局部极小值和 episode 终点；目标为下一关键帧附近两帧视频片段的 V-JEPA patch 表示。
  • 损失：条件流匹配动作损失、SmoothL1 JEPA 表示预测损失，以及带 margin 的任务/过程反事实损失；查询观测 token 在预测损失路径上停止梯度。
  • 策略：沿用 \(\pi_0\)/ContextFlow 风格的流匹配 action expert，由 \(\pi_0\) 初始化并使用 LoRA 适配；动作 horizon 为 50，推理使用 10 个 Euler 步。
  • 上下文数量：训练时 \(N\sim\mathcal U\{1,\ldots,16\}\)；论文将 \(N\geq4\) 定义为 many-shot，并单独报告 \(N=16\) 的结果。
  • 数据增强式调度：以 0.2 概率加入 1–4 条其他配置的干扰示教；以 0.5 概率将语言指令替换为空字符串。
  • 支持集与查询来自同一配置的不同 episode；存在过程标签时，两者过程一致。过程标签由基准构造提供，或通过每个任务的关键帧潜在序列聚类获得，仅用于选择过程负样本。
  • 示教选择：预计算库内示教两两预测误差，并结合查询初始观测相似度加权；选择分数最低的 \(N\) 条。多过程任务可在完成阶段后在线重选，但预测器和 V-JEPA 不进入逐控制步闭环。
  • 真机：双臂机器人；后训练覆盖 10 个任务，每个训练 bank 等比例混合人手和机器人示教，查询始终为同任务机器人 episode；机器人本体状态和动作 token 以 0.5 概率丢弃。
  • 真机后训练保持 SigLIP 与 V-JEPA 冻结，训练关键点编码器和预测器，以 LoRA 更新压缩器，并以较低学习率更新策略；测试时可只提供人手视频且不更新权重。
  • 表 1 数字报告均值与误差，并称预测选择实验跨 3 个随机种子；所给正文片段未披露每个任务的 episode 数、完整硬件配置、槽数 \(k\)、损失权重、反事实 margin 和选择温度。
AI导读和推荐理由
  • 推荐这篇的核心原因不是单纯提高成功率，而是它把“压缩表示是否真的控制行为”变成配对上下文实验：交换目标、固定终点而改变过程，再观察策略究竟跟随哪一条示教。
  • 论文还给出了一个适合多示教场景的工程接口：示教逐条压缩、离线缓存和检索，控制环内只运行策略，因而可在不线性保留完整轨迹 token 的情况下扩大上下文。

与本项目关系

  • JEDI 与 Austin 项目最直接的联系是条件遵循评测：其目标交换和同终点异过程测试，对应 G/A-F 研究中的置零、反向与交换消融，均试图排除“策略只把条件当作任务 ID”这一解释。
  • 两者的表示选择不同。Austin 的 G 或 A/F 显式指定接近区域及期望物体运动，便于几何操控和定向消融；JEDI 槽从完整示教中隐式保留任务及过程，表达能力更宽，却难以直接解释为接触点、方向或物体变化。其“预测查询下一阶段关键帧”目标可用于约束 G/A-F 编码器保留阶段性变化，但不能替代显式几何语义。
  • JEDI 使用 \(\pi_0\) 初始化的流匹配策略，而非直接验证 OpenPI 的 \(\pi_0.5\)；它也没有证明潜在槽或强执行器能补出未在训练数据中出现的接触技能。论文对放置偏差、失败恢复和执行过程中是否持续跟随目标的证据仍有限。

启发

  • 在现有 OpenPI 执行器上并行接入三种条件：显式 G、A/F token 和 JEDI 式多示教槽；冻结或使用同等 LoRA 预算训练执行器，统一做条件置零、方向反转、目标交换、阶段中途换条件，比较任务成功率与条件遵循率。
  • 给 G/A-F 表示增加辅助目标：由当前观测和条件预测“下一交互阶段的物体关键帧表示”，同时构造同场景异目标、同终点异过程负样本；检查该目标能否减少“抓到物体但送错目标”和“翻转 G 仅切换任务 ID”的现象。
  • 数据划分应从普通未见配置升级为物体×目标×过程的交叉留出：训练中保留各单因素及运动 primitive，但不出现特定组合；分别测新物体—目标配对、新方向、新放置终点和新过程顺序，避免把场景记忆误判为组合泛化。
  • 为目标持续跟随增加阶段级审计：记录每一阶段条件与下一物体关键帧的预测误差，并在放置、遮挡或轨迹偏离后重选示教或更新 G；同时报告是否恢复、恢复耗时以及最终放置误差。
  • 可把 JEDI 的示教选择器用作数据诊断工具：若某条示教无法预测同任务其他示教的关键阶段，检查其是否包含异常接触、失败恢复或不同目标定义，再决定将其作为负样本、独立过程簇或训练中的稀有恢复案例。

一句话总结

纽约大学坦登工程学院与 NYU Abu Dhabi CAIR/AIR Lab 提出的 JEDI，以冻结 V-JEPA 2.1 中的下一阶段关键帧预测和任务/过程反事实训练可缓存示教槽，在 LIBERO 客观控制中达到 75.4% 成功率，并将交换示教遵循率相对动作损失压缩提高 40.8 个百分点。
