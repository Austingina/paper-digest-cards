深读｜Seeing Is Not Reaching

问题

  • VLA 通常继承自具备视觉定位能力的 VLM，但目标物体被移走后，机械臂仍可能伸向训练时的位置；仅观察失败轨迹，无法判断模型是丢失了视觉 grounding、没有使用它，还是其作用被其他捷径覆盖。
  • 论文区分两类失败：场景捷径让策略无视新指令、继续执行该场景原有任务；指令捷径则由物体名称检索训练中的熟悉位置，而非依据当前图像定位物体。
  • 作者在 LIBERO 仿真操作任务中，对六种 VLA 进行目标重定位和同场景指令替换，并在闭环执行中记录夹爪首次闭合位置；进一步对 π0.5 的信息路径进行因果遮罩。PSG 是推理时干预，不更新策略参数。
  • 目标是解释“看到了目标却没有伸向目标”的因果机制，并在不重新训练、不提供目标坐标或分割掩码的条件下，提高位置扰动下的目标到达率和任务成功率。

方法

  • 输入与评测设置：模型接收主相机/腕部相机图像与语言请求，组成观测 $\mathbf{o}_t=(I_m,I_w,\ell)$，再输出机械臂动作块。图中以五组 scene–request 为单位，对比训练分布与 Task-paired 设置；后者保持同一场景，仅更换目标物体请求，用于分离场景线索和指令线索。
  • 视觉注意与目标定位：指令中的物体名称词元 $N\subset\ell$ 与主相机图像词元 $I_m$ 发生跨模态注意。$\pi_{0.5}$ 的 image-average-normalized attention 明显落在被请求物体上，说明模型“看见”并定位了正确目标，但注意对齐并不保证后续动作受该视觉证据约束。
  • 快捷路径驱动动作：在 Task-paired 条件下，OpenVLA-OFT 主要沿用 scene shortcut（场景捷径），趋向当前场景训练时对应的位置；$\pi_0$ 与 $\pi_{0.5}$ 则采用 instruction shortcut（指令捷径），移动到该目标名称在训练数据中的惯常位置，而非其当前可见位置。
  • 输出与统计指标：图右侧以 First-close rate 衡量末端执行器首次接近哪个位置，并将其与归一化注意热图并列汇总。结果揭示“视觉注意正确、到达行为错误”的解耦：$\pi_{0.5}$ 虽关注请求物体，动作生成仍被语言到训练位置的直接关联覆盖。

  • 整体流程为：输入主相机、腕部相机、机器人状态与语言指令 → π0.5 通过 flow matching 生成动作块 → 分离语言影响动作的两条路径 → 在每个 Euler 采样步调整预测速度 → 闭环执行经引导的动作。
  • 作者定义两条指令到动作的路径：grounding 路径由图像 token 读取物体名称 token，再由动作 token 读取图像表示；direct 路径则允许动作 token 绕过图像、直接读取完整指令。
  • 因果诊断分别遮罩两条路径：grounding cut 阻止主相机图像 token 读取名称 token，direct cut 阻止动作 token 直接读取指令；输入图像、指令、噪声动作与 flow timestep 保持不变，以观察夹爪目的地如何变化。
  • Pathway-Separated Guidance（PSG）在同一采样状态下计算原始速度 \(v\)、切断 grounding 路径后的速度和切断 direct 路径后的速度，据此得到 grounding effect 与 direct effect；随后放大前者并抑制后者，而不是像整指令 guidance 那样将两种相反作用混在一个对比信号中。
  • PSG 不修改模型权重，也不使用目标坐标、检测器、分割掩码或额外训练数据；它只调整六个运动维度的速度，夹爪速度保持原预测。
  • 相比原始采样器，PSG 每个动作块增加一次 prefix 计算，并在每个 Euler 步增加两次 action-expert 前向评估；因此它是外挂式推理干预，而非新的策略训练方法。

实验与结果

  • 在五个 LIBERO-Object 任务上，Position 扰动将请求物体与另一物体交换。六种模型中有五种会回到目标的训练位置；π0.5 在宽松 reach 判据下，200 个 episode 中有 42 次到达重定位目标，但大多数轨迹仍返回训练位置。
  • Task-paired 在场景不变时改为请求另一个物体：OpenVLA-OFT、TurboVLA 和 SmolVLA 主要返回场景原任务的位置，表现为场景捷径；π0、π0-FAST 与多数 π0.5 轨迹则前往新指令所指物体的训练位置，表现为指令捷径。
  • π0.5 保留了视觉定位信号：酒瓶重定位后，其名称 token 对新位置的注意力由 0% 升至 30%；跨两个任务套件的九个物体，LIBERO 微调后的 π0.5 对移动目标的名称注意力达到图像平均值的 6.4 倍，而两个 π0 变体仍接近图像平均值。该差异在 LIBERO 微调前的机器人预训练模型中已经出现。
  • 在采用更保守 reach 判据的 200 个目标重定位 episode 中，原始 π0.5 到达新目标 29 次；切断 grounding 路径后降至 0 次，说明视觉定位确实参与动作控制；切断 direct 路径后升至 64 次，同时训练位置处的闭合次数接近减半，说明 direct 路径携带的指令捷径正在覆盖 grounding。
  • 同一个 direct cut 在原始、未重定位场景中仍有 199/200 个 episode 到达目标，表明熟悉场景中 grounding 与位置捷径指向同一位置，常规评测会掩盖二者的冲突；但仅切断捷径也只能在重定位测试中达到 64/200，仍不足以稳定解决问题。
  • 在 LIBERO-PRO Object 的 Position 扰动下，PSG 将 π0.5 的目标到达率从 22.0% 提高到 52.6%，任务成功率从 16.6% 提高到 40.8%，两项指标均超过原来的两倍；论文称原始任务性能“基本保持”，但所提供正文在表格处截断，无法核对其逐任务数值。

局限与可以继续做的

  • PSG 的机制与主要改进数字集中在 π0.5；六种 VLA 虽用于捷径诊断，但现有原文片段没有证明 PSG 能迁移到 π0、OpenVLA-OFT、TurboVLA、SmolVLA 或其他机器人策略。
  • 实验证据来自 LIBERO 系列仿真任务与有限的物体重定位、指令替换组合，尚不能直接外推到真机中的遮挡、相机漂移、抓取误差、动态目标或长时序失败恢复。
  • 注意力转移本身不等于因果 grounding；本文通过路径遮罩补足了这一点，但遮罩按架构预定义路径，无法排除目标信息还经由其他 token、腕部图像或中间表示传播。正文也提到后续分析腕部相机，但所提供片段未包含对应结果。
  • Reach 只判断夹爪首次闭合是否位于请求物体，不能完整覆盖抓取稳定性、运输过程中的持续目标跟随、正确放置和失败后的重试；Reach 明显高于最终成功率也说明到达目标并不等于完成任务。
  • 可继续构造物体×目标×场景的交叉覆盖和严格留出组合，并加入同一初始画面下的多目标反事实任务；同时分别统计接近、接触、抓取、运输、放置和恢复阶段，判断 direct shortcut 在哪个阶段重新占据控制。
  • PSG 带来每个动作块一次额外 prefix 计算及每个 Euler 步两次额外 action-expert 评估；论文片段未报告实际延迟、吞吐量或控制频率，真机部署前应测量其是否满足闭环实时性。
实验设置
  • 平台：LIBERO、LIBERO-PRO 与 LIBERO-Plus 仿真操作基准；正文重点报告五个 LIBERO-Object 任务及 LIBERO-PRO Object 的 Position 扰动。
  • 机器人观测：主相机图像、腕部相机图像、机器人状态和语言指令；执行对象为带夹爪的机械臂，所提供原文未给出具体机器人型号。
  • 评测模型：OpenVLA-OFT、TurboVLA、SmolVLA、π0、π0-FAST、π0.5；PaliGemma 作为三个 π 模型共享的机器人训练前 VLM 参考。
  • 反事实协议：Position 扰动交换请求物体与另一物体但保持指令不变；Task/Task-paired 保持场景不变、改为请求场景内另一物体。
  • 行为指标：记录夹爪首次闭合位置；在请求物体上闭合计为 Reach。路径遮罩实验采用更保守判据，排除移动物体恰好位于另一任务训练位置、因而无法区分 grounding 与捷径的闭合。
  • 路径诊断规模：π0.5 的目标重定位因果遮罩测试包含 200 个 episode；原始场景 direct-cut 对照同样报告 200 个 episode。注意力汇总还涉及五个 scene–request pair，以及两个任务套件中的九个物体。
  • grounding cut：阻止图像 token 读取指令中的物体名称；PSG 中具体遮罩主相机图像 token 到名称 token 的注意力。名称 token 由固定文本规则识别指令中的全部名词短语。
  • direct cut：阻止动作 token 直接读取完整指令；π0 的诊断还同时涉及 state token。所有遮罩跨全部 Transformer 层和注意力头生效。
  • 动作生成：π0.5 通过 flow matching 和 Euler 积分生成动作块，并在闭环过程中重新规划。
  • PSG：在每个 Euler 步于相同 noisy action 和 flow timestep 下评估三种速度；direct-effect 抑制系数设为 \(b=1\)，grounding 放大系数 \(a\) 的具体取值未出现在所提供原文片段中。
  • 训练状态：PSG 不更新参数、不增加训练；论文比较机器人预训练 base model 与 LIBERO 微调后策略，但所提供片段未披露微调数据量、训练步数、硬件、随机种子及完整检查点名称。
AI导读和推荐理由
  • 这篇论文值得推荐，因为它没有把“注意力落在目标上”直接当作策略理解视觉条件，而是用闭环目标重定位和路径遮罩区分“已编码”“被动作使用”与“被另一条捷径覆盖”三个层次。
  • 它对基于 OpenPI/π0.5 构建条件执行器尤其直接：π0.5 并非完全缺少视觉 grounding，而是 grounding 与语言检索出的训练位置同时影响动作，后者在分布外组合中占据上风。

与本项目关系

  • 论文直接对应 Austin 项目中“把 G 或 A/F 条件喂给策略，不等于策略真正遵循条件”的观察：π0.5 的物体名称注意力会跟随移动目标，但机械臂仍常被熟悉的“语言—训练位置”关联拉回去，类似 G 被编码却只表现为任务 ID，或被其他条件路径覆盖。
  • 本文没有提出 G/A-F 交互几何，也没有验证接触点、运动轴、物体期望运动或放置目标；其 grounding 主要解决“当前图像中请求物体在哪里”，因此与 A 的“接近哪个交互区域”联系较强，与 F 的“物体应如何运动”及新接触技能生成联系较弱。
  • 对当前 OpenPI π0/π0.5 执行器，关键风险是语言或训练中的物体—目标关联可能绕过 G，直接驱动动作。本文证明这种旁路可在原始任务中几乎不可见，却在目标重定位或未见组合上压过视觉条件。

启发

  • 在现有 G 消融的置零、反向和交换之外，加入路径级干预：分别切断“视觉/G → 动作”与“语言 → 动作”的直接连接，比较接近区域、抓取、运输和放置阶段的闭环轨迹，判断 G 是未被使用，还是已发挥作用但被语言捷径覆盖。
  • 建立与 Position 和 Task-paired 对应的二维反事实矩阵：一类保持语言不变、交换物体或目标位置；另一类保持初始场景完全相同、只替换目标或期望运动。这样可区分场景捷径、物体名称捷径、目标位置捷径和真正的 A/F 条件遵循。
  • 对物体×目标×场景做交叉覆盖与留出组合，并刻意加入“同一物体在同一场景中送往不同目标”的训练样本；否则语言或场景可唯一检索目标位置，训练损失和原始任务成功率都无法证明组合泛化。
  • 将评测拆成“到达正确物体—稳定抓取—持续跟随目标—送达正确区域—释放—失败恢复”，同时记录 G/A-F 条件与动作的局部一致性；本文 Reach 从 52.6% 到最终成功率 40.8% 的差距提示，仅修复接近阶段不足以解决放置问题。
  • 可在 π0.5 上实现 PSG 式三次前向对比，分别估计 G-mediated effect 与 direct language effect，再尝试只在冲突显著的 replanning step 启用 guidance，以降低额外计算，并与原有 G 置零、反向、交换测试形成因果证据链。

一句话总结

澳大利亚国立大学、CSIRO 与 GE Research 的作者证明 π0.5 的视觉 grounding 已参与控制却被指令到动作的训练位置捷径覆盖，并以无需训练的 PSG 将 LIBERO-PRO Object 位置扰动下的 Reach 从 22.0% 提升至 52.6%、成功率从 16.6% 提升至 40.8%。
