深读｜RAFT

📐 原版模型结构图详解🤖 向千问提问本篇论文原文 ↗

问题

  • 通用 VLA 在大规模机器人数据上预训练后，仍需用目标任务示范进行后训练；但少量示范通常来自狭窄环境，普通微调虽然提高名义成功率，却可能削弱模型对外观、物体身份和指令变化的鲁棒性。
  • 现有方法主要通过权重插值/合并（如 RETAIN）或限制视觉编码器漂移并在推理时加入提示引导（如 DeLock）缓解遗忘，尚未系统研究“先对齐任务推理、再学习动作”的低数据后训练方案。
  • 论文同时覆盖仿真与真机闭环执行：MolmoSpaces 中的拾取放置和开抽屉、单臂 DROID，以及双臂 YAM 长时序任务；策略并非整体冻结，而是在两个阶段中训练互补的参数集合。
  • 作者目标是：在不增加目标任务动作示范的前提下，通过任务相关推理监督提升 VLA 后训练后的分布外成功率，并保留对对象、空间关系和任务进度的表征。

方法

  • 输入与共享主干：任务指令 $T$ 与观测 $s_t$ 从左向右进入策略；图像由预训练 SigLIP Vision Encoder（视觉编码器）提取视觉特征，再经投影层送入 Language Model（语言模型）。SigLIP 基础权重全程冻结，视觉适配仅由其中的 LoRA 完成。
  • Stage I—Reasoning Alignment（推理对齐）：Gemini 3.1 Pro 根据 $(s,T)$ 生成框、关键点、轨迹、空间描述或 VQA 等推理标注 $r=(r_1,\ldots,r_{|r|})$，构成 $\mathcal D_{\mathrm{reason}}$；仅更新视觉编码器与语言模型中的 reasoning adapters $\phi$，最小化 $\mathcal L_{\mathrm{reason}}(\phi)=-\mathbb E\sum_j\log p(r_j\mid r_{<j},s,T)$。
  • Stage II—Action Adaptation（动作适配）：输入小规模动作示范 $\mathcal D_\eta=\{(s_t,a_t,T)\}$，冻结 Stage I 学得的 LoRA 参数 $\phi$，仅更新语言模型、Action Expert（动作专家）及 projection layers，统记为 $\theta$，其初值为 $\theta_{\mathrm{pre}}$。
  • 梯度隔离与输出：动作监督沿 Action Expert—语言模型—投影层反向传播，但不进入 reasoning adapters；最终融合冻结的推理适配器与更新后的动作参数，得到策略 $\pi_{\theta,\phi}(a_t\mid s_t,T)$ 并输出动作 $a_t$。

\textbf{Overview of \ours{}.} Stage~I updates only the reasoning adapters, using reasoning annotations. Stage~II freezes the adapters and updates the language model, action expert, and projection layers on action demonstrations, so action gradients do not reach the reasoning adapters.
  • 两阶段 pipeline：从目标任务观察与指令生成推理标注，先训练低秩适配器进行推理对齐；随后冻结该适配器，用同一目标任务的动作示范监督微调策略，最终直接输出机器人动作。
  • Stage I：推理对齐。Gemini 3.1 Pro 根据观察和任务指令生成任务相关标注，包括物体框、关键点、运动轨迹、空间描述和视觉问答；模型以自回归交叉熵预测这些推理 token。
  • Stage I 只更新视觉编码器和语言模型中的 LoRA 参数；其余预训练参数全部冻结，使适配器先学习目标物体、交互关系与运动结构，而不受动作模仿梯度干扰。
  • Stage II：动作适配。固定 Stage I 得到的 LoRA，使用示范进行监督式动作学习；只更新语言模型、动作专家和投影层，动作梯度不会写入推理适配器。
  • 预训练 SigLIP 视觉塔的原始权重在两个阶段始终冻结；视觉侧的任务适配仅由 Stage I 的 LoRA 承担。消融显示，收益不能简单归因于“冻结视觉编码器”。
  • 相比 Plain FT，RAFT 增加了动作训练前的推理对齐阶段，但不改变目标任务的动作示范集合；相比联合训练，它刻意隔离推理监督与动作监督，并在第二阶段保留固定的推理适配器。

实验与结果

  • 仿真拾取放置：五个匹配评测 split 的平均成功率为 83.2%，高于 Plain FT 的 79.6%、RETAIN 的约 79% 和 DeLock 的约 74%。在新物体条件下，RAFT 为 43%，Plain FT 为 36%，RETAIN 为 37%。
  • 仿真开抽屉：RAFT 平均成功率为 39%，Plain FT 为 29%；其中 ID 条件为 44% vs. 29%，纹理变化条件为 28% vs. 15%，且 RAFT 在光照和指令变化上也领先。
  • DROID 真机分布外评测：RAFT 的汇总 OOD 成功率为 75.0%，Plain FT 为 27.9%。细分为新物体颜色 83% vs. 33%、加入干扰物 75% vs. 25%、更换桌面背景 65% vs. 25%；在训练分布内两者较接近，为 63% vs. 60%。
  • 双臂 YAM 长时序任务：RAFT 完成“开盒—取物—放入盒中”完整序列的五类条件汇总成功率为 70.0%，高于 DeLock 的 36%、Plain FT 的 35% 和 RETAIN 的 29%；RAFT 在 ID 为 73%，四种分布偏移下为 60%–80%。Plain FT 往往能打开盒子，却在后续放置阶段失败。
  • 训练调度是关键变量：在仿真拾取放置上，冻结适配器的分阶段 RAFT 为 83.21%；Stage II 继续更新适配器降至 73.96%，推理与动作按 1:1 联合训练仅 63.21%，Stage I 后不做动作微调为 48.30%，而 Plain FT 为 79.62%。
  • 表征分析支持其机制主张：第 14–17 层的物体身份线性探针平衡准确率为 0.51–0.53，高于 Plain FT 的 0.45 和基础模型的 0.40；任务进度四分位预测为 0.62–0.65，对照分别为 0.55 和 0.51。第 11 层对标注任务区域的注意力富集为其面积占比的 3.2–3.4 倍，Plain FT 仅为 1.9–2.1 倍。
  • 更广的推理数据混合将留出推理损失从域内数据的 0.62 降至 0.29，并在三个动作示范预算下将 ID 成功率提高 0.9–3.8 个百分点；25 条示范时 RAFT 与 Plain FT 均为 46.2%，使用全部示范时为 95.3% vs. 90.6%。

局限与可以继续做的

  • 证据覆盖两个仿真任务和两个真机平台，但每个平台的目标技能较少；目前不足以证明 RAFT 可普遍迁移到移动操作、导航或更多接触丰富技能，也未报告长期连续部署中的稳定性。
  • 推理标注由 Gemini 3.1 Pro 生成，增加了额外的数据生成成本，并可能引入标注错误与模型依赖；给定原文未量化标注成本、人工审核量或错误标注对策略的影响。
  • 仿真每个 split 有 106 次试验，但所给原文未披露 DROID 与 YAM 各条件的具体试验次数、置信区间或随机种子重复数；真机百分比之间的差异因此难以进一步判断统计不确定性。
  • RAFT 依赖 Stage I 标注模态与数据组成：论文已经观察到不同推理模态产生不同效果，但尚未形成无需下游闭环试验即可选取标注形式的可靠准则。可以进一步比较物体框、关键点、轨迹、空间文本及其组合在等标注成本下的收益。
  • 可在 OpenPI 中做严格的配对实验：固定预训练检查点、动作示范、训练步数和执行器，仅改变 Plain FT、RAFT、联合训练及“Stage II 解冻 LoRA”四种调度，并加入对象×背景×指令的组合留出评测。
  • 可增加在线监控接口，记录任务区域注意力富集、后层 participation ratio 和对象身份探针；再检验这些离线信号能否在闭环部署前预测 OOD 失败，而不只是在训练后与成功率相关。
实验设置
  • 仿真平台：MolmoBot 策略与 MolmoSpaces 模拟器；任务为拾取放置和开抽屉。
  • 仿真数据：每个任务使用同一布局中的 106 条成功示范进行后训练。
  • 仿真协议：ID 及 OOD-light、OOD-texture、OOD-prompt；拾取放置额外包含 OOD-object。每个 split 为 106 次试验，不同方法使用匹配随机种子。
  • DROID 真机：单臂 DROID，MolmoBot 使用 50 条拾取放置示范进行后训练；评测 ID、新物体颜色、干扰物和桌面背景变化。
  • YAM 真机：双臂 YAM，以 π0.5 为基础策略，使用 100 条“开铰链盒—拿起物体—放入盒中”示范；评测 ID、杂物、盒子位姿、物体颜色和背景变化。
  • 基线：未经后训练的 Base、Plain FT、RETAIN 和 DeLock。
  • 动作训练：所有微调策略均在 5,000 个动作训练 step后评测。
  • Stage I 标注器与标注：Gemini 3.1 Pro；标注形式包括边界框、关键点、运动轨迹、空间描述和视觉问答。开抽屉主结果使用边界框监督，拾取放置主结果使用完整推理监督。
  • 参数更新：Stage I 仅训练视觉编码器和语言模型中的 LoRA；Stage II 冻结 LoRA，更新语言模型、动作专家和投影层；预训练 SigLIP 权重始终冻结。
  • 联合训练消融：推理样本与动作样本等概率采样，两项损失权重为 1:1。
  • 表征评测：线性探针使用相同的 414 帧，按 episode 留出；物体身份为 7 类，随机水平为 1/7，任务进度划分为 4 个时间区间，随机水平为 1/4。
  • 所给原文片段未披露 LoRA 秩、优化器、学习率、batch size、真机各条件试验次数及具体硬件配置。
AI导读和推荐理由
  • 推荐这篇的核心原因不是又一种 LoRA 配方，而是它揭示了 VLA 少样本后训练中的一个反直觉现象：推理监督与动作监督同时训练反而可能更差，先对齐推理、再冻结并学习动作才有效。
  • 工作同时给出闭环真机结果和内部表征证据，将 OOD 成功率提升与任务区域注意力、对象身份及任务进度的可解码性联系起来，适合用于设计 π/OpenPI 后训练与监控实验。

与π系列的关系

  • 论文与 π 系列存在直接但有限的实验联系：双臂 YAM 实验明确以 π0.5 为基础策略，并用 RAFT 对其进行目标任务后训练；该任务上 RAFT 达到 70.0%，Plain FT 为 35%。
  • RAFT 改的是后训练顺序与参数更新边界：先训练视觉/语言模块中的推理 LoRA，再冻结 LoRA 微调语言模型、动作专家和投影层；它没有提出新的 π 动作表示、流匹配目标、动作分块机制或执行器架构。
  • 所给原文没有报告 π0、π0-FAST 或 OpenPI 检查点上的独立对照，也没有把 FAST 动作 token 化作为实验变量；因此不能据此断言该收益能等幅迁移到所有 π 系列实现。
  • 对 OpenPI 而言，RAFT 更适合作为可外挂的 post-training recipe：保留原有动作训练目标与执行接口，在动作 SFT 前增加推理标注 LoRA 阶段，并确保动作梯度不再更新该 LoRA。

对Austin研究的启发

  • 在 OpenPI 执行器上复现时，应将“冻结边界”做成显式配置和单元检查：Stage I 只允许推理 LoRA 更新，Stage II 则锁死 LoRA 与 SigLIP，并验证动作梯度仅进入语言模型、动作专家和投影层。
  • 对引导场 \(G\) 或条件遵循研究，可让 Stage I 标注覆盖目标对象、禁止区域、关键点和预期轨迹，再检查固定推理适配器是否提高执行器对 \(G\) 的闭环遵循，而非只提升训练布局中的动作拟合。
  • 评测应同时包含单因素和组合留出，如“新对象×新背景”“新指令×干扰物”，并分阶段记录到达、抓取、开盒和最终放置成功率；YAM 中 Plain FT“能开盒但不能完成放置”的现象说明仅报告整段均值会掩盖失败位置。
  • 可将论文的注意力富集和线性探针变成训练后验收项：若任务区域注意力在 Stage II 后明显回落，或对象身份/任务进度可解码性下降，则提前停止训练或回退检查点，并与真实闭环 OOD 成功率做相关性验证。
  • 推理数据实验应控制标注预算而非只控制记录数，比较目标域少量高质量标注与跨任务大规模混合数据；论文中更广混合数据在各示范预算上仅提高 0.9–3.8 个百分点，说明数据扩展有收益，但不能替代训练调度本身。

一句话总结

Princeton University 与 Microsoft Research 的作者提出 RAFT，以“推理 LoRA 预对齐—冻结 LoRA—动作微调”提升 VLA 后训练鲁棒性，在 DROID 的 OOD 试验中将成功率从 27.9% 提至 75.0%，并在基于 π0.5 的双臂 YAM 长时序任务上将最强基线的 36.0% 提至 70.0%。
